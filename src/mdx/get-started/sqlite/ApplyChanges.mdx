你可以使用 `drizzle-kit push` 命令直接将变更应用到你的数据库。这是在本地开发环境中快速测试新 schema 设计或修改的便捷方法，它可以快速迭代，而无需管理迁移文件：

```bash copy
npx drizzle-kit push
```

在[文档](/docs/sqlite/drizzle-kit-push)中阅读更多关于 push 命令的内容。

<Callout type='info' title='Tips' emoji='💡'>
或者，你可以使用 `drizzle-kit generate` 命令生成迁移，然后使用 `drizzle-kit migrate` 命令应用它们：

生成迁移：
```bash copy
npx drizzle-kit generate
```

应用迁移：
```bash copy
npx drizzle-kit migrate
```

在[文档](/docs/sqlite/kit-overview)中阅读更多关于迁移流程的内容。
</Callout>
