Drizzle Kit 提供了一条 CLI 命令，用于内省你的数据库并生成带有迁移的 schema 文件。该 schema 文件包含有关你的数据库表、列、关系和索引的所有信息。

例如，你的数据库中有这样一张表：

```sql copy
CREATE TABLE `users_table` (
	`id` integer PRIMARY KEY AUTOINCREMENT NOT NULL,
	`name` text NOT NULL,
	`age` integer NOT NULL,
	`email` text NOT NULL UNIQUE
);
```

拉取你的数据库 schema：

```bash copy
npx drizzle-kit pull --init
```

内省的结果将是一个 `schema.ts` 文件、一个包含数据库 schema 快照的 `meta` 文件夹、
一个包含迁移的 sql 文件，以及用于[关系查询](/docs/sqlite/rqb)的 `relations.ts` 文件。

以下是一个生成的 `schema.ts` 文件示例：

```typescript copy filename="drizzle/schema.ts"
// 由内省生成的表 schema
import {
  sqliteTable,
  uniqueIndex,
  integer,
  text,
} from "drizzle-orm/sqlite-core";

export const usersTable = sqliteTable(
  "users_table",
  {
    id: integer().primaryKey({ autoIncrement: true }).notNull(),
    name: text().notNull(),
    age: integer().notNull(),
    email: text().notNull(),
  },
  (table) => [
    uniqueIndex("users_table_email_unique").on(table.email)
  ]
);
```

在[文档](/docs/sqlite/drizzle-kit-pull)中了解有关内省的更多信息。
