在 `src/db` 目录中创建 `index.ts` 文件并初始化连接：

<CodeTabs items={['mysql2', 'mysql2 带配置', '你的 mysql2 驱动']}>
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/mysql2";

const db = drizzle(process.env.DATABASE_URL!);
```
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/mysql2";

// 你可以指定 mysql2 连接选项中的任何属性
const db = drizzle({
  connection: {
    uri: process.env.DATABASE_URL!,
    ssl: { rejectUnauthorized: true },
  },
});
```
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/mysql2";
import mysql from "mysql2/promise";

const poolConnection = mysql.createPool({
  uri: process.env.DATABASE_URL!,
});
const db = drizzle({ client: poolConnection });

// 或者如果你需要客户端连接
async function main() {
  const connection = await mysql.createConnection(process.env.DATABASE_URL!);
  const db = drizzle({ client: connection });
}
main();
```
</CodeTabs>

<Callout type="warning" emoji="⚙️">
  Appwrite Cloud 上的连接使用 TLS 加密。如果你的运行时或 `mysql2` 配置无法从连接字符串推断出 TLS，请在连接选项中传入 `ssl: { rejectUnauthorized: true }`。

  对于带有 DDL 迁移的内置 `migrate` 函数，我们和驱动都强烈建议你使用单个 `client` 连接。
</Callout>

<Callout title='连接端口' type='info'>
Appwrite MySQL 在同一主机名上支持两个连接端口：
- **3306 端口** — 直接连接到 MySQL 引擎。将其用于 Drizzle Kit 迁移和内省。
- **6033 端口** — 通过[连接池](https://appwrite.io/docs/products/databases/mysql/connection-pooling)以事务模式连接。推荐用于 serverless 和边缘环境。详情请参阅 [Appwrite MySQL 连接指南](/docs/mysql/connect-appwrite-mysql#无服务器环境下的连接池)。
</Callout>
