我们建议将 `drizzle/schema.ts` 和 `drizzle/relations.ts` 中生成的代码转移到实际的 schema 文件中。在本指南中，我们将代码转移到了 `src/db/schema.ts`。为 schema 和关系生成的文件可以删除。这样，你可以以更有条理的方式管理你的 schema。
```plaintext {5-6}
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ │ ├ 📜 snapshot.json
 │ │ └ 📜 migration.sql
 │ ├ 📜 relations.ts ────────┐
 │ └ 📜 schema.ts ───────────┤
 ├ 📂 src                    │ 
 │ ├ 📂 db                   │
 │ │ ├ 📜 relations.ts <─────┤
 │ │ └ 📜 schema.ts <────────┘
 │ └ 📜 index.ts         
 └ …
```
