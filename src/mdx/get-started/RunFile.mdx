要运行任何 TypeScript 文件，你有多种选择，但我们只选一种：使用 `tsx`

你已经安装了 `tsx`，所以现在可以运行查询了

**运行 `index.ts` 脚本**
<Npx>
  tsx src/index.ts
</Npx>

<Callout title='提示'>
  我们建议使用 `bun` 来运行 TypeScript 文件。使用 `bun` 时，无论你的项目配置的是 CommonJS (CJS)、ECMAScript Modules (ESM) 还是其他任何模块格式，这类脚本都能顺利执行，无需额外设置。
  要使用 `bun` 运行脚本，请使用以下命令：
  ```bash copy
  bun src/index.ts
  ```

  如果你还没有安装 bun，请查看 [Bun 安装文档](https://bun.sh/docs/installation#installing)
</Callout>
