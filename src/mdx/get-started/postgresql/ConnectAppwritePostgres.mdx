在 `src` 目录中创建 `index.ts` 文件并初始化连接：

<CodeTabs items={["node-postgres", "带配置的 node-postgres", "你现有的 node-postgres 驱动"]}>
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

const db = drizzle(process.env.DATABASE_URL!);
```
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

// 你可以指定 node-postgres 连接选项中的任意属性
const db = drizzle({ 
  connection: { 
    connectionString: process.env.DATABASE_URL!,
    ssl: true
  }
});
```
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL!,
});
const db = drizzle({ client: pool });
```
</CodeTabs>

<Callout title='连接端口' type='info'>
Appwrite Postgres 在同一主机名上支持两个连接端口：
- **Port 5432** — 直接连接到 PostgreSQL 引擎。用于 Drizzle Kit 迁移和内省。
- **Port 6432** — 通过事务模式下的[连接池](https://appwrite.io/docs/products/databases/postgresql/connection-pooling)连接。推荐用于 serverless 和边缘环境。详见 [Appwrite Postgres 连接指南](/docs/connect-appwrite-postgres#面向-serverless-的连接池)。
</Callout>
