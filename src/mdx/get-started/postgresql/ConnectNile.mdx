在 `src` 目录中创建 `index.ts` 文件并初始化连接：

<CodeTabs items={["node-postgres", "带配置的 node-postgres", "你现有的 node-postgres 驱动"]}>
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

const db = drizzle(process.env.NILEDB_URL!);
```
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

// 你可以指定 node-postgres 连接选项中的任意属性
const db = drizzle({ 
  connection: { 
    connectionString: process.env.NILEDB_URL!,
    ssl: true
  }
});
```
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.NILEDB_URL!,
});
const db = drizzle({ client: pool });
```
</CodeTabs>

<Callout title='多租户'>
Nile 提供**虚拟租户数据库**。查询 Nile 时，你可以设置租户上下文，Nile 会将你的查询定向到该特定租户的虚拟数据库。所有带租户上下文发送的查询只作用于该租户（即 `select * from table` 只会返回该租户的记录）。想了解如何在 Drizzle 中设置租户上下文，请查看 **[Nile-Drizzle 官方示例](https://www.thenile.dev/docs/getting-started/languages/drizzle#72-tenantdb)**。
</Callout>
