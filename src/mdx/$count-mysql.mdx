`db.$count()` 是 `count(*)` 的工具封装，它是一个非常灵活的运算符，既可以按原样使用，也可以作为子查询使用，更多细节请参阅我们的 [GitHub 讨论](https://github.com/drizzle-team/drizzle-orm/discussions/3119)。

<Section>
```ts
const count = await db.$count(users);
//    ^? number

const count = await db.$count(users, eq(users.name, "Dan")); // 可与过滤器一起使用
```
```sql
select count(*) from `users`;
select count(*) from `users` where `users`.`name` = 'Dan';
```
</Section>

它在[子查询](/docs/mysql/select#从子查询中-select)中特别有用：

```ts
const users = await db.select({
  ...users,
  postsCount: db.$count(posts, eq(posts.authorId, users.id)),
}).from(users);
```

与[关系查询](/docs/mysql/rqb)搭配的使用示例
```ts 
const users = await db.query.users.findMany({
  extras: {
    postsCount: (t) => db.$count(posts, eq(posts.authorId, t.id)),
  },
});
```
