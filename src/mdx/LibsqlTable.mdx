|                          |                                                                                                                                           |
| :----------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| `@libsql/client`         | 默认为 `node` 导入；如果为打包工具设置了 `target` 或 `platform`，则自动改为 `web`，例如 `esbuild --platform=browser` |
| `@libsql/client/node`    | `node` 兼容模块，支持 `:memory:`、`file`、`wss`、`http` 和 `turso` 连接协议                                     |
| `@libsql/client/web`     | 适用于 `next`、`nuxt`、`astro` 等全栈 Web 框架的模块                                                                    |
| `@libsql/client/http`    | 适用于 `http` 和 `https` 连接协议的模块                                                                                        |
| `@libsql/client/ws`      | 适用于 `ws` 和 `wss` 连接协议的模块                                                                                            |
| `@libsql/client/sqlite3` | 适用于 `:memory:` 和 `file` 连接协议的模块                                                                                     |
| `@libsql/client-wasm`    | 独立的 WASM 实验性包                                                                                                    |
