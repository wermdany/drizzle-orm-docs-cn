# Drizzle Serverless 性能

使用 `serverless functions`（如 AWS Lambda 或 Vercel Server Functions（它们基于 AWS Lambda））可以获得巨大的收益，
因为它们最长可存活 15 分钟，并可以复用数据库连接和预编译语句。

另一方面，`edge functions` 往往在被调用后立即清理，因此几乎没有性能收益。
  
要复用你的数据库连接和预编译语句，你只需在 handler 作用域之外声明它们：
```ts
const databaseConnection = ...;
const db = drizzle({ client: databaseConnection });
const prepared = db.select().from(...).prepare();

// AWS 处理器
export const handler = async (event: APIGatewayProxyEvent) => {
  return prepared.execute();
}
```
