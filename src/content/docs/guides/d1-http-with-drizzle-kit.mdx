---
title: 使用 Drizzle Kit 的 Cloudflare D1 HTTP API
---

import Prerequisites from "@mdx/Prerequisites.astro";

<Prerequisites>
- [Drizzle Kit](/docs/kit-overview)
- [Drizzle Studio](/docs/kit-overview#drizzle-studio)
- [Drizzle Chrome 扩展](https://chromewebstore.google.com/detail/drizzle-studio/mjkojjodijpaneehkgmeckeljgkimnmd)
- 你应当已安装 `drizzle-kit@0.21.3` 或更高版本
- 你应当已有 [Cloudflare 账户](https://dash.cloudflare.com/login)、已部署 [D1 数据库](https://developers.cloudflare.com/d1/)，以及具有 D1 编辑权限的 token
</Prerequisites>

要将 Drizzle Kit 与 Cloudflare D1 HTTP API 一起使用，你需要像这样配置 `drizzle.config.ts` 文件：

```ts copy filename="drizzle.config.ts" {7, 9-11}
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  schema: './src/schema.ts',
  out: './migrations',
  dialect: 'sqlite',
  driver: 'd1-http',
  dbCredentials: {
    accountId: process.env.CLOUDFLARE_ACCOUNT_ID!,
    databaseId: process.env.CLOUDFLARE_DATABASE_ID!,
    token: process.env.CLOUDFLARE_D1_TOKEN!,
  },
});
```

你可以在 [Cloudflare 仪表盘](https://dash.cloudflare.com/login?) 中找到 `accountId`、`databaseId` 和 `token`。

1. 要获取 `accountId`，请进入 **Workers & Pages** -> **Overview** -> 从右侧边栏复制 **Account ID**。
2. 要获取 `databaseId`，请打开你要连接的 D1 数据库并复制 **Database ID**。
3. 要获取 `token`，请进入 **My profile** -> **API Tokens** 并创建具有 D1 编辑权限的 token。

配置好 `drizzle.config.ts` 文件后，Drizzle Kit 让你可以使用 Cloudflare D1 HTTP API 运行 `migrate`、`push`、`introspect` 和 `studio` 命令。

你也可以使用 [Drizzle Chrome 扩展](https://chromewebstore.google.com/detail/drizzle-studio/mjkojjodijpaneehkgmeckeljgkimnmd) 直接在其管理面板中浏览 Cloudflare D1 数据库。
