### PostgreSQL、MySQL、SQLite 和 Cockroach

要使用 Drizzle 实现 PostgreSQL、MySQL、SQLite 和 Cockroach 的 SQL Limit/Offset 分页（可跳到 [MSSQL](/docs/guides/limit-offset-pagination#mssql)），你可以使用以下示例：

Limit 是要返回的行数 `(page size)`，offset 是要跳过的行数 `((page number - 1) * page size)`。
为获得一致的分页，请确保按唯一列排序。否则，结果可能不一致。

如果你需要按非唯一列排序，还应将唯一列追加到排序中。

以下是如何使用 2 列实现 `limit/offset` 分页：

<Section>
```ts copy {5}
const getUsers = async (page = 1, pageSize = 3) => {
  await db
    .select()
    .from(users)
    .orderBy(asc(users.firstName), asc(users.id)) // 按 first_name（非唯一）、id（主键）排序
    .limit(pageSize) 
    .offset((page - 1) * pageSize);
}

await getUsers();
```
</Section>

Drizzle 拥有实用的关系查询 API，可以让你轻松实现 `limit/offset` 分页：

<Section>
```ts copy {7,8,9}
import * as schema from './db/schema';

const db = drizzle({ schema });

const getUsers = async (page = 1, pageSize = 3) => {
  await db.query.users.findMany({
    orderBy: (users, { asc }) => asc(users.id),
    limit: pageSize,
    offset: (page - 1) * pageSize,
  });
};

await getUsers();
```
</Section>

Drizzle 拥有简单灵活的 API，可以让你轻松创建自定义方案。以下是如何使用 `.$dynamic()` 函数创建自定义分页函数：

<Section>
```ts copy {11,12,13,16}
import { SQL, asc } from 'drizzle-orm';
import { PgColumn, PgSelect } from 'drizzle-orm/pg-core';

function withPagination<T extends PgSelect>(
  qb: T,
  orderByColumn: PgColumn | SQL | SQL.Aliased,
  page = 1,
  pageSize = 3,
) {
  return qb
    .orderBy(orderByColumn)
    .limit(pageSize)
    .offset((page - 1) * pageSize);
}

const query = db.select().from(users); // 你希望带分页执行的查询

await withPagination(query.$dynamic(), asc(users.id));
```

</Section>

你可以通过使用 `deferred join`（延迟连接）技术来提升 `limit/offset` 分页的性能。该方法在数据子集而非整张表上执行分页。

要实现它，你可以这样做：

```ts copy {10}
const getUsers = async (page = 1, pageSize = 10) => {
   const sq = db
    .select({ id: users.id })
    .from(users)
    .orderBy(users.id)
    .limit(pageSize)
    .offset((page - 1) * pageSize)
    .as('subquery');

   await db.select().from(users).innerJoin(sq, eq(users.id, sq.id)).orderBy(users.id);
};
```

`limit/offset` 分页的**优点**：实现简单，页面易于访问，这意味着你无需保存之前页面的状态就可以导航到任意页面。

`limit/offset` 分页的**缺点**：随着 offset 增大，查询性能会下降，因为数据库必须先扫描 offset 之前的所有行才能跳过它们；此外，由于数据变动会导致不一致，可能出现同一行在不同页面重复返回或某些行被跳过的情况。

它的工作方式如下：

<Section>
```ts copy
const getUsers = async (page = 1, pageSize = 3) => {
  await db
    .select()
    .from(users)
    .orderBy(asc(users.id))
    .limit(pageSize)
    .offset((page - 1) * pageSize);
};

// 用户正在浏览第一页
await getUsers();
```


```ts

```

因此，如果你的数据库实时频繁执行插入和删除操作，或者你需要对大型表进行高性能分页，则应考虑改用[基于游标](/docs/guides/cursor-based-pagination)的分页。

要了解有关 `deferred join` 技术的更多信息，你可以参考以下指南：[Planetscale 分页指南](https://planetscale.com/blog/mysql-pagination) 和 [Aaron Francis 的高效分页指南](https://aaronfrancis.com/2022/efficient-pagination-using-deferred-joins)。

### MSSQL

要使用 Drizzle 实现 MSSQL Limit/Offset 分页，你可以使用以下示例：

<CodeTabs items={["index.ts", "schema.ts"]}>
  <CodeTab>
    ```ts copy {9,10,11}
    import { asc } from 'drizzle-orm';
    import { users } from './schema';

    const db = drizzle(...);

    await db
	  .select()
	  .from(users)
	  .orderBy(asc(users.id)) // order by 是必需的
	  .offset(4) // 跳过的行数
	  .fetch(4) // 要获取的行数
    ```

    ```sql
    select * from [users] order by [id] asc offset 5 rows fetch next 10 rows only;
    ```
