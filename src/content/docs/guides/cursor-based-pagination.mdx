本指南演示了如何在 Drizzle 中实现 `cursor-based`（基于游标的）分页：

<CodeTabs items={["index.ts", "schema.ts"]}>
  <CodeTab>
  ```ts copy {10,11,12}
  import { asc, gt } from 'drizzle-orm';
  import { users } from './schema';

  const db = drizzle(...);

  const nextUserPage = async (cursor?: number, pageSize = 3) => {
    await db
      .select()
      .from(users)
      .where(cursor ? gt(users.id, cursor) : undefined) // 如果提供了 cursor，则获取其之后的行
      .limit(pageSize) // 要返回的行数
      .orderBy(asc(users.id)); // 排序
  };

  // 传入上一页最后一行的 cursor（id）
  await nextUserPage(3);
  ```

如果你需要动态排序，可以像下面这样做：

```ts copy {6,8}
const nextUserPage = async (order: 'asc' | 'desc' = 'asc', cursor?: number, pageSize = 3) => {
  await db
    .select()
    .from(users)
    // 游标比较
    .where(cursor ? (order === 'asc' ? gt(users.id, cursor) : lt(users.id, cursor)) : undefined)
    .limit(pageSize)
    .orderBy(order === 'asc' ? asc(users.id) : desc(users.id));
};

await nextUserPage();
await nextUserPage('asc', 3);
// 降序
await nextUserPage('desc');
await nextUserPage('desc', 7);
```

这种分页的核心思想是使用游标作为指向数据集中特定行的指针，表示上一页的结束位置。为了实现正确的排序和游标比较，游标应当是唯一且连续的。

如果你需要按非唯一且不连续的列排序，可以为游标使用多个列。下面是你如何做到这一点：

<Section>
```ts copy {14,15,16,17,18,19,22}
import { and, asc, eq, gt, or } from 'drizzle-orm';

const nextUserPage = async (
  cursor?: {
    id: number;
    firstName: string;
  },
  pageSize = 3,
) => {
  await db
    .select()
    .from(users)
    .where(
      cursor
        ? or(
            gt(users.firstName, cursor.firstName),
            and(eq(users.firstName, cursor.firstName), gt(users.id, cursor.id)),
          )
        : undefined,
    )
    .limit(pageSize)
    .orderBy(asc(users.firstName), asc(users.id));
};

// 传入上一页的 cursor（id 和 firstName）
await nextUserPage({
  id: 2,
  firstName: 'Alex',
});
```

```sql
select * from users
  where (first_name > 'Alex' or (first_name = 'Alex' and id > 2))
  order by first_name asc, id asc limit 3;
```

请确保为用作游标的列创建索引，以保证查询高效。

<Section>
```ts copy {7,8}
import { index, ...imports } from 'drizzle-orm/pg-core';

export const users = pgTable('users', {
  // 列声明
},
(t) => [
  index('first_name_index').on(t.firstName).asc(),
  index('first_name_and_id_index').on(t.firstName, t.id).asc(),
]);
```

```sql
-- 到目前为止 drizzle-kit 只支持索引名称和 on() 参数，因此你必须手动添加排序
CREATE INDEX IF NOT EXISTS "first_name_index" ON "users" ("first_name" ASC);
CREATE INDEX IF NOT EXISTS "first_name_and_id_index" ON "users" ("first_name" ASC,"id" ASC);
```

如果你使用的是非连续的主键（例如 `UUIDv4`），应该添加一个连续列（例如 `created_at` 列）并使用多列游标。
下面是你如何做到这一点：

<Section>
```ts copy {12,13,14,15,16,17,18,21}

const nextUserPage = async (
  cursor?: {
    id: string;
    createdAt: Date;
  },
  pageSize = 3,
) => {
  await db
    .select()
    .from(users)
    .where(
      // 请确保为用作游标的列添加索引
      cursor
        ? or(
            gt(users.createdAt, cursor.createdAt),
            and(eq(users.createdAt, cursor.createdAt), gt(users.id, cursor.id)),
          )
        : undefined,
    )
    .limit(pageSize)
    .orderBy(asc(users.createdAt), asc(users.id));
};

// 传入上一页的 cursor（id 和 createdAt）
await nextUserPage({
  id: '66ed00a4-c020-4dfd-a1ca-5d2e4e54d174',
  createdAt: new Date('2024-03-09T17:59:36.406Z'),
});
```
</Section>

Drizzle 拥有实用的关系查询 API，让你可以轻松实现 `cursor-based` 分页：

```ts copy {7,8,9}
import * as schema from './db/schema';

const db = drizzle(..., { schema });

const nextUserPage = async (cursor?: number, pageSize = 3) => {
  await db.query.users.findMany({
    where: (users, { gt }) => (cursor ? gt(users.id, cursor) : undefined),
    orderBy: (users, { asc }) => asc(users.id),
    limit: pageSize,
  });
};

// 下一页，传入第一页最后一行的 cursor（id = 3）
await nextUserPage(3);
```

`cursor-based` 分页的**优点**：查询结果一致，不会因插入或删除操作导致行被跳过或重复；并且比 `limit/offset` 分页更高效，因为它无需扫描和跳过前面的行即可访问下一页。

`cursor-based` 分页的**缺点**：无法直接跳转到特定页，且实现较为复杂。由于你向排序顺序中添加了更多列，就需要向 `where` 子句添加更多过滤条件来进行游标比较，以确保分页的一致性。

因此，如果你需要直接跳转到特定页，或者需要更简单的分页实现，则可以考虑使用 [offset/limit](/docs/guides/limit-offset-pagination) 分页。
