PostgreSQL 有一种用于存储几何数据的特殊数据类型，称为 `point`。它用于表示二维空间中的一个点。point 数据类型表示为一对 `(x, y)` 坐标。
point 期望先接收经度，然后是纬度。

<Section>
```ts copy {6}
import { sql } from 'drizzle-orm';

const db = drizzle(...);

await db.execute(
  sql`select point(-90.9, 18.7)`,
);
```

```json
[ 
  { 
    point: '(-90.9,18.7)' 
  }
]
```
</Section>

以下是如何在 Drizzle 中创建带有 `point` 数据类型的表：

```ts {6}
import { pgTable, point, serial, text } from 'drizzle-orm/pg-core';

export const stores = pgTable('stores', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  location: point('location', { mode: 'xy' }).notNull(),
});
```

以下是如何在 Drizzle 中向表中插入 point 数据：

```ts {4, 10, 16}
// mode: 'xy'
await db.insert(stores).values({
  name: 'Test',
  location: { x: -90.9, y: 18.7 },
});

// mode: 'tuple'
await db.insert(stores).values({
  name: 'Test',
  location: [-90.9, 18.7],
});

// 原生 sql
await db.insert(stores).values({
  name: 'Test',
  location: sql`point(-90.9, 18.7)`,
});
```

要计算对象之间的距离，你可以使用 `<->` 操作符。以下是如何在 Drizzle 中按坐标查询最近的位置：

<Callout type='warning'>
`getColumns` 从 `drizzle-orm@1.0.0-beta.2` 起可用（在[此处](/docs/upgrade-v1)阅读更多内容）

如果你使用的是 1.0 之前的版本（如 `0.45.1`），请使用 `getTableColumns`
</Callout>

<Section>
```ts {9, 14, 17}
import { getColumns, sql } from 'drizzle-orm';
import { stores } from './schema';

const point = {
  x: -73.935_242,
  y: 40.730_61,
};

const sqlDistance = sql`location <-> point(${point.x}, ${point.y})`;

await db
  .select({
    ...getColumns(stores),
    distance: sql`round((${sqlDistance})::numeric, 2)`,
  })
  .from(stores)
  .orderBy(sqlDistance)
  .limit(1);
```

```sql
select *, round((location <-> point(-73.935242, 40.73061))::numeric, 2)
from stores order by location <-> point(-73.935242, 40.73061)
limit 1;
```
</Section>

要过滤行，仅包含 `point` 类型 `location` 落在由两个对角点定义的指定矩形边界内的那些行，你可以使用 `<@` 操作符。它会检查第一个对象是否被包含在第二个对象内或其上：

<Section>
```ts {12}
const point = {
  x1: -88,
  x2: -73,
  y1: 40,
  y2: 43,
};

await db
  .select()
  .from(stores)
  .where(
    sql`${stores.location} <@ box(point(${point.x1}, ${point.y1}), point(${point.x2}, ${point.y2}))`
  );
```

```sql
select * from stores where location <@ box(point(-88, 40), point(-73, 43));
```
</Section>
