# JIT 映射器

JIT mapper **默认禁用**。通过 `jit` 选项启用它们：

```ts
import { drizzle } from 'drizzle-orm/...';

const db = drizzle({ client, jit: true });
```

初始化时，Drizzle 会运行一次兼容性检查，测试 `Function` 构造函数在当前运行时中是否可用。如果不可用（例如某些边缘运行时或受 CSP 限制的环境），它会回退到常规 mapper，并给出一个控制台警告。

`jit` 选项在每个驱动的配置中都可用

## 什么是 JIT 映射器？

JIT（Just-In-Time，即时）mapper 是动态生成的 JavaScript 函数，用于将数据库行转换为 JS 对象。JIT mapper 不会在运行时为每一行解释列元数据，而是**一次性编译一个专用函数**，并在结果集的所有行中复用它。

## 为什么需要它们？

常规的 Drizzle ORM mapper 会为每一行循环遍历列元数据：

```
对于每一行：
  对于每一列：
    → 查找 decoder
    → 检查 codec 是否存在
    → 检查值是否为 null
    → 如有需要则应用 codec
    → 如有需要则应用 decoder
    → 导航嵌套路径
    → 赋值到结果对象
```

当成千上万行时，这种解释执行的开销会不断累积。JIT mapper 通过在生成时将所有的元数据查找、null 检查和嵌套对象构造都硬编码到函数体中，从而消除了这种开销
