# SQL Update

<Callout type='info'>
传递给 `.set()` 的所有值都会自动参数化。
例如，这个查询：
```ts
await db.update(users).set({ name: "Mr. Dan" }).where(eq(users.name, "Dan"));
```
会被转换为：
```sql
update "users" set "name" = $1 where "users"."name" = $2; -- 参数：['Mr. Dan', 'Dan']
```
</Callout>

<br/>

传递给 `update` 的对象的键应与数据库 schema 中的列名匹配。
对象中 `undefined` 的值会被忽略：要将列设置为 `null`，请传 `null`。

```typescript copy
await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'));
```
```typescript copy
await db.update(users)
  .set({ name: null })
  .where(eq(users.name, 'Dan'));
```

你可以将 SQL 作为值传入以用于 update 对象，如下所示：

```typescript copy
await db.update(users)
  .set({ updatedAt: sql`NOW()` })
  .where(eq(users.name, 'Dan'));
```

### Returning

在 CockroachDB 中，你可以更新一行并获取其返回结果：
```typescript copy
const updatedUserId = await db.update(users).set({ name: "Mr. Dan" }).where(eq(users.name, "Dan")).returning({ updatedId: users.id });
//      ^ { updatedId: number | null }[]
```
```sql
update "users" set "name" = 'Mr. Dan' where "users"."name" = 'Dan' returning "id";
```

## `with update` 子句

<Callout>
  查看如何将 WITH 语句与 [select](/docs/cockroach/select#with-子句)、[insert](/docs/cockroach/insert#with-insert-子句)、[delete](/docs/cockroach/delete#with-delete-子句) 一起使用
</Callout>

使用 `with` 子句可以将复杂查询拆分为更小的子查询（称为公共表表达式 CTE），从而帮助简化查询：
<Section>
```typescript copy
const averagePrice = db.$with('average_price').as(
	db.select({ value: sql`avg(${products.price})`.as('value') }).from(products)
);

const result = await db.with(averagePrice)
	.update(products)
	.set({
		cheap: true
	})
	.where(lt(products.price, sql`(select * from ${averagePrice})`))
	.returning({
		id: products.id
	});
```
```sql
with "average_price" as (select avg("price") as "value" from "products") 
update "products" set "cheap" = true 
where "products"."price" < (select * from "average_price") 
returning "id"
```
</Section>

## Update ... from

正如 CockroachDB 文档所述：

> 一个表表达式，允许其他表的列出现在 WHERE 条件和更新表达式中

<Section>
```ts
await db
  .update(users)
  .set({ cityId: cities.id })
  .from(cities)
  .where(and(eq(cities.name, 'Seattle'), eq(users.name, 'John')))
```
```sql
update "users" set "city_id" = "cities"."id" 
from "cities" 
where (("cities"."name" = 'Seattle') and ("users"."name" = 'John'))
```
</Section>

你还可以为连接的表设置别名（也可以为被更新的表设置别名）。
<Section>
```ts
const c = alias(cities, 'c');
await db
  .update(users)
  .set({ cityId: c.id })
  .from(c);
```
```sql
update "users" set "city_id" = "c"."id" 
from "cities" "c"
```
</Section>

在 Postgres 中，你还可以从连接的表返回列。
<Section>
```ts
const updatedUsers = await db
  .update(users)
  .set({ cityId: cities.id })
  .from(cities)
  .returning({ id: users.id, cityName: cities.name });
```
```sql
update "users" set "city_id" = "cities"."id" 
from "cities" 
returning "users"."id", "cities"."name"
```
</Section>
