# Drizzle \<\> CockroachDB

<br/>

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/cockroach/connect-overview)
- node-postgres [基础](https://node-postgres.com/)
</Prerequisites>

Drizzle 通过 `node-postgres` 驱动原生支持 CockroachDB 连接。

#### 第 1 步 - 安装包
<Npm>
drizzle-orm@rc pg
-D drizzle-kit@rc @types/pg
</Npm>

#### 第 2 步 - 初始化驱动并执行查询
<CodeTabs items={["node-postgres", "带配置的 node-postgres"]}>
```typescript copy
// 请确保安装 'pg' 包 
import { drizzle } from 'drizzle-orm/cockroach';

const db = drizzle(process.env.DATABASE_URL);
 
const result = await db.execute('select 1');
```
```typescript copy
// 请确保安装 'pg' 包 
import { drizzle } from 'drizzle-orm/cockroach';

// 你可以指定 node-postgres 连接选项中的任意属性
const db = drizzle({ 
  connection: { 
    connectionString: process.env.DATABASE_URL,
    ssl: true
  }
});
 
const result = await db.execute('select 1');
```
</CodeTabs>

如果你需要提供你现有的驱动：

```typescript copy
// 请确保安装 'pg' 包 
import { drizzle } from "drizzle-orm/cockroach";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});
const db = drizzle({ client: pool });
 
const result = await db.execute('select 1');
```
