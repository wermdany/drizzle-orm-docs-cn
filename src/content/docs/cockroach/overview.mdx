# Drizzle ORM

Drizzle ORM 是一个有头的无头 TypeScript ORM。🐲
> Drizzle 是一位好朋友，需要时它就在你身边，你需要空间时它不会打扰你。

它看起来和用起来都很简单，在你的项目进入 _第 1000 天_ 时依然性能出色，\
让你按自己的方式做事，并在你需要时随时待命。

**它是唯一同时提供[关系式](/docs/cockroach/rqb)和[类 SQL](/docs/cockroach/select)查询 API 的 ORM**， 
在访问关系型数据时为你提供两全其美的体验。 
Drizzle 轻量、高性能、类型安全、不含乳糖、无麸质、清醒、灵活，并且**在设计上就支持无服务器**。
Drizzle 不只是一个库，它是一种体验。🤩

[![Drizzle bestofjs](@/assets/images/bestofjs.jpg)](https://bestofjs.org/projects/drizzle-orm)

## Headless ORM? 
首先，Drizzle 是一个库，也是一系列互补的可选工具。 

**ORM** 代表 _对象关系映射_，开发者倾向于把类似 Django 或类似 Spring 的工具称为 ORM。 
我们真心认为这是基于历史遗留命名的一种误解，我们称它们为**数据框架**。

<Callout type="error" emoji="️💔">
  使用数据框架时，你必须**围绕它们**构建项目，而不是**用它们**构建项目。
</Callout>

**Drizzle** 让你按自己希望的方式构建项目，不干扰你的项目或结构。 

使用 Drizzle，你可以在 TypeScript 中定义和管理数据库 schema，以类 SQL 
或关系式的方式访问数据，并利用可选工具
将你的开发体验推向_巅峰_。🤯 

## 为什么 SQL-like?
**如果你懂 SQL，你就懂 Drizzle。**

其它 ORM 和数据框架倾向于让你偏离/抽象远离 SQL，这
会导致双重学习曲线：既需要懂 SQL，又需要懂框架的 API。  

Drizzle 则相反。 
我们拥抱 SQL，并将 Drizzle 构建为在核心上就是类 SQL 的，因此你可以拥有零学习曲线
或几乎没有学习曲线，并充分享受 SQL 的强大能力。  

我们带来了所有你熟悉的 **[SQL schema](/docs/cockroach/sql-schema-declaration)**、**[查询](/docs/cockroach/select)**、 
**[自动迁移](/docs/cockroach/migrations)** 以及 **[还有一件事](/docs/cockroach/rqb)**。✨

<CodeTabs items={["index.ts", "schema.ts", "migration.sql"]}>
```typescript copy
// 访问你的数据
await db
	.select()
	.from(countries)
	.leftJoin(cities, eq(cities.countryId, countries.id))
	.where(eq(countries.id, 10))
```
```typescript copy
// 管理你的 schema
export const countries = cockroachTable('countries', {
  id: int4().primaryKey(),
  name: varchar({ length: 256 }),
});

export const cities = cockroachTable('cities', {
  id: int4().primaryKey(),
  name: varchar({ length: 256 }),
  countryId: int4('country_id').references(() => countries.id),
});
```
```sql
-- 生成迁移
CREATE TABLE "countries" (
	"id" int4 PRIMARY KEY,
	"name" varchar(256)
);

CREATE TABLE "cities" (
	"id" int4 PRIMARY KEY,
	"name" varchar(256),
	"country_id" int4
);

ALTER TABLE "cities" ADD CONSTRAINT "cities_country_id_countries_id_fkey" FOREIGN KEY ("country_id") REFERENCES "countries"("id");
```
</CodeTabs>

## 为什么不用 SQL-like?
我们始终追求一个完美平衡的解决方案，虽然类 SQL 已经覆盖了 100% 的需求， 
但在某些常见场景中，你可以用更好的方式查询数据。  

我们为你构建了 **[查询 API](/docs/cockroach/rqb)**，让你能够以最便捷、最高性能的方式
从数据库中获取关系型嵌套数据，而不必再考虑连接和数据映射。  

**Drizzle 始终只输出 1 条 SQL 查询。** 你可以放心地将它用于无服务器数据库，不必担心性能或往返开销！

```ts
const result = await db._query.users.findMany({
	with: {
		posts: true
	},
});
```

## Serverless?
<Callout type="info" emoji="🥳">
  最好的部分就是没有部分。**Drizzle 有恰好 0 个依赖！**
</Callout>


![Drizzle 精简且支持无服务器](@/assets/images/drizzle31kb.jpg)
  
Drizzle ORM 是方言特定的、精简、高性能，并且**在设计上就**支持无服务器。  

我们花了大量时间确保你拥有同类最佳的 SQL 方言支持，包括 Postgres、MySQL 以及其它。

Drizzle 通过业界标准的数据库驱动原生运行。我们支持所有主流的 **[PostgreSQL](/docs/get-started-postgresql)**、**[MySQL](/docs/mysql/get-started-mysql)**、**[SQLite](/docs/sqlite/get-started-sqlite)**、**[SingleStore](/docs/singlestore/get-started-singlestore)**、**[MSSQL](/docs/mssql/get-started-mssql)** 或 **[CockroachDB](/docs/cockroach/get-started-cockroach)** 驱动，并且我们正在**[非常快速地](https://twitter.com/DrizzleORM/status/1653082492742647811?s=20)**添加新的驱动。
