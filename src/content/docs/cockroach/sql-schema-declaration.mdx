# Drizzle schema

Drizzle 让你可以用 TypeScript 定义 schema，并使用底层数据库支持的各种模型和属性。
当你定义 schema 时，它会成为后续查询修改（使用 Drizzle-ORM）
和迁移（使用 Drizzle-Kit）的事实来源。

<Callout> 
如果你使用 Drizzle-Kit 进行迁移流程，请确保导出 schema 文件中定义的所有模型，以便 Drizzle-Kit 可以导入它们并在迁移差异对比流程中使用。 
</Callout>

<CodeTabs items={["使用导入", "使用回调", "使用 import *"]}>
```ts
import { int4, cockroachTable, varchar } from "drizzle-orm/cockroach-core";

export const usersTable = cockroachTable("users", {
  id: int4().primaryKey().generatedAlwaysAsIdentity(),
  name: varchar().notNull(),
  age: int4().notNull(),
  email: varchar().notNull().unique(),
});
```
```ts
import { cockroachTable } from "drizzle-orm/cockroach-core";

export const usersTable = cockroachTable("users", (t) => ({
  id: t.int4().primaryKey().generatedAlwaysAsIdentity(),
  name: t.varchar().notNull(),
  age: t.int4().notNull(),
  email: t.varchar().notNull().unique(),
}));
```
```ts
import * as p from "drizzle-orm/cockroach-core";

export const usersTable = p.cockroachTable("users", {
  id: p.int4().primaryKey().generatedAlwaysAsIdentity(),
  name: p.varchar().notNull(),
  age: p.int4().notNull(),
  email: p.varchar().notNull().unique(),
});
```
</CodeTabs>

## 组织你的 schema 文件 
你可以在 TypeScript 中直接声明 SQL schema，既可以放在单个 `schema.ts` 文件中，
也可以分散到多个地方 —— 随你喜欢，完全自由！

#### 单文件中的 Schema
用 Drizzle 声明 schema 最常见的方式是把所有表都放进一个 `schema.ts` 文件。

> 注意：你可以随意命名你的 schema 文件。例如，它可以是 `models.ts` 或其它名字。

如果你定义的表模型不太多，或者你不介意把它们都放在一个文件里，这种方案就很合适

示例：
```plaintext
📦 <project root>
 └ 📂 src
    └ 📂 db
       └ 📜 schema.ts
```

在 `drizzle.config.ts` 文件中，你需要指定 schema 文件的路径。使用这个配置，Drizzle 会
从 `schema.ts` 文件读取，并在迁移生成流程中使用这些信息。关于 `drizzle.config.ts` 文件
以及使用 Drizzle 进行迁移的更多信息，请查看：[链接](/docs/cockroach/drizzle-config-file)
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: 'cockroach',
  schema: './src/db/schema.ts'
})
```

#### 多文件中的 Schema

你可以把你的 Drizzle 模型 —— 例如表、枚举、序列等 —— 不只放在一个文件中，而是放在你喜欢的任何文件里。
你唯一需要确保的是，从这些文件中导出所有模型，以便 Drizzle kit 可以导入
它们并在迁移中使用。

一个用例是把每张表拆分到各自的文件中。
```plaintext
📦 <project root>
 └ 📂 src
    └ 📂 db
       └ 📂 schema
          ├ 📜 users.ts
          ├ 📜 countries.ts
          ├ 📜 cities.ts
          ├ 📜 products.ts
          ├ 📜 clients.ts
          └ 📜 etc.ts
```

在 `drizzle.config.ts` 文件中，你需要指定 schema 文件夹的路径。使用这个配置，Drizzle 会
从 `schema` 文件夹读取，递归地查找所有文件，并从中获取所有 drizzle 表。关于 `drizzle.config.ts` 文件
以及使用 Drizzle 进行迁移的更多信息，请查看：[链接](/docs/cockroach/drizzle-config-file)

```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: 'cockroach',
  schema: './src/db/schema'
})
```

你也可以按任何你喜欢的方式对它们进行分组，例如为用户相关的表、消息相关的表、商品相关的表等创建分组。
```plaintext
📦 <project root>
 └ 📂 src
    └ 📂 db
       └ 📂 schema
          ├ 📜 users.ts
          ├ 📜 messaging.ts
          └ 📜 products.ts
```

## 塑造你的数据 schema

Drizzle schema 由你所使用数据库的若干模型类型组成。使用 drizzle 你可以指定：
- 带有列、约束等的表
- Schema
- 枚举
- 序列
- 视图
- 物化视图
- 等等

让我们逐一查看应该如何用 drizzle 定义 schema

#### **表和列的声明** 

在 Drizzle 中定义一张表至少需要 1 个列，这与在数据库中所做的相同。有一件重要的事需要了解，
drizzle 中并不存在通用的 table 对象。你需要选择你所使用的方言：Cockroach、MySQL、SQLite 等。

![](@/assets/images/table-structure.svg)

```ts copy
import { cockroachTable, int4 } from "drizzle-orm/cockroach-core"

export const users = cockroachTable('users', {
  id: int4()
});
```

默认情况下，Drizzle 会在数据库查询中使用 TypeScript 的键名作为列名。
因此，示例中的 schema 和查询将生成如下所示的 SQL 查询

<Callout>
这个示例使用了一个 db 对象，其初始化不在本文档的这一部分中介绍。要了解如何连接数据库，请参考[连接文档](/docs/cockroach/get-started-cockroach)
</Callout>

\
**TypeScript 键 = 数据库键**
<Section>
```ts
// schema.ts
import { int4, cockroachTable, varchar } from "drizzle-orm/cockroach-core";

export const users = cockroachTable('users', {
  id: int4(),
  first_name: varchar()
})
```
```ts
// query.ts
await db.select().from(users);
```
```sql
SELECT "id", "first_name" from users;
```
</Section>

如果你想在 TypeScript 代码和数据库中使用不同的名称，你可以使用列别名

<Section>
```ts
// schema.ts
import { int4, cockroachTable, varchar } from "drizzle-orm/cockroach-core";

export const users = cockroachTable('users', {
  id: int4(),
  firstName: varchar('first_name')
})
```
```ts
// query.ts
await db.select().from(users);
```
```sql
SELECT "id", "first_name" from users;
```
</Section>

### 驼峰与蛇形命名

数据库模型名称通常使用 `snake_case` 约定，而在 TypeScript 中，模型命名常用 `camelCase`。
这可能导致 schema 中出现大量别名定义。为解决这个问题，Drizzle 提供了一种方式，可以通过
专用的构建器自动把 TypeScript 中的 `camelCase` 映射为数据库中的 `snake_case`。

使用 `drizzle-orm/cockroach-core` 中的 `snakeCase` 或 `camelCase` 构建器来声明一张表，其列键会
自动映射到所选的数据库命名约定

<Section>
```ts {2,4,11,12}
// schema.ts
import { snakeCase, camelCase } from 'drizzle-orm/cockroach-core';

export const users = snakeCase.table('users', {
  id: int4().primaryKey(),
  fullName: text(),        // → 数据库中为 full_name
  createdAt: timestamp(),  // → 数据库中为 created_at
});

// 在所有实体类型上都可用：
snakeCase.table / snakeCase.view / snakeCase.materializedView / snakeCase.schema
camelCase.table / camelCase.view / camelCase.materializedView / camelCase.schema
```
```ts
// db.ts
import { drizzle } from "drizzle-orm/cockroach";

const db = drizzle({ connection: process.env.DATABASE_URL })
```
```ts
// query.ts
await db.select().from(users);
```
```sql
select "id", "full_name", "created_at" from "users"
```
</Section>

### 进阶

使用 Drizzle ORM 时有几个技巧可以用。只要 Drizzle 完全在 TypeScript 文件中，
你基本上可以在代码里做任何在普通 TypeScript 项目中会做的事。

一个常见做法是把列拆分到不同的地方，然后再复用它们。
例如，考虑 `updated_at`、`created_at` 和 `deleted_at` 这三个列。许多表/模型可能都需要这三个
字段，用来追踪和分析系统中实体的创建、删除和更新。

我们可以在一个单独的文件中定义这些列，然后导入并把它们展开到你所拥有的所有表对象中

<Section>
```ts
// columns.helpers.ts
export const timestamps = {
  updated_at: timestamp(),
  created_at: timestamp().defaultNow().notNull(),
  deleted_at: timestamp(),
}
```
```ts
// users.sql.ts
export const users = cockroachTable('users', {
  id: int4(),
  ...timestamps
})
```
```ts
// posts.sql.ts
export const posts = cockroachTable('posts', {
  id: int4(),
  ...timestamps
})
```
</Section>

#### **Schemas**

\
在 cockroach 中，有一个称为 `schema` 的实体（我们认为它应该被称为 `folders`）。它会在 cockroach 中创建一个结构：

![](@/assets/images/postgresql-db-structure.png)

你可以用 `cockroachSchema` 管理你的 cockroach schema，并把任何其它模型放在其中。

使用 Drizzle 定义你想管理的 schema
```ts
import { cockroachSchema } from "drizzle-orm/cockroach-core"

export const customSchema = cockroachSchema('custom');
```

然后把表放到 schema 对象内部
```ts {5-7}
import { int4, cockroachSchema } from "drizzle-orm/cockroach-core";

export const customSchema = cockroachSchema('custom');

export const users = customSchema.table('users', {
  id: int4()
})
```

### 示例

了解了基础知识后，让我们为一个真实项目定义一个 schema 示例，以便更好地了解和理解

> 所有示例都会使用 `generateUniqueString`。它的实现将在所有 schema 示例之后提供

```ts copy
import type { AnyCockroachColumn } from "drizzle-orm/cockroach-core";
import { cockroachEnum, cockroachTable as table } from "drizzle-orm/cockroach-core";
import * as t from "drizzle-orm/cockroach-core";

export const rolesEnum = cockroachEnum("roles", ["guest", "user", "admin"]);

export const users = table(
  "users",
  {
    id: t.int4().primaryKey().generatedAlwaysAsIdentity(),
    firstName: t.varchar("first_name", { length: 256 }),
    lastName: t.varchar("last_name", { length: 256 }),
    email: t.varchar().notNull(),
    invitee: t.int4().references((): AnyCockroachColumn => users.id),
    role: rolesEnum().default("guest"),
  },
  (table) => [
    t.uniqueIndex("email_idx").on(table.email)
  ]
);

export const posts = table(
  "posts",
  {
    id: t.int4().primaryKey().generatedAlwaysAsIdentity(),
    slug: t.varchar().$default(() => generateUniqueString(16)),
    title: t.varchar({ length: 256 }),
    ownerId: t.int4("owner_id").references(() => users.id),
  },
  (table) => [
    t.uniqueIndex("slug_idx").on(table.slug),
    t.index("title_idx").on(table.title),
  ]
);

export const comments = table("comments", {
  id: t.int4().primaryKey().generatedAlwaysAsIdentity(),
  text: t.varchar({ length: 256 }),
  postId: t.int4("post_id").references(() => posts.id),
  ownerId: t.int4("owner_id").references(() => users.id),
});
```

**`generateUniqueString` 的实现：**
```ts
function generateUniqueString(length: number = 12): string {
  const characters =
    "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
  let uniqueString = "";

  for (let i = 0; i < length; i++) {
    const randomIndex = Math.floor(Math.random() * characters.length);
    uniqueString += characters[randomIndex];
  }

  return uniqueString;
}
```
