# `drizzle-kit push`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/cockroach/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/cockroach/sql-schema-declaration) 
- 数据库连接基础 - [阅读此处](/docs/cockroach/connect-overview) 
- Drizzle 迁移基础 - [阅读此处](/docs/cockroach/migrations) 
- Drizzle Kit [概览](/docs/cockroach/kit-overview)和[配置文件](/docs/cockroach/drizzle-config-file)文档
</Prerequisites>


`drizzle-kit push` 让你可以字面意义上地将你的 schema 及后续的 schema 变更直接推送到
数据库，同时省略 SQL 文件的生成，它的设计目标是覆盖 Drizzle 迁移的[代码优先](/docs/cockroach/migrations)
方式。

<Callout collapsed="它的工作原理是什么？">
当你运行 Drizzle Kit `push` 命令时，它会：
1. 读取你的 Drizzle schema 文件，并组成一个 schema 的 json 快照
2. 拉取（内省）数据库 schema 
3. 基于两者之间的差异，它会生成 SQL 迁移
4. 将 SQL 迁移应用到数据库

<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/cockroach-core";

export const users = p.cockroachTable("users", {
  id: p.int4().primaryKey(),
  name: p.string(),
});
```
```
┌─────────────────────┐                  
│ ~ drizzle-kit push  │                  
└─┬───────────────────┘                  
  │                                           ┌──────────────────────────┐
  └ Pull current datatabase schema ---------> │                          │
                                              │                          │
  ┌ Generate alternations based on diff <---- │         DATABASE         │
  │                                           │                          │
  └ Apply migrations to the database -------> │                          │
                                       │      └──────────────────────────┘
                                       │
  ┌───────────────────────────────────────────┴────────────────┐
   CREATE TABLE "users" ("id" int4 PRIMARY KEY, "name" string);
```
</Section>
</Callout>

它是快速原型开发的最佳方式，我们已经看到许多团队
和独立开发者成功地将它作为其生产应用中的主要迁移流程。
它与蓝/绿部署策略以及无服务器数据库如
[Planetscale](https://planetscale.com)、[Neon](https://neon.tech)、[Turso](https://turso.tech/drizzle) 等搭配得非常好。

`drizzle-kit push` 要求你指定 `dialect`、`schema` 文件的路径，以及
数据库连接 `url` 或 `user:password@host:port/db` 参数，你可以通过 [drizzle.config.ts](/docs/cockroach/drizzle-config-file) 配置文件
或 CLI 选项来提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname",
  },
});
```
```shell
npx drizzle-kit push
```
</Section>

```shell
npx drizzle-kit push --dialect=cockroach --schema=./src/schema.ts --url=postgresql://user:password@host:port/dbname
```

</CodeTabs>

### Schema 文件路径

你可以只有一个 `schema.ts` 文件，也可以有任意多个散布在项目中的 schema 文件。
Drizzle Kit 要求你通过 `schema` 配置选项，以 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的形式指定它们的路径。

### 单个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你需要多个数据库阶段，或者在同一个项目中有多个数据库或不同的数据库时，这非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.config.ts
  drizzle-kit push --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 指定数据库驱动
Drizzle Kit 不自带预打包的数据库驱动， 
它会根据 `dialect` 从你当前的项目中自动挑选可用的数据库驱动 - [参见讨论](https://github.com/drizzle-team/drizzle-orm/discussions/2203)。



### 包含表和 schema 
`drizzle-kit push` 默认会管理所有表和 schema。
你可以通过 `tablesFilter` 和 `schemaFilter` 选项配置表和 schema 的列表。

|                     |                                                                                               |
| :------------------ | :-------------------------------------------------------------------------------------------- |
| `tablesFilter`      | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认为 `"*"` |
| `schemaFilter`      | Schema 名过滤器，例如 `["public", "drizzle"]`。默认为 "*"                       |
<br/>

让我们配置 drizzle-kit 只操作 **public** schema 中的 **所有表**，
并让 drizzle-kit 知道有一个 **postgis** 扩展已安装， 
它会在 public schema 中创建自己的表，因此 drizzle 可以忽略它们。

<Section>
```ts filename="drizzle.config.ts" {9-10}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname",
  },
  schemaFilter: ["public"],
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit push
```
</Section>

### 扩展配置列表

`drizzle-kit push` 有一系列仅限 CLI 的选项

<rem025/>

|           |                                                                 |
| :-------- | :---------------------------------------------------------------|
| `verbose` | 在执行前打印所有 SQL 语句                     |
| `explain` | 打印计划中的 SQL 变更，但不应用它们（dry run）  |
| `force`   | 自动接受所有数据丢失语句                            |
<br/>
<Npx>
drizzle-kit push --explain --verbose --force
</Npx>

<br/>
<hr/>
<br/>
我们建议通过 [drizzle.config.ts](/docs/cockroach/drizzle-config-file) 文件来配置 `drizzle-kit`， 
但你也可以在必要时通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中，等等。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，取值为 <Dialects/> 之一                                      |
| `schema`            | `required` | TypeScript schema 文件或包含多个 schema 文件的文件夹的路径 |
| `tablesFilter`      |            | 表名过滤器                                                         |
| `schemaFilter`      |            | Schema 名过滤器。默认：`["*"]`                                 |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                         |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名                                                             |
| `config`            |            | 配置文件路径，默认=`drizzle.config.ts`                             |

<Npx>
drizzle-kit push dialect=cockroach schema=src/schema.ts url=postgresql://user:password@host:port/dbname
drizzle-kit push dialect=cockroach schema=src/schema.ts driver=pglite url=database/
drizzle-kit push dialect=cockroach schema=src/schema.ts --tablesFilter='user*' url=postgresql://user:password@host:port/dbname
</Npx>

npx drizzle-kit push
