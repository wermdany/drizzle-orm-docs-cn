# Drizzle Kit 配置文件
<Prerequisites>

Drizzle Kit 让你可以在 `TypeScript` 或 `JavaScript` 配置文件中声明配置选项。

<Section>
```plaintext {5}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
<CodeTabs items={["drizzle.config.ts", "drizzle.config.js"]}>
<CodeTab>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
<CodeTab>
```js
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
</CodeTabs>
</Section>

一个扩展配置文件的示例
```ts collapsable
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "cockroach",
  schema: "./src/schema.ts",

  dbCredentials: {
    url: "./database/",
  },

  schemaFilter: "public",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
    schema: "drizzle",
  },

  entities: {
    roles: {
      provider: '',
      exclude: [],
      include: []
    }
  },

  breakpoints: true,
  verbose: true,
});
```

### 多个配置文件
你可以在项目中拥有多个配置文件，当你有多个数据库环境、多个数据库或同一项目下的不同数据库时，这非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 迁移文件夹
`out` 参数让你定义迁移的文件夹，它是可选的，默认为 `drizzle`。
这非常有用，因为你可以在同一项目中为不同数据库拥有许多独立的 schema，
并为它们设置不同的迁移文件夹。
  
迁移文件夹包含带有 `.sql` 迁移文件的文件夹，供 `drizzle-kit` 使用

<Section>
```plaintext {3}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ ├ 📜 user.ts 
 │ ├ 📜 post.ts 
 │ └ 📜 comment.ts 
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
```ts {6}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema/*",
  out: "./drizzle",
});
```
</Section>

### `dbCredentials`
<rem025/>

以 `url`、`user:password@host:port/db` 参数形式提供的数据库连接凭据，
或异常驱动（<Drivers/>）特定的连接选项。

|               |                      |
| :------------ | :-----------------   |
| 类型          | <Dialects/> |
| 默认值       | --                    |
| 命令      | `push`, `pull`, `migrate`, `studio` |

<rem025/>

<CodeTabs items={["连接字符串", "连接参数"]}>
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "cockroach",
  dbCredentials: {
    url: "postgres://user:password@host:port/db",
  }
});
```
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "cockroach",
  dbCredentials: {
    host: "host",
    port: 26257,
    user: "user",
    password: "password",
    database: "dbname",
    ssl: true, // 可以是 boolean | "require" | "allow" | "prefer" | "verify-full" | 来自 node:tls 的选项
  }
});
```

### `migrations`
<rem025/>

运行 `drizzle-kit migrate` 时 —— drizzle 会在数据库的 `drizzle` schema 中名为 `__drizzle_migrations` 的日志表里记录
成功应用的迁移。

`migrations` 配置选项让你可以更改迁移日志的 `table` 名称和 `schema`。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `{ table: string, schema: string }` |
| 默认值       | `{ table: "__drizzle_migrations", schema: "drizzle" }`                    |
| 命令      | `migrate`, `push`, `pull` |

<rem025/>

```ts
export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  migrations: {
    table: 'my-migrations-table', // 默认是 `__drizzle_migrations`
    schema: 'my_schema', // 默认是 `drizzle`
  },
});
```

### `tablesFilter`
<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/cockroach/goodies#多项目-schema)。
</Callout>
<rem025/>
`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有表。
你可以通过 `tablesFilters`、`schemaFilter` 和 `extensionFilters` 选项配置表、schema 和扩展的列表。

`tablesFilter` 选项让你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值       | --                    |
| 命令      | `push` `pull`   |

<rem025/>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  tablesFilter: ["users", "posts", "project1_*"],
});
```

### `schemaFilter`


<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/cockroach/goodies#多项目-schema)。
</Callout>

`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有 schema。

`schemaFilter` 选项让你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
的 schema 名称过滤器，例如 `["public", "auth"]` 或 `"tenant_*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string[]` |
| 命令      | `push` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "cockroach",
  schemaFilter: ["public", "schema1", "schema2"],
});
```

### `entities`

此配置用于为数据库中的特定 `entities` 设置管理选项。

目前它只包含 `roles`，但最终所有数据库实体都会迁移到这里，例如 `tables`、`schemas`、`extensions`、`functions`、`triggers` 等

#### `roles`

<rem025/>

如果你使用 Drizzle Kit 来管理 schema，尤其是已定义的 roles，可能会遇到某些 roles 未在 Drizzle schema 中定义的情况。
在这种情况下，你可能希望 Drizzle Kit 跳过那些 `roles`，而无需在 Drizzle schema 中逐个写出每个 role 并标记为 `.existing()`。

`roles` 选项让你可以：

- 启用或禁用 Drizzle Kit 对 role 的管理。
- 将特定 roles 排除在 Drizzle Kit 的管理之外。
- 将特定 roles 纳入 Drizzle Kit 的管理。
- 为诸如 `Neon` 和 `Supabase` 这类不管理其特定 roles 的提供商启用相应模式。
- 组合以上所有选项

|               |                       |
| :------------ | :-----------------    |
| 类型          | `boolean \| { provider: "neon" \| "supabase", include: string[], exclude: string[] }`|
| 默认值       | `false`                  |
| 命令      | `push` `pull` |

<rem025/>

默认情况下，`drizzle-kit` 不会为你管理 roles，因此你需要启用它。在 `drizzle.config.ts` 中
```ts
export default defineConfig({
  dialect: "cockroach",
  entities: {
    roles: true
  }
});
```

**你有一个 role `admin`，想把它排除在可管理的 roles 列表之外**

```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  ...
  entities: {
    roles: {
      exclude: ['admin']
    }
  }
});
```

**你有一个 role `admin`，想把它加入可管理的 roles 列表**

```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  ...
  entities: {
    roles: {
      include: ['admin']
    }
  }
});
```

**如果你使用 `Neon` 并想排除 `Neon` 定义的 roles，可以使用 provider 选项**

```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  ...
  entities: {
    roles: {
      provider: 'neon'
    }
  }
});
```

**如果你使用 `Supabase` 并想排除 `Supabase` 定义的 roles，可以使用 provider 选项**

```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  ...
  entities: {
    roles: {
      provider: 'supabase'
    }
  }
});
```

<Callout title='重要'>
你可能会遇到 Drizzle 相比数据库提供商新指定的 roles 略微滞后的情况，
因此你可能需要同时使用 `provider` 选项和 `exclude` 来排除额外的 roles。你可以用 Drizzle 轻松做到这一点：

```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  ...
  entities: {
    roles: {
      provider: 'supabase',
      exclude: ['new_supabase_role']
    }
  }
});
```
</Callout>

<rem025/>

在 `drizzle-kit push` 命令期间打印所有 SQL 语句。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `false`                    |

<rem025/>

```ts
export default defineConfig({
  dialect: "cockroach",
  verbose: false,
});
```

### `breakpoints`
<rem025/>

Drizzle Kit 会自动将 `--> statement-breakpoint` 嵌入到生成的 SQL 迁移文件中，
这对于不支持在一个事务中执行多条 DDL 交替语句的数据库（MySQL 和 SQLite）是必需的。

`breakpoints` 选项标志让你可以开启和关闭它

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `true`                    |
| 命令      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "cockroach",
  breakpoints: false,
});
```
