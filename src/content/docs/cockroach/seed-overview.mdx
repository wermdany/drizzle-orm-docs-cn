# Drizzle Seed

`drizzle-seed` 是一个 TypeScript 库，帮助你生成确定性的、但看起来真实的
假数据来填充你的数据库。通过利用可设定种子的伪随机数生成器（pRNG），
它确保你生成的数据在不同运行之间保持一致且可复现。
这在测试、开发和调试场景中尤其有用。

#### 什么是确定性数据生成?

确定性数据生成意味着相同的输入总是产生相同的输出。
在 `drizzle-seed` 的语境中，当你使用相同的种子数字初始化该库时，
它每次都会生成相同的假数据序列。这让你可以得到可预测、可重复的数据集。

#### 伪随机数生成器 (pRNG)

伪随机数生成器是一种算法，它产生一串
近似具有随机数性质的数字。然而，由于它基于一个称为种子的初始值，
你可以控制它的随机性。使用相同的种子，pRNG 将产生
相同的数字序列，从而使你的数据生成过程可复现。

#### 使用 pRNG 的好处:

- 一致性：确保你的测试每次都在相同的数据上运行。
- 调试：通过提供一致的数据集，让复现和修复 bug 变得更容易。
- 协作：团队成员可以共享种子数字，以便使用相同的数据集。

使用 drizzle-seed，你可以兼得两方面的好处：既能生成真实的假数据，又能在需要时复现它。

## 安装

<Npm>drizzle-seed</Npm>

## 基本用法

在这个示例中，我们将创建 10 个拥有随机姓名和 id 的用户

```ts {12}
import { cockroachTable, int4, text } from "drizzle-orm/cockroach-core";
import { drizzle } from "drizzle-orm/cockroach";
import { seed } from "drizzle-seed";

const users = cockroachTable("users", {
  id: int4().primaryKey(),
  name: text().notNull(),
});

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await seed(db, { users });
}

main();
```

## 选项

**`count`**

默认情况下，`seed` 函数会创建 10 个实体。
但如果你的测试需要更多，你可以在 seed 选项对象中指定它

```ts
await seed(db, schema, { count: 1000 });
```

**`seed`**

如果你需要一个种子来为所有后续运行生成不同的值集，你可以在 `seed` 选项中
定义一个不同的数字。任何新数字都会生成一组唯一的值

```ts
await seed(db, schema, { seed: 12345 });
```

## 重置数据库

使用 `drizzle-seed`，你可以轻松重置数据库并为其填充新的值，例如在你的测试套件中

```ts
// 指向你想要重置的 schema 文件的路径
import * as schema from "./schema.ts";
import { reset } from "drizzle-seed";

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await reset(db, schema);
}

main();
```

不同的方言在数据库重置方面会有不同的策略

对于 CockroachDB，`drizzle-seed` 包会生成带 `CASCADE` 选项的 `TRUNCATE` 语句，
以确保在运行 reset 函数后所有表都为空

```sql
TRUNCATE tableName1, tableName2, ... CASCADE;
```

## 细化

如果你需要更改 `drizzle-seed` 默认使用的种子生成器函数的行为，你可以指定自己的实现，甚至为种子填充过程使用自己的值列表

`.refine` 是一个回调，它会接收来自 `drizzle-seed` 的所有可用生成器函数列表。它应返回一个对象，其键表示你想要细化的表，并按需定义它们的行为。
每张表可以指定多个属性，以简化数据库的种子填充：

<rem025 />

- `columns`：通过指定所需的生成器函数来细化每一列的默认行为，或者通过指定 `false` 将该列排除在种子填充之外。
- `count`：指定要插入数据库的行数。默认为 10。如果在 `seed()` 选项中定义了全局 count，此处定义的 count 将针对这张特定的表覆盖它。
- `with`：如果你想生成关联实体，定义要为每张父表创建多少个被引用实体。

<Callout title='信息'>
你也可以为你想要创建的被引用值的数量指定加权随机分布。关于这个 API 的细节，你可以参考 [加权随机文档](#加权随机)章节
</Callout>

**API**
```ts
await seed(db, schema).refine((f) => ({
  users: {
    columns: {},
    count: 10,
    with: {
        posts: 10
    }
  },
}));
```

## 加权随机

有时你可能需要使用多个具有不同优先级的、应在种子填充阶段插入数据库的数据集。针对这类情况，drizzle-seed 提供了一个名为加权随机的 API

Drizzle Seed 包中有几个地方可以使用加权随机：

- 每张表细化中的列
- `with` 属性，用于确定要创建的相关实体的数量

让我们各看一个示例：

```ts filename="schema.ts"
import { cockroachTable, int4, text, varchar, doublePrecision } from "drizzle-orm/cockroach-core";

export const orders = cockroachTable(
  "orders",
  {
    id: int4().primaryKey(),
    name: text().notNull(),
    quantityPerUnit: varchar().notNull(),
    unitPrice: doublePrecision().notNull(),
    unitsInStock: int4().notNull(),
    unitsOnOrder: int4().notNull(),
    reorderLevel: int4().notNull(),
    discontinued: int4().notNull(),
  }
);

export const details = cockroachTable(
  "details",
  {
    unitPrice: doublePrecision().notNull(),
    quantity: int4().notNull(),
    discount: doublePrecision().notNull(),

    orderId: int4()
      .notNull()
      .references(() => orders.id, { onDelete: "cascade" }),
  }
);
```

**示例 1**：细化 `unitPrice` 的生成逻辑，生成 `5000` 个随机价格，其中 30% 的概率是 10-100 之间的价格，70% 的概率是 100-300 之间的价格

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/cockroach";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       count: 5000,
       columns: {
           unitPrice: f.weightedRandom(
               [
                   {
                       weight: 0.3,
                       value: f.int({ minValue: 10, maxValue: 100 })
                   },
                   {
                       weight: 0.7,
                       value: f.number({ minValue: 100, maxValue: 300, precision: 100 })
                   }
               ]
           ),
       }
    }
  }));
}

main();
```

**示例 2**：为每个订单生成 1 到 3 条 detail 的概率为 60%，生成 5 到 7 条的概率为 30%，生成 8 到 10 条的概率为 10%

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/cockroach";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       with: {
           details:
               [
                   { weight: 0.6, count: [1, 2, 3] },
                   { weight: 0.3, count: [5, 6, 7] },
                   { weight: 0.1, count: [8, 9, 10] },
               ]
       }
    }
  }));
}

main();
```

## 局限性

#### `with` 的类型限制

由于 TypeScript 的某些限制以及 Drizzle 当前的 API，无法正确推断表之间的引用，尤其是当表之间存在循环依赖时。

这意味着 `with` 选项会显示 schema 中的所有表，你需要手动选择具有一对多关系的那张表

<Callout title='警告'>
`with` 选项适用于一对多关系。例如，如果你有一个 `user` 和多个 `posts`，你可以使用 users `with` posts，但不能使用 posts `with` users
</Callout>

#### Drizzle 表中第三个参数的类型限制:

目前，我们还不支持 Drizzle 表第三个参数的类型。虽然它在运行时会正常工作，但在类型层面不会正确生效
