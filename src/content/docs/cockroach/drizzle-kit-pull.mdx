# `drizzle-kit pull`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/cockroach/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/cockroach/sql-schema-declaration) 
- 数据库连接基础 - [阅读此处](/docs/cockroach/connect-overview) 
- Drizzle 迁移基础 - [阅读此处](/docs/cockroach/migrations) 
- Drizzle Kit [概览](/docs/cockroach/kit-overview)和[配置文件](/docs/cockroach/drizzle-config-file)文档
</Prerequisites>

`drizzle-kit pull` 让你可以字面意义上地拉取（内省）你现有的数据库 schema 并生成 `schema.ts` drizzle schema 文件， 
它的设计目标是覆盖 Drizzle 迁移的[数据库优先](/docs/cockroach/migrations)方式。

<Callout collapsed="它的工作原理是什么？">
当你运行 Drizzle Kit `pull` 命令时，它会：
1. 从你现有的数据库中拉取数据库 schema（DDL）
2. 生成 `schema.ts` drizzle schema 文件并将其保存到 `out` 文件夹

<Section>
```
                                  ┌────────────────────────┐      ┌─────────────────────────┐ 
                                  │                        │ <---  CREATE TABLE "users" (
┌──────────────────────────┐      │                        │       	"id" int4 PRIMARY KEY,
│ ~ drizzle-kit pull       │      │                        │       	"name" string,
└─┬────────────────────────┘      │                        │       	"email" string unique
  │                               │        DATABASE        │       );
  │                               │                        │
  └ Pull datatabase schema -----> │                        │
  ┌ Generate Drizzle       <----- │                        │
  │ schema TypeScript file        └────────────────────────┘
  │
  v
```
```typescript
import * as p from "drizzle-orm/cockroach-core";

export const users = p.cockroachTable("users", {
    id: p.int4().primaryKey(),
    name: p.string(),
    email: p.string(),
  },
  (table) => [p.uniqueIndex('users_email_key').using('btree', table.email.asc())],
);
```
</Section>
</Callout>

如果你需要在 TypeScript 项目之外管理数据库 schema，或者你使用的数据库由其他人管理， 
这是一个很好的方式。

<br/>
<hr/>
<br/>

`drizzle-kit pull` 要求你指定 `dialect` 以及
数据库连接 `url` 或 `user:password@host:port/db` 参数，你可以通过 [drizzle.config.ts](/docs/cockroach/drizzle-config-file) 配置文件
或 CLI 选项来提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname",
  },
});
```
```shell
npx drizzle-kit pull
```
</Section>

```shell
npx drizzle-kit pull --dialect=cockroach --url=postgresql://user:password@host:port/dbname
```
</CodeTabs>

### 单个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你需要多个数据库阶段，或者在同一个项目中有多个数据库或不同的数据库时，这非常有用：

<Npx>
  drizzle-kit pull --config=drizzle-dev.config.ts
  drizzle-kit pull --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 指定数据库驱动
Drizzle Kit 不自带预打包的数据库驱动， 
它会根据 `dialect` 从你当前的项目中自动挑选可用的数据库驱动 - [参见讨论](https://github.com/drizzle-team/drizzle-orm/discussions/2203)。

### 初次拉取

你可以使用 `--init` 标志将拉取到的 schema 标记为数据库中已应用的迁移， 
这样后续所有迁移都会与初始迁移进行差异对比

```shell
npx drizzle-kit pull --init
```

### 包含表、schema 和扩展
`drizzle-kit pull` 默认会管理所有 schema 中的所有表。
你可以通过 `tablesFilters`、`schemaFilter` 和 `extensionFilters` 选项配置表、schema 和扩展的列表。

|                     |                                                                                               |
| :------------------ | :-------------------------------------------------------------------------------------------- |
| `tablesFilter`      | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认为 `"*"` |
| `schemaFilter`      | 基于 `glob` 的 schema 名过滤器，例如 `["public", "drizzle"]` 或 `"drizzle*"`。默认为 `"*"`                     |
<br/>

让我们配置 drizzle-kit 只操作 **public** schema 中的 **所有表**，
并让 drizzle-kit 知道有一个 **postgis** 扩展已安装， 
它会在 public schema 中创建自己的表，因此 drizzle 可以忽略它们。

<Section>
```ts filename="drizzle.config.ts" {9-11}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname",
  },
  schemaFilter: ["public"],
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit pull
```
</Section>

### 扩展配置列表
我们建议通过 [drizzle.config.ts](/docs/cockroach/drizzle-config-file) 文件来配置 `drizzle-kit`， 
但你也可以在必要时通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中，等等。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，取值为 <Dialects/> 之一                                      |
| `driver`            |            | 驱动例外 <Drivers/>                                             |
| `out`               |            | 迁移输出文件夹路径，默认为 `./drizzle`                     |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                         |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名                                                             |
| `config`            |            | 配置文件路径，默认为 `drizzle.config.ts`                          |
| `introspect-casing` |            | 在列、表等中创建 JS 键的策略。`preserve` `camel` |
| `tablesFilter`      |            | 表名过滤器                                                         |
| `schemaFilter`      |            | Schema 名过滤器。默认：`["*"]`                                 |

<Npx>
drizzle-kit pull --dialect=cockroach --url=postgresql://user:password@host:port/dbname
drizzle-kit pull --dialect=cockroach --driver=pglite url=database/
drizzle-kit pull --dialect=cockroach --tablesFilter='user*' url=postgresql://user:password@host:port/dbname
</Npx>
