本教程演示如何将 Drizzle ORM 与 [Supabase Edge Functions](https://supabase.com/docs/guides/functions) 一起使用。

<Prerequisites>
- 你需要安装最新版本的 [Supabase CLI](https://supabase.com/docs/guides/cli/getting-started#installing-the-supabase-cli)。
- 你需要安装 Drizzle ORM 和 [Drizzle kit](https://orm.drizzle.team/kit-docs/overview)。你可以通过运行以下命令来完成：
<Npm>
  drizzle-orm@rc
  -D drizzle-kit@rc
</Npm>
- 你需要安装 Docker Desktop。这是本地开发的先决条件。请遵循官方[文档](https://docs.docker.com/desktop)进行安装。
</Prerequisites>

要了解如何在本地机器上创建一个基础的 Edge Function 然后部署它，请参阅 [Edge Functions 快速入门](https://supabase.com/docs/guides/functions/quickstart)。

<Steps>
#### 创建表

在你的 `src` 目录中创建一个 `schema.ts` 文件，并声明一个表结构：

```typescript copy filename="src/schema.ts"
import { pgTable, serial, text, integer } from "drizzle-orm/pg-core";

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull()
})
```

该文件将用于为你的数据库生成迁移。

#### 设置 Drizzle 配置文件

**Drizzle config** —— 一个由 [Drizzle Kit](https://orm.drizzle.team/kit-docs/overview) 使用的配置文件，包含关于你的数据库连接、迁移文件夹和 schema 文件的所有信息。

在你的项目根目录下创建一个 `drizzle.config.ts` 文件，并添加以下内容：

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./src/schema.ts",
  out: "./supabase/migrations",
  dialect: "postgresql",
});
```

在本教程中，我们将使用 Drizzle kit 为我们的 schema 生成迁移。

#### 初始化新的 Supabase 项目

在本地机器上的一个文件夹中创建一个新的 Supabase 项目：

```bash copy
supabase init
```

它将创建一个包含 `config.toml` 文件的 `supabase` 文件夹：

```text
└── supabase
    └── config.toml
```

如果你使用 Visual Studio Code，请按照 [Supabase 文档](https://supabase.com/docs/guides/functions/local-development#deno-with-visual-studio-code) 为 Deno 设置相关配置。

#### 生成迁移

运行 `drizzle-kit generate` 命令来生成迁移：

```bash copy
npx drizzle-kit generate
```

它将在 `supabase/migrations` 目录中创建一个新的迁移文件：

#### 应用迁移

要启动 Supabase 本地开发栈，请运行以下命令：

```bash copy
supabase start
```

要应用迁移，请运行以下命令：

```bash copy
supabase migration up
```

你可以在[文档](https://supabase.com/docs/guides/deployment/database-migrations)中阅读更多关于 Supabase 迁移的内容。

<Callout type="warning">别忘了运行 Docker</Callout>

或者，你可以使用 `drizzle-kit migrate` 命令来应用迁移。在[文档](https://orm.drizzle.team/docs/migrations)中了解更多关于此迁移流程的内容。

#### 创建新的 Edge Function

运行 `supabase functions new [FUNCTION_NAME]` 命令来创建一个新的 Edge Function：

```bash copy
supabase functions new drizzle-tutorial
```

它将在 `supabase/functions` 目录中创建一个以该函数名命名的新文件夹：

```text
└── supabase
    └── functions
    │   └── drizzle-tutorial
    │   │   ├── .npmrc ## 函数专属的 npm 配置（如需要）
    │   │   ├── deno.json ## 函数专属的 Deno 配置
    │   │   └── index.ts ## 你的函数代码
```

当你创建一个新的 Edge Function 时，默认情况下会使用 TypeScript。但是，也可以用 JavaScript 编写 Edge Function。在[文档](https://supabase.com/docs/guides/functions/quickstart#not-using-typescript)中了解更多。

#### 设置导入

将以下导入添加到 `supabase/functions/drizzle-tutorial` 目录中的 `deno.json` 文件：

```json copy filename="supabase/functions/drizzle-tutorial/deno.json"
{
  "imports": {
    "drizzle-orm/": "npm:/drizzle-orm/",
    "postgres": "npm:postgres"
  }
}
```

你可以在[此处](https://supabase.com/docs/guides/functions/dependencies#managing-dependencies)阅读更多关于管理依赖的内容。

#### 将你的 schema 复制到 functions 目录

将你将在 edge function 中使用的代码从 `src/schema.ts` 文件复制到 `supabase/functions/drizzle-tutorial/index.ts` 文件：

```typescript copy filename="supabase/functions/drizzle-tutorial/index.ts"
// 为内置 Supabase Runtime API 设置类型定义
import "jsr:@supabase/functions-js/edge-runtime.d.ts"
import { pgTable, serial, text, integer } from "drizzle-orm/pg-core";

const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull()
})

Deno.serve(async (req) => {
  const { name } = await req.json()
  const data = {
    message: `Hello ${name}!`,
  }

  return new Response(
    JSON.stringify(data),
    { headers: { "Content-Type": "application/json" } },
  )
})  
```

<Callout type="warning">
在 Deno 生态系统中，每个函数都应被视为一个独立项目，拥有自己的一套依赖和配置。
出于这些原因，Supabase 建议在每个函数的目录中维护单独的配置文件（`deno.json`、`.npmrc` 或 `import_map.json`），即使这意味着要重复一些配置。在此处了解更多[内容](https://supabase.com/docs/guides/functions/dependencies#managing-dependencies)。
</Callout>

#### 将 Drizzle ORM 连接到你的数据库

用你的数据库配置更新你的 edge function 代码：

```typescript copy filename="supabase/functions/drizzle-tutorial/index.ts" {14,17,18}
// 为内置 Supabase Runtime API 设置类型定义
import { integer, pgTable, serial, text } from "drizzle-orm/pg-core";
import { drizzle } from "drizzle-orm/postgres-js";
import "jsr:@supabase/functions-js/edge-runtime.d.ts";
import postgres from "postgres";

const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull()
})

Deno.serve(async () => {
  const connectionString = Deno.env.get("SUPABASE_DB_URL")!;

  // 禁用预取（prefetch），因为 "Transaction" 池模式不支持它
  const client = postgres(connectionString, { prepare: false });
  const db = drizzle({ client });

  await db.insert(usersTable).values({
    name: "Alice",
    age: 25
  })
  const data = await db.select().from(usersTable);

  return new Response(
    JSON.stringify(data)
  )
})
```

`SUPABASE_DB_URL` 是用于直接数据库连接的默认环境变量。在[文档](https://supabase.com/docs/guides/functions/secrets)中了解更多关于在 Supabase Edge Functions 中管理环境变量的内容。

#### 在本地测试你的代码

运行以下命令在本地测试你的函数：

```bash copy
supabase functions serve --no-verify-jwt
```

在浏览器中导航到路由 `(e.g. /drizzle-tutorial)`：

```plaintext
[
  {
    "id": 1,
    "name": "Alice",
    "age": 25
  }
]
```

#### 将本地项目链接到托管的 Supabase 项目

你可以在[控制面板](https://supabase.com/dashboard)中创建新的 Supabase 项目，或通过此[链接](https://database.new/)创建。

从项目设置中复制 `Reference ID`，并通过运行以下命令用它把你的本地开发项目链接到托管的 Supabase 项目：

```bash copy
supabase link --project-ref=<REFERENCE_ID>
```

通过运行以下命令将你的 schema 变更推送到托管的 Supabase 项目：

```bash copy
supabase db push
```

#### 设置环境变量

你可以通过点击控制面板顶栏中的 **Connect** 找到 `Project connect details`，并从 `Transaction pooler` 部分复制 URI。记得将密码占位符替换为你实际的数据库密码。

在[文档](https://supabase.com/docs/guides/database/connecting-to-postgres#connection-pooler)中了解更多关于 Connection Pooler 的内容。

更新你的 edge function 代码，使用 `DATABASE_URL` 环境变量代替 `SUPABASE_DB_URL`：

```typescript copy filename="supabase/functions/drizzle-tutorial/index.ts"
// imports

// const connectionString = Deno.env.get("SUPABASE_DB_URL")!;
const connectionString = Deno.env.get("DATABASE_URL")!;

// code
```

运行以下命令来设置环境变量：

```bash copy
supabase secrets set DATABASE_URL=<CONNECTION_STRING>
```

在[文档](https://supabase.com/docs/guides/functions/secrets)中了解更多关于在 Supabase Edge Functions 中管理环境变量的内容。

#### 部署你的函数

通过运行以下命令部署你的函数：

```bash copy
supabase functions deploy drizzle-tutorial --no-verify-jwt
```
</Steps>

最后，你可以使用已部署项目的 URL，并导航到你创建的路由 `(e.g. /drizzle-tutorial)` 来访问你的 edge function。
