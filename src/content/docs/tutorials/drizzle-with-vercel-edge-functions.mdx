## 兼容 Edge 的驱动

在将 Drizzle ORM 与 Vercel Edge functions 一起使用时，你必须使用兼容 edge 的驱动，因为这些函数运行在 [Edge 运行时](https://vercel.com/docs/functions/runtimes/edge-runtime)中，而不是 Node.js 运行时中，因此标准 Node.js API 存在一些限制。

你可以根据你的数据库方言选择以下驱动之一：

- [Neon serverless 驱动](/docs/get-started-postgresql#neon) 允许你通过 HTTP 或 WebSockets 代替 TCP，从 serverless 和 edge 环境查询你的 Neon Postgres 数据库。我们推荐使用此驱动来连接 `Neon Postgres`。
- [Vercel Postgres 驱动](/docs/get-started-postgresql#vercel-postgres) 构建在 `Neon serverless driver` 之上。我们推荐使用此驱动来连接 `Vercel Postgres`。
- [PlanetScale serverless 驱动](/docs/mysql/get-started-mysql#planetscale) 允许你访问任何 `MySQL` 客户端并通过 HTTP 连接执行查询，这通常不会被云服务提供商阻止。
- [libSQL 客户端](/docs/sqlite/get-started-sqlite#turso) 允许你访问 [Turso](https://docs.turso.tech/introduction) 数据库。

### Neon Postgres

<Steps>
#### 安装 `@neondatabase/serverless` 驱动

安装 `@neondatabase/serverless` 驱动：

<Npm>
@neondatabase/serverless
</Npm>

#### 创建表

在 `src/db` 目录中创建一个 `schema.ts` 文件，并声明一个表结构：

```typescript copy filename="src/db/schema.ts"
import { pgTable, serial, text } from "drizzle-orm/pg-core";

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: text('age').notNull(),
  email: text('email').notNull().unique(),
})
```

#### 设置 Drizzle 配置文件

**Drizzle config** —— 一个由 [Drizzle Kit](/docs/kit-overview) 使用的配置文件，包含关于你的数据库连接、迁移文件夹和 schema 文件的所有信息。

在你的项目根目录下创建一个 `drizzle.config.ts` 文件，并添加以下内容：

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./src/db/schema.ts",
  dialect: "postgresql",
  dbCredentials: {
    url: process.env.POSTGRES_URL!,
  },
});
```

在 `.env` 文件中配置你的数据库连接字符串：

```plaintext filename=".env"
POSTGRES_URL="postgres://[user]:[password]@[host]-[region].aws.neon.tech:5432/[db-name]?sslmode=[ssl-mode]"
```

#### 将更改应用到数据库

你可以使用 `drizzle-kit generate` 命令生成迁移，然后使用 `drizzle-kit migrate` 命令运行它们。

生成迁移：

```bash copy
npx drizzle-kit generate
```

这些迁移存储在 `drizzle` 目录中，正如你在 `drizzle.config.ts` 中所指定的。该目录将包含更新数据库 schema 所需的 SQL 文件，以及用于存储不同迁移阶段 schema 快照的 `meta` 文件夹。

生成的迁移示例：

```sql
CREATE TABLE IF NOT EXISTS "users_table" (
	"id" serial PRIMARY KEY NOT NULL,
	"name" text NOT NULL,
	"age" text NOT NULL,
	"email" text NOT NULL,
	CONSTRAINT "users_table_email_unique" UNIQUE("email")
);
```

运行迁移：

```bash copy
npx drizzle-kit migrate
```

或者，你可以使用 [Drizzle kit push 命令](/docs/kit-overview#prototyping-with-db-push) 将变更直接推送到数据库：

```bash copy
npx drizzle-kit push
```

<Callout type="warning">Push 命令适用于你需要快速测试新的 schema 设计或本地开发环境中的变更的场景，它允许快速迭代，而无需管理迁移文件的开销。</Callout>

#### 将 Drizzle ORM 连接到你的数据库

在 `src/db` 目录中创建一个 `index.ts` 文件并配置你的数据库连接：

```typescript copy filename="src/db/index.ts"
import { drizzle } from 'drizzle-orm/neon-serverless';


export const db = drizzle(process.env.POSTGRES_URL!)
```

#### 创建 API 路由

在 `src/app/api/hello` 目录中创建 `route.ts` 文件。要了解更多关于如何编写函数的内容，请参阅 [Functions API 参考](https://vercel.com/docs/functions/functions-api-reference) 和 [Vercel Functions 快速入门](https://vercel.com/docs/functions/quickstart)。

```ts copy filename="src/app/api/hello/route.ts"
import { db } from "@/db";
import { usersTable } from "@/db/schema";
import { NextResponse } from "next/server";

export const dynamic = 'force-dynamic'; // 默认静态，除非读取请求
export const runtime = 'edge' // 指定运行时为 edge

export async function GET(request: Request) {
  const users = await db.select().from(usersTable)

  return NextResponse.json({ users, message: 'success' });
}
```

#### 在本地测试你的代码

运行 `next dev` 命令来启动你的本地开发服务器：

```bash copy
npx next dev
```

在浏览器中导航到你创建的路由 `(e.g. /api/hello)`：

```plaintext
{
  "users": [],
  "message": "success"
}
```

#### 部署你的项目

在[控制面板](https://vercel.com/new)中创建一个新项目，或运行 `vercel` 命令来部署你的项目：

```bash copy
vercel
```

添加 `POSTGRES_URL` 环境变量：

```bash copy
vercel env add POSTGRES_URL
```

重新部署你的项目以更新你的环境变量：

```bash copy
vercel
```
</Steps>

最后，你可以使用已部署项目的 URL，并导航到你创建的路由 `(e.g. /api/hello)` 来访问你的 edge function。

```ts copy filename="src/app/api/hello/route.ts"
import { NextResponse } from "next/server";

export const dynamic = 'force-dynamic'; // 默认静态，除非读取请求
export const runtime = 'edge' // 指定运行时为 edge

export async function GET(request: Request) {
  const users = await db.select().from(usersTable)

  return NextResponse.json({ users, message: 'success' });
```
```plaintext
}
```

#### 部署你的项目

在[控制面板](https://vercel.com/new)中创建一个新项目，或运行 `vercel` 命令来部署你的项目：

```bash copy
vercel
```

添加 `TURSO_CONNECTION_URL` 环境变量：

```bash copy
vercel env add TURSO_CONNECTION_URL
```

添加 `TURSO_AUTH_TOKEN` 环境变量：

```bash copy
vercel env add TURSO_AUTH_TOKEN
```

重新部署你的项目以更新你的环境变量：

```bash copy
vercel
```
</Steps>

最后，你可以使用已部署项目的 URL，并导航到你创建的路由 `(e.g. /api/hello)` 来访问你的 edge function。
