本教程演示如何将 Drizzle ORM 与 [Netlify Edge Functions](https://docs.netlify.com/edge-functions/overview/) 和 [Neon Postgres](https://neon.tech/) 数据库一起使用。

<Prerequisites>
- 你需要安装最新版本的 [Netlify CLI](https://docs.netlify.com/cli/get-started/#installation)。
- 你需要安装 Drizzle ORM 和 [Drizzle kit](/docs/kit-overview)。你可以通过运行以下命令来完成：
<Npm>
  drizzle-orm@rc
  -D drizzle-kit@rc
</Npm>

- 你需要安装 `dotenv` 包来管理环境变量。如果你使用 Node.js `v20.6.0` 或更高版本，则无需安装，因为 Node.js 原生支持 `.env` 文件。可在[此处](https://nodejs.org/en/blog/release/v20.6.0#built-in-env-file-support)了解更多。
<Npm>
  dotenv
</Npm>

- 可选地，你可以安装 `@netlify/edge-functions` 包，以便导入稍后将使用的 `Context` 对象的类型。
<Npm>
  @netlify/edge-functions
</Npm>
</Prerequisites>

<Callout type="warning">
这些已安装的包仅用于在 [Create a table](#创建表)、[Setup Drizzle config file](#设置-drizzle-配置文件) 和 [Apply changes to the database](#将更改应用到数据库) 步骤中在数据库里创建表。这些包不会影响在 Netlify Edge Functions 内部运行的代码。我们将使用 `import_map.json` 为 Edge Functions 导入所需的包。
</Callout>

<Steps>
#### 设置 Neon Postgres

登录 [Neon Console](https://console.neon.tech/app/projects) 并导航到 Projects 部分。选择一个项目，或点击 `New Project` 按钮创建一个新项目。

你的 Neon 项目自带一个名为 `neondb` 的、开箱即用的 Postgres 数据库。本教程中我们将使用它。

#### 设置连接字符串变量

在 **Project Dashboard** 部分点击 `Connect` 按钮并复制你的数据库连接字符串。它应该类似于这样：

```bash
postgres://username:password@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb?sslmode=require
```

将 `DATABASE_URL` 环境变量添加到你的 `.env` 文件中，你将使用它来连接 Neon 数据库。

```text copy
DATABASE_URL=NEON_DATABASE_CONNECTION_STRING
```

#### 设置 Netlify Edge Functions

在你的项目根目录下创建 `netlify/edge-functions` 目录。这里将存放你的 Edge Functions。

在 `netlify/edge-functions` 目录中创建一个函数 `user.ts`。

```typescript copy filename="netlify/edge-functions/user.ts"
import type { Context } from "@netlify/edge-functions";

export default async (request: Request, context: Context) => {
  return new Response("User data");
};
```

<Callout type="warning">
`Request` 和 `Response` 对象的类型位于全局作用域中。
</Callout>

#### 设置导入

在你的项目根目录下创建一个 `import_map.json` 文件，并添加以下内容：

```json copy filename="import_map.json"
{
  "imports": {
    "drizzle-orm/": "https://esm.sh/drizzle-orm/",
    "@neondatabase/serverless": "https://esm.sh/@neondatabase/serverless"
  }
}
```

在 Netlify Edge Functions 中关于 `import_map.json` 的更多内容，请参阅[此处](https://docs.netlify.com/edge-functions/api/#import-maps)。

#### 创建 Netlify 配置文件

在你的项目根目录下创建一个 `netlify.toml` 文件，并添加以下内容：

```toml copy filename="netlify.toml"
[functions]
  deno_import_map = "./import_map.json"

[[edge_functions]]
  path = "/user"
  function = "user"
```

此配置告诉 Netlify 使用 `import_map.json` 文件进行 Deno 导入，并将 `/user` 路径的请求路由到 `user.ts` 函数。
在[此处](https://docs.netlify.com/configure-builds/file-based-configuration/)了解更多关于 `netlify.toml` 的内容。

#### 创建表

在 `netlify/edge-functions/common` 目录中创建一个 `schema.ts` 文件，并声明一个表结构：

```typescript copy filename="netlify/edge-functions/common/schema.ts"
import { pgTable, serial, text, integer } from "drizzle-orm/pg-core";

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull(),
  email: text('email').notNull().unique(),
})
```

#### 设置 Drizzle 配置文件

**Drizzle config** —— 一个由 [Drizzle Kit](/docs/kit-overview) 使用的配置文件，包含关于你的数据库连接、迁移文件夹和 schema 文件的所有信息。

在你的项目根目录下创建一个 `drizzle.config.ts` 文件，并添加以下内容：

```typescript copy filename="drizzle.config.ts"
import 'dotenv/config'; // remove this line if you use Node.js v20.6.0 or later
import type { Config } from "drizzle-kit";

export default {
  schema: './netlify/edge-functions/common/schema.ts',
  out: './drizzle',
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
} satisfies Config;
```

在本教程中，我们将使用 Drizzle kit 将变更推送到 Neon 数据库。

#### 将更改应用到数据库

```bash copy
npx drizzle-kit push
```
<Callout type="warning">Push 命令适用于你需要快速测试新的 schema 设计或本地开发环境中的变更的场景，它允许快速迭代，而无需管理迁移文件的开销。</Callout>

或者，你可以使用迁移工作流。在此处了解它：[Migrations](/docs/migrations)。

#### 将 Drizzle ORM 连接到你的数据库

更新你的 `netlify/edge-functions/user.ts` 文件并配置你的数据库连接：

```typescript copy filename="netlify/edge-functions/user.ts"
import type { Context } from "@netlify/edge-functions";
import { usersTable } from "./common/schema.ts";
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';

export default async (request: Request, context: Context) => {
  const sql = neon(Netlify.env.get("DATABASE_URL")!);
  const db = drizzle({ client: sql });

  const users = await db.select().from(usersTable);

  return new Response(JSON.stringify(users));
};
```

<Callout type="warning">
如果你使用 VS Code，可能会在导入语句下方看到红色下划线。Edge Function 仍会正常执行。要消除红色下划线，你可以在下一步中配置 VS Code 以使用 Edge Functions。
</Callout>

#### 在本地测试你的代码

运行以下命令来启动 Netlify 开发服务器：

```bash copy
netlify dev
```

当你第一次运行该命令时，它会提示你将 VS Code 配置为使用 Edge Functions。点击 `Yes` 进行配置。`settings.json` 文件将在 `.vscode` 目录中创建。
如果你仍然看到红色下划线，可以重启 Deno Language Server。

打开浏览器并导航到路由 `/user`。你应该会看到从 Neon 数据库返回的用户数据：

```plaintext
[]
```

如果你还没有向 `users_table` 表添加任何数据，它可能是一个空数组。

#### 初始化新的 Netlify 项目

运行以下命令来初始化一个新的 Netlify 项目：

```bash copy
netlify init
```

在 CLI 中回答问题以创建一个新的 Netlify 项目。在本教程中，我们将选择 `Yes, create and deploy site manually` -> `<YOUR_TEAM>` -> `<SITE_NAME>`。

#### 设置 Netlify 环境变量

运行以下命令将你的环境变量导入 Netlify：

```bash copy
netlify env:import .env
```

在[此处](https://docs.netlify.com/environment-variables/get-started/)了解更多关于 Netlify 环境变量的内容。

#### 部署你的项目

运行以下命令来部署你的项目：

```bash copy
netlify deploy
```

按照 CLI 中的说明将你的项目部署到 Netlify。在本教程中，我们的发布目录是 `'.'`。

默认情况下它是一个[草稿部署](https://docs.netlify.com/cli/get-started/#draft-deploys)。
要进行生产部署，请运行以下命令：

```bash copy
netlify deploy --prod
```

</Steps>

最后，你可以使用已部署网站的 URL，并导航到你创建的路由 `(e.g. /user)` 来访问你的 edge function。
