# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [在此阅读](/docs/singlestore/get-started)
- Drizzle schema 基础 - [在此阅读](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [在此阅读](/docs/singlestore/connect-overview)
- Drizzle 迁移基础 - [在此阅读](/docs/singlestore/migrations)
</Prerequisites>


**Drizzle Kit** 是一个用于配合 Drizzle 管理 SQL 数据库迁移的 CLI 工具。
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
请务必先阅读 Drizzle [入门](/docs/singlestore/get-started) 和 [迁移基础](/docs/singlestore/migrations)，并选择最适合你业务需求的 SQL 迁移流程。
</Callout>

基于你的 schema，Drizzle Kit 让你可以生成并运行 SQL 迁移文件、
直接将 schema 推送到数据库、从数据库拉取 schema、启动 drizzle studio，还有一些实用命令。
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/singlestore/drizzle-kit-generate) | 让你基于 Drizzle schema 生成 SQL 迁移文件，无论是在声明时还是在后续变更时，[见此](/docs/singlestore/drizzle-kit-generate)。       |
| [`drizzle-kit migrate`](/docs/singlestore/drizzle-kit-migrate)   | 让你将生成的 SQL 迁移文件应用到数据库，[见此](/docs/singlestore/drizzle-kit-migrate)。                                                              |
| [`drizzle-kit pull`](/docs/singlestore/drizzle-kit-pull)         | 让你拉取（内省）数据库 schema，将其转换为 Drizzle schema 并保存到你的代码库，[见此](/docs/singlestore/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/singlestore/drizzle-kit-push)         | 让你将 Drizzle schema 推送到数据库，无论是在声明时还是在后续 schema 变更时，[见此](/docs/singlestore/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/singlestore/drizzle-kit-studio)     | 会连接到你的数据库并为 Drizzle Studio 启动代理服务器，你可以用它来方便地浏览数据库，[见此](/docs/singlestore/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/singlestore/drizzle-kit-check)       | 会遍历所有生成的迁移，检查生成的迁移之间是否存在竞态条件（冲突），[见此](/docs/singlestore/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/singlestore/drizzle-kit-up)             | 用于升级之前生成的迁移的快照，[见此](/docs/singlestore/drizzle-kit-up)                                                                     |
<br/>

Drizzle Kit 通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件或 CLI 参数进行配置。<br/>
至少需要提供 SQL `dialect` 和 `schema` 路径，Drizzle Kit 才能知道如何生成迁移。
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle 配置文件
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["简单配置", "扩展配置"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "singlestore",
  schema: "./src/schema.ts",

  driver: "pglite",
  dbCredentials: {
    url: "./database/",
  },

  extensionsFilters: ["postgis"],
  schemaFilter: "public",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    prefix: "timestamp",
    table: "__drizzle_migrations__",
    schema: "public",
  },

  breakpoints: true,
  strict: true,
  verbose: true,
});
```
</CodeTabs>

你可以通过 CLI 参数提供 Drizzle Kit 配置路径，当你有多个数据库阶段、多个数据库，或者同一项目中有不同数据库时非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
