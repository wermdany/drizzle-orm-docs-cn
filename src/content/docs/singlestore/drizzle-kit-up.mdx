# `drizzle-kit up`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/singlestore/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/singlestore/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/singlestore/migrations)
- Drizzle Kit [概览](/docs/singlestore/kit-overview)和[配置文件](/docs/singlestore/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读此处](/docs/singlestore/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit up` 命令让你将 drizzle schema 快照升级到更新的版本。
每当我们对 schema 的 json 快照引入破坏性变更并升级内部版本时，都需要用到它。

<br/>
<hr/>
<br/>

`drizzle-kit up` 命令要求你同时指定 `dialect` 和数据库连接凭据，
你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件或 CLI 选项来提供它们

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
});
```
```shell
npx drizzle-kit up
```
</Section>
```shell
npx drizzle-kit up --dialect=singlestore
```
</CodeTabs>

### 一个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你拥有多个数据库阶段或同一项目上的多个数据库时，这非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展的配置列表
我们推荐通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 文件来配置 `drizzle-kit`，
不过在必要时，例如在 CI/CD 流水线等场景中，你也可以通过 CLI 提供所有配置选项。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。可以是 `postgresql`、`mysql`、`sqlite` 或 `singlestore` |
| `out`     |            | 迁移文件夹，默认值=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认值=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit up --dialect=singlestore
drizzle-kit up --dialect=singlestore --out=./migrations-folder
</Npx>
