# Drizzle \<\> SingleStore

要在 SingleStore 数据库中使用 Drizzle，你应该使用 `mysql2` 驱动

Drizzle ORM 通过 `drizzle-orm/singlestore` 包原生支持 `mysql2`。

#### 步骤 1 - 安装依赖包
<Npm>
 drizzle-orm@rc mysql2
 -D drizzle-kit@rc
</Npm>

#### 步骤 2 - 初始化驱动程序并发起查询
<CodeTabs items={['mysql2', 'mysql 带配置']}>
```typescript copy
import { drizzle } from "drizzle-orm/singlestore";

const db = drizzle(process.env.DATABASE_URL);

const response = await db.select().from(...)
```
```typescript copy
import { drizzle } from "drizzle-orm/singlestore";

// 你可以指定 mysql2 连接选项中的任意属性
const db = drizzle({ connection:{ uri: process.env.DATABASE_URL }});

const response = await db.select().from(...)
```
</CodeTabs>

如果你需要提供已有的驱动：

<CodeTabs items={['客户端连接', '连接池连接']}>
  ```typescript copy
  import { drizzle } from "drizzle-orm/singlestore";
  import mysql from "mysql2/promise";

  const connection = await mysql.createConnection({
    host: "host",
    user: "user",
    database: "database",
    ...
  });

  const db = drizzle({ client: connection });
  ```
  ```typescript copy
  import { drizzle } from "drizzle-orm/singlestore";
  import mysql from "mysql2/promise";

  const poolConnection = mysql.createPool({
    host: "host",
    user: "user",
    database: "database",
    ...
  });

  const db = drizzle({ client: poolConnection });
  ```
</CodeTabs>

<Callout type="warning" emoji="⚙️">
  对于用于 DDL 迁移的内置 `migrate` 函数，我们和驱动都强烈建议你使用单一的 `client` 连接。  

  出于查询目的，请根据你的业务需求随意使用 `client` 或 `pool`。
</Callout>

#### 限制

目前，SingleStore 方言存在一组在 SingleStore 数据库侧无法工作的限制和特性：

- SingleStore 的 serial 列类型只能确保列值的唯一性。
- `ORDER BY` 和 `LIMIT` 不能链式一起使用。
- 不支持外键（可检查）。
- SingleStore 不支持 `INTERSECT ALL` 和 `EXCEPT ALL` 操作。
- [SingleStore](https://docs.singlestore.com/cloud/reference/sql-reference/procedural-sql-reference/transactions-in-stored-procedures/) 不支持嵌套事务。
- SingleStore [仅支持](https://docs.singlestore.com/cloud/getting-started-with-singlestore-helios/about-singlestore-helios/singlestore-helios-faqs/durability/) 一个 `isolationLevel`。
- 不支持 `DATE`、`TIMESTAMP` 和 `DATETIME` 中的 FSP 选项。
- 不支持关系 API，一旦 SingleStore 团队为其开发出所有必要的 API，就会实现它。
- 可能存在更多限制，因为 SingleStore 并非 100% 兼容 MySQL。
