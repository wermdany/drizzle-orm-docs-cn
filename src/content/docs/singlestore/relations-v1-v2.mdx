### API 变更
#### 与 v1 相比有哪些不同

{/* ##### Drizzle Relations schema definition */}

最大的更新之一在 **Relations Schema 定义** 部分

第一个区别是，你不再需要为每个表在不同对象中分别指定 `relations`，
然后再将它们与 schema 一起传递给 `drizzle()`。在 Relational Queries v2 中，你现在有一个专门的地方来
为你需要的所有表指定所有关系。

回调中的 `r` 参数提供了全面的自动补全
功能——包括 schema 中的所有表以及诸如 `one`、`many` 和 `through` 等函数——基本上
提供了你指定关系所需的一切。

```ts
// relations.ts
import * as schema from "./schema"
import { defineRelations } from "drizzle-orm"

export const relations = defineRelations(schema, (r) => ({
    ...
}));
```
```ts
// index.ts
import { relations } from "./relations"
import { drizzle } from "drizzle-orm/..."

const db = drizzle(process.env.DATABASE_URL, { relations })
```

##### 有什么不同？

<Callout collapsed="Schema 定义">
```ts copy
import * as p from 'drizzle-orm/pg-core';

export const users = p.pgTable('users', {
	id: p.integer().primaryKey(),
	name: p.text(),
	invitedBy: p.integer('invited_by'),
});

export const posts = p.pgTable('posts', {
	id: p.integer().primaryKey(),
	content: p.text(),
	authorId: p.integer('author_id'),
});
```
</Callout>

**在一个地方定义你所有的关系**

<Callout title="❌ v1">
```ts
import { relations } from "drizzle-orm/_relations";
import { users, posts } from './schema';

export const usersRelation = relations(users, ({ one, many }) => ({
  invitee: one(users, {
    fields: [users.invitedBy],
    references: [users.id],
  }),
  posts: many(posts),
}));

export const postsRelation = relations(posts, ({ one, many }) => ({
  author: one(users, {
    fields: [posts.authorId],
    references: [users.id],
  }),
}));
```
</Callout>

<Callout title='✅ v2'>
```ts
import { defineRelations } from "drizzle-orm";
import * as schema from "./schema";

export const relations = defineRelations(schema, (r) => ({
  users: {
    invitee: r.one.users({
      from: r.users.invitedBy,
      to: r.users.id,
    }),
    posts: r.many.posts(),
  },
  posts: {
    author: r.one.users({
      from: r.posts.authorId,
      to: r.users.id,
    }),
  },
}));
```
</Callout>

你仍然可以将其拆分到不同的 `parts` 中，并且可以让各部分大小任意

```ts
import { defineRelations, defineRelationsPart } from 'drizzle-orm';
import * as schema from "./schema";

export const relations = defineRelations(schema, (r) => ({
  users: {
    invitee: r.one.users({
      from: r.users.invitedBy,
      to: r.users.id,
    }),
    posts: r.many.posts(),
  }
}));

export const part = defineRelationsPart(schema, (r) => ({
  posts: {
    author: r.one.users({
      from: r.posts.authorId,
      to: r.users.id,
    }),
  }
}));
```

然后你可以将其提供给 db 实例

```ts
const db = drizzle(process.env.DB_URL, { relations: { ...relations, ...part } })
```

**在不使用 `one` 的情况下定义 `many`**

在 v1 中，如果你只想要关系的 `many` 一侧，你必须在另一端指定 `one` 一侧，
这使得开发者体验很差。

在 v2 中，你可以直接使用 `many` 一侧，无需任何额外步骤

<Callout title="❌ v1">
```ts
import { relations } from "drizzle-orm/_relations";
import { users, posts } from './schema';

export const usersRelation = relations(users, ({ one, many }) => ({
  posts: many(posts),
}));

export const postsRelation = relations(posts, ({ one, many }) => ({
  author: one(users, {
    fields: [posts.authorId],
    references: [users.id],
  }),
}));
```
</Callout>

<Callout title='✅ v2'>
```ts
import { defineRelations } from "drizzle-orm";
import * as schema from "./schema";

export const relations = defineRelations(schema, (r) => ({
  users: {
    posts: r.many.posts({
      from: r.users.id,
      to: r.posts.authorId,
    }),
  },
}));
```
</Callout>

**新增 `optional` 选项**

`optional: false` 在类型层面会使 `posts` 对象中的 `author` 键变为必需。
当你确定这个特定实体始终存在时，应使用它。

<Callout title="❌ v1">
在 v1 中不支持
</Callout>

<Callout title='✅ v2'>
```ts {9}
import { defineRelations } from "drizzle-orm";
import * as schema from "./schema";

export const relations = defineRelations(schema, (r) => ({
  posts: {
    author: r.one.users({
      from: r.posts.authorId,
      to: r.users.id,
      optional: false,
    }),
  },
}));
```
</Callout>

**`drizzle()` 中不再有 modes**

我们找到了一种对所有 MySQL 方言使用相同策略的方法，因此无需再指定它们

<Callout title="❌ v1">
```ts
import * as schema from './schema'

const db = drizzle(process.env.DATABASE_URL, { mode: "planetscale", schema });
// 或
const db = drizzle(process.env.DATABASE_URL, { mode: "default", schema });
```
</Callout>

<Callout title='✅ v2'>
```ts
import { relations } from './relations'

const db = drizzle(process.env.DATABASE_URL, { relations });
```
</Callout>

**`from` 和 `to` 升级**

我们将 `fields` 重命名为 `from`，将 `references` 重命名为 `to`，并且让两者都接受单个值或数组

<Callout title="❌ v1">
```ts
...
author: one(users, {
  fields: [posts.authorId],
  references: [users.id],
}),
...
```
</Callout>

<Callout title='✅ v2'>
```ts
... 
author: r.one.users({
  from: r.posts.authorId,
  to: r.users.id,
}),
...
```
```ts
... 
author: r.one.users({
  from: [r.posts.authorId],
  to: [r.users.id],
}),
...
```
</Callout>

**`relationName` -> `alias`**

<Callout title="❌ v1">
```ts {8}
import { relations } from "drizzle-orm/_relations";
import { users, posts } from './schema';

export const postsRelation = relations(posts, ({ one }) => ({
  author: one(users, {
    fields: [posts.authorId],
    references: [users.id],
	  relationName: "author_post",
  }),
}));
```
</Callout>

<Callout title='✅ v2'>
```ts {9}
import { defineRelations } from "drizzle-orm";
import * as schema from "./schema";

export const relations = defineRelations(schema, (r) => ({
  posts: {
    author: r.one.users({
      from: r.posts.authorId,
      to: r.users.id,
      alias: "author_post",
    }),
  },
}));
```
</Callout>

**`custom types` 新函数**

custom types 中新增了一个 [codec](/docs/codecs) 函数，因此你可以控制数据如何映射

你可以在[这里](/docs/custom-types#类型定义的-ts-文档)了解更多信息

<Callout title='✅ v2'>
```ts
const customBytes = customType<{
  data: Buffer;
  driverData: Buffer;
  jsonData: string;
}>({
  dataType: () => "bytea",
  codec: "bytea",
});
```

</Callout>

##### 新增了什么？

**用于多对多关系的 `through`**

以前，你需要通过中间表进行查询，然后为每个响应手动映射

现在你不需要这样做了！

<Callout collapsed='Schema'>
```ts
import * as p from "drizzle-orm/pg-core";

export const users = p.pgTable("users", {
  id: p.integer().primaryKey(),
  name: p.text(),
  verified: p.boolean().notNull(),
});

export const groups = p.pgTable("groups", {
  id: p.integer().primaryKey(),
  name: p.text(),
});

export const usersToGroups = p.pgTable(
  "users_to_groups",
  {
    userId: p
      .integer("user_id")
      .notNull()
      .references(() => users.id),
    groupId: p
      .integer("group_id")
      .notNull()
      .references(() => groups.id),
  },
  (t) => [p.primaryKey({ columns: [t.userId, t.groupId] })]
);
```
</Callout>

<Callout title="❌ v1">
```ts
export const usersRelations = relations(users, ({ many }) => ({
  usersToGroups: many(usersToGroups),
}));

export const groupsRelations = relations(groups, ({ many }) => ({
  usersToGroups: many(usersToGroups),
}));

export const usersToGroupsRelations = relations(usersToGroups, ({ one }) => ({
  group: one(groups, {
    fields: [usersToGroups.groupId],
    references: [groups.id],
  }),
  user: one(users, {
    fields: [usersToGroups.userId],
    references: [users.id],
  }),
}));
```
```ts
// 查询示例
const response = await db.query.users.findMany({
  with: {
    usersToGroups: {
      columns: {},
      with: {
        group: true,
      },
    },
  },
});
```
</Callout>

<Callout title='✅ v2'>
```ts
import * as schema from './schema';
import { defineRelations } from 'drizzle-orm';

export const relations = defineRelations(schema, (r) => ({
  users: {
    groups: r.many.groups({
      from: r.users.id.through(r.usersToGroups.userId),
      to: r.groups.id.through(r.usersToGroups.groupId),
    }),
  },
  groups: {
    participants: r.many.users(),
  },
}));
```
```ts
// 查询示例
const response = await db.query.users.findMany({
  with: {
    groups: true,
  },
});
```
</Callout>

#### 如何将关系 schema 定义从 v1 迁移到 v2

##### **选项 1**：使用 `drizzle-kit pull`

在新版本中，`drizzle-kit pull` 支持以新语法拉取 `relations.ts` 文件：

##### 步骤 1

<Npx>
drizzle-kit pull
</Npx>

#### 步骤 2 

将生成的 relations 代码从 `drizzle/relations.ts` 转移到你用于指定关系的文件中
```plaintext {4-5}
 ├ 📂 drizzle
 │ ├ 📂 meta
 │ ├ 📜 migration.sql
 │ ├ 📜 relations.ts ────────┐
 │ └ 📜 schema.ts            |
 ├ 📂 src                    │ 
 │ ├ 📂 db                   │
 │ │ ├ 📜 relations.ts <─────┘
 │ │ └ 📜 schema.ts 
 │ └ 📜 index.ts         
 └ …
```

<Callout>
`drizzle/relations.ts` 包含了对 `drizzle/schema.ts` 中所有表的导入，如下所示：
```ts
import * as schema from './schema'
```

你可能需要将此导入改为包含你所有 schema 表的文件。

如果有多个 schema 文件，你可以这样做：
```ts
import * as schema1 from './schema1'
import * as schema2 from './schema2'
...
```
</Callout>

#### 步骤 3

更改 drizzle 数据库实例的创建方式，提供 `relations` 对象而不是 `schema`

<Callout title='之前'>
```ts
import * as schema from './schema'
import { drizzle } from 'drizzle-orm/...'

const db = drizzle('<url>', { schema })
```
</Callout>

<Callout title='之后'>
```ts
// 应从 Step 2 中的文件导入
import { relations } from './relations'
import { drizzle } from 'drizzle-orm/...'

const db = drizzle('<url>', { relations })
```
</Callout>

<Callout>
如果你使用的是 MySQL 方言，只要在版本 2 中不需要，就可以从 `drizzle()` 中移除 `mode`
</Callout>

##### **选项 2**：手动迁移

如果你想手动迁移，可以查看我们的 [Drizzle Relations 章节](/docs/relations)，了解完整 API 参考以及一对一、一对多和多对多关系的示例。

##### 迁移 `orderBy` 语句

Order by 被简化为单个对象，你在其中指定列和排序方向（`asc` 或 `desc`）

<Callout title="❌ v1">
```ts
const response = db._query.users.findMany({
  orderBy: (users, { asc }) => [asc(users.id)],
});
```
</Callout>

<Callout title="✅ v2">
```ts
const response = db.query.users.findMany({
  orderBy: { id: "asc" },
});
```
</Callout>

##### 迁移 `many-to-many` 查询

Relational Queries v1 管理多对多查询的方式非常复杂。
你必须使用中间表来显式地通过它们进行查询，然后手动映射这些表，像这样：

```ts
const response = await db.query.users.findMany({
  with: {
    usersToGroups: {
      columns: {},
      with: {
        group: true,
      },
    },
  },
});
```

升级到 Relational Queries v2 后，你的多对多关系将如下所示：

```ts
import * as schema from './schema';
import { defineRelations } from 'drizzle-orm';

export const relations = defineRelations(schema, (r) => ({
  users: {
    groups: r.many.groups({
      from: r.users.id.through(r.usersToGroups.userId),
      to: r.groups.id.through(r.usersToGroups.groupId),
    }),
  },
  groups: {
    participants: r.many.users(),
  },
}));
```

当你迁移查询时，它将变成这样：

```ts
// 查询示例
const response = await db.query.users.findMany({
  with: {
    groups: true,
  },
});
```
