# `drizzle-kit check`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [在此阅读](/docs/singlestore/get-started)
- Drizzle schema 基础知识 - [在此阅读](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [在此阅读](/docs/singlestore/connect-overview)
- Drizzle 迁移基础知识 - [在此阅读](/docs/singlestore/migrations)
- Drizzle Kit [概览](/docs/singlestore/kit-overview) 和 [配置文件](/docs/singlestore/drizzle-config-file)
- `drizzle-kit generate` 命令 - [在此阅读](/docs/singlestore/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit check` 命令让你可以检查已生成的 SQL 迁移历史的一致性。

当你有多个开发者在同一项目上工作，并在不同的分支上修改数据库 schema 时，
这非常有用 - 阅读更多关于[团队迁移](/docs/singlestore/kit-migrations-for-teams)的内容。

<br/>
<hr/>
<br/>

`drizzle-kit check` 命令要求你同时指定 `dialect` 和数据库连接凭证，
你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件或 CLI 选项来提供它们

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
});
```
```shell
npx drizzle-kit check
```
</Section>
```shell
npx drizzle-kit check --dialect=singlestore
```
</CodeTabs>

### 一个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你有多个数据库阶段或多个数据库在同一项目中时，这非常有用：
<Npx>
  drizzle-kit check --config=drizzle-dev.config.ts
  drizzle-kit check --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展的配置列表
我们建议通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 文件来配置 `drizzle-kit`，
但如果需要，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中等。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。可以是 `postgresql`、`mysql`、`sqlite` 或 `singlestore` |
| `out`     |            | 迁移文件夹，默认=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit check --dialect=singlestore
drizzle-kit check --dialect=singlestore --out=./migrations-folder
</Npx>
