# `drizzle-kit migrate`
<Prerequisites>
- Drizzle 与 `drizzle-kit` 入门 - [阅读文档](/docs/singlestore/get-started)
- Drizzle schema 基础 - [阅读文档](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [阅读文档](/docs/singlestore/connect-overview)
- Drizzle 迁移基础 - [阅读文档](/docs/singlestore/migrations)
- Drizzle Kit [概览](/docs/singlestore/kit-overview) 与 [配置文件](/docs/singlestore/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读文档](/docs/singlestore/drizzle-kit-generate)
</Prerequisites>
<br/>


`drizzle-kit migrate` 让你可以应用由 [`drizzle-kit generate`](/docs/singlestore/drizzle-kit-generate) 生成的 SQL 迁移。
它旨在覆盖管理 Drizzle 迁移的 [代码优先（方案 3）](/docs/singlestore/migrations) 方式。

<Callout collapsed="底层是如何工作的？">
Drizzle Kit 的 `migrate` 命令会触发一系列事件：
1. 读取迁移文件夹并读取所有 `.sql` 迁移文件
2. 连接到数据库并从 drizzle 迁移日志表中获取记录
3. 基于之前已应用的迁移，它会决定要运行哪些新迁移
4. 运行 SQL 迁移并将已应用的迁移记录到 drizzle 迁移表中

<Section>
```plaintext
  ├ 📂 drizzle       
  │ ├ 📂 20242409125510_premium_mister_fear
  │ └ 📂 20242409135510_delicate_professor_xavie
  └ …
```
```plaintext
┌───────────────────────┐                  
│ $ drizzle-kit migrate │                  
└─┬─────────────────────┘                  
  │                                                         ┌──────────────────────────┐                                         
  └ 1. reads migration.sql files in migrations folder       │                          │
    2. fetch migration history from database -------------> │                          │
  ┌ 3. pick previously unapplied migrations <-------------- │         DATABASE         │
  └ 4. apply new migration to the database ---------------> │                          │
                                                            │                          │
                                                            └──────────────────────────┘
[✓] done!        
```
</Section>
</Callout>

`drizzle-kit migrate` 命令要求你同时指定 `dialect` 和数据库连接凭据，
你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件提供，也可以通过 CLI 选项提供

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname"
  },
});
```
```shell
npx drizzle-kit migrate
```
</Section>
```shell
npx drizzle-kit migrate --dialect=singlestore --url=mysql://user:password@host:3306/dbname
```
</CodeTabs>

### 数据库中已应用迁移的日志
运行迁移后，Drizzle Kit 会把你数据库中成功应用的迁移记录持久化保存。
它会将这些记录存储在一个名为 `__drizzle_migrations` 的迁移日志表中。

你可以通过 drizzle 配置文件自定义该日志表的**表名**：
```ts filename="drizzle.config.ts" {8-9}
export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname"
  },
  migrations: {
    table: 'my-migrations-table', // 默认为 `__drizzle_migrations`
  },
});
```

### 忽略冲突

<Callout type='warning'>
`--ignore-conflicts` 从 `drizzle-orm@1.0.0-beta.16` 起可用
</Callout>

如果你需要让 `migrate` 命令跳过可交换性检查并绕过它，可以使用 `--ignore-conflicts`。如果你遇到需要用到它的场景，
那么很有可能是 `drizzle-kit` 没有正确检查迁移，这是一个 bug。请向我们报告你的情况，以便我们修复

```shell
drizzle-kit migrate --ignore-conflicts
```

### 一个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你存在多个数据库环境、多个数据库或同一项目下的不同数据库时，这非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展示例
让我们使用 `drizzle-kit generate` 和 `drizzle-kit migrate` 命令生成 SQL 迁移并将其应用到我们的数据库

```plaintext
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 │ ├ 📜 schema.ts
 │ └ 📜 index.ts
 ├ 📜 drizzle.config.ts
 └ …
```
<CodeTabs items={["drizzle.config.ts", "src/schema.ts"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname"
  },
  migrations: {
    table: 'journal', 
  },
});
```
```ts 
import * as p from "drizzle-orm/singlestore-core";

export const users = p.singlestoreTable("users", {
  id: p.int().primaryKey().autoincrement(),
  name: p.varchar({ length: 255 }),
})
```
</CodeTabs>

现在我们运行
```shell
npx drizzle-kit generate --name=init
```
它就会生成
<Section>
```plaintext {5}
📦 <project root>
 ├ …
 ├ 📂 migrations
 │ ├ 📂 20242409125510_init
 └ …
```
```sql
-- ./drizzle/0000_init.sql

CREATE TABLE `users`(
  `id` int auto_increment primary key,
  `name` varchar(255)
)
```
</Section>

现在我们运行
```shell
npx drizzle-kit migrate
```

我们的 SQL 迁移现在就成功应用到数据库了 ✅
