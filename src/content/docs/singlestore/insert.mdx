# SQL Insert
Drizzle ORM 为你提供了最接近 SQL 的方式，将行插入数据库表中。

使用 Drizzle 插入数据极其直观且贴近 SQL。你自己看：

<Section>
```typescript copy 
await db.insert(users).values({ name: 'Andrew' });
```
```sql
insert into `users` (`name`) values ('Andrew');
```
</Section>

如果你需要某张表的插入类型，可以使用 `typeof usersTable.$inferInsert` 语法。
```typescript copy 
type NewUser = typeof users.$inferInsert;

const insertUser = async (user: NewUser) => {
  return db.insert(users).values(user);
}

const newUser: NewUser = { name: "Alef" };
await insertUser(newUser);
```

## $returningId
SingleStore 在 `INSERT` 之后不原生支持 `RETURNING`。对于 `autoincrement`（或 `serial`）类型的 `primary keys`，只有一种方式可以实现，即访问 `insertId` 和 `affectedRows` 字段。我们为你准备了一种自动化的方式，用 Drizzle 处理这类场景，并自动将所有插入的 ID 作为独立对象接收

```ts
import { boolean, int, text, singlestoreTable } from 'drizzle-orm/singlestore-core';

const usersTable = singlestoreTable('users', {
  id: int('id').primaryKey(),
  name: text('name').notNull(),
  verified: boolean('verified').notNull().default(false),
});


const result = await db.insert(usersTable).values([{ name: 'John' }, { name: 'John1' }]).$returningId();
//    ^? { id: number }[]
```

此外，使用 Drizzle 时，你可以为 `primary key` 指定 `$default` 函数，在运行时生成自定义主键。我们也会在 `$returningId()` 调用中为你返回这些生成的键

```ts
import { varchar, text, singlestoreTable } from 'drizzle-orm/singlestore-core';
import { createId } from '@paralleldrive/cuid2';

const usersTableDefFn = singlestoreTable('users_default_fn', {
  customId: varchar('id', { length: 256 }).primaryKey().$defaultFn(createId),
  name: text('name').notNull(),
});


const result = await db.insert(usersTableDefFn).values([{ name: 'John' }, { name: 'John1' }]).$returningId();
//  ^? { customId: string }[]
```

> 如果没有主键 -> 这类查询的类型将是 `{}[]`

## Upsert 与冲突
Drizzle ORM 为处理 upsert 和冲突提供了简单的接口。

### On duplicate key update
SingleStore 支持 [`ON DUPLICATE KEY UPDATE`](https://dev.mysql.com/doc/refman/8.0/en/insert-on-duplicate.html) 而不是 `ON CONFLICT` 子句。SingleStore 会根据主键和唯一索引自动确定冲突目标，并在*任意*唯一索引冲突时更新该行。

Drizzle 通过 `onDuplicateKeyUpdate` 方法支持这一点：

```typescript
// 注意，SingleStore 会根据主键和唯一索引自动确定目标
await db.insert(users)
  .values({ id: 1, name: 'John' })
  .onDuplicateKeyUpdate({ set: { name: 'John' } });
```

虽然 SingleStore 不直接支持在冲突时什么都不做，但你可以通过将任意列的值设为它自身来做空操作，从而达到相同的效果：

```typescript
import { sql } from 'drizzle-orm';

await db.insert(users)
  .values({ id: 1, name: 'John' })
  .onDuplicateKeyUpdate({ set: { id: sql`id` } });
```

## Insert into ... select

由于 SingleStore 文档遵循 MySQL 兼容的 `INSERT ... SELECT` 行为：

<Callout>
使用 INSERT ... SELECT，你可以从 SELECT 语句的结果中快速将多行插入到一张表中，而该 SELECT 可以从一张或多张表中选择数据
</Callout>

Drizzle 为所有方言支持当前语法，并且它们共享相同的语法。让我们看一些常见场景和 API 用法。
在 insert 语句中使用 select 有几种方式，你可以选择自己偏好的方法：

- 你可以在 select 函数中传入一个查询构建器。
- 你可以在回调函数中使用查询构建器。
- 你可以传入一个带有任意自定义 select 查询的 SQL 模板标签

<Tabs items={["查询构建器", "回调", "SQL 模板标签"]}>
<Tab>
<Section>
```ts
const insertedEmployees = await db
  .insert(employees)
  .select(
    db.select({ name: users.name }).from(users).where(eq(users.role, 'employee'))
  );
```
```ts
const qb = new QueryBuilder();
await db.insert(employees).select(
    qb.select({ name: users.name }).from(users).where(eq(users.role, 'employee'))
);
```
</Section>
