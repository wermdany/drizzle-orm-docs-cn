# `drizzle-kit pull`

<Prerequisites>
- Drizzle 与 `drizzle-kit` 入门 - [阅读文档](/docs/singlestore/get-started)
- Drizzle schema 基础 - [阅读文档](/docs/singlestore/sql-schema-declaration) 
- 数据库连接基础 - [阅读文档](/docs/singlestore/connect-overview) 
- Drizzle 迁移基础 - [阅读文档](/docs/singlestore/migrations) 
- Drizzle Kit [概览](/docs/singlestore/kit-overview) 与 [配置文件](/docs/singlestore/drizzle-config-file) 文档
</Prerequisites>

`drizzle-kit pull` 让你可以原样拉取（introspect，内省）现有的数据库 schema 并生成 `schema.ts` drizzle schema 文件，
它旨在覆盖 Drizzle 迁移的 [数据库优先](/docs/singlestore/migrations) 方式。

<Callout collapsed="底层是如何工作的？">
当你运行 Drizzle Kit 的 `pull` 命令时，它会：
1. 从你现有的数据库拉取数据库 schema（DDL）
2. 生成 `schema.ts` drizzle schema 文件并保存到 `out` 文件夹

<Section>
```
                                  ┌────────────────────────┐      ┌─────────────────────────┐ 
                                  │                        │ <---  CREATE TABLE "users" (
┌──────────────────────────┐      │                        │        `id` int auto_increment primary key,
│ ~ drizzle-kit pull       │      │                        │        `name` varchar(255),
└─┬────────────────────────┘      │        DATABASE        │        `email` varchar(255) unique
  │                               │                        │       );
  └ Pull datatabase schema -----> │                        │
  ┌ Generate Drizzle       <----- │                        │
  │ schema TypeScript file        └────────────────────────┘
  │
  v
```
```typescript
import * as p from "drizzle-orm/singlestore-core";

export const users = p.singlestoreTable("users", {
  id: p.int().primaryKey().autoincrement(),
  name: p.varchar({ length: 255 }),
  email: p.varchar({ length: 255 }).unique(), 
};
```
</Section>
</Callout>

如果你需要在 TypeScript 项目之外管理数据库 schema，或者你使用的数据库由其他人管理，这是一个很好的方式。

<br/>
<hr/>
<br/>

`drizzle-kit pull` 要求你指定 `dialect`，以及数据库连接 `url` 或 `user:password@host:port/db` 参数，
你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件提供，也可以通过 CLI 选项提供：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },
});
```
```shell
npx drizzle-kit pull
```
</Section>

```shell
npx drizzle-kit pull --dialect=singlestore --url=mysql://user:password@host:3306/dbname
```
</CodeTabs>

### 一个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你存在多个数据库环境、多个数据库或同一项目下的不同数据库时，这非常有用：

<Npx>
  drizzle-kit pull --config=drizzle-dev.config.ts
  drizzle-kit pull --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 指定数据库驱动
Drizzle Kit 不附带预打包的数据库驱动，
它会基于 `dialect: "singlestore"` 自动从你当前项目中挑选一个可用的 SingleStore 驱动 - [查看讨论](https://github.com/drizzle-team/drizzle-orm/discussions/2203)。

SingleStore 使用与 MySQL 兼容的连接参数，因此通常你只需要提供 `dbCredentials`。

### 初始拉取

<Callout type='error'>
该功能在 `1.0.0-beta.2` 及更高版本中可用。
</Callout>

<Npm>
drizzle-orm@rc
drizzle-kit@rc -D
</Npm>

<br/>

你可以使用 `--init` 标志将拉取的 schema 标记为数据库中已应用的迁移，
这样后续所有迁移都会与初始迁移进行差异比对

```shell
npx drizzle-kit push --init
```

### 包含表
默认情况下，`drizzle-kit pull` 会内省所有 SingleStore 表。
你可以通过 `tablesFilter` 配置表列表。

|                |                                                                                               |
| :------------- | :-------------------------------------------------------------------------------------------- |
| `tablesFilter` | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认为 `"*"` |
<br/>

让我们配置 drizzle-kit 以内省已连接 SingleStore 数据库中的**所有表**。

<Section>
```ts filename="drizzle.config.ts" {8}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit pull
```
</Section>

### 扩展的配置列表
我们推荐通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 文件来配置 `drizzle-kit`，
但如果需要（例如在 CI/CD 流水线等场景中），你也可以通过 CLI 提供所有配置选项。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，取值为 <Dialects/> 之一                                        |
| `out`               |            | 迁移输出文件夹路径，默认为 `./drizzle`                                     |
| `url`               |            | 数据库连接字符串                                                          |
| `user`              |            | 数据库用户                                                                |
| `password`          |            | 数据库密码                                                                |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名称                                                                |
| `config`            |            | 配置文件路径，默认为 `drizzle.config.ts`                                  |
| `introspect-casing` |            | 列、表等中 JS 键的生成策略，`preserve` `camel`                            |
| `tablesFilter`      |            | 表名过滤器                                                                |

<Npx>
drizzle-kit pull --dialect=singlestore --url=mysql://user:password@host:3306/dbname
drizzle-kit pull --dialect=singlestore --tablesFilter='user*' url=mysql://user:password@host:3306/dbname
</Npx>
