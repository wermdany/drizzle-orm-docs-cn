Drizzle Kit 允许你在 `TypeScript` 或 `JavaScript` 配置文件中声明配置选项。

<Section>
```plaintext {5}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
<CodeTabs items={["drizzle.config.ts", "drizzle.config.js"]}>
<CodeTab>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
<CodeTab>
```js
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
</CodeTabs>
</Section>

扩展配置文件的示例
```ts collapsable
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "singlestore",
  schema: "./src/schema.ts",

  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },

  introspect: {
    casing: "camel",
  },

  migrations: {
    prefix: "timestamp",
    table: "__drizzle_migrations__",
  },

  breakpoints: true,
  strict: true,
  verbose: true,
});
```

### 多个配置文件
你可以在项目中拥有多个配置文件，当你有多个数据库阶段、多个数据库，或同一项目中有不同数据库时，这非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 迁移文件夹
`out` 参数让你可以定义迁移所在的文件夹，它是可选的，默认是 `drizzle`。
这非常有用，因为你可以在同一项目中为不同的数据库拥有许多独立的 schema，
并为它们使用不同的迁移文件夹。
  
迁移文件夹包含带有 `.sql` 迁移文件的文件夹，供 `drizzle-kit` 使用

<Section>
```plaintext {3}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ ├ 📜 user.ts 
 │ ├ 📜 post.ts 
 │ └ 📜 comment.ts 
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
```ts {5}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore", // "mysql" | "sqlite" | "postgresql" | "turso" | "singlestore" | "mssql"
  schema: "./src/schema/*",
  out: "./drizzle",
});
```
</Section>

### `driver`
<rem025/>

SingleStore 使用与 MySQL 兼容的连接参数，因此你通常不需要单独的 `driver` 选项。

|               |                      |
| :------------ | :-----------------   |
| 类型          | --                    |
| 默认值       | --                    |
| 命令      | `migrate` `push` `pull`   |

### `migrations`
<rem025/>

运行 `drizzle-kit migrate` 时——drizzle 会在数据库中一个名为 `__drizzle_migrations` 的日志表里
记录成功应用的迁移。

`migrations` 配置选项让你可以更改迁移日志 `table` 的名称。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `{ table: string }` |
| 默认值       | `{ table: "__drizzle_migrations" }`                    |
| 命令      | `migrate`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  migrations: {
    table: 'my-migrations-table', // 默认是 `__drizzle_migrations`
  },
});
```

### `tablesFilter`
<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/singlestore/goodies#多项目-schema)。
</Callout>
<rem025/>
`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有表。
你可以通过 `tablesFilter` 配置表的列表。

`tablesFilter` 选项让你可以指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值       | --                    |
| 命令      | `generate` `push` `pull`   |

<rem025/>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  tablesFilter: ["users", "posts", "project1_*"],
});
```

### `strict`
<rem025/>

在运行 `drizzle-kit push` 命令时，提示确认执行所打印的 SQL 语句。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `false`                    |
| 命令      | `push`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "singlestore",
  strict: false,
});
```

### `verbose`
<rem025/>

在 `drizzle-kit push` 命令执行期间打印所有 SQL 语句。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `true`                    |
| 命令      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "singlestore",
  verbose: false,
});
```

### `breakpoints`
<rem025/>

Drizzle Kit 会自动将 `--> statement-breakpoint` 嵌入到生成的 SQL 迁移文件中，
这对于那些不支持在一个事务中执行多条 DDL 变更语句的数据库（MySQL 和 SQLite）是必要的。

`breakpoints` 选项标志让你可以开启或关闭它

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `true`                    |
| 命令      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "singlestore",
  breakpoints: false,
});
```
