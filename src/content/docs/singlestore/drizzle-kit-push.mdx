# `drizzle-kit push`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/singlestore/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/singlestore/sql-schema-declaration) 
- 数据库连接基础 - [阅读此处](/docs/singlestore/connect-overview) 
- Drizzle 迁移基础 - [阅读此处](/docs/singlestore/migrations) 
- Drizzle Kit [概览](/docs/singlestore/kit-overview)和[配置文件](/docs/singlestore/drizzle-config-file)文档
</Prerequisites>


`drizzle-kit push` 让你可以真正地把 schema 以及后续的 schema 变更直接推送到数据库，同时省略 SQL 文件的生成，它专为覆盖 Drizzle 迁移的[代码优先](/docs/singlestore/migrations)方式而设计。

<Callout collapsed="底层是如何工作的？">
当你运行 Drizzle Kit `push` 命令时，它会：
1. 读取你的 Drizzle schema 文件，并组合出一份 schema 的 json 快照
2. 拉取（introspect）数据库 schema 
3. 基于两者之间的差异生成 SQL 迁移
4. 将 SQL 迁移应用到数据库

<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/singlestore-core";

export const users = p.singlestoreTable("users", {
  id: p.int().primaryKey().autoincrement(),
  name: p.varchar({ length: 255 }),
};
```
```
┌─────────────────────┐                  
│ ~ drizzle-kit push  │                  
└─┬───────────────────┘                  
  │                                           ┌──────────────────────────┐
  └ Pull current datatabase schema ---------> │                          │
                                              │                          │
  ┌ Generate alternations based on diff <---- │         DATABASE         │
  │                                           │                          │
  └ Apply migrations to the database -------> │                          │
                                       │      └──────────────────────────┘
                                       │
  ┌────────────────────────────────────┴────────────────┐
   create table users(`id` int auto_increment primary key, `name` varchar(255));
```
</Section>
</Callout>

这是快速原型开发的最佳方式，我们已经看到许多团队和独立开发者成功地将其作为生产应用中的主要迁移流程。
它与蓝绿部署策略以及像 [Planetscale](https://planetscale.com)、[Neon](https://neon.tech)、[Turso](https://turso.tech/drizzle) 等 serverless 数据库配合得极为出色。

`drizzle-kit push` 要求你指定 `dialect`、`schema` 文件的路径，以及数据库连接 `url` 或 `user:password@host:port/db` 参数，你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件或 CLI 选项来提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },
});
```
```shell
npx drizzle-kit push
```
</Section>

```shell
npx drizzle-kit push --dialect=singlestore --schema=./src/schema.ts --url=mysql://user:password@host:3306/dbname
```

</CodeTabs>

### schema 文件路径

你可以只有一个 `schema.ts` 文件，也可以有任意多个分布在项目各处的 schema 文件。
Drizzle Kit 要求你通过 `schema` 配置项以 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的形式指定它们的路径。

### 一个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你拥有多个数据库阶段、多个数据库或同一项目上的不同数据库时，这非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.config.ts
  drizzle-kit push --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 指定数据库驱动
Drizzle Kit 不附带预先打包的数据库驱动，
它会根据 `dialect: "singlestore"` 自动从你当前项目中挑选一个可用的 SingleStore 驱动 - [参见讨论](https://github.com/drizzle-team/drizzle-orm/discussions/2203)。

SingleStore 使用与 MySQL 兼容的连接参数，因此通常你只需要提供 `dbCredentials`。

### 包含表
`drizzle-kit push` 默认会管理所有 SingleStore 表。
你可以通过 `tablesFilter` 配置表的列表。

|                |                                                                                               |
| :------------- | :-------------------------------------------------------------------------------------------- |
| `tablesFilter` | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认值为 `"*"` |
<br/>

让我们配置 drizzle-kit 以操作已连接的 SingleStore 数据库中的**所有表**。

<Section>
```ts filename="drizzle.config.ts" {9}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit push
```
</Section>

### 扩展的配置列表

`drizzle-kit push` 有一组仅限 CLI 的选项

<rem025/>

|           |                                                          |
| :-------- | :---------------------------------------------------     |
| `verbose` | 在执行前打印所有 SQL 语句              |
| `strict`  | 在执行 SQL 语句前始终询问批准  |
| `force`   | 自动接受所有数据丢失语句                     |
<br/>
<Npx>
drizzle-kit push --strict --verbose --force
</Npx>

<br/>
<hr/>
<br/>
我们推荐通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 文件来配置 `drizzle-kit`，
不过在必要时，例如在 CI/CD 流水线等场景中，你也可以通过 CLI 提供所有配置选项。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，<Dialects/> 之一                                      |
| `schema`            | `required` | 指向 typescript schema 文件或包含多个 schema 文件的文件夹的路径 |
| `tablesFilter`      |            | 表名过滤器                                                         |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                         |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名称                                                             |
| `config`            |            | 配置文件路径，默认值=`drizzle.config.ts`                             |

<Npx>
drizzle-kit push dialect=singlestore schema=src/schema.ts url=mysql://user:password@host:3306/dbname
drizzle-kit push dialect=singlestore schema=src/schema.ts --tablesFilter='user*' url=mysql://user:password@host:3306/dbname
</Npx>
