## 类型 API
要从表 schema 中检索用于 `select` 和 `insert` 查询的类型，你可以使用我们的类型助手。

```ts
import { int, text, singlestoreTable } from 'drizzle-orm/singlestore-core';
import { type InferSelectModel, type InferInsertModel } from 'drizzle-orm'

const users = singlestoreTable('users', {
  id: int('id').primaryKey(),
  name: text('name').notNull(),
});

type SelectUser = typeof users.$inferSelect;
type InsertUser = typeof users.$inferInsert;
// 或者
type SelectUser = typeof users._.$inferSelect;
type InsertUser = typeof users._.$inferInsert;
// 或者
type SelectUser = InferSelectModel<typeof users>;
type InsertUser = InferInsertModel<typeof users>;
```


## 日志记录
要启用默认的查询日志记录，只需向 `drizzle` 初始化函数传入 `{ logger: true }`：
```typescript copy
import { drizzle } from 'drizzle-orm/...'; // 因驱动而异

const db = drizzle({ logger: true });
```

你可以通过创建一个 `DefaultLogger` 实例并为其提供自定义 `writer` 来更改日志目的地：
```typescript copy
import { DefaultLogger, LogWriter } from 'drizzle-orm/logger';
import { drizzle } from 'drizzle-orm/...'; // 因驱动而异

class MyLogWriter implements LogWriter {
  write(message: string) {
    // 写入文件、stdout 等。
  }
}

const logger = new DefaultLogger({ writer: new MyLogWriter() });
const db = drizzle({ logger });
```

你也可以创建自定义 logger：
```typescript copy
import { Logger } from 'drizzle-orm/logger';
import { drizzle } from 'drizzle-orm/...'; // 因驱动而异

class MyLogger implements Logger {
  logQuery(query: string, params: unknown[]): void {
    console.log({ query, params });
  }
}

const db = drizzle({ logger: new MyLogger() });
```


## 多项目 schema
**Table creator** API 让你可以定义自定义表名。  
当你需要在一个数据库中保存不同项目的 schema 时，它非常有用。

```ts {3}
import { int, text, singlestoreTableCreator } from 'drizzle-orm/singlestore-core';

const singlestoreTable = singlestoreTableCreator((name) => `project1_${name}`);

const users = singlestoreTable('users', {
  id: int('id').primaryKey(),
  name: text('name').notNull(),
});
```
```ts {10}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./src/schema/*",
  out: "./drizzle",
  dialect: "singlestore", 
  dbCredentials: {
    url: process.env.DATABASE_URL,
  }
  tablesFilter: ["project1_*"],
});
```

你可以应用多个 `or` 过滤器：
```ts
tablesFilter: ["project1_*", "project2_*"]
```


## 打印 SQL 查询
你可以使用 `db` 实例或通过 **[`standalone query builder`](#独立查询构建器)** 打印 SQL 查询。
```typescript copy
const query = db
  .select({ id: users.id, name: users.name })
  .from(users)
  .groupBy(users.id)
  .toSQL();
// 查询：
{
  sql: 'select `id`, `name` from `users` group by `users`.`id`',
  params: [],
}
```

## 原生 SQL 查询执行
如果你有一些复杂的查询要执行，而 `drizzle-orm` 目前还无法处理它们，
你可以使用 `db.execute` 方法来执行原始的 `parametrized`（参数化）查询。

```typescript copy
import { ..., SingleStoreRawQueryResult } from "drizzle-orm/singlestore";

const statement = sql`select * from ${users} where ${users.id} = ${userId}`;
const res: SingleStoreRawQueryResult = await db.execute(statement);
```


## 独立查询构建器
Drizzle ORM 提供了一个独立查询构建器，让你无需创建数据库实例即可构建查询并获取生成的 SQL。
```typescript copy
import { QueryBuilder } from 'drizzle-orm/singlestore-core';

const qb = new QueryBuilder();

const query = qb.select().from(users).where(eq(users.name, 'Dan'));
const { sql, params } = query.toSQL();
```

## 获取带类型的列
你可以获取一个类型化的列映射，
当你需要在查询时省略某些列时非常有用。

<Callout type='warning'>
`getColumns` 从 `drizzle-orm@1.0.0-beta.2` 开始可用（阅读更多 [此处](/docs/singlestore/upgrade-v1)）

如果你使用的是 1 之前的版本（如 `0.45.1`），那么请使用 `getTableColumns`
</Callout>


<br/>

<CodeTabs items={["index.ts", "schema.ts"]}>
  ```ts
  import { getColumns } from "drizzle-orm";
  import { user } from "./schema";

  const { password, role, ...rest } = getColumns(user);

  await db.select({ ...rest }).from(users);
  ```
  ```ts
  import { int, text, singlestoreTable } from "drizzle-orm/singlestore-core";

  export const user = singlestoreTable("user", {
    id: int("id").primaryKey().autoincrement(),
    name: text("name"),
    email: text("email"),
    password: text("password"),
    role: text("role").$type<"admin" | "customer">(),
  });
  ```
</CodeTabs>

## 获取表信息
```ts copy
import { getTableConfig, singlestoreTable } from 'drizzle-orm/singlestore-core';

export const table = singlestoreTable(...);

const {
  columns,
  indexes,
  checks,
  primaryKeys,
  name,
  schema,
} = getTableConfig(table);
```

## 比较对象类型（instanceof 的替代方案）

你可以使用 `is()` 函数检查某个对象是否属于特定的 Drizzle 类型。
你可以将其与 Drizzle 中任何可用的类型一起使用。

<Callout type="warning" emoji="⭐️">
  你应该始终使用 `is()` 而不是 `instanceof`
</Callout>

**几个示例**
```ts
import { Column, is } from 'drizzle-orm';

if (is(value, Column)) {
  // value 的类型被收窄为 Column
}
```

### Mock 驱动
该 API 是不明确的 `drizzle({} as any)` API 的后继者，我们曾在 Drizzle 测试内部使用后者，很少推荐外部开发者使用。

我们决定构建并公开一个合适的 API，现在每个 `drizzle` 驱动都有 `drizzle.mock()`：
```ts
import { drizzle } from "drizzle-orm/...";

const db = drizzle.mock();
```

如有需要，你可以为类型提供 schema
```ts
import { drizzle } from "drizzle-orm/...";
import * as schema from "./schema"

const db = drizzle.mock({ schema });
```
