# Drizzle 查询

<Callout type='error'>
本页介绍的是 drizzle `1.0.0-beta.1` 及更高版本中可用的概念。
</Callout>

<Npm>
drizzle-orm@rc
drizzle-kit@rc -D
</Npm>

<br/>

Drizzle ORM 旨在成为构建在 SQL 之上的轻量类型化层。
我们相信我们已经设计出了从 TypeScript 操作 SQL 数据库的最佳方式，而现在是时候让它变得更好了。
  
关系查询旨在为你提供出色的开发体验，用于从 SQL 数据库查询
嵌套的关系数据，避免多次 join 和复杂的数据映射。

它是对现有 schema 定义和查询构建器的扩展。
你可以根据自身需求选择是否启用它。
我们确保你既能拥有业界一流的开发体验，也能拥有出色的性能。

关系查询是 Drizzle 原有 **[查询构建器](/docs/singlestore/select)** 的扩展。
你需要在初始化 `drizzle()` 时从你的 schema 文件中提供所有的 `tables` 和 `relations`，
然后直接使用 `db.query` API。
<Callout type="info" emoji="ℹ️">
	`drizzle` 的导入路径取决于你正在使用的 **[数据库驱动](/docs/singlestore/connect-overview)**。
</Callout>

```typescript copy
import { type AnyMySqlColumn, boolean, int, singlestoreTable, primaryKey, text, timestamp } from 'drizzle-orm/singlestore-core';

export const users = singlestoreTable('users', {
	id: int().primaryKey().autoincrement(),
	name: text().notNull(),
	invitedBy: int('invited_by').references((): AnyMySqlColumn => users.id),
});

export const groups = singlestoreTable('groups', {
	id: int().primaryKey().autoincrement(),
	name: text().notNull(),
	description: text(),
});

export const usersToGroups = singlestoreTable('users_to_groups', {
	id: int().primaryKey().autoincrement(),
	userId: int('user_id').notNull().references(() => users.id),
	groupId: int('group_id').notNull().references(() => groups.id),
}, (t) => [
	primaryKey(t.userId, t.groupId)
]);

export const posts = singlestoreTable('posts', {
	id: int().primaryKey().autoincrement(),
	content: text().notNull(),
	authorId: int('author_id').references(() => users.id),
	createdAt: timestamp('created_at').notNull().defaultNow(),
});

export const comments = singlestoreTable('comments', {
	id: int().primaryKey().autoincrement(),
	content: text().notNull(),
	creator: int().references(() => users.id),
	postId: int('post_id').references(() => posts.id),
	createdAt: timestamp('created_at').notNull().defaultNow(),
});

export const commentLikes = singlestoreTable('comment_likes', {
	id: int().primaryKey().autoincrement(),
	creator: int().references(() => users.id),
	commentId: int('comment_id').references(() => comments.id),
	createdAt: timestamp('created_at').notNull().defaultNow(),
});
```
```typescript copy
import { defineRelations } from 'drizzle-orm';
import * as schema from './schema';

export const relations = defineRelations(schema, (r) => ({
    users: {
      invitee: r.one.users({
        from: r.users.invitedBy,
        to: r.users.id,
      }),
      groups: r.many.groups({
        from: r.users.id.through(r.usersToGroups.userId),
        to: r.groups.id.through(r.usersToGroups.groupId),
      }),
      posts: r.many.posts(),
    },
    groups: {
      users: r.many.users(),
    },
    posts: {
      author: r.one.users({
        from: r.posts.authorId,
        to: r.users.id,
      }),
      comments: r.many.comments(),
    },
    comments: {
      post: r.one.posts({
        from: r.comments.postId,
        to: r.posts.id,
      }),
      author: r.one.users({
        from: r.comments.creator,
        to: r.users.id,
      }),
      likes: r.many.commentLikes(),
    },
    commentLikes: {
      comment: r.one.comments({
        from: r.commentLikes.commentId,
        to: r.comments.id,
      }),
      author: r.one.users({
        from: r.commentLikes.creator,
        to: r.users.id,
      }),
    },
  })
);
```

### 包含关系

`With` 操作符让你可以组合来自多个关联表的数据，并正确地聚合结果。

**获取所有带评论的文章：**
```typescript copy
const posts = await db.query.posts.findMany({
	with: {
		comments: true,
	},
});
```

**获取第一条带评论的文章：**
```typescript copy
const post = await db.query.posts.findFirst({
	with: {
		comments: true,
	},
});
```

你可以按需任意链式嵌套 with 语句。
对于任何嵌套的 `with` 查询，Drizzle 都会使用 [Core Type API](/docs/singlestore/goodies#类型-api) 推断类型。
  
**获取所有带文章的用户。每篇文章应包含一个评论列表：**
```typescript copy
const users = await db.query.users.findMany({
	with: {
		posts: {
			with: {
				comments: true,
			},
		},
	},
});
```

### 部分字段 select
`columns` 参数让你可以包含或排除想从数据库中获取的列。

<Callout type="info" emoji="ℹ️">
  Drizzle 在查询层面执行部分查询，不会从数据库传输额外数据。

  请记住，**Drizzle 只会输出单条 SQL 语句。**
</Callout>

**获取所有文章，只包含 `id`、`content`，并包含 `comments`：**
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		id: true,
		content: true,
	},
	with: {
		comments: true,
	}
});
```

**获取所有不包含 `content` 的文章：**
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		content: false,
	},
});
```

<Callout type="info" emoji="ℹ️">
当同时存在 `true` 和 `false` 的查询选项时，所有 `false` 选项都会被忽略。
</Callout>

如果你包含了 `name` 字段并排除了 `id` 字段，那么排除 `id` 是多余的，
因为除 `name` 之外的所有字段本来都会被排除。
  
**在同一条查询中排除并包含字段：**
<Section>
```typescript copy
const users = await db.query.users.findMany({
	columns: {
		name: true,
		id: false //ignored
	},
});
```
```ts
// result type
const users: {
	name: string;
};
```
</Section>

**只包含嵌套关系中的列：**
<Section>
```typescript copy
const res = await db.query.users.findMany({
	columns: {},
	with: {
		posts: true
	}
});
```
```ts
// result type
const res: {
	posts: {
		id: number,
		text: string
	}
}[];
```
</Section>

### 嵌套部分字段 select
就像 **[`partial select`](#partial-select)** 一样，你可以包含或排除嵌套关系的列：
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		id: true,
		content: true,
	},
	with: {
		comments: {
			columns: {
				authorId: false
			}
		}

```

### Select 过滤器
就像我们类似 SQL 的查询构建器一样，
关系查询 API 让你可以使用我们的 **[`operators`](/docs/singlestore/operators)** 列表来定义过滤器和条件。
  
你可以从 `drizzle-orm` 中导入它们，或者使用回调语法：
<Section>
```typescript copy
const users = await db.query.users.findMany({
	where: {
		id: 1
	}
});
```
```sql
select * from users where id = 1
```
</Section>

查找 `id=1` 的文章，以及在该日期之前创建的评论：
```typescript copy
await db.query.posts.findMany({
  where: {
    id: 1,
  },
  with: {
    comments: {
      where: {
        createdAt: { lt: new Date() },
      },
    },
  },
});
```

**所有过滤器操作符的列表**
```ts
where: {
    OR: [],
    AND: [],
    NOT: {},
    RAW: (table) => sql`${table.id} = 1`,

    // filter by relations
    [relation]: {},

	  // filter by columns
    [column]: {
      OR: [],
      AND: [],
      NOT: {},
      eq: 1,
      ne: 1,
      gt: 1,
      gte: 1,
      lt: 1,
      lte: 1,
      in: [1],
      notIn: [1],
      like: "",
      notLike: "",
      isNull: true,
      isNotNull: true,
    },
},
```

```ts
import { int, json, singlestoreTable, text, timestamp } from "drizzle-orm/singlestore-core";

export const users = singlestoreTable("users", {
  id: int("id").primaryKey().autoincrement(),
  name: text("name"),
  email: text("email").notNull(),
  age: int("age"),
  createdAt: timestamp("created_at").defaultNow(),
  lastLogin: timestamp("last_login"),
  subscriptionEnd: timestamp("subscription_end"),
  lastActivity: timestamp("last_activity"),
  preferences: json("preferences"),        // JSON column for user settings/preferences
  interests: text("interests"),            // Comma-separated user interests
});
```
```ts
const response = db.query.users.findMany({
  where: {
    AND: [
      {
        OR: [
          { RAW: (table) => sql`LOWER(${table.name}) LIKE 'john%'` },
          { name: { like: "jane%" } },
        ],
      },
      {
        OR: [
          { RAW: (table) => sql`JSON_EXTRACT(${table.preferences}, '$.theme') = '"dark"'` },
          { RAW: (table) => sql`JSON_EXTRACT(${table.preferences}, '$.theme') IS NULL` },
        ],
      },
      { RAW: (table) => sql`${table.age} BETWEEN 25 AND 35` },
    ],
  },
});
```

```sql
`d0`.`email` as `email`, `d0`.`age` as `age`, 
`d0`.`created_at` as `createdAt`, `d0`.`last_login` as `lastLogin`, 
`d0`.`subscription_end` as `subscriptionEnd`, `d0`.`last_activity` as `lastActivity`, 
`d0`.`preferences` as `preferences`, `d0`.`interests` as `interests` 
from `users` as `d0` 
where ((LOWER(`d0`.`name`) LIKE 'john%' or `d0`.`name` like 'jane%')

```

### 关系过滤器

借助 Drizzle Relations，你不仅可以按正在查询的表进行过滤，还可以按查询中包含的任何表进行过滤。

**示例：** 获取所有 ID>10 且至少有一篇内容以 "M" 开头的文章的用户
```ts
const usersWithPosts = await db.query.usersTable.findMany({
  where: {
    id: {
      gt: 10
    },
    posts: {
      content: {
        like: 'M%'
      }
    }
  },
});
```

**示例：** 获取所有带文章的用户，仅限至少有 1 篇文章的用户
```ts
const response = db.query.users.findMany({
  with: {
    posts: true,
  },
  where: {
    posts: true,
  },
});
```

### Limit 与 Offset
Drizzle ORM 为查询以及嵌套实体提供了 `limit` 和 `offset` API。
  
**查找 5 篇文章：**
```typescript copy
await db.query.posts.findMany({
	limit: 5,
});
```

**查找文章并最多获取 3 条评论：**
```typescript copy
await db.query.posts.findMany({
	with: {
		comments: {
			limit: 3,
		},
	},
});
```

<Callout type="warning" emoji="⚠️">
  `offset` 现在也可以在 with 子表中使用了！
</Callout>
```typescript 
await db.query.posts.findMany({
	limit: 5,
	offset: 2, // correct ✅
	with: {
		comments: {
			offset: 3, // correct ✅
			limit: 3,
		},
	},
});
```

查找文章，并获取从第 5 篇到第 10 篇文章的评论：
```typescript copy
await db.query.posts.findMany({
	with: {
		comments: true,
	},
  limit: 5,
  offset: 5,
});
```

### Order By
Drizzle 在关系查询构建器中提供了用于排序的 API。
  
你可以使用相同的排序 **[core API](/docs/singlestore/select#order-by)**，或者使用
回调中的 `order by` 操作符，无需任何导入。
  
<Callout title='important'>
当你在同一张表中使用多个 `orderBy` 语句时，它们会按照你添加它们的顺序被包含在查询中
</Callout>

<Section>
```typescript copy
await db.query.posts.findMany({
  orderBy: {
    id: "asc",
  },
});
```
</Section>

**按 `asc` + `desc` 排序：**
```typescript copy
  await db.query.posts.findMany({
    orderBy: { id: "asc" },
    with: {
      comments: {
        orderBy: { id: "desc" },
      },
    },
  });
```

你也可以在 order by 语句中使用自定义 `sql`：

```typescript copy
await db.query.posts.findMany({
  orderBy: (t) => sql`${t.id} asc`,
  with: {
    comments: {
      orderBy: (t, { desc }) => desc(t.id),
    },
  },
});
```

### 包含自定义字段
关系查询 API 让你可以添加自定义的额外字段。
当你需要获取数据并对其应用额外函数时，这很有用。
<Callout type="warning" emoji="⚠️">
	截至目前，`extras` 中不支持聚合，请改用 **[`core queries`](/docs/singlestore/select)**。
</Callout>

<Section>
```typescript copy {5}
import { sql } from 'drizzle-orm';

await db.query.users.findMany({
	extras: {
		loweredName: sql`lower(${users.name})`,
	},
})
```
```typescript copy {3}
await db.query.users.findMany({
	extras: {
		loweredName: (users, { sql }) => sql`lower(${users.name})`,
	},
})
```
</Section>

`lowerName` 作为键会被包含到返回对象的所有字段中。

<Callout type="warning" emoji="⚠️">
  如果你为任何 extras 字段指定 `.as("<alias>")`，drizzle 会忽略它
</Callout>

要检索所有带分组的用户，但额外包含 fullName 字段（它是 firstName 和 lastName 的拼接），
你可以使用 Drizzle 关系查询构建器执行以下查询。

<Section>
```typescript copy
const res = await db.query.users.findMany({
	extras: {
		fullName: (users, { sql }) => sql<string>`concat(${users.name}, " ", ${users.name})`,
	},
	with: {
		usersToGroups: {
			with: {
				group: true,
			},
		},
	},
});
```
```ts
// result type
const res: {
	id: number;
	name: string;
	verified: boolean;
	invitedBy: number | null;
	fullName: string;
	usersToGroups: {
			group: {
					id: number;
					name: string;
					description: string | null;
			};
	}[];
}[];
```
</Section>

要检索所有带评论的文章，并添加一个额外字段来计算文章内容的大小以及每条评论内容的大小：
<Section>
```typescript copy
const res = await db.query.posts.findMany({
	extras: {
		contentLength: (table, { sql }) => sql<number>`length(${table.content})`,
	},
	with: {
		comments: {
			extras: {
				commentSize: (table, { sql }) => sql<number>`length(${table.content})`,
			},
		},
	},
});
```
```ts
// result type
const res: {
	id: number;
	createdAt: Date;
	content: string;
	authorId: number | null;
	contentLength: number;
	comments: {
			id: number;
```

### 包含子查询

你还可以在关系查询中使用子查询，以利用自定义 SQL 语法的强大能力

**获取带文章的用户，以及每个用户的文章总数**
```ts
import { posts } from './schema';
import { eq } from 'drizzle-orm';

await db.query.users.findMany({
  with: {
    posts: true
  },
  extras: {
    totalPostsCount: (table) => db.$count(posts, eq(posts.authorId, table.id)),
  }
});
```
```sql
select `d0`.`id` as `id`, `d0`.`name` as `name`,
((select coalesce(json_arrayagg(json_object('id', `d1`.`id`, 'content', `d1`.`content`, 'authorId', `d1`.`author_id`)), json_array())
  from `posts` as `d1` where `d0`.`id` = `d1`.`author_id`)) as `posts`,
((select count(*) from `posts` where `posts`.`author_id` = `d0`.`id`)) as `totalPostsCount`
from `users` as `d0`
```

### 预处理语句
预编译语句旨在大幅提升查询性能 —— [参见此处。](/docs/singlestore/perf-queries)

在本节中，你将学习如何定义占位符，并使用 Drizzle 关系查询构建器执行预编译语句。
