## 新功能/辅助函数

### 为所有方言中的所有查询构建器提供详细的 JSDoc

你现在可以在开发和直接在 IDE 中使用 JSDoc 时访问更多信息、提示、文档链接等。以前我们只为过滤表达式提供了这些，但现在你可以看到 Drizzle 查询构建器所有部分的这些内容

### 用于 SQL 聚合函数的新辅助函数

> 请记住，聚合函数通常与 SELECT 语句的 GROUP BY 子句一起使用。因此，如果你在一个查询中同时使用聚合函数和其它列进行查询，
请务必使用 `.groupBy` 子句

以下是函数列表以及使用 `sql` 模板的等价写法：

count

```ts copy {1,2,6,9}
await db.select({ value: count() }).from(users);
await db.select({ value: count(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`count('*'))`.mapWith(Number) 
}).from(users);
await db.select({ 
  value: sql`count(${users.id})`.mapWith(Number) 
}).from(users);
```

countDistinct

```ts copy {1,5}
await db.select({ value: countDistinct(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`count(${users.id})`.mapWith(Number) 
}).from(users);
```

avg

```ts copy {1,5}
await db.select({ value: avg(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`avg(${users.id})`.mapWith(String) 
}).from(users);
```

avgDistinct

```ts copy {1,5}
await db.select({ value: avgDistinct(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`avg(distinct ${users.id})`.mapWith(String) 
}).from(users);
```

sum

```ts copy {1,5}
await db.select({ value: sum(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`sum(${users.id})`.mapWith(String) 
}).from(users);
```

sumDistinct

```ts copy {1,5}
await db.select({ value: sumDistinct(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`sum(distinct ${users.id})`.mapWith(String) 
}).from(users);
```

max

```ts copy {1,5}
await db.select({ value: max(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`max(${expression})`.mapWith(users.id) 
}).from(users);
```

min

```ts copy {1,5}
await db.select({ value: min(users.id) }).from(users);

// 等价于
await db.select({ 
  value: sql`min(${users.id})`.mapWith(users.id) 
}).from(users);
```

要查找更多信息，请查看文档：[聚合辅助函数](/docs/select#聚合辅助函数)

## 新包

### Drizzle ESLint 插件

对于无法对特定场景执行类型检查的情况，或者虽然可以执行但错误信息难以理解的情况，我们决定创建一个包含推荐规则的 ESLint 包。该包旨在帮助开发人员在开发过程中处理关键场景。更多信息请查看[文档](/docs/eslint-plugin)。

### 安装

<Npm>
eslint eslint-plugin-drizzle
</Npm>

你可以安装这些包以在你的 IDE 中获得 typescript 支持

<Npm>
@typescript-eslint/eslint-plugin @typescript-eslint/parser
</Npm>

### 用法

创建一个 `.eslintrc.yml` 文件，将 `drizzle` 添加到 `plugins`，并指定你想要使用的规则。你可以在下面找到所有现有规则的列表

```yaml copy {6,8,9}
root: true
parser: '@typescript-eslint/parser'
parserOptions:
  project: './tsconfig.json'
plugins:
  - drizzle
rules:
  'drizzle/enforce-delete-with-where': "error"
  'drizzle/enforce-update-with-where': "error"
```

#### 所有配置

该插件导出一个 all 配置，它使用了所有规则（弃用的规则除外）。

```yaml copy
root: true
extends:
  - "plugin:drizzle/all"
parser: '@typescript-eslint/parser'
parserOptions:
  project: './tsconfig.json'
plugins:
  - drizzle
```

目前，`all` 等同于 `recommended`

```yaml copy
root: true
extends:
  - "plugin:drizzle/recommended"
parser: '@typescript-eslint/parser'
parserOptions:
  project: './tsconfig.json'
plugins:
  - drizzle
```

### 规则

**enforce-delete-with-where**：强制在 `.delete()` 语句中使用 `delete` 配合 `the.where()` 子句。大多数情况下，你不需要删除表中的所有行，而需要某种 `WHERE` 语句。

错误信息：

```plaintext
Without `.where(...)` you will delete all the rows in a table. If you didn't want to do it, please use `db.delete(...).where(...)` instead. Otherwise you can ignore this rule here
```

可选地，你可以在插件选项中定义一个 `drizzleObjectName`，它接受 `string` 或 `string[]`。当你拥有带有非 Drizzle 的 delete 方法的对象或类时，这很有用。这样的 `delete` 方法会触发 ESLint 规则。为避免这种情况，你可以定义你在代码库中使用的 Drizzle 对象的名称（例如 db），这样只有当 delete 方法来自该对象时才会触发规则：

示例，配置 1：

```json copy
"rules": {
  "drizzle/enforce-delete-with-where": ["error"]
}
```

```ts copy
class MyClass {
  public delete() {
    return {}
  }
}

const myClassObj = new MyClass();

// ---> 将会被 ESLint Rule 触发
myClassObj.delete()

const db = drizzle(...)
// ---> 将会被 ESLint Rule 触发
db.delete()
```

示例，配置 2：

```json copy
"rules": {
  "drizzle/enforce-delete-with-where": ["error", { "drizzleObjectName": ["db"] }],
}
```

```ts copy
class MyClass {
  public delete() {
    return {}
  }
}

const myClassObj = new MyClass();

// ---> 将不会被 ESLint Rule 触发
myClassObj.delete()

const db = drizzle(...)
// ---> 将会被 ESLint Rule 触发
db.delete()
```

**enforce-update-with-where**：强制在 `.update()` 语句中使用 `update` 配合 `the.where()` 子句。大多数情况下，你不需要更新表中的所有行，而需要某种 `WHERE` 语句。

错误信息：

```plaintext
Without `.where(...)` you will update all the rows in a table. If you didn't want to do it, please use `db.update(...).set(...).where(...)` instead. Otherwise you can ignore this rule here
```
