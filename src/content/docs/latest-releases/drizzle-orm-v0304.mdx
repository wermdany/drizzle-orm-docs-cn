## 新特性

### 🎉 xata-http 驱动支持

根据其**[官方网站](https://xata.io)**，Xata 是一个专注于可靠性、可扩展性和开发者体验的 Postgres 数据平台。Xata Postgres 服务目前处于 beta 阶段，请查看 [Xata 文档](https://xata.io/docs/postgres)了解如何在你的账户中启用它。

Drizzle ORM 原生支持使用 `drizzle-orm/xata` 包的 `xata` 驱动，以及用于访问 Xata Postgres 数据库的 **`postgres`** 或 **`pg`** 驱动。

下面的示例使用了 Xata 生成的客户端，你可以通过运行 [xata init](https://xata.io/docs/getting-started/installation) CLI 命令来获取它。

<Npm>
  drizzle-orm@rc @xata.io/client
  -D drizzle-kit@rc
</Npm>

```ts
import { drizzle } from 'drizzle-orm/xata-http';
import { getXataClient } from './xata'; // 生成的客户端

const xata = getXataClient();
const db = drizzle(xata);

const result = await db.select().from(...);
```

你也可以使用 `pg` 或 `postgres.js` 驱动连接到 Xata

要开始使用 Xata 和 Drizzle，请遵循[文档](/docs/get-started-postgresql#xata)。
