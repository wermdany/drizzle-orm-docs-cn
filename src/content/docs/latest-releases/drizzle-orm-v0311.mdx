# 新特性

## Live Queries 🎉

> ### 关于 Drizzle + Expo 的完整说明，欢迎查看[讨论](https://github.com/drizzle-team/drizzle-orm/discussions/2447)

从 `v0.31.1` 开始，Drizzle ORM 现在原生支持 Expo SQLite 实时查询！
我们实现了一个原生的 `useLiveQuery` React Hook，它会监听必要的数据库变更并自动重新执行数据库查询。它同时适用于类 SQL 查询和 Drizzle 查询：

```tsx
import { useLiveQuery, drizzle } from 'drizzle-orm/expo-sqlite';
import { openDatabaseSync } from 'expo-sqlite';
import { users } from './schema';
import { Text } from 'react-native';

const expo = openDatabaseSync('db.db', { enableChangeListener: true }); // <-- 启用变更监听器
const db = drizzle(expo);

const App = () => {
  // 数据变更时自动重新渲染
  const { data } = useLiveQuery(db.select().from(users));

  // const { data, error, updatedAt } = useLiveQuery(db.query.users.findFirst());
  // const { data, error, updatedAt } = useLiveQuery(db.query.users.findMany());


  return <Text>{JSON.stringify(data)}</Text>;
};

export default App;
```

我们有意没有修改 ORM 本身的 API，以遵循常规的 React Hook API，因此我们使用 `useLiveQuery(databaseQuery)`，而不是 `db.select().from(users).useLive()` 或 `db.query.users.useFindMany()`

我们还决定将 `data`、`error` 和 `updatedAt` 字段作为 hook 的返回结果提供，以便按照 `React Query` 和 `Electric SQL` 的实践进行简洁明确的错误处理
