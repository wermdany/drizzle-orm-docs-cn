## 社区贡献版本 🎉

### 内部功能与变更
- 为 d1 添加了一组测试
- 修复了内部文档中的问题

### 修复
- 解决了 MySQL 截断 timestamp 毫秒的问题
- 修正了基于 sqlite 的方言中 `.get()` 方法的类型（[#565](https://github.com/drizzle-team/drizzle-orm/issues/565)）
- 修复了导致查询执行两次的 sqlite-proxy bug

### 新包 🎉

在 [drizzle-typebox](/docs/typebox) 包中新增了对 [Typebox](https://github.com/sinclairzx81/typebox) 的支持。

请查看文档页面以获取更多用法示例：/docs/typebox
