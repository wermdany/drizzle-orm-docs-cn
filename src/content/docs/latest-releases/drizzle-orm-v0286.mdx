## 变更

> **注意**：
> MySQL 的 `datetime` 配合 `mode: 'date'` 现在将以 UTC 字符串存储日期，并以 UTC 检索数据，以与 MySQL 对 `datetime` 的行为保持一致。如果你需要不同的行为并希望以另一种方式处理 `datetime` 映射，请使用 `mode: 'string'` 或 [自定义类型](/docs/custom-types) 实现

查看 [修复 MySQL 的 Datetime 映射](https://github.com/drizzle-team/drizzle-orm/pull/1082) 以了解实现细节

## 新功能

### 🎉 `LibSQL` batch api 支持

参考：https://docs.turso.tech/reference/client-access/javascript-typescript-sdk#execute-a-batch-of-statements

Batch API 用法示例：

<Section>
```ts copy {1}
const batchResponse = await db.batch([
	db.insert(usersTable).values({ id: 1, name: 'John' }).returning({
		id: usersTable.id,
	}),
	db.update(usersTable).set({ name: 'Dan' }).where(eq(usersTable.id, 1)),
	db.query.usersTable.findMany({}),
	db.select().from(usersTable).where(eq(usersTable.id, 1)),
	db.select({ id: usersTable.id, invitedBy: usersTable.invitedBy }).from(
		usersTable,
	),
]);
```

```ts
type BatchResponse = [
	{
		id: number;
	}[],
	ResultSet,
	{
		id: number;
		name: string;
		verified: number;
		invitedBy: number | null;
	}[],
	{
		id: number;
		name: string;
		verified: number;
		invitedBy: number | null;
	}[],
	{
		id: number;
		invitedBy: number | null;
	}[],
];
```
</Section>

所有可以在 `db.batch` 内使用的构建器：

```ts
`db.all()`,
`db.get()`,
`db.values()`,
`db.run()`,
`db.query.<table>.findMany()`,
`db.query.<table>.findFirst()`,
`db.select()...`,
`db.update()...`,
`db.delete()...`,
`db.insert()...`,
```

更多用法示例见：[integration-tests/tests/libsql-batch.test.ts](https://github.com/drizzle-team/drizzle-orm/pull/1161/files#diff-17253895532e520545027dd48dcdbac2d69a5a49d594974e6d55d7502f89b838R248) 以及 [文档](/docs/batch-api)

### 🎉 为 SQLite 中的 text 新增 json 模式

在 [文档](/docs/get-started-postgresql#http-proxy) 中阅读更多内容

```ts copy {2}
const test = sqliteTable('test', {
	dataTyped: text('data_typed', { mode: 'json' }).$type<{ a: 1 }>().notNull(),
});
```

### 🎉 为 Relational Query API 调用新增 `.toSQL()`

```ts copy {1}
const query = db.query.usersTable.findFirst().toSQL();
```

### 🎉 新增了用于数组的 PostgreSQL 操作符

操作符列表及用法示例
`arrayContains`、`arrayContained`、`arrayOverlaps`

在 [文档](/docs/get-started-postgresql#http-proxy) 中阅读更多内容

```ts copy {2,5,8,11,12,13,14}
const contains = await db.select({ id: posts.id }).from(posts)
	.where(arrayContains(posts.tags, ['Typescript', 'ORM']));

const contained = await db.select({ id: posts.id }).from(posts)
	.where(arrayContained(posts.tags, ['Typescript', 'ORM']));

const overlaps = await db.select({ id: posts.id }).from(posts)
	.where(arrayOverlaps(posts.tags, ['Typescript', 'ORM']));

const withSubQuery = await db.select({ id: posts.id }).from(posts)
	.where(arrayContains(
		posts.tags,
		db.select({ tags: posts.tags }).from(posts).where(eq(posts.id, 1)),
	));
```

### 🎉 为 Relational Queries 中的 where 过滤函数新增更多 SQL 操作符

你可以在 [文档](/docs/rqb#select-过滤器) 中找到更多示例

<Section>
```ts
// 之前
import { inArray } from "drizzle-orm/pg-core";

await db.users.findFirst({
  where: (table, _) => inArray(table.id, [ ... ])
})
```

```ts copy {3}
// 之后
await db.users.findFirst({
  where: (table, { inArray }) => inArray(table.id, [ ... ])
})
```
</Section>
