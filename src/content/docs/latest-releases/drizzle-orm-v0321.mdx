pubDate: 2024-07-23

- 修复索引的类型定义，并允许在 3 个及以上的列上创建索引，可混合使用列和表达式
- 在所有方言中添加了对 "limit 0" 的支持 - 关闭 [#2011](https://github.com/drizzle-team/drizzle-orm/issues/2011)
- 让 inArray 和 notInArray 接受空列表，关闭 [#1295](https://github.com/drizzle-team/drizzle-orm/issues/1295)
- 修复 lt typedoc 中的拼写错误
- 修复 README.md 中的错误示例
