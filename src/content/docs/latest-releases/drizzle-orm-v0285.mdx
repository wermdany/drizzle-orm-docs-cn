## 修复

- 修复了导致运行时错误的错误的 OpenTelemetry 类型导入

ORM 中目前存在的 OpenTelemetry 逻辑并非供 Drizzle 使用，并且 Drizzle 从未通过 drizzle-orm 收集过任何统计数据。OpenTelemetry 只是一个协议。如果你查看 drizzle-orm 中实际使用它的代码，会发现它只是使用 tracer 来收集查询统计数据，并不会将其发送到任何地方。它的设计初衷是让 ORM 用户能够将这些统计数据发送到他们自己的遥测消费者。

重要的是——当前版本中 OpenTelemetry 逻辑是禁用的。它实际上什么都不做。我们在过去的某个时候对它进行了实验，但在发布前就禁用了它。

至于上一个版本中该问题的原因：它是因为[这一行](https://github.com/drizzle-team/drizzle-orm/blob/594e96538e588fee5748e372884dbaf32c331524/drizzle-orm/src/tracing.ts#L1)上错误的类型导入导致的。我们使用了 `import { type ... }` 语法而不是 `import type { ... }`，导致 `import '@opentelemetry/api'` 这一行泄漏到了运行时。
