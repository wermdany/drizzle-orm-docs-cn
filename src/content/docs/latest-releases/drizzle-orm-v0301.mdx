## 新特性

### 🎉 OP-SQLite 驱动支持

用法示例

```ts copy {4,5,6,8}
import { open } from '@op-engineering/op-sqlite';
import { drizzle } from 'drizzle-orm/op-sqlite';

const opsqlite = open({
	name: 'myDB',
});

const db = drizzle(opsqlite);

await db.select().from(users);
```

有关更多用法和设置细节，请查看我们的 [op-sqlite 文档](http://orm.drizzle.team/docs/sqlite/get-started-sqlite#op-sqlite)

## 修复

- 修复了 Expo 驱动的迁移 hook
