## 新特性

### PGlite 驱动支持

[PGlite](https://github.com/electric-sql/pglite) 是一个打包成 TypeScript 客户端库的 WASM Postgres 构建，使你能够在浏览器、Node.js 和 Bun 中运行 Postgres，无需安装任何其他依赖。它 gzip 压缩后仅 2.6mb。

它可以用作临时的内存数据库，也可以持久化到文件系统（Node/Bun）或 indexedDB（浏览器）。

与之前的 "Postgres in the browser" 项目不同，PGlite 不使用 Linux 虚拟机——它只是 WASM 中的 Postgres。


在[这里](/docs/get-started-postgresql#pglite)阅读 Drizzle 和 PGlite 入门指南。

用法示例
```ts copy {1,6}
import { PGlite } from '@electric-sql/pglite';
import { drizzle } from 'drizzle-orm/pglite';
import { users } from './schema';

// 内存中的 Postgres
const client = new PGlite();
const db = drizzle(client);

await db.select().from(users);
```
