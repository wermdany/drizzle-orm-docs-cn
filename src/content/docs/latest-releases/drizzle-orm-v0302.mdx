## 改进

LibSQL 迁移已更新为使用批处理执行而不是事务。如[文档](https://docs.turso.tech/sdk/ts/reference#batch-transactions)所述，LibSQL 现在支持批处理操作

> 一个批处理由多条 SQL 语句组成，它们在一个隐式事务中按顺序执行。后端负责处理事务：成功则提交所有更改，任何失败都会导致完全回滚且不做任何修改。

要开始使用 Turso 和 Drizzle，请遵循[文档](/docs/sqlite/get-started-sqlite#turso)

## 修复

- [Sqlite] 修复 bun:sqlite 的 findFirst 查询（[#1885](https://github.com/drizzle-team/drizzle-orm/pull/1885)）

要开始使用 Bun SQLite 和 Drizzle，请遵循[文档](/docs/sqlite/get-started-sqlite#bun-sqlite)
