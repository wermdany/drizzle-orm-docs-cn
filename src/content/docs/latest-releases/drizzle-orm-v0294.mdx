## 新特性

### 🎉 Neon HTTP 批处理

更多信息你可以查看 [Neon 文档](https://neon.tech/docs/serverless/serverless-driver#issue-multiple-queries-with-the-transaction-function) 和 [开始使用 Neon 与 Drizzle](/docs/get-started-postgresql#neon)。

<Section>
```ts copy {8}
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';
import { usersTable } from './schema';

const sql = neon(process.env.DRIZZLE_DATABASE_URL!);
const db = drizzle(sql);

const batchResponse: BatchType = await db.batch([
	db.insert(usersTable).values({ id: 1, name: 'John' }).returning({
		id: usersTable.id,
	}),
	db.insert(usersTable).values({ id: 2, name: 'Dan' }),
	db.query.usersTable.findMany({}),
	db.query.usersTable.findFirst({}),
]);
```

```ts
type BatchType = [
	{
		id: number;
	}[],
	NeonHttpQueryResult<never>,
	{
		id: number;
		name: string;
		verified: number;
		invitedBy: number | null;
	}[],
	{
		id: number;
		name: string;
		verified: number;
		invitedBy: number | null;
	} | undefined,
];
```
</Section>

## 改进

感谢 `database-js` 和 `PlanetScale` 团队，我们更新了 `database-js` 的默认行为和实例。

按照 `database-js` 核心团队的建议，你应该使用 `Client` 实例而不是 `connect()`：

```ts copy {1,5}
import { Client } from '@planetscale/database';
import { drizzle } from 'drizzle-orm/planetscale-serverless';

// 创建连接
const client = new Client({
	host: process.env['DATABASE_HOST'],
	username: process.env['DATABASE_USERNAME'],
	password: process.env['DATABASE_PASSWORD'],
});

const db = drizzle(client);
```

> 警告：在此版本中没有任何破坏性变更，但从 `0.30.0` 版本开始，如果你尝试使用除 `Client` 实例以外的任何东西，都会遇到错误。
>
> 我们建议现在就开始将连接改为 PlanetScale，以避免将来出现任何运行时错误。

之前我们的文档说明使用 `connect()`，并且只有这个函数可以传给 drizzle。在此版本中，我们根据 `database-js` 团队的建议，增加了对 `new Client()` 的支持并弃用 `connect()`。在此版本中，当你尝试传入 `connect()` 函数的结果时，你会看到一条 `warning`：

**警告文本**

```mdx
Warning: You need to pass an instance of Client:

import { Client } from "@planetscale/database";

const client = new Client({
  host: process.env["DATABASE_HOST"],
  username: process.env["DATABASE_USERNAME"],
  password: process.env["DATABASE_PASSWORD"],
});

const db = drizzle(client);

Starting from version 0.30.0, you will encounter an error if you attempt to use anything other than a Client instance.

Please make the necessary changes now to prevent any runtime errors in the future
```
