## 新特性

### PostgreSQL、MySQL 和 SQLite 的 `$onUpdate` 功能

为列添加动态更新值。
该函数会在行更新时被调用；如果没有提供列值，则返回的值将用作列值。
如果没有提供 `default`（或 `$defaultFn`）值，则函数也会在行插入时被调用，返回的值将用作列值。

> 注意：该值不会影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时中使用。

```ts copy {4,5,6}
const usersOnUpdate = pgTable('users_on_update', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  updateCounter: integer('update_counter').default(sql`1`).$onUpdateFn(() => sql`update_counter + 1`),
  updatedAt: timestamp('updated_at', { mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
  alwaysNull: text('always_null').$type<string | null>().$onUpdate(() => null),
});
```

## 修复

- smallserial 数据类型列的插入不是可选的 - [#1848](https://github.com/drizzle-team/drizzle-orm/issues/1848)
