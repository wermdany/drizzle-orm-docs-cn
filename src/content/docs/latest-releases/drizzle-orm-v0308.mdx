## 新特性

- 为 Postgres 中的枚举添加了自定义 schema 支持（修复 [#669](https://github.com/drizzle-team/drizzle-orm/issues/669)，通过 [#2048](https://github.com/drizzle-team/drizzle-orm/pull/2048)）：

```ts copy {3,4}
import { pgSchema } from 'drizzle-orm/pg-core';

const mySchema = pgSchema('mySchema');
const colors = mySchema.enum('colors', ['red', 'green', 'blue']);
```

在[这里](/docs/schemas)了解关于 Postgres [schema](/docs/schemas) 以及[枚举](/docs/column-types#enum)的更多信息。

## 修复

- 将 D1 的 `migrate()` 函数改为使用批量 API（[#2137](https://github.com/drizzle-team/drizzle-orm/pull/2137)）

要开始使用 Drizzle 和 D1，请遵循[文档](/docs/sqlite/get-started-sqlite#cloudflare-d1)。

- 将 Postgres `.onConflictDoUpdate` 方法中的 `where` 子句拆分为 `setWhere` 和 `targetWhere` 子句，以支持 `on conflict ...` 子句中的两种 `where` 情况（修复 [#1628](https://github.com/drizzle-team/drizzle-orm/issues/1628)、[#1302](https://github.com/drizzle-team/drizzle-orm/issues/1302)，通过 [#2056](https://github.com/drizzle-team/drizzle-orm/pull/2056)）。

```ts copy
await db.insert(employees)
  .values({ employeeId: 123, name: 'John Doe' })
  .onConflictDoUpdate({
    target: employees.employeeId,
    targetWhere: sql`name <> 'John Doe'`,
    set: { name: sql`excluded.name` }
  });
  
await db.insert(employees)
  .values({ employeeId: 123, name: 'John Doe' })
  .onConflictDoUpdate({
    target: employees.employeeId,
    set: { name: 'John Doe' },
    setWhere: sql`name <> 'John Doe'`
  });
```

在[这里](/docs/insert#on-conflict-do-update)了解关于 `.onConflictDoUpdate` 方法的更多信息。
- 修复了 Postgres `.onConflictDoNothing` 方法中 `where` 子句的查询生成，因为它被放在了错误的位置（修复 [#1628](https://github.com/drizzle-team/drizzle-orm/issues/1628)，通过 [#2056](https://github.com/drizzle-team/drizzle-orm/pull/2056)）。

在[这里](/docs/insert#on-conflict-do-nothing)了解关于 `.onConflictDoNothing` 方法的更多信息。

- 修复了 AWS Data API 驱动的多个问题（修复 [#1931](https://github.com/drizzle-team/drizzle-orm/pull/1931)、[#1932](https://github.com/drizzle-team/drizzle-orm/issues/1932)、[#1934](https://github.com/drizzle-team/drizzle-orm/issues/1934)、[#1936](https://github.com/drizzle-team/drizzle-orm/issues/1936)，通过 [#2119](https://github.com/drizzle-team/drizzle-orm/pull/2119)）
- 修复 AWS Data API 中数组值的插入和更新（修复 [#1912](https://github.com/drizzle-team/drizzle-orm/issues/1912)，通过 [#1911](https://github.com/drizzle-team/drizzle-orm/pull/1911)）

要开始使用 Drizzle 和 AWS Data API，请遵循[文档](/docs/get-started-postgresql#aws-data-api)。
