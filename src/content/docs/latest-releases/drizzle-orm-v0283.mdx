## 新功能

### 🎉 新增 SQLite 简化查询 API

### 🎉 为列构建器新增 `.$defaultFn()` / `.$default()` 方法

更多信息请查看 [PostgreSQL](/docs/column-types#默认值)、[MySQL](/docs/mysql/column-types#默认值) 和 [SQLite](/docs/sqlite/column-types#默认值) 的文档。

你可以为类似 `cuid()` 的函数指定任意逻辑和任意实现，用于运行时默认值。Drizzle 不会限制你可以添加的实现数量。

> 注意：该值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用

```ts copy {5}
import { varchar, mysqlTable } from "drizzle-orm/mysql-core";
import { createId } from '@paralleldrive/cuid2';

const table = mysqlTable('table', {
	id: varchar('id', { length: 128 }).$defaultFn(() => createId()),
});
```

### 🎉 新增 `table.$inferSelect` / `table._.inferSelect` 和 `table.$inferInsert` / `table._.inferInsert`，以便更方便地进行表模型类型推断

- 🛠 弃用了 `InferModel` 类型，改用更明确的 `InferSelectModel` 和 `InferInsertModel`

```ts copy {11,12,14,15}
import { InferSelectModel, InferInsertModel } from 'drizzle-orm'

const usersTable = pgTable('users', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  verified: boolean('verified').notNull().default(false),
  jsonb: jsonb('jsonb').$type<string[]>(),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});

type SelectUser = typeof usersTable.$inferSelect;
type InsertUser = typeof usersTable.$inferInsert;

type SelectUser2 = InferSelectModel<typeof usersTable>;
type InsertUser2 = InferInsertModel<typeof usersTable>;
```

- 🛠 禁用了 `.d.ts` 文件的打包
