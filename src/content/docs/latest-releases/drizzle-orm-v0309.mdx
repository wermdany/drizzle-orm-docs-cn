## 新特性

- 在 SQLite 的 `.onConflictDoUpdate()` 配置中添加了 `setWhere` 和 `targetWhere` 字段，取代单一的 `where` 字段：

```ts copy
await db.insert(employees)
  .values({ employeeId: 123, name: 'John Doe' })
  .onConflictDoUpdate({
    target: employees.employeeId,
    targetWhere: sql`name <> 'John Doe'`,
    set: { name: sql`excluded.name` }
  });
  
await db.insert(employees)
  .values({ employeeId: 123, name: 'John Doe' })
  .onConflictDoUpdate({
    target: employees.employeeId,
    set: { name: 'John Doe' },
    setWhere: sql`name <> 'John Doe'`
  });
```

在[这里](/docs/insert#on-conflict-do-update)了解关于 `.onConflictDoUpdate()` 方法的更多信息。

- 🛠️ 通过 `db._.fullSchema` 为 Drizzle 实例添加了 schema 信息

## 修复

- 修复了 AWS Data API 中的迁移器

要开始使用 Drizzle 和 AWS Data API，请遵循[文档](/docs/get-started-postgresql#aws-data-api)。
