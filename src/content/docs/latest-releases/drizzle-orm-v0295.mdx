## 新特性

### 🎉 WITH UPDATE, WITH DELETE, WITH INSERT

你现在可以在 [INSERT](/docs/insert#with-insert-子句)、[UPDATE](/docs/update#with-update-子句) 和 [DELETE](/docs/delete#with-delete-子句) 语句中使用 `WITH` 语句

用法示例

<Section>
```ts copy {6,7}
const averageAmount = db.$with('average_amount').as(
	db.select({ value: sql`avg(${orders.amount})`.as('value') }).from(orders),
);

const result = await db
	.with(averageAmount)
	.delete(orders)
	.where(gt(orders.amount, sql`(select * from ${averageAmount})`))
	.returning({
		id: orders.id,
	});
```

```sql
with "average_amount" as (select avg("amount") as "value" from "orders") 
delete from "orders" 
where "orders"."amount" > (select * from "average_amount") 
returning "id";
```
</Section>

有关所有语句的更多示例，请查看文档：

- [with update 文档](/docs/update#with-update-子句)

### 🎉 可为 migrations 表指定自定义 schema 和自定义名称

- **迁移的自定义表**

默认情况下，所有关于已执行迁移的信息都会存储在数据库的 `__drizzle_migrations` 表中，对于 PostgreSQL，则存储在 `drizzle` schema 中。不过，你可以配置这些记录的存储位置。

要为存储在数据库中的迁移添加自定义表名，你应该使用 `migrationsTable` 选项

用法示例

```ts copy {3}
await migrate(db, {
	migrationsFolder: './drizzle',
	migrationsTable: 'my_migrations',
});
```

- **迁移的自定义 schema**

> 仅适用于 PostgreSQL 数据库

要为存储在数据库中的迁移添加自定义 schema 名称，你应该使用 `migrationsSchema` 选项

用法示例

```ts copy {3}
await migrate(db, {
	migrationsFolder: './drizzle',
	migrationsSchema: 'custom',
});
```

### 🎉 SQLite Proxy 批处理与关系查询支持

你可以在[文档](/docs/sqlite/get-started-sqlite#http-proxy)中找到关于 SQLite 代理的更多信息。

- 你现在可以在 sqlite 代理驱动中使用 `.query.findFirst` 和 `.query.findMany` 语法

- SQLite Proxy 支持批处理请求，与所有其他驱动的做法相同。查看完整[文档](/docs/batch-api)

  你需要为批处理查询指定一个特定的回调，并处理对代理服务器的请求：

```ts
import { drizzle } from 'drizzle-orm/sqlite-proxy';

type ResponseType = { rows: any[][] | any[] }[];

const db = drizzle(
	async (sql, params, method) => {
		// single query logic
	},
	// new batch callback
	async (
		queries: {
			sql: string;
			params: any[];
			method: 'all' | 'run' | 'get' | 'values';
		}[],
	) => {
		try {
			const result: ResponseType = await axios.post(
				'http://localhost:3000/batch',
				{ queries },
			);

			return result;
		} catch (e: any) {
			console.error('Error from sqlite proxy server:', e);
			throw e;
		}
	},
);
```

然后你可以使用 `db.batch([])` 方法，它会代理所有查询

> 批处理的响应应该是一个原始值数组（数组中包含数组），顺序与它们发送到代理服务器时的顺序相同
