### bigint
`int` `int8` `int64` `integer`

有符号 8 字节整数     

如果你预期值大于 2^31 但小于 2^53，可以使用 `mode: 'number'`，以 javascript number 而非 bigint 来处理。
<Section>
```typescript
import { bigint, cockroachTable } from "drizzle-orm/cockroach-core";

export const table = cockroachTable('table', {
	bigint: bigint({ mode: 'number' })
});

// 将被推断为 `number`
bigint: bigint({ mode: 'number' })

// 将被推断为 `bigint`
bigint: bigint({ mode: 'bigint' })
```

```sql
CREATE TABLE "table" (
	"bigint" bigint
);
```
</Section>

<Section>
```typescript
import { sql } from "drizzle-orm";
import { bigint, cockroachTable } from "drizzle-orm/cockroach-core";

export const table = cockroachTable('table', {
	bigint1: bigint().default(10),
	bigint2: bigint().default(sql`'10'::bigint`)
});
```

```sql
CREATE TABLE "table" (
	"bigint1" bigint DEFAULT 10,
	"bigint2" bigint DEFAULT '10'::bigint
);
```
</Section>

### string
`text` `varchar`, `char`

`STRING` 数据类型存储 Unicode 字符组成的字符串。

<Callout>
为了与 PostgreSQL 兼容，CockroachDB 支持以下与 STRING 相关的类型及其别名：

`VARCHAR`（以及别名 `CHARACTER VARYING`）
`CHAR`（以及别名 `CHARACTER`）
`NAME`
</Callout>

更多信息请参阅 CockroachDB 官方 **[文档。](https://www.cockroachlabs.com/docs/stable/string)**
  
你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。
<Section>
```typescript
import { string, cockroachTable } from "drizzle-orm/cockroach-core";

export const table = cockroachTable('table', {
  stringColumn: string(), // 等价于 PostgreSQL 的 `text` 类型
  stringColumn1: string({ length: 256 }), // 等价于 PostgreSQL 的 `varchar(256)` 类型
});

// 将被推断为 text: "value1" | "value2" | null
stringColumn: string({ enum: ["value1", "value2"] })
```

```sql
CREATE TABLE "table" (
	"stringColumn" string,
    "stringColumn1" string(256),
);
```
</Section>

### jsonb
`jsonb`  

JSONB 数据类型以 JSONB 值的二进制表示形式存储 JSON（JavaScript Object Notation）数据，从而消除空白、重复键和键顺序

更多信息请参阅 CockroachDB 官方 **[文档。](https://www.cockroachlabs.com/docs/stable/jsonb)**
<Section>
```typescript
import { jsonb, cockroachTable } from "drizzle-orm/cockroach-core";

const table = cockroachTable('table', {
	jsonb1: jsonb(),
	jsonb2: jsonb().default({ foo: "bar" }),
	jsonb3: jsonb().default(sql`'{foo: "bar"}'::jsonb`),
});
```
```sql
CREATE TABLE "table" (
	"jsonb1" jsonb,
	"jsonb2" jsonb default '{"foo": "bar"}'::jsonb,
	"jsonb3" jsonb default '{"foo": "bar"}'::jsonb
);
```
</Section>

你可以为 json 对象推断指定 `.$type<..>()`，它**不会**检查运行时值。 
它为默认值、insert 和 select schema 提供编译期保护。

```typescript
// 将被推断为 { foo: string }
jsonb: jsonb().$type<{ foo: string }>();

// 将被推断为 string[]
jsonb: jsonb().$type<string[]>();

// 无法编译
jsonb: jsonb().$type<string[]>().default({});
```

你可以指定 `date` 或 `string` 推断模式：
```typescript

```

> `string` 模式不会为你执行任何映射。此模式被添加到 Drizzle ORM，是为了让开发者
可以根据自身需求自行处理日期和日期映射。
Drizzle 会以字符串形式将原始日期 `to` 和 `from` 数据库传递，因此其行为应尽可能可预测，
并与数据库行为 100% 保持一致

> `date` 模式是处理日期的常规方式。Drizzle 会负责数据库与 JS Date 对象之间的所有映射

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，允许你自定义列的数据类型。 

例如，对于未知类型或品牌类型（branded types），这很有用：
```ts
type UserId = number & { __brand: 'user_id' };
type Data = {
	foo: string;
	bar: number;
};

const users = cockroachTable('users', {
  id: int().$type<UserId>().primaryKey(),
  jsonField: json().$type<Data>(),
});
```

### 标识列

<Callout type="info">
要使用此功能，你需要 `drizzle-orm@0.32.0` 或更高版本，以及 `drizzle-kit@0.23.0` 或更高版本
</Callout>

PostgreSQL 和 CockroachDB 支持标识列，用于为列自动生成唯一整数值。这些值通过序列生成，并可使用 GENERATED AS IDENTITY 子句定义。

**标识列的类型**
- `GENERATED ALWAYS AS IDENTITY`：数据库始终为该列生成值。除非使用 OVERRIDING SYSTEM VALUE 子句，否则不允许手动插入或更新该列。
- `GENERATED BY DEFAULT AS IDENTITY`：数据库默认生成值，但也可以插入或更新手动值。如果提供了手动值，将使用该值而非系统生成的值。

**用法示例**
```ts
import { pgTable, integer, text } from 'drizzle-orm/pg-core' 

export const ingredients = pgTable("ingredients", {
  id: integer().primaryKey().generatedAlwaysAsIdentity({ startWith: 1000 }),
  name: text().notNull(),
  description: text(),
});
```

你可以在 `.generatedAlwaysAsIdentity()` 函数中指定序列可用的所有属性。此外，你还可以为这些序列指定自定义名称

PostgreSQL 文档[参考](https://www.postgresql.org/docs/current/sql-createtable.html#SQL-CREATETABLE-PARMS-GENERATED-IDENTITY)。

### 默认值
`DEFAULT` 子句指定当用户执行 `INSERT` 时未显式提供值时该列使用的默认值。
如果列定义上没有附加显式的 `DEFAULT` 子句，
则该列的默认值为 `NULL`。

显式的 `DEFAULT` 子句可以将默认值指定为 `NULL`、
字符串常量、blob 常量、带符号数字，或任何括号内的常量表达式。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { integer, pgTable, uuid } from "drizzle-orm/pg-core";

const table = pgTable('table', {
	integer1: integer().default(42),
	integer2: integer().default(sql`'42'::integer`),
	uuid1: uuid().defaultRandom(),
	uuid2: uuid().default(sql`gen_random_uuid()`),
});
```

```sql
CREATE TABLE IF NOT EXISTS "table" (
	"integer1" integer DEFAULT 42,
	"integer2" integer DEFAULT '42'::integer,
	"uuid1" uuid DEFAULT gen_random_uuid(),
	"uuid2" uuid DEFAULT gen_random_uuid()
);
```
</Section>

当使用 `$default()` 或 `$defaultFn()`（它们只是同一函数的不同别名）时，
你可以在运行时生成默认值，并在所有插入查询中使用这些值。 

这些函数可以帮助你使用各种实现，例如 `uuid`、`cuid`、`cuid2` 等等。

<Callout type="info" emoji="ℹ️">
	注意：此值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用
</Callout>

```ts
import { text, pgTable } from "drizzle-orm/pg-core";
import { createId } from '@paralleldrive/cuid2';

const table = pgTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

当使用 `$onUpdate()` 或 `$onUpdateFn()`（它们只是同一函数的不同别名）时，
你可以在运行时生成默认值，并在所有更新查询中使用这些值。 

为列添加动态更新值。当行被更新时会调用该函数，
如果未提供列值，则将返回值用作列值。
如果未提供默认值（或 $defaultFn）值，则在插入行时也会调用该函数，
并将返回值用作列值。

<Callout type="info" emoji="ℹ️">
	注意：此值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用
</Callout>

```ts
import { integer, timestamp, text, pgTable } from "drizzle-orm/pg-core";

const table = pgTable('table', {
	updateCounter: integer().default(sql`1`).$onUpdateFn((): SQL => sql`${table.update_counter} + 1`),
	updatedAt: timestamp({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
    	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```


### Not null
`NOT NULL` 约束规定关联的列不能包含 `NULL` 值。

<Section>
```typescript
import { integer, pgTable } from "drizzle-orm/pg-core";

const table = pgTable('table', {
	integer: integer().notNull(),
});
```

```sql
CREATE TABLE IF NOT EXISTS "table" (
	"integer" integer NOT NULL
);
```
</Section>


### 主键
主键约束表示一个列或一组列可以作为表中行的唯一标识符。 
这要求这些值既唯一又非空。
<Section>
```typescript
import { serial, pgTable } from "drizzle-orm/pg-core";

const table = pgTable('table', {
	id: serial().primaryKey(),
});
```

```sql
CREATE TABLE IF NOT EXISTS "table" (
	"id" serial PRIMARY KEY NOT NULL
);
```
</Section>
