### bigint
`bigint`

有符号 8 字节整数  

如果你预期值大于 2^31 但小于 2^53，可以使用 `mode: 'number'`，以 javascript number 而非 bigint 来处理。
<Section>
```typescript
import { bigint, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	bigint: bigint({ mode: 'number' })
});

// 将被推断为 `number`
bigint: bigint({ mode: 'number' })

// 将被推断为 `bigint`
bigint: bigint({ mode: 'bigint' })

// 将被推断为 `string`
bigint: bigint({ mode: 'string' })
```

```sql
CREATE TABLE [table] (
	[bigint] bigint
);
```
</Section>

<Section>

### text
`text`  
服务器代码页中的可变长度非 Unicode 数据，最大字符串长度

更多信息请参阅 MSSQL 官方 **[文档。](https://learn.microsoft.com/en-us/sql/t-sql/data-types/ntext-text-and-image-transact-sql?view=sql-server-ver17#text)**

### varchar
`varchar(n|max)`  
可变大小字符串数据。使用 n 以字节为单位定义字符串大小，其值可以为 1 到 8,000

更多信息请参阅 MSSQL 官方 **[文档。](https://learn.microsoft.com/en-us/sql/t-sql/data-types/char-and-varchar-transact-sql?view=sql-server-ver17#varchar---n--max--)**

你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。

根据 MSSQL 文档，`length` 参数是可选的。
<Section>
```typescript
import { varchar, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
  varchar1: varchar(),
  varchar2: varchar({ length: 256 }),
  varchar3: varchar({ length: 'max' })
});

// 将被推断为 text: "value1" | "value2" | null
varchar: varchar({ enum: ["value1", "value2"] }),
```

```sql
CREATE TABLE [table] (
	[varchar1] varchar,
	[varchar2] varchar(256),
	[varchar3] varchar(max)
);
```
</Section>

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，允许你自定义列的数据类型。 

例如，对于未知类型或品牌类型（branded types），这很有用：
```ts
type UserId = number & { __brand: 'user_id' };
type Data = {
	foo: string;
	bar: number;
};

const users = mssqlTable('users', {
  id: int().$type<UserId>().primaryKey(),
  jsonField: json().$type<Data>(),
});
```

### 默认值
`DEFAULT` 子句指定当用户执行 `INSERT` 时未显式提供值时该列使用的默认值。
如果列定义上没有附加显式的 `DEFAULT` 子句，
则该列的默认值为 `NULL`。

显式的 `DEFAULT` 子句可以将默认值指定为 `NULL`、
字符串常量、blob 常量、带符号数字，或任何括号内的常量表达式。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { int, mssqlTable, text } from "drizzle-orm/mssql-core";

const table = mssqlTable('table', {
	integer: integer().default(42),
	text: text().default('text'),
});
```

```sql
CREATE TABLE [table] (
	[integer1] integer DEFAULT 42,
	[text] text DEFAULT 'text',
);
```
</Section>

当使用 `$default()` 或 `$defaultFn()`（它们只是同一函数的不同别名）时，
你可以在运行时生成默认值，并在所有插入查询中使用这些值。 

<Callout type="info" emoji="ℹ️">
	注意：此值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用
</Callout>

```ts
import { text, mssqlTable } from "drizzle-orm/mssql-core";
import { createId } from '@paralleldrive/cuid2';

const table = mssqlTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

当使用 `$onUpdate()` 或 `$onUpdateFn()`（它们只是同一函数的不同别名）时，
你可以在运行时生成默认值，并在所有更新查询中使用这些值。 

为列添加动态更新值。当行被更新时会调用该函数，
如果未提供列值，则将返回值用作列值。
如果未提供默认值（或 $defaultFn）值，则在插入行时也会调用该函数，
并将返回值用作列值。

<Callout type="info" emoji="ℹ️">
	注意：此值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用
</Callout>

```ts
import { int, datetime2, text, mssqlTable } from "drizzle-orm/mssql-core";

const table = mssqlTable('table', {
	updateCounter: int().default(sql`1`).$onUpdateFn((): SQL => sql`${table.updateCounter} + 1`),
	updatedAt: datetime2({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```

`NOT NULL` 约束规定关联的列不能包含 `NULL` 值。

<Section>
```typescript

```

```sql
CREATE TABLE [table] (
	[int] int NOT NULL
);
```
</Section>


### 主键
主键约束表示一个列或一组列可以作为表中行的唯一标识符。 
这要求这些值既唯一又非空。
<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

const table = pgTable('table', {
	id: int().primaryKey(),
});
```

```sql
CREATE TABLE [table] (
	[id] int PRIMARY KEY
);
```
</Section>
