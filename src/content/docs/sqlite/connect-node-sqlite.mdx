# Drizzle \<\> Node SQLite

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/sqlite/connect-overview)
- Node - [网站](https://nodejs.org/)
- Node SQLite 驱动 - [文档](https://nodejs.org/api/sqlite.html)
</Prerequisites>

Drizzle ORM 原生支持 **[`node:sqlite`](https://nodejs.org/api/sqlite.html)** 模块

我们拥抱 SQL 方言以及方言特定的驱动和语法，与其它任何 ORM 不同，
对于像 `node:sqlite` 这样的同步驱动，我们同时提供 **async** 和 **sync** API，并且我们仿照了最流行的
类 SQLite 的 `all`、`get`、`values` 和 `run` 查询方法语法。

#### 第 1 步 - 安装包
<Npm>
 drizzle-orm@rc
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并执行查询
```typescript copy
import { drizzle } from 'drizzle-orm/node-sqlite';

const db = drizzle("sqlite.db");

const result = await db.select().from(...);
```

如果你需要提供已有的驱动：
```typescript copy
import { drizzle } from 'drizzle-orm/node-sqlite';
import { DatabaseSync } from 'node:sqlite';

const sqlite = new DatabaseSync('sqlite.db');
const db = drizzle({ client: sqlite });

const result = await db.select().from(...);
```

如果你想要使用 **sync** API：
```typescript copy
import { drizzle } from 'drizzle-orm/node-sqlite';
import { DatabaseSync } from 'node:sqlite';

const sqlite = new DatabaseSync('sqlite.db');
const db = drizzle({ client: sqlite });

const result = db.select().from(users).all();
const result = db.select().from(users).get();
const result = db.select().from(users).values();
const result = db.select().from(users).run();
```
