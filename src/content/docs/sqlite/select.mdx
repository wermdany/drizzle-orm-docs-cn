# SQL Select
Drizzle 为你提供了最接近 SQL 的方式从数据库获取数据，同时保持类型安全和可组合性。
它原生支持几乎所有方言的每一种查询特性和能力，
而对于它尚不支持的部分，用户可以通过强大的 [sql](/docs/sqlite/sql) 操作符来添加。

对于以下示例，假设你有一个像这样定义的 `users` 表：

```typescript
import { sqliteTable, integer, text } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id: integer().primaryKey(),
  name: text().notNull(),
  age: integer(),
});
```

### 基础 select
从表中查询所有行，包含所有列：

<Section>
```typescript
const result = await db.select().from(users);
/*
  {
    id: number;
    name: string;
    age: number | null;
  }[]
*/
```
```sql
select "id", "name", "age" from "users";
```
</Section>

注意，结果类型会根据表定义自动推断，包括列的可空性。

<Callout type="info">
Drizzle 总是在 `select` 子句中显式列出列，而不使用 `select *`。<br />
这是内部所必需的，以保证查询结果中字段的顺序，并且通常也被视为一种良好实践。
</Callout>

### 部分 select
在某些情况下，你可能只想查询表中的一部分列。
你可以通过给 `.select()` 方法提供一个选择对象来实现：
<Section>
```typescript copy
const result = await db.select({
  field1: users.id,
  field2: users.name,
}).from(users);

const { field1, field2 } = result[0];
```
```sql
select "id", "name" from "users";
```
</Section>

就像在 SQL 中一样，你可以使用任意表达式作为选择字段，而不仅仅是表列：

<Section>
```typescript
const result = await db.select({
  id: users.id,
  lowerName: sql<string>`lower(${users.name})`,
}).from(users);
```
```sql
select "id", lower("name") from "users";
```
</Section>

<Callout type="warning">
通过指定 `sql<string>`，你是在告诉 Drizzle 该字段的**期望**类型是 `string`。<br />
如果你指定错误（例如对一个将作为字符串返回的字段使用 `sql<number>`），运行时值将不匹配期望类型。
Drizzle 无法基于提供的类型泛型执行任何类型转换，因为该信息在运行时不可用。

如果你需要对返回值应用运行时转换，可以使用 [`.mapWith()`](/docs/sqlite/sql#sqlmapwith) 方法。
</Callout>

### 条件 select

你可以基于某些条件使用动态的选择对象：

```typescript
async function selectUsers(withName: boolean) {
  return db
    .select({
      id: users.id,
      ...(withName ? { name: users.name } : {}),
    })
    .from(users);
}

const result = await selectUsers(true);
```

### Distinct select

你可以使用 `.selectDistinct()` 代替 `.select()`，以从数据集中仅检索唯一的行：
<Section>
```ts
await db.selectDistinct().from(users).orderBy(users.id, users.name);

await db.selectDistinct({ id: users.id }).from(users).orderBy(users.id);
```
```sql
select distinct "id", "name", "age" from "users" order by "users"."id", "users"."name";

select distinct "id" from "users" order by "users"."id";
```
</Section>

### 高级 select
由 TypeScript 驱动，Drizzle API 让你能以多种灵活的方式构建 select 查询。

高级部分选择的预览，更详细的高级用法示例——参见我们的[专门指南](/docs/sqlite/guides/include-or-exclude-columns)。

<CodeTabs items={["示例 1", "示例 2", "示例 3", "示例 4"]}>
```ts
import { getColumns, sql } from 'drizzle-orm';

await db.select({
    ...getColumns(posts),
    titleLength: sql<number>`length(${posts.title})`,
  }).from(posts);
```
```ts
import { getColumns } from 'drizzle-orm';

const { content, ...rest } = getColumns(posts); // 排除 "content" 列
await db.select({ ...rest }).from(posts); // 查询所有其它列
```
```ts
await db.query.posts.findMany({
  columns: {
    title: true,
  },
});
```
```ts
await db.query.posts.findMany({
  columns: {
    content: false,
  },
});
```
</CodeTabs>

### 过滤器

你可以在 `.where()` 方法中使用[过滤操作符](/docs/sqlite/operators)来过滤查询结果：

<Section>
```typescript copy
import { eq, lt, gte, ne } from 'drizzle-orm';

await db.select().from(users).where(eq(users.id, 42));
await db.select().from(users).where(lt(users.id, 42));
await db.select().from(users).where(gte(users.id, 42));
await db.select().from(users).where(ne(users.id, 42));
...
```
```sql
select "id", "name", "age" from "users" where "users"."id" = 42;
select "id", "name", "age" from "users" where "users"."id" < 42;
select "id", "name", "age" from "users" where "users"."id" >= 42;
select "id", "name", "age" from "users" where "users"."id" <> 42;
```
</Section>

所有过滤操作符都是使用 [`sql`](/docs/sqlite/sql) 函数实现的。
你可以自己使用它来编写任意的 SQL 过滤器，或构建你自己的操作符。
作为灵感，你可以查看 Drizzle 提供的操作符是如何[实现](https://github.com/drizzle-team/drizzle-orm/blob/main/drizzle-orm/src/sql/expressions/conditions.ts)的。
<Section>
```typescript copy
import { sql } from 'drizzle-orm';
import type { SQLiteColumn } from "drizzle-orm/sqlite-core";

function equals42(col: SQLiteColumn) {
  return sql`${col} = 42`;
}

await db.select().from(users).where(sql`${users.id} < 42`);
await db.select().from(users).where(sql`${users.id} = 42`);
await db.select().from(users).where(equals42(users.id));
await db.select().from(users).where(sql`${users.id} >= 42`);
await db.select().from(users).where(sql`${users.id} <> 42`);
await db.select().from(users).where(sql`lower(${users.name}) = 'aaron'`);
```
```sql
select "id", "name", "age" from "users" where "users"."id" < 42;
select "id", "name", "age" from "users" where "users"."id" = 42;
select "id", "name", "age" from "users" where "users"."id" = 42;
select "id", "name", "age" from "users" where "users"."id" >= 42;
select "id", "name", "age" from "users" where "users"."id" <> 42;
select "id", "name", "age" from "users" where lower("users"."name") = 'aaron';
```
</Section>

<Callout type='info'>
提供给过滤操作符和 `sql` 函数的所有值都会自动参数化。
例如，这个查询：
```ts
await db.select().from(users).where(eq(users.id, 42));
```
会被转换为：
```sql
select "id", "name", "age" from "users" where "users"."id" = ?; -- 参数：[42]
```
</Callout>

使用 `not` 操作符反转条件：
<Section>
```typescript copy
import { eq, not, sql } from 'drizzle-orm';

await db.select().from(users).where(not(eq(users.id, 42)));
await db.select().from(users).where(sql`not ${users.id} = 42`);
```
```sql
select "id", "name", "age" from "users" where not ("users"."id" = 42);
select "id", "name", "age" from "users" where not "users"."id" = 42;
```
</Section>

<Callout type="info">
你可以安全地修改 schema、重命名表和列，
由于模板插值，这些更改会自动反映在你的查询中，
这与在编写原生 SQL 时硬编码列名或表名的方式不同。
</Callout>

### 组合过滤器
你可以使用 `and()` 和 `or()` 操作符在逻辑上组合过滤操作符：
<Section>
```typescript copy
import { eq, and, sql } from 'drizzle-orm';

await db.select().from(users).where(
  and(
    eq(users.id, 42),
    eq(users.name, 'Dan')
  )
);
await db.select().from(users).where(sql`${users.id} = 42 and ${users.name} = 'Dan'`);
```
```sql
select "id", "name", "age" from "users" where (("users"."id" = 42) and ("users"."name" = 'Dan'));
select "id", "name", "age" from "users" where "users"."id" = 42 and "users"."name" = 'Dan';
```
</Section>

<Section>
```typescript copy
import { eq, or, sql } from 'drizzle-orm';

await db.select().from(users).where(
  or(
    eq(users.id, 42), 
    eq(users.name, 'Dan')
  )
);
await db.select().from(users).where(sql`${users.id} = 42 or ${users.name} = 'Dan'`);
```
```sql
select "id", "name", "age" from "users" where (("users"."id" = 42) or ("users"."name" = 'Dan'));
select "id", "name", "age" from "users" where "users"."id" = 42 or "users"."name" = 'Dan';
```
</Section>

### Limit 与 offset
使用 `.limit()` 和 `.offset()` 为查询添加 limit 和 offset 子句——例如，实现分页：

```ts
await db.select().from(users).limit(10);
await db.select().from(users).limit(10).offset(10);
```

```sql
select "id", "name", "age" from "users" limit 10;
select "id", "name", "age" from "users" limit 10 offset 10;
```

### Order By
使用 `.orderBy()` 为查询添加 `order by` 子句，按指定字段对结果排序：
<Section>
```typescript
import { asc, desc } from 'drizzle-orm';

await db.select().from(users).orderBy(users.name);
await db.select().from(users).orderBy(desc(users.name));

// 按多个字段排序
await db.select().from(users).orderBy(users.name, users.name2);
await db.select().from(users).orderBy(asc(users.name), desc(users.name2));
```
```sql
select "id", "name", "name2", "age" from "users" order by "users"."name";
select "id", "name", "name2", "age" from "users" order by "users"."name" desc;

select "id", "name", "name2", "age" from "users" order by "users"."name", "users"."name";
select "id", "name", "name2", "age" from "users" order by "users"."name" asc, "users"."name2" desc;
```
</Section>

### 高级分页
由 TypeScript 驱动，Drizzle API 让你可以实现所有可能的 SQL 分页和排序方式。

高级分页的预览，更详细的高级
用法示例——参见我们的 [limit offset pagination](/docs/sqlite/guides/limit-offset-pagination)
和 [cursor pagination](/docs/sqlite/guides/cursor-based-pagination) 指南。

<CodeTabs items={["示例 1", "示例 2", "示例 3", "示例 4"]}>
```ts
await db
  .select()
  .from(users)
  .orderBy(asc(users.id)) // order by 是必需的
  .limit(4) // 要返回的行数
  .offset(4); // 要跳过的行数
```
```ts
const getUsers = async (page = 1, pageSize = 3) => {
  return await db.query.users.findMany({
    orderBy: (users, { asc }) => asc(users.id),
    limit: pageSize,
    offset: (page - 1) * pageSize,
  });
};
await getUsers();
```
```ts
const getUsers = async (page = 1, pageSize = 10) => {
   const sq = db
    .select({ id: users.id })
    .from(users)
    .orderBy(users.id)
    .limit(pageSize)
    .offset((page - 1) * pageSize)
    .as('subquery');
   return await db.select().from(users).innerJoin(sq, eq(users.id, sq.id)).orderBy(users.id);
};
```
```ts
const nextUserPage = async (cursor?: number, pageSize = 3) => {
  return await db
    .select()
    .from(users)
    .where(cursor ? gt(users.id, cursor) : undefined) // 如果提供了 cursor，则获取它之后的行
    .limit(pageSize) // 要返回的行数
    .orderBy(asc(users.id)); // 排序
};
// 传入上一页最后一行的 cursor（id）
await nextUserPage(3);
```
</CodeTabs>

### WITH 子句

<Callout>
  查看如何配合 [insert](/docs/sqlite/insert#with-insert-子句)、[update](/docs/sqlite/update#with-update-子句)、[delete](/docs/sqlite/delete#with-delete-子句) 使用 WITH 语句
</Callout>

使用 `with` 子句可以通过将复杂查询拆分为更小的、称为公共表表达式（CTE）的子查询来帮助你简化它们：
<Section>
```typescript copy
const sq = db.$with('sq').as(db.select().from(users).where(eq(users.id, 42)));

const result = await db.with(sq).select().from(sq);
```
```sql
with "sq" as (select "id", "name", "age" from "users" where "users"."id" = 42)
select "id", "name", "age" from "sq";
```
</Section>

你还可以在 `with` 中提供 `insert`、`update` 和 `delete` 语句

<Section>
```typescript copy
const sq = db.$with('sq').as(
    db.insert(users).values({ name: 'John' }).returning(),
);

const result = await db.with(sq).select().from(sq);
```
</Section>

<Section>
```typescript copy
const sq = db.$with('sq').as(
    db.update(users).set({ age: 25 }).where(eq(users.name, 'John')).returning(),
);
const result = await db.with(sq).select().from(sq);
```
</Section>

<Section>
```typescript copy
const sq = db.$with('sq').as(
  db.delete(users).where(eq(users.name, 'John')).returning(),
);

const result = await db.with(sq).select().from(sq);
```
</Section>

若要在 CTE 中选择任意 SQL 值作为字段，并在其它 CTE 或主查询中引用它们，
你需要为它们添加别名：
```typescript copy
const sq = db.$with('sq').as(db.select({ 
  name: sql<string>`upper(${users.name})`.as('name'),
})
.from(users));

const result = await db.with(sq).select({ name: sq.name }).from(sq);
```
如果你不提供别名，该字段类型将变成 `DrizzleTypeError`，你就无法在其它查询中引用它。
如果你忽略类型错误并仍然尝试使用该字段，
你将遇到运行时错误，因为不通过别名就无法引用该字段。

### 从子查询 Select
就像在 SQL 中一样，你可以使用子查询 API 将查询嵌入到其它查询中：
<Section>
```typescript copy
const sq = db.select().from(users).where(eq(users.id, 42)).as('sq');
const result = await db.select().from(sq);
```
```sql
select "id", "name", "age" from (select "id", "name", "age" from "users" where "users"."id" = 42) "sq";
```
</Section>

子查询可以用在任何可以使用表的地方，例如在 joins 中：
<Section>
```typescript copy
const sq = db.select().from(users).where(eq(users.id, 42)).as('sq');
const result = await db.select().from(users).leftJoin(sq, eq(users.id, sq.id));
```
```sql
select "users"."id", "users"."name", "users"."age", "sq"."id", "sq"."name", "sq"."age" from "users"
  left join (select "id", "name", "age" from "users" where "users"."id" = 42) "sq"
    on "users"."id" = "sq"."id";
```
</Section>

### 聚合
使用 Drizzle，你可以通过 `sum`、`count`、`avg` 等函数进行聚合，方法是
分别使用 `.groupBy()` 和 `.having()` 进行分组和过滤，就像你在原生 SQL 中所做的一样：

<Section>
```typescript
import { gt, sql } from "drizzle-orm";

await db.select({
  age: users.age,
  count: sql<number>`cast(count(${users.id}) as int)`,
})
  .from(users)
  .groupBy(users.age);

await db.select({
  age: users.age,
  count: sql<number>`cast(count(${users.id}) as int)`,
})
  .from(users)
  .groupBy(users.age)
  .having(({ count }) => gt(count, 1));
```
```sql
select "age", cast(count("id") as int)
  from "users"
  group by "users"."age";

select "age", cast(count("id") as int)
  from "users"
  group by "users"."age"
  having cast(count("users"."id") as int) > 1;
```
</Section>

<Callout type="info">
`cast(... as int)` 会将选中的 count 值保持为 number 类型。
或者，你可以使用 [`.mapWith(Number)`](/docs/sqlite/sql#sqlmapwith) 在运行时将值转换为数字。

如果你需要 count 聚合——我们建议使用我们的 [$count](/docs/sqlite/select#count) API
</Callout>

### 聚合辅助函数

Drizzle 有一组包装好的 `sql` 函数，因此你无需为应用中的常见场景
编写 `sql` 模板

<Callout type="info">
 请记住，聚合函数常与 SELECT 语句的 GROUP BY 子句一起使用。
 因此如果你在同一个查询中同时使用聚合函数和其它列进行选择，
 务必使用 `.groupBy` 子句
</Callout>

<Section>


```typescript copy
const details = sqliteTable('order_detail', {

db
  .select({
    id: orders.id,
    shippedDate: orders.shippedDate,
    shipName: orders.shipName,
    shipCity: orders.shipCity,
    shipCountry: orders.shipCountry,
    productsCount: sql<number>`cast(count(${details.productId}) as int)`,
    quantitySum: sql<number>`sum(${details.quantity})`,
    totalPrice: sql<number>`sum(${details.quantity} * ${details.unitPrice})`,
  })
  .from(orders)
  .leftJoin(details, eq(orders.id, details.orderId))
  .groupBy(orders.id)
  .orderBy(asc(orders.id))
  .all();
```
