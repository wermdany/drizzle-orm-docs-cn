# Drizzle \<\> Turso Cloud

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/sqlite/connect-overview)
- Turso Cloud - [网站](https://docs.turso.tech/turso-cloud)
- Turso Cloud 驱动 - [网站](https://docs.turso.tech/sdk/ts/reference) & [GitHub](https://github.com/tursodatabase/libsql-client-ts)
</Prerequisites>

根据 **[官方网站](https://turso.tech/drizzle)**，
Turso 是一个由 **[libSQL](https://github.com/libsql/libsql)** 驱动的边缘 SQLite 数据库即服务。
  
Drizzle ORM 原生支持 libSQL 驱动。
我们拥抱 SQL 方言以及方言特定的驱动和语法，并仿照了最流行的
类 SQLite 的 `all`、`get`、`values` 和 `run` 查询方法语法。

#### 第 1 步 - 安装包
<Npm>
 drizzle-orm@rc @libsql/client
 -D drizzle-kit@rc
</Npm>

import { drizzle } from 'drizzle-orm/libsql';
import { createClient } from '@libsql/client';

const client = createClient({ 
  url: process.env.DATABASE_URL,
  authToken: process.env.DATABASE_AUTH_TOKEN

#### 第 3 步 - 执行查询

```ts
import { drizzle } from 'drizzle-orm/libsql';
import * as s from 'drizzle-orm/sqlite-core';

const db = drizzle({ connection: {
  url: process.env.DATABASE_URL, 
  authToken: process.env.DATABASE_AUTH_TOKEN 
}});

const users = s.sqliteTable("users", {
  id: s.integer(),
  name: s.text(),
})

const result = await db.select().from(users);
```
