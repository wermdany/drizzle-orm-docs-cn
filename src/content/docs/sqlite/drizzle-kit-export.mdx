# `drizzle-kit export` 

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/sqlite/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/sqlite/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/sqlite/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/sqlite/migrations)
- Drizzle Kit [概览](/docs/sqlite/kit-overview) 和 [配置文件](/docs/sqlite/drizzle-config-file)
</Prerequisites>


<br/>

`drizzle-kit export` 让你导出 Drizzle schema 的 SQL 表示，并在控制台打印其 SQL DDL 表示。
<Callout collapsed="底层是如何工作的？">
Drizzle Kit 的 `export` 命令会触发一系列事件：
1. 它会读取你的 Drizzle schema 文件，并组合出 schema 的 json 快照
2. 基于当前的 json 快照，它会生成 SQL DDL 语句
3. 将 SQL DDL 语句输出到控制台
</Callout>

它旨在覆盖管理 Drizzle 迁移的[代码优先](/docs/sqlite/migrations)方式。
你可以导出 Drizzle schema 的 SQL 表示，让 Atlas 等外部工具为你处理所有迁移

`drizzle-kit export` 命令要求你同时提供 `dialect` 和 `schema` 路径选项，
你可以通过 [drizzle.config.ts](/docs/sqlite/drizzle-config-file) 配置文件或 CLI 选项设置它们
<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema.ts",
});
```
```shell
npx drizzle-kit export
```
</Section>

```shell
npx drizzle-kit export --dialect=sqlite --schema=./src/schema.ts
```
</CodeTabs>

### schema 文件路径
你可以拥有单个 `schema.ts` 文件，也可以在项目各处散布任意多个 schema 文件。
Drizzle Kit 要求你通过 `schema` 配置选项以 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的形式指定它们的路径。

<SchemaFilePaths/>

### 一个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你拥有多个数据库阶段，或者同一项目中有多个数据库或不同数据库时，这非常有用：
<Npx>
  drizzle-kit export --config=drizzle-dev.config.ts
  drizzle-kit export --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 可用配置项的扩展列表
`drizzle-kit export` 有一个仅限 CLI 的选项列表

<rem025/>

|               |                                                      |
| :--------     | :--------------------------------------------------- |
| `--sql`       | 生成 Drizzle Schema 的 SQL 表示               |

默认情况下，Drizzle Kit 输出 SQL 文件，但未来我们希望能支持不同的格式

<rem025/>

<Npx>
drizzle-kit export --sql=true
</Npx>

<br/>
<hr/>
<br/>
我们推荐通过 [drizzle.config.ts](/docs/sqlite/drizzle-config-file) 文件来配置 `drizzle-kit`，
但如果需要（例如在 CI/CD 流水线等场景中），你也可以通过 CLI 提供所有配置选项。

|               |            |                                                                            |
| :------------ | :-------   | :----------------------------------------------------------------------    |
| `dialect`     | `required` | 数据库方言，<Dialects/> 之一                                       |
| `schema`      | `required` | 指向 typescript schema 文件或包含多个 schema 文件的文件夹的路径  |
| `config`      |            | 配置文件路径，默认是 `drizzle.config.ts`                    |

### 示例
以下示例展示如何将位于 `./src/schema.ts` 的 Drizzle schema 导出到控制台

我们还会把 drizzle 配置文件放在 `configs` 文件夹中。

让我们创建配置文件：

```plaintext {4}
📦 <project root>
 ├ 📂 configs
 │ └ 📜 drizzle.config.ts
 ├ 📂 src
 │ └ 📜 schema.ts
 └ …
```
```ts filename='drizzle.config.ts'
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema.ts",
});
```

```ts filename='schema.ts'
import { sqliteTable, integer, text } from 'drizzle-orm/sqlite-core'

export const users = sqliteTable('users', {
	id: integer().primaryKey({ autoIncrement: true }),
	email: text().notNull(),
	name: text()
});
```

现在让我们运行
```shell
npx drizzle-kit export --config=./configs/drizzle.config.ts
```
它就会成功输出 drizzle schema 的 SQL 表示
```bash
CREATE TABLE `users` (
        `id` integer PRIMARY KEY AUTOINCREMENT,
        `email` text NOT NULL,
        `name` text
);
```
