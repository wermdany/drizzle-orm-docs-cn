# 查询性能
说到 **Drizzle** —— 我们是 SQL 之上薄薄的 TypeScript 层，开销几乎为 0，而要让它真正为 0，你可以利用我们的预处理语句 API。
  
**当你在数据库上运行查询时，会发生以下几件事：**
- 查询构建器的所有配置被拼接成 SQL 字符串
- 该字符串和参数被发送给数据库驱动
- 驱动将 SQL 查询编译为二进制 SQL 可执行格式，并将其发送到数据库

使用预处理语句时，你在 Drizzle ORM 侧只进行一次 SQL 拼接，之后数据库驱动就能复用预编译的二进制 SQL，而不必每次都解析查询。
它在大体积 SQL 查询上有极高的性能优势。

不同的数据库驱动以不同方式支持预处理语句，有时使用 Drizzle ORM，你可以[**比 better-sqlite3 驱动更快。**](https://twitter.com/_alexblokh/status/1593593415907909634)

## 预编译语句

```typescript copy {3}
    const db = drizzle(...);

    const prepared = db.select().from(customers).prepare();
    
    const res1 = prepared.all();
    const res2 = prepared.all();
    const res3 = prepared.all();
    ```

## 占位符
当你需要嵌入动态的运行时值时，可以使用 `sql.placeholder(...)` API

```ts copy {6,9-10,15,18}
    import { sql } from "drizzle-orm";

    const p1 = db
      .select()
      .from(customers)
      .where(eq(customers.id, sql.placeholder('id')))
      .prepare()

    p1.get({ id: 10 }) // SELECT * FROM customers WHERE id = 10
    p1.get({ id: 12 }) // SELECT * FROM customers WHERE id = 12

    const p2 = db
      .select()
      .from(customers)
      .where(sql`lower(${customers.name}) like ${sql.placeholder('name')}`)
      .prepare();

    p2.all({ name: '%an%' }) // SELECT * FROM customers WHERE lower(name) like '%an%'
    ```
