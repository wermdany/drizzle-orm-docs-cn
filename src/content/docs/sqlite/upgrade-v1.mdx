# 升级到 Drizzle v1

<Npm>
 drizzle-orm@rc
 -D drizzle-kit@rc
</Npm>

#### 步骤 1 - 运行 `drizzle-kit up`

> v3 migration folder discussion: https://github.com/drizzle-team/drizzle-orm/discussions/2832  

我们通过以下方式更新了迁移文件夹结构：
- 移除了 `journal.json`
- 将 SQL 文件和快照分组到独立的迁移文件夹中
- 移除了 `drizzle-kit drop` 命令

这些改动消除了可能与 journal 文件产生的 Git 冲突，并简化了删除或修复冲突迁移的过程

drizzle-kit 在架构上经过了重新设计：
- 从数据库快照迁移到 DDL 快照

新增了可交换性（commutativity）检查：
- 检测跨分支的非可交换迁移
> Commutativity discussion: https://github.com/drizzle-team/drizzle-orm/discussions/5005

要从旧结构迁移到新结构，你需要运行

<Npx>
drizzle-kit up
</Npx>

#### 步骤 2 - 审查破坏性变更

你可以在[这里](/docs/sqlite/v0-v1-changes#破坏性变更)找到破坏性变更的完整列表，并确保相应更新你的代码

如果你此前使用了关系查询（Relational Queries），则需要升级到 v2：
- [如何将关系定义从 v1 迁移到 v2](/docs/sqlite/relations-v1-v2#如何将关系-schema-定义从-v1-迁移到-v2)
- [如何将查询从 v1 迁移到 v2](/docs/sqlite/relations-v1-v2#如何将查询从-v1-迁移到-v2)

#### 步骤 3 - 完成 ✅
