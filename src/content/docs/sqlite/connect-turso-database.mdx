# Drizzle \<\> Turso Database

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/sqlite/connect-overview)
- Turso Database - [网站](https://docs.turso.tech/introduction)
- Turso Database 驱动 - [网站](https://docs.turso.tech/connect/javascript) & [GitHub](https://github.com/tursodatabase/turso/tree/main/bindings/javascript)
</Prerequisites>

根据 **[官方网站](https://docs.turso.tech/introduction)**，
Turso 是在 AI 时代为你的宏大梦想提供动力的小型数据库。

#### 第 1 步 - 安装包
<Npm>
 drizzle-orm@rc @tursodatabase/database
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并执行查询
```typescript
import { drizzle } from 'drizzle-orm/tursodatabase/database';

const db = drizzle('sqlite.db');

const result = await db.all('select 1');
```

如果你需要提供已有的驱动：

```typescript
import { Database } from '@tursodatabase/database';
import { drizzle } from 'drizzle-orm/tursodatabase/database';

const client = new Database('sqlite.db');
const db = drizzle({ client });

const result = await db.all('select 1');
```
