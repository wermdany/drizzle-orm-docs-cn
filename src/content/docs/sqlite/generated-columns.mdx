# 生成的列

1. Virtual（或非持久化）生成列：这些列在每次被查询时动态计算。它们不占用数据库中的存储空间。

2. Stored（或持久化）生成列：这些列在插入或更新行时计算，其值会存储在数据库中。这使得它们可以被索引，并且能提升查询性能，因为每次查询时无需重新计算这些值。

#### 数据库端
    **类型**：`STORED`、`VIRTUAL`

    **工作原理**
    - 在表的 schema 中通过表达式定义。
    - Virtual 列在读取操作期间计算。
    - Stored 列在写入操作期间计算并存储。

    **能力**
    - 可用于 SELECT、INSERT、UPDATE 和 DELETE 语句。
    - 可以被索引，virtual 和 stored 列皆可。
    - 可以指定 NOT NULL 及其他约束。
    
    **限制**
    - 不能直接向生成列中插入或更新值

    更多信息，请查阅 [SQLite](https://www.sqlite.org/gencol.html) 文档

    #### Drizzle 侧
    在 Drizzle 中，你可以在任意列类型上指定 `.generatedAlwaysAs()` 函数，并添加一个受支持的 sql 查询，
    它会为你生成该列的数据。

    #### 特性
    该函数可以通过 2 种方式接受生成表达式：

    **`sql`** 标签 - 如果你希望 drizzle 为你转义某些值

    ```ts
    export const test = sqliteTable("test", {
        id: int().primaryKey(),
        generatedName: text("gen_name").generatedAlwaysAs(sql`'hello "world"!'`),
    });
    ```
    ```sql
    CREATE TABLE `test` (
      `id` integer PRIMARY KEY,
      `gen_name` text GENERATED ALWAYS AS ('hello "world"!') VIRTUAL
    );
    ```

    **`callback`** - 如果你需要引用表中的列

    ```ts
    export const test = sqliteTable("test", {
        name: text("first_name"),
        generatedName: text("gen_name").generatedAlwaysAs(
          (): SQL => sql`'hi,' || ${test.name} || '!'`
        ),
    });
    ```
    ```sql
    CREATE TABLE `test` (
      `first_name` text,
      `gen_name` text GENERATED ALWAYS AS ('hi,' || "first_name" || '!') VIRTUAL
    );
    ```

    #### 在 Drizzle Kit 中的行为
	`push` 和 `generate` 命令：
    1. 修改现有表中 `stored` 列的生成表达式会导致表重建。（修改 `virtual` 表达式会导致列重建）。
    2. 为现有列添加 `stored` 生成表达式会导致表重建。（为现有列添加 `virtual` 表达式会导致列重建）。
    3. 将生成模式从 `virtual` 改为 `stored` 会导致表重建。（从 `stored` 切换为 `virtual` 会导致列重建）。

      storedGenerated: text("stored_gen").generatedAlwaysAs(

    CREATE TABLE `users` (

    );
