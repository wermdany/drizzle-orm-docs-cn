# Drizzle \<\> SQLite Cloud
<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/sqlite/connect-overview)
- **SQLite Cloud 数据库** - [文档](https://docs.sqlitecloud.io/docs/overview)
- **SQLite Cloud 驱动** - [文档](https://docs.sqlitecloud.io/docs/sdk-js-introduction) & [GitHub](https://github.com/sqlitecloud/sqlitecloud-js)
</Prerequisites>

根据 **[官方网站](https://docs.sqlitecloud.io/docs/overview)**，SQLite Clouds 是一个构建在 SQLite 数据库引擎之上的托管式分布式关系数据库系统。

#### 第 1 步 - 安装包
<Npm>
 drizzle-orm@rc @sqlitecloud/drivers
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并执行查询
```typescript
import { drizzle } from 'drizzle-orm/sqlite-cloud';

const db = drizzle(process.env.SQLITE_CLOUD_CONNECTION_STRING);

const result = await db.all('select 1');
```

如果你需要提供已有的驱动：

```typescript
import { Database } from '@sqlitecloud/drivers';
import { drizzle } from 'drizzle-orm/sqlite-cloud';

const client = new Database(process.env.SQLITE_CLOUD_CONNECTION_STRING!);
const db = drizzle({ client });

const result = await db.all('select 1');
```
