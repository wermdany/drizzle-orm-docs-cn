# Drizzle \<\> Expo SQLite
根据 **[官方网站](https://expo.dev/)**，Expo 是一个用于在 React Native 上开发、构建和发布应用的工具体系。
它由 Hermes JavaScript 运行时和 Metro 打包器驱动，Drizzle Expo 驱动专为原生支持二者而构建。  
  
Drizzle ORM 为 Expo SQLite 提供了同类最佳的工具体系：
- 面向 Expo SQLite 的原生 ORM 驱动 ✅
- [Drizzle Kit](/docs/sqlite/kit-overview) 支持在应用中生成迁移和打包 ✅
- [Drizzle Studio](https://github.com/drizzle-team/drizzle-studio-expo) 开发工具插件，用于浏览设备上的数据库 ✅
- 实时查询（Live Queries）✅
  
<Npm>
 drizzle-orm@rc expo-sqlite@next
 -D drizzle-kit@rc
</Npm>

```ts
import { drizzle } from "drizzle-orm/expo-sqlite";
import { openDatabaseSync } from "expo-sqlite";

const expo = openDatabaseSync("db.db");
const db = drizzle(expo);

await db.select().from(users);
```
#### 实时查询
使用 `useLiveQuery` hook，你可以让任何 Drizzle 查询变为响应式：
```ts
import { useLiveQuery, drizzle } from 'drizzle-orm/expo-sqlite';
import { openDatabaseSync } from 'expo-sqlite';
import { Text } from 'react-native';
import * as schema from './schema';

const expo = openDatabaseSync('db.db', { enableChangeListener: true }); // <-- 启用变更监听器
const db = drizzle(expo);

const App = () => {
  // 数据变化时自动重新渲染
  const { data } = useLiveQuery(db.select().from(schema.users));
  return <Text>{JSON.stringify(data)}</Text>;
};

export default App;
```

#### 使用 Drizzle Kit 进行 Expo SQLite 迁移
你可以使用 Drizzle Kit 生成 SQL 迁移。  
在继续之前，请务必了解 [Drizzle migrations](/docs/sqlite/kit-overview) 的工作原理。  
Expo / React Native 要求你把 SQL 迁移打包进应用，我们已经为你处理好这一点。  

<Steps>
#### 安装 babel 插件
有必要将 SQL 迁移文件作为字符串直接打包进你的 bundle。
```shell
npm install babel-plugin-inline-import
```

#### 更新配置文件。
你需要更新 `babel.config.js`、`metro.config.js` 和 `drizzle.config.ts` 文件
```js filename='babel.config.js'
module.exports = function(api) {
  api.cache(true);

  return {
    presets: ['babel-preset-expo'],
    plugins: [["inline-import", { "extensions": [".sql"] }]] // <-- 添加这一项
  };
};
```

```js filename="metro.config.js"
const { getDefaultConfig } = require('expo/metro-config');

/** @type {import('expo/metro-config').MetroConfig} */
const config = getDefaultConfig(__dirname);

config.resolver.sourceExts.push('sql'); // <--- 添加这一项

module.exports = config;
```

确保在 Drizzle Kit 配置中设置 `dialect: 'sqlite'` 和 `driver: 'expo'`
```ts filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
	schema: './db/schema.ts',
	out: './drizzle',
  dialect: 'sqlite',
	driver: 'expo', // <--- 非常重要
});
```

#### 生成迁移
在创建 SQL schema 文件和 drizzle.config.ts 文件后，你就可以生成迁移
```bash
npx drizzle-kit generate
```

#### 将迁移添加到你的应用
现在你需要从 `./drizzle` 文件夹将 `migrations.js` 文件导入到你的 Expo/React Native 应用中。
你可以使用我们自定义的 `useMigrations` 迁移 hook，在应用启动时运行迁移，或者按你的想法在 `useEffect` hook 中手动运行。

```ts filename="App.tsx"
import { drizzle } from "drizzle-orm/expo-sqlite";
import { openDatabaseSync } from "expo-sqlite";
import { useMigrations } from 'drizzle-orm/expo-sqlite/migrator';
import migrations from './drizzle/migrations';

const expoDb = openDatabaseSync("db.db");

const db = drizzle(expoDb);

export default function App() {
  const { success, error } = useMigrations(db, migrations);

  if (error) {
    return (
      <View>
        <Text>Migration error: {error.message}</Text>
      </View>
    );
  }

  if (!success) {
    return (
      <View>
        <Text>Migration is in progress...</Text>
      </View>
    );
  }

  return ...your application component;
}
```
</Steps>
