# Drizzle 迁移基础

SQL 数据库要求你预先指定将要存储的实体的**严格 schema**，
如果（当）你需要更改这些实体的形态 —— 你将需要通过 **schema 迁移** 来完成。

有多种生产级别的数据库迁移管理方式。
Drizzle 被设计为完美适配所有这些方式，无论你是采用**数据库优先**还是**代码库优先**。

**数据库优先**是指你的数据库 schema 是唯一事实来源。你可以直接在数据库上或
通过数据库迁移工具管理数据库 schema，然后将数据库 schema 拉取到代码库应用层面的实体中。  
 
**代码库优先**是指代码库中的数据库 schema 是唯一事实来源，并处于版本控制之下。你用 JavaScript/TypeScript 声明并管理数据库 schema，
然后使用 Drizzle、直接或通过外部迁移工具将该 schema 应用到数据库本身。 

#### Drizzle 能提供什么帮助？
我们构建了 [**drizzle-kit**](/docs/sqlite/kit-overview) —— 用于通过 Drizzle 管理迁移的 CLI 应用。 
```shell
drizzle-kit migrate
drizzle-kit generate
drizzle-kit push
drizzle-kit pull
drizzle-kit export
```
它旨在让你根据当前业务需求选择如何处理迁移。 

它同时适用于数据库优先和代码库优先方法，让你**推送 schema**或**生成 SQL 迁移**文件，或从数据库**拉取 schema**。 
无论你是独立工作还是团队协作，它都非常适合。

<rem/>

<Tag style="font-size: 12px">**选项 1**</Tag>
> 我自己使用外部迁移工具或直接在数据库上运行 SQL 迁移来管理数据库 schema。
> 从 Drizzle 我只需要从数据库获取当前 schema 状态，并将其保存为 TypeScript schema 文件。

<Callout collapsed="展开详情">
这是一种**数据库优先**方法。你将数据库 schema 作为**唯一事实来源**，
Drizzle 让你使用 [`drizzle-kit pull`](/docs/sqlite/drizzle-kit-pull) 命令将数据库 schema 拉取到 TypeScript。

<Section>
```
                                  ┌────────────────────────┐      ┌───────────────────────────────────────┐ 
                                  │                        │ <---  CREATE TABLE `users` (
┌──────────────────────────┐      │                        │        `id` integer primary key autoincrement,
│ ~ drizzle-kit pull       │      │                        │        `name` TEXT,
└─┬────────────────────────┘      │        DATABASE        │        `email` TEXT UNIQUE
  │                               │                        │       );
  └ Pull datatabase schema -----> │                        │
  ┌ Generate Drizzle       <----- │                        │
  │ schema TypeScript file        └────────────────────────┘
  │
  v
```
```typescript
import * as p from "drizzle-orm/sqlite-core";

export const users = p.sqliteTable("users", {
	id: p.integer().primaryKey({ autoIncrement: true }),
	name: p.text(),
	email: p.text().unique(),
});
```
</Section>

<Tag style="font-size: 12px">**选项 2**</Tag>
> 我想在 TypeScript 代码库中拥有数据库 schema， 
> 我不想处理 SQL 迁移文件。  
> 我希望 Drizzle 将我的 schema 直接「推送」到数据库

<Callout collapsed="展开详情">
这是一种**代码库优先**方法。你将 TypeScript Drizzle schema 作为**唯一事实来源**，
Drizzle 让你使用 [`drizzle-kit push`](/docs/sqlite/drizzle-kit-push) 命令将 schema 变更推送到数据库。

这是快速原型开发的最佳方法，我们已看到数十个团队
和独立开发者成功地将其用作生产应用中的主要迁移流程。

<Section>
```typescript {6} filename="src/schema.ts"
import * as p from "drizzle-orm/sqlite-core";

export const users = p.sqliteTable("users", {
  id: p.integer().primaryKey({ autoIncrement: true }),
  name: p.text(),
  email: p.text(), // <--- 新增列
});
```
```
Add column to `users` table                                                                          
┌──────────────────────────┐                  
│ + email: text()          │                  
└─┬────────────────────────┘                  
  │                                           
  v                                           
┌──────────────────────────┐                  
│ ~ drizzle-kit push       │                  
└─┬────────────────────────┘                  
  │                                           ┌──────────────────────────┐
  └ Pull current datatabase schema ---------> │                          │
                                              │                          │
  ┌ Generate alternations based on diff <---- │         DATABASE         │
  │                                           │                          │
  └ Apply migrations to the database -------> │                          │
                                       │      └──────────────────────────┘
                                       │
  ┌────────────────────────────────────┴─┐
   ALTER TABLE `users` ADD `email` text; 
```

<Tag style="font-size: 12px">**选项 3**</Tag>
> 我想在 TypeScript 代码库中拥有数据库 schema， 
> 我希望 Drizzle 为我生成 SQL 迁移文件并将其应用到我的数据库

<Callout collapsed="展开详情">
这是一种**代码库优先**方法。你将 TypeScript Drizzle schema 作为唯一事实来源，
Drizzle 让你使用 [`drizzle-kit generate`](/docs/sqlite/drizzle-kit-generate) 根据 schema 变更生成 SQL 迁移文件，
然后使用 [`drizzle-kit migrate`](/docs/sqlite/drizzle-kit-migrate) 命令将它们应用到数据库。 
<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/sqlite-core";

export const users = p.sqliteTable("users", {
  id: p.integer().primaryKey({ autoIncrement: true }),
  name: p.text(),
  email: p.text().unique(),
});
```
```                                  
┌────────────────────────┐                  
│ $ drizzle-kit generate │                  
└─┬──────────────────────┘                  
  │                                           
  └ 1. read previous migration folders
    2. find diff between current and previous schema
    3. prompt developer for renames if necessary
  ┌ 4. generate SQL migration and persist to file
  │    ┌─┴───────────────────────────────────────┐  
  │      📂 drizzle       
  │      └ 📂 20242409125510_premium_mister_fear
  │        ├ 📜 snapshot.json
  │        └ 📜 migration.sql
  v
```
```sql
-- drizzle/20242409125510_premium_mister_fear/migration.sql

CREATE TABLE `users` (
	`id` integer PRIMARY KEY AUTOINCREMENT,
	`name` text,
	`email` text UNIQUE
);
```
```
┌───────────────────────┐                  
│ $ drizzle-kit migrate │                  
└─┬─────────────────────┘                  
  │                                                         ┌──────────────────────────┐                                         
  └ 1. read migration.sql files in migrations folder        │                          │
    2. fetch migration history from database -------------> │                          │
  ┌ 3. pick previously unapplied migrations <-------------- │         DATABASE         │
  └ 4. apply new migration to the database ---------------> │                          │
                                                            │                          │
                                                            └──────────────────────────┘
[✓] done!                                                 
```

<Tag style="font-size: 12px">**选项 4**</Tag>
> 我想在 TypeScript 代码库中拥有数据库 schema，
> 我希望 Drizzle 为我生成 SQL 迁移文件，并希望 Drizzle 在运行时应用它们

<Callout collapsed="展开详情">
这是一种**代码库优先**方法。你将 TypeScript Drizzle schema 作为唯一事实来源，
Drizzle 让你使用 [`drizzle-kit generate`](/docs/sqlite/drizzle-kit-generate) 根据 schema 变更生成 SQL 迁移文件，然后
你可以在应用运行时将它们应用到数据库。

这种方法广泛用于**单体**应用，在零停机部署期间应用数据库迁移，
并在出现问题时回滚 DDL 变更。 
它也用于**无服务器**部署，迁移在部署过程中作为**自定义资源**运行一次。

<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/sqlite-core";

export const users = p.sqliteTable("users", {
  id: p.integer().primaryKey({ autoIncrement: true }),
  name: p.text(),
  email: p.text().unique(),
});
```
```                                  
┌────────────────────────┐                  
│ $ drizzle-kit generate │                  
└─┬──────────────────────┘                  
  │                                           
  └ 1. read previous migration folders
    2. find diff between current and previous schema
    3. prompt developer for renames if necessary
  ┌ 4. generate SQL migration and persist to file
  │    ┌─┴───────────────────────────────────────┐  
  │      📂 drizzle       
  │      └ 📂 20242409125510_premium_mister_fear
  │        ├ 📜 snapshot.json
  │        └ 📜 migration.sql
  v
```
```sql
-- drizzle/20242409125510_premium_mister_fear/migration.sql

CREATE TABLE `users` (
	`id` integer PRIMARY KEY AUTOINCREMENT,
	`name` text,
	`email` text UNIQUE
);
```
```ts
// index.ts
import { drizzle } from "drizzle-orm/better-sqlite3"
import { migrate } from 'drizzle-orm/better-sqlite3/migrator';

const db = drizzle(process.env.DATABASE_URL);

await migrate(db);
```
```

    3. fetch migration history from database -------------> │                          │

  └ 5. apply new migration to the database ---------------> │                          │
```
