# Drizzle 查询

Drizzle ORM 的设计目标是在 SQL 之上提供一层薄薄的类型化封装。
我们真心相信我们已经设计出了从 TypeScript 操作 SQL 数据库的最佳方式，而现在是时候让它更好了。
  
关系查询旨在为你提供出色的开发体验，让你能够从 SQL 数据库查询
嵌套的关系型数据，避免多次 joins 和复杂的数据映射。

它是对现有 schema 定义和查询构建器的扩展。
你可以根据自己的需要选择使用它。
我们确保你同时拥有同类最佳的开发体验和性能。

<Callout type="info" title='重要'>
在关系查询中，对表列的引用必须通过回调参数，而不是通过导入的表对象。
这一点适用于所有接受回调的子句——`orderBy`、`where`.`RAW`、`extras` 以及 `extras 内部的子查询`。
回调会暴露当前查询作用域中被别名化的表，这对于在嵌套或自引用查询中正确生成 SQL 是必需的。

<Callout type="error" title='❌' collapsed="示例">
```ts
await db.query.posts.findMany({
  orderBy: sql`${posts.id} asc`, // <- ❌ 直接使用表对象
  with: {
    comments: {
      orderBy: sql`${comments.id} desc`, // <- ❌ 直接使用表对象
    },
  },
});
```
```ts
await db.query.users.findMany({
  where: {
    RAW: sql`LOWER(${users.name}) LIKE 'john%'`, // <- ❌ 直接使用表对象
  },
});
```
```ts
await db.query.users.findMany({
  extras: {
    loweredName: sql<string>`lower(${users.name})`, // <- ❌ 直接使用表对象
    totalPostsCount: db.$count(posts, eq(posts.authorId, users.id)),  // <- ❌ 直接使用表对象
  },
});
```
</Callout>
<Callout type="default" title='✅' collapsed="示例">
```ts
await db.query.posts.findMany({
  orderBy: (t) => sql`${t.id} asc`, // <- ✅ 使用了回调
  with: {
    comments: {
      orderBy: (t, { desc }) => desc(t.id), // <- ✅ 使用了回调
    },
  },
});
```
```ts
await db.query.users.findMany({
  where: {
    RAW: (t) => sql`LOWER(${t.name}) LIKE 'john%'`, // <- ✅ 使用了回调
  },
});
```
```ts
await db.query.users.findMany({
  extras: {
    loweredName: (t, { sql }) => sql<string>`lower(${t.name})`, // <- ✅ 使用了回调
    totalPostsCount: (t) => db.$count(posts, eq(posts.authorId, t.id)), // <- ✅ 使用了回调
  },
});
```
</Callout>
</Callout>

你需要在初始化 `drizzle()` 时提供 schema 文件中的所有 `tables` 和 `relations`，
然后直接使用 `db.query` API。

<CodeTab>
```ts

await db.query.users.findMany(...);
```

```typescript copy
import { type AnySQLiteColumn, integer, sqliteTable, primaryKey, text } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
	id: integer().primaryKey({ autoIncrement: true }),
	name: text().notNull(),
	invitedBy: integer('invited_by').references((): AnySQLiteColumn => users.id),
});

export const groups = sqliteTable('groups', {
	id: integer().primaryKey({ autoIncrement: true }),
	name: text().notNull(),
	description: text(),
});

export const usersToGroups = sqliteTable('users_to_groups', {
	id: integer().primaryKey({ autoIncrement: true }),
	userId: integer('user_id').notNull().references(() => users.id),
	groupId: integer('group_id').notNull().references(() => groups.id),
}, (t) => [
	primaryKey({ columns: [t.userId, t.groupId] })
]);

export const posts = sqliteTable('posts', {
	id: integer().primaryKey({ autoIncrement: true }),
	content: text().notNull(),
	authorId: integer('author_id').references(() => users.id),
	createdAt: integer('created_at', { mode: 'timestamp' }).notNull(),
});

export const comments = sqliteTable('comments', {
	id: integer().primaryKey({ autoIncrement: true }),
	content: text().notNull(),
	creator: integer().references(() => users.id),
	postId: integer('post_id').references(() => posts.id),
	createdAt: integer('created_at', { mode: 'timestamp' }).notNull(),
});

export const commentLikes = sqliteTable('comment_likes', {
	id: integer().primaryKey({ autoIncrement: true }),
	creator: integer().references(() => users.id),
	commentId: integer('comment_id').references(() => comments.id),
	createdAt: integer('created_at', { mode: 'timestamp' }).notNull(),
});
```
```typescript copy
import { defineRelations } from 'drizzle-orm';
import * as schema from './schema';

export const relations = defineRelations(schema, (r) => ({
    users: {
      invitee: r.one.users({
        from: r.users.invitedBy,
        to: r.users.id,
      }),
      groups: r.many.groups({
        from: r.users.id.through(r.usersToGroups.userId),
        to: r.groups.id.through(r.usersToGroups.groupId),
      }),
      posts: r.many.posts(),
    },
    groups: {
      users: r.many.users(),
    },
    posts: {
      author: r.one.users({
        from: r.posts.authorId,
        to: r.users.id,
      }),
      comments: r.many.comments(),
    },
    comments: {
      post: r.one.posts({
        from: r.comments.postId,
        to: r.posts.id,
      }),
      author: r.one.users({
        from: r.comments.creator,
        to: r.users.id,
      }),
      likes: r.many.commentLikes(),
    },
    commentLikes: {
      comment: r.one.comments({
        from: r.commentLikes.commentId,
        to: r.comments.id,
      }),
      author: r.one.users({
        from: r.commentLikes.creator,
        to: r.users.id,
      }),
    },
  })
);
```

### 包含关系

`With` 操作符让你能够组合来自多个相关表的数据，并正确地聚合结果。

**获取所有带有 comments 的 posts：**
```typescript copy
const posts = await db.query.posts.findMany({
	with: {
		comments: true,
	},
});
```

**获取第一条带有 comments 的 post：**
```typescript copy
const post = await db.query.posts.findFirst({
	with: {
		comments: true,
	},
});
```

你可以根据需要尽可能多地链式嵌套 with 语句。
对于任何嵌套的 `with` 查询，Drizzle 都会使用 [Core Type API](/docs/sqlite/goodies#类型-api) 推断类型。
  
**获取所有 users 及其 posts。每篇 post 应包含一个 comments 列表：**
```typescript copy
const users = await db.query.users.findMany({
	with: {
		posts: {
			with: {
				comments: true,
			},
		},
	},
});
```

### 部分字段选择
`columns` 参数让你可以包含或省略想从数据库中获取的列。

<Callout type="info" emoji="ℹ️">
  Drizzle 在查询层面执行部分选择，不会有额外数据从数据库传输过来。

  请记住，**Drizzle 只输出一条 SQL 语句。**
</Callout>

**获取所有 posts，仅包含 `id`、`content`，并包含 `comments`：**
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		id: true,
		content: true,
	},
	with: {
		comments: true,
	}
});
```

**获取所有不带 `content` 的 posts：**
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		content: false,
	},
});
```

<Callout type="info" emoji="ℹ️">
当同时存在 `true` 和 `false` 选择项时，所有 `false` 选项都会被忽略。
</Callout>

如果你包含 `name` 字段并排除 `id` 字段，那么排除 `id` 就是多余的，
因为除 `name` 以外的所有字段本来都会被排除。
  
**在同一个查询中排除并包含字段：**
<Section>
```typescript copy
const users = await db.query.users.findMany({
	columns: {
		name: true,
		id: false //忽略
	},
});
```
```ts
// 结果类型
const users: {
	name: string;
};
```
</Section>

**仅包含嵌套 relations 中的列：**
<Section>
```typescript copy
const res = await db.query.users.findMany({
	columns: {},
	with: {
		posts: true
	}
});
```
```ts
// 结果类型
const res: {
	posts: {
		id: number,
		text: string
	}
}[];
```
</Section>

### 嵌套部分字段选择

```typescript copy
const posts = await db.query.posts.findMany({
```

### Select 过滤器
就像我们的 SQL 风格查询构建器一样，
关系查询 API 让你可以使用我们的 **[`operators`](/docs/sqlite/operators)** 列表来定义过滤器和条件。

你可以从 `drizzle-orm` 导入它们，也可以使用回调语法：
<Section>
```typescript copy
const users = await db.query.users.findMany({
	where: {
		id: 1
	}
});
```
```sql {7}
select
  "d0"."id" as "id",
  "d0"."name" as "name"
from
  "users" as "d0"
where
  "d0"."id" = 1
```
</Section>

查找 `id=1` 的 post，以及创建时间早于特定日期的 comments：
```typescript copy
await db.query.posts.findMany({
  where: {
    id: 1,
  },
  with: {
    comments: {
      where: {
        createdAt: { lt: new Date() },
      },
    },
  },
});
```

**所有过滤运算符的列表**
```ts
where: {
    OR: [],
    AND: [],
    NOT: {},
    RAW: (table) => sql`${table.id} = 1`,

    // 按 relations 过滤
    [relation]: {},

	  // 按列过滤
    [column]: {
      OR: [],
      AND: [],
      NOT: {},
      eq: 1,
      ne: 1,
      gt: 1,
      gte: 1,
      lt: 1,
      lte: 1,
      in: [1],
      notIn: [1],
      like: "",
      notLike: "",
      isNull: true,
      isNotNull: true,
    },
},
```

### 关系过滤器

使用 Drizzle Relations，你不仅可以按正在查询的表进行过滤，还可以按查询中包含的任何表进行过滤。

**示例：** 获取所有 ID>10 且至少有一篇 content 以 "M" 开头的 post 的 `users`
```ts
const usersWithPosts = await db.query.usersTable.findMany({
  where: {
    id: {
      gt: 10
    },
    posts: {
      content: {
        like: 'M%'
      }
    }
  },
});
```

**示例：** 获取所有带 posts 的 `users`，仅当该 user 至少有 1 篇 post 时
```ts
const response = await db.query.users.findMany({
  with: {
    posts: true,
  },
  where: {
    posts: true,
  },
});
```

### Limit 与 Offset
Drizzle ORM 为查询以及嵌套实体提供了 `limit` 和 `offset` API。
  
**查找 5 篇 posts：**
```typescript copy
await db.query.posts.findMany({
	limit: 5,
});
```

**查找 posts，并最多获取 3 条 comments：**
```typescript copy
await db.query.posts.findMany({
	with: {
		comments: {
			limit: 3,
		},
	},
});
```

<Callout type="warning" emoji="⚠️">
  `offset` 现在也可以用在 with 的表中了！
</Callout>
```typescript 
await db.query.posts.findMany({
	limit: 5,
	offset: 2, // 正确 ✅
	with: {
		comments: {
			offset: 3, // 正确 ✅
			limit: 3,
		},
	},
});
```

查找从第 6 篇到第 10 篇 post 及其 comments：
```typescript copy
await db.query.posts.findMany({
	with: {
		comments: true,
	},
  limit: 5,
  offset: 5,
});
```

### Order By
Drizzle 在关系查询构建器中提供了排序 API。

你可以使用相同的排序 **[core API](/docs/sqlite/select#order-by)**，也可以
无需导入，直接使用回调中的 `order by` 操作符。

<Callout title='重要'>
当你在同一张表中使用多个 `orderBy` 语句时，它们会按你添加它们的顺序被包含在查询中
</Callout>

<Section>
```typescript copy
await db.query.posts.findMany({
  orderBy: {
    id: "asc",
  },
});
```
</Section>

**按 `asc` + `desc` 排序：**
```typescript copy
  await db.query.posts.findMany({
    orderBy: { id: "asc" },
    with: {
      comments: {
        orderBy: { id: "desc" },
      },
    },
  });
```

你还可以在 order by 语句中使用自定义 `sql`：

```typescript copy
await db.query.posts.findMany({
  orderBy: (t) => sql`${t.id} asc`,
  with: {
    comments: {
      orderBy: (t, { desc }) => desc(t.id),
    },
  },
});
```

### 包含自定义字段
关系查询 API 让你可以添加自定义的额外字段。
当你需要检索数据并对其应用额外函数时，这很有用。
<Callout type="warning" emoji="⚠️">
	截至目前，`extras` 中尚不支持聚合，请为此使用 **[`core queries`](/docs/sqlite/select)**。
</Callout>

<Section>
```typescript copy {5}
import { sql } from 'drizzle-orm';

await db.query.users.findMany({
  extras: {
    loweredName: (table) => sql`lower(${table.name})`,
  },
});
```
```typescript copy {3}
await db.query.users.findMany({
	extras: {
		loweredName: (users, { sql }) => sql`lower(${users.name})`,
	},
})
```
</Section>

`lowerName` 作为键会被包含到返回对象的所有字段中。

<Callout type="warning" emoji="⚠️">
  如果你为任何 extras 字段指定 `.as("<alias>")`——drizzle 会忽略它
</Callout>

要获取所有 users 及其 groups，但包含 fullName 字段（它是 firstName 和 lastName 的拼接），
你可以使用以下查询搭配 Drizzle 关系查询构建器。

<Section>
```typescript copy
const res = await db.query.users.findMany({
	extras: {
		fullName: (users, { sql }) => sql<string>`concat(${users.name}, " ", ${users.name})`,
	},
	with: {
		groups: true,
	},
});
```
```ts
// 结果类型
const res: {
    id: number;
    name: string;
    age: number | null;
    invitedBy: number | null;
    fullName: string;
    groups: {
        id: number;
        name: string;
        description: string | null;
    }[];
}[]
```
</Section>

要获取所有 posts 及其 comments，并添加一个额外字段来计算 post content 的长度以及每条 comment content 的长度：

### 包含子查询

你还可以在关系查询中使用子查询，以利用自定义 SQL 语法的强大能力

**获取 users 及其 posts，以及每个 user 的 posts 总数**
```ts
import { posts } from './schema';
import { eq } from 'drizzle-orm';

await db.query.users.findMany({
  with: {
    posts: true
  },
  extras: {
    totalPostsCount: (table) => db.$count(posts, eq(posts.authorId, table.id)),
  }
});
```
```sql
SELECT
	"d0"."id" AS "id",
	"d0"."name" AS "name",
	"d0"."age" AS "age",
	"d0"."invited_by" AS "invitedBy",
	(
		(
			SELECT
				count(*)
			FROM
				"posts"
			WHERE
				"posts"."author_id" = "d0"."id"
		)
	) AS "totalPostsCount",
	coalesce(
		(
			SELECT
				json_group_array(json_object('id', "id", 'content', "content", 'authorId', "authorId", 'createdAt', "createdAt")) AS "r"
			FROM
				(
					SELECT
						"d1"."id" AS "id",
						"d1"."content" AS "content",
						"d1"."author_id" AS "authorId",
						"d1"."created_at" AS "createdAt"
					FROM
						"posts" AS "d1"
					WHERE
						"d0"."id" = "d1"."author_id"
				) AS "t"
		),
		jsonb_array ()
	) AS "posts"
FROM
	"users" AS "d0"
```

### 预编译语句
Prepared statements 旨在大幅提升查询性能——[参见这里。](/docs/sqlite/perf-queries)

在本节中，你可以学习如何使用 Drizzle 关系查询构建器定义占位符并执行 prepared statements。

##### **`where` 中的占位符**

<Section>
```ts copy
const prepared = db.query.users.findMany({
    where: { id: { eq: sql.placeholder("id") } },
    with: {
      posts: {
        where: { id: 1 },
      },
    },
}).prepare();

const usersWithPosts = await prepared.execute({ id: 1 });
```
</Section>

##### **`limit` 中的占位符**

<Section>

```ts copy
    },
```

</Section>

##### **多个占位符**

<Section>
```ts copy
const prepared = db.query.users.findMany({
```
