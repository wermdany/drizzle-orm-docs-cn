# 只读副本

当你的项目涉及一组只读副本实例，并且你需要一种便捷的方式来管理
来自只读副本的 SELECT 查询，以及在主实例上执行创建、删除和更新操作时，
你可以利用 Drizzle 中的 `withReplicas()` 函数

```ts copy
import { sql } from 'drizzle-orm';
import { sqliteTable, int, text, withReplicas } from 'drizzle-orm/sqlite-core';
import { createClient } from '@libsql/client';
import { drizzle } from 'drizzle-orm/libsql';

const usersTable = sqliteTable('users', {
	id: int().primaryKey(),
	name: text().notNull(),
});

const primaryDb = drizzle({ client: createClient({ url: 'DATABASE_URL', authToken: 'DATABASE_AUTH_TOKEN' }) });
const read1 = drizzle({ client: createClient({ url: 'DATABASE_URL', authToken: 'DATABASE_AUTH_TOKEN' }) });
const read2 = drizzle({ client: createClient({ url: 'DATABASE_URL', authToken: 'DATABASE_AUTH_TOKEN' }) });

const db = withReplicas(primaryDb, [read1, read2]);
```

现在你可以像以前一样使用 `db` 实例。Drizzle 将
自动处理只读副本和主实例之间的选择。

```ts
// 从 read1 连接或 read2 连接读取
await db.select().from(usersTable)

// 对 delete 操作使用主数据库
await db.delete(usersTable).where(eq(usersTable.id, 1))
```

你可以使用 `$primary` 键强制使用主实例，即使是读操作

```ts
// 从主实例读取
await db.$primary.select().from(usersTable);
```

使用 Drizzle，你还可以为选择只读副本指定自定义逻辑。 
你可以做出加权决策或任何其他用于随机选择只读副本的自定义选择方法。 
以下是一个用于选择只读副本的自定义逻辑实现示例，
其中第一个副本有 70% 的概率被选中，第二个副本有 30% 
的概率被选中。

请记住，你可以为只读副本实现任何类型的随机选择方法

```ts
const db = withReplicas(primaryDb, [read1, read2], (replicas) => {
    const weight = [0.7, 0.3];
    let cumulativeProbability = 0;
    const rand = Math.random();

    for (const [i, replica] of replicas.entries()) {
      cumulativeProbability += weight[i]!;
      if (rand < cumulativeProbability) return replica;
    }
    return replicas[0]!
});

await db.select().from(usersTable)
```
