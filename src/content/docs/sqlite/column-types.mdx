title: SQLite 列类型

import Section from '@mdx/Section.astro';
import Callout from '@mdx/Callout.astro';

基于官方 **[SQLite 文档](https://www.sqlite.org/datatype3.html)**，
存储在 SQLite 数据库中的每个值（或由数据库引擎操作的值）
都属于以下存储类之一：`NULL`、`INTEGER`、`REAL`、`TEXT` 和 `BLOB`。

我们对所有这些类型都提供原生支持；不过如果这些还不够，你也可以自由创建 **[自定义类型](/docs/sqlite/custom-types)**。

<Callout title='important' type='warning'>
本文档这一部分的所有示例都不使用数据库列名别名，列名由 TypeScript 的键生成。

如果你愿意，也可以在列名中使用数据库别名，还可以使用 `casing API` 为 Drizzle 定义映射策略。
你可以在[这里](/docs/sqlite/sql-schema-declaration#塑造你的数据-schema)了解更多

</Callout>

### Integer

一个带符号整数，根据数值大小，存储在 `0`、`1`、`2`、`3`、`4`、`6` 或 `8` 字节中。

<Section>
```typescript
import { integer, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	id: integer()
});

// 你可以将 integer 的 mode 自定义为 number、boolean、timestamp、timestamp_ms
integer({ mode: 'number' })
integer({ mode: 'boolean' })
integer({ mode: 'timestamp_ms' })
integer({ mode: 'timestamp' }) // Date

```

```sql
CREATE TABLE `table` (
	`id` integer
);
```

</Section>

<Section>
```typescript
// 让 integer 主键自动递增
integer({ mode: 'number' }).primaryKey({ autoIncrement: true })
```
```sql
CREATE TABLE `table` (
	`id` integer PRIMARY KEY AUTOINCREMENT
);
```
</Section>

### Real

一个浮点值，以 `8 字节 IEEE` 浮点数形式存储。

<Section>
```typescript
import { real, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	real: real()
});

```

```sql
CREATE TABLE `table` (
	`real` real
);
```

</Section>

### Text

一个文本字符串，使用数据库编码（`UTF-8`、`UTF-16BE` 或 `UTF-16LE`）存储。  

<Callout type="info" emoji="ℹ️">
	你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。
</Callout>

<Section>
```typescript
import { text, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	text: text()
});

// 会被推断为 text: "value1" | "value2" | null
text({ enum: ["value1", "value2"] })
text({ mode: 'json' })
text({ mode: 'json' }).$type<{ foo: string }>()
```

```sql
CREATE TABLE `table` (
	`text` text
);
```

</Section>

### Blob

一块二进制数据，按输入时的原样存储。

<Callout type="info" emoji="ℹ️">
	推荐使用 `text('', { mode: 'json' })` 而不是 `blob('', { mode: 'json' })`，
	因为它支持 JSON 函数：

	目前所有 JSON 函数在其任一参数为 BLOB 时都会抛出错误，因为 BLOB
	是为未来的增强功能保留的，届时 BLOB 将存储 JSON 的二进制编码。

	参见 **https://www.sqlite.org/json1.html**。
</Callout>

<Section>
```typescript
import { blob, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	blob: blob()
});

blob()
blob({ mode: 'buffer' })
blob({ mode: 'bigint' })

blob({ mode: 'json' })
blob({ mode: 'json' }).$type<{ foo: string }>()

```

```sql
CREATE TABLE `table` (
	`blob` blob
);
```

你可以为 blob 的类型推断指定 `.$type<..>()`，它**不会**检查运行时值。
它为默认值、insert 和 select schema 提供编译时保护。  

```typescript
// 会被推断为 { foo: string }
json: blob({ mode: 'json' }).$type<{ foo: string }>();

// 会被推断为 string[]
json: blob({ mode: 'json' }).$type<string[]>();

// 无法通过编译
json: blob({ mode: 'json' }).$type<string[]>().default({});
```

</Section>

### Boolean

SQLite 没有原生的 `boolean` 数据类型，但你可以将 `integer` 列指定为 `boolean` 模式。
这样你就可以在代码中操作布尔值，而 Drizzle 会把它们作为 0 和 1 的整数值
存储在数据库中。


<Section>
```typescript
import { integer, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	id: integer({ mode: 'boolean' })
});
```

```sql
CREATE TABLE `table` (
	`id` integer
);
```

</Section>

### Bigint

由于 SQLite 中没有 `bigint` 数据类型，Drizzle 为 `blob` 列提供了特殊的 `bigint` 模式。
该模式允许你在代码中使用 BigInt 实例，而 Drizzle 会将它们作为 blob 值存储在数据库中。


<Section>
```typescript
import { blob, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	id: blob({ mode: 'bigint' })
});

```

```sql
CREATE TABLE `table` (
	`id` blob
);
```
</Section>

### Numeric

<Section>
```typescript
import { numeric, sqliteTable } from 'drizzle-orm/sqlite-core';

export const table = sqliteTable('table', {
  numeric: numeric(),
  numericNum: numeric({ mode: 'number' }),
  numericBig: numeric({ mode: 'bigint' }),
  numericString: numeric({ mode: 'string' }),
});
```

```sql
CREATE TABLE `table` (
	`numeric` numeric,
	`numericNum` numeric,
	`numericBig` numeric,
	`numericString` numeric
);
```
</Section>

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，可用于自定义列的数据类型。例如，这在处理未知类型或品牌类型（branded type）时很有用。
```ts
type UserId = number & { __brand: 'user_id' };
type Data = {
	foo: string;
	bar: number;
};

export const users = sqliteTable('users', {
  id: integer().$type<UserId>().primaryKey(),
  jsonField: blob().$type<Data>(),
});
```

### Not null
`NOT NULL` 约束规定相关列不能包含 `NULL` 值。
<Section>
```typescript
export const table = sqliteTable('table', { 
	numInt: integer().notNull() 
});
```

```sql
CREATE TABLE table (
	`numInt` integer NOT NULL
);
```
</Section>

### 默认值

`DEFAULT` 子句用于指定当用户执行 `INSERT` 时未显式提供值的情况下该列使用的默认值。
如果列定义中没有附加显式的 `DEFAULT` 子句，
那么该列的默认值为 `NULL`。

显式的 `DEFAULT` 子句可以指定默认值为 `NULL`、
一个字符串常量、一个 blob 常量、一个有符号数值，或任何用括号括起来的常量表达式。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { integer, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
	int1: integer().default(42),
	int2: integer().default(sql`(abs(42))`)
});

```
```sql
CREATE TABLE `table` (
	`int1` integer DEFAULT 42,
	`int2` integer DEFAULT (abs(42))
);
```
</Section>

默认值也可以是特殊的不区分大小写关键字 `CURRENT_TIME`、`CURRENT_DATE` 或 `CURRENT_TIMESTAMP` 之一。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { text, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable("table", {
  time: text().default(sql`(CURRENT_TIME)`),
  date: text().default(sql`(CURRENT_DATE)`),
  timestamp: text().default(sql`(CURRENT_TIMESTAMP)`),
});
```

```sql
CREATE TABLE `table` (
	`time` text DEFAULT (CURRENT_TIME),
	`date` text DEFAULT (CURRENT_DATE),
	`timestamp` text DEFAULT (CURRENT_TIMESTAMP)
);
```
</Section>

使用 `$default()` 或 `$defaultFn()` 时（它们只是同一个函数的不同别名），
你可以在运行时生成默认值，并在所有 insert 查询中使用这些值。
这些函数可以帮助你使用诸如 `uuid`、`cuid`、`cuid2` 等各种实现。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它只在 `drizzle-orm` 的运行时中使用
</Callout>

```ts
import { text, sqliteTable } from "drizzle-orm/sqlite-core";
import { createId } from '@paralleldrive/cuid2';

export const table = sqliteTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

使用 `$onUpdate()` 或 `$onUpdateFn()` 时（它们只是同一个函数的不同别名），
你可以在运行时生成默认值，并在所有 update 查询中使用这些值。

为列添加动态更新值。该函数会在行被更新时被调用，
如果未提供值，则返回的值将用作列的值。
如果未提供默认值（或 $defaultFn 值），该函数在行被插入时也会被调用，
返回的值将用作列的值。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它只在 `drizzle-orm` 的运行时中使用
</Callout>

```ts
import { text, sqliteTable } from "drizzle-orm/sqlite-core";

export const table = sqliteTable('table', {
    alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```
