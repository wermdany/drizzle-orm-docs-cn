# Drizzle \<\> SQLite

Drizzle 通过 `libsql`、`node:sqlite` 和 `better-sqlite3` 驱动原生支持 SQLite 连接。
  
在我们同时使用 `libsql` 与 `node:sqlite`/`better-sqlite3` 驱动并将它们集成到 Drizzle ORM 的过程中，发现它们之间存在一些差异。例如：

在驱动层面，两者之间可能没有太多差异，但主要区别是 `libSQL` 既可以连接 SQLite 文件，也可以连接 `Turso` 远程数据库。LibSQL 是 SQLite 的一个分支，相比标准 SQLite 提供了更多功能，例如：

- 使用 `libSQL` 驱动时可以使用更多的 ALTER 语句，让你比仅使用 `better-sqlite3` 更容易管理 schema。
- 你可以原生地配置静态加密（encryption at rest）功能。
- SQLite 数据库支持的大量扩展同样得到 `libSQL` 的支持。

#### 步骤 3 - 发起查询
<CodeTabs items={["libsql", "带配置的 libsql"]}>
```typescript copy
import { drizzle } from 'drizzle-orm/libsql';

const db = drizzle(process.env.DATABASE_URL);
 
const result = await db.all('select 1');
```
```typescript copy
import { drizzle } from 'drizzle-orm/libsql';

// 你可以指定 libsql 连接选项中的任意属性
const db = drizzle({ connection: { url:'', authToken: '' }});
 
const result = await db.all('select 1');
```
</CodeTabs>

如果你需要同步连接，可以使用我们额外的连接 API，
在其中指定驱动连接并将其传递给 Drizzle 实例。

```typescript copy
import { drizzle } from 'drizzle-orm/libsql';
import { createClient } from '@libsql/client';

const client = createClient({ url: process.env.DATABASE_URL, authToken: process.env.DATABASE_AUTH_TOKEN });
const db = drizzle({ client });

const result = await db.all('select 1');
```

## node:sqlite
#### 步骤 1 - 安装依赖包
<Npm>
 drizzle-orm@rc
 -D drizzle-kit@rc
</Npm>

#### 步骤 2 - 初始化驱动并执行查询
<CodeTabs items={["node:sqlite", "带配置的 node:sqlite"]}>
```typescript copy
import { drizzle } from 'drizzle-orm/node-sqlite';

const db = drizzle(process.env.DB_FILE_NAME);

const result = await db.execute('select 1');
```
```typescript copy
import { drizzle } from 'drizzle-orm/node-sqlite';

// 你可以指定 node-sqlite 连接选项中的任意属性
const db =  drizzle({ connection: { path: process.env.DB_FILE_NAME }});

const result = await db.execute('select 1');
```
</CodeTabs>

如果你需要提供现有的驱动：
```typescript copy
import { drizzle } from 'drizzle-orm/node-sqlite';
import { DatabaseSync } from 'node:sqlite';

const sqlite = new DatabaseSync('sqlite.db');
const db = drizzle({ client: sqlite });

const result = await db.execute('select 1');
```

## better-sqlite3

<Npm>
 drizzle-orm@rc better-sqlite3
 -D drizzle-kit@rc @types/better-sqlite3
</Npm>

#### 步骤 2 - 初始化驱动并执行查询
<CodeTabs items={["better-sqlite3", "带配置的 better-sqlite3"]}>
```typescript copy
import { drizzle } from 'drizzle-orm/better-sqlite3';

const db = drizzle(process.env.DB_FILE_NAME);

const result = await db.all('select 1');
```
```typescript copy
import { drizzle } from 'drizzle-orm/better-sqlite3';

// 你可以指定 better-sqlite3 连接选项中的任意属性
const db =  drizzle({ connection: { source: process.env.DB_FILE_NAME }});

const result = await db.all('select 1');
```
</CodeTabs>

如果你需要提供现有的驱动：
```typescript copy
import { drizzle } from 'drizzle-orm/better-sqlite3';
import Database from 'better-sqlite3';

const sqlite = new Database('sqlite.db');
const db = drizzle({ client: sqlite });

const result = await db.all('select 1');
```
