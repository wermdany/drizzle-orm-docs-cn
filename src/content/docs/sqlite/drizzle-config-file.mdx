# Drizzle Kit 配置文件

Drizzle Kit 允许你在 `TypeScript` 或 `JavaScript` 配置文件中声明配置选项。

<Section>
```plaintext {5}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
<CodeTabs items={["drizzle.config.ts", "drizzle.config.js"]}>
<CodeTab>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
<CodeTab>
```js
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
</CodeTabs>
</Section>

扩展配置文件的示例
```ts collapsable
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "sqlite",
  schema: "./src/schema.ts",

  driver: "d1-http",
  dbCredentials: {
    url: "./sqlite.db",
  },

  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
  },

  breakpoints: true,
  verbose: true,
});
```

### 多个配置文件
你可以在项目中拥有多个配置文件，当你拥有多个数据库阶段，或者同一项目中有多个数据库或不同数据库时，这非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 迁移文件夹
`out` 参数让你定义迁移所在的文件夹，它是可选的，默认为 `drizzle`。  
这非常有用，因为同一个项目中你可以为不同的数据库拥有许多独立的 schema，
并为它们设置不同的迁移文件夹。  
  
迁移文件夹包含带有 `.sql` 迁移文件的文件夹，供 `drizzle-kit` 使用

<Section>
```plaintext {3}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ ├ 📜 user.ts 
 │ ├ 📜 post.ts 
 │ └ 📜 comment.ts 
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
```ts {6}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema/*",
  out: "./drizzle",
});
```
</Section>

### `dialect`
<rem025/>

你正在使用的数据库方言
|               |                                                 |
| :------------ | :-----------------------------------            |

```ts {4}
import { defineConfig } from "drizzle-kit";
```

### `schema`
<rem025/>

的路径，指向 drizzle schema 文件或包含 schema 文件的文件夹。
|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值        | --                    |
| 命令      | `generate`, `push`, `export`, `studio`  |

<rem025/>

### `out`
<rem025/>

定义你的 SQL 迁移文件、schema 的 json 快照以及 `drizzle-kit pull` 命令生成的 `schema.ts` 的输出文件夹。
|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值        | `drizzle`                    |
| 命令      | `generate`, `pull`, `migrate`, `check`, `up` |

<rem025/>
```ts {4}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle", 
});
```

### `driver`
<rem025/>

Drizzle Kit 会根据 `dialect: "sqlite"` 自动从你当前项目中挑选一个可用的 SQLite 驱动。
对于 SQLite 驱动的例外情况（例如 Cloudflare D1 HTTP），请使用 `driver`。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `d1-http` |
| 默认值        | --                    |
| 命令      | `push`, `migrate`, `pull`, `studio`  |

<rem025/>

```ts {5}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  driver: "d1-http",
  dbCredentials: {
    accountId: "accountId",
    databaseId: "databaseId",
    token: "token",
  },
});
```

### `dbCredentials`
<rem025/>

数据库连接凭据，形式为 `url`、
`user:password@host:port/db` 参数，或例外驱动（<Drivers/>）特定的连接选项。

|               |                      |
| :------------ | :-----------------   |
| 类型          | <Dialects/> |
| 默认值       | --                    |
| 命令      | `push`, `pull`, `migrate`, `studio` |

<rem025/>

<CodeTabs items={["SQLite", "Turso", "Cloudflare D1"]}>
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "sqlite",
  dbCredentials: {
    url: ":memory:", // 内存数据库
    // 或者
    url: "sqlite.db", 
    // 或者
    url: "file:sqlite.db" // libsql 需要 file: 前缀
  }
});
```
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "turso",
  dbCredentials: {
    url: "libsql://acme.turso.io" // 远程 Turso 数据库 url
    authToken: "...",

    // 或者如果你需要本地数据库

    url: ":memory:", // 内存数据库
    // 或者
    url: "file:sqlite.db", // libsql 需要 file: 前缀
  }
});
```
```ts

export default defineConfig({
  dialect: "sqlite",
```

### `migrations`
<rem025/>

运行 `drizzle-kit migrate` 时 - drizzle 会在数据库中名为 `__drizzle_migrations` 的日志表里
记录成功应用的迁移。

`migrations` 配置选项让你可以更改迁移日志的 `table` 名称。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `{ table: string }` |
| 默认值       | `{ table: "__drizzle_migrations" }`                    |
| 命令      | `migrate`, `push`, `pull` |

<rem025/>

```ts
export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema.ts",
  migrations: {
    table: 'my-migrations-table', // 默认是 `__drizzle_migrations`
  },
});
```

### `tablesFilter`
<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/sqlite/goodies#多项目-schema)。
</Callout>
<rem025/>
`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有表。
你可以通过 `tablesFilter` 配置表列表。

`tablesFilter` 选项让你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值       | --                    |
| 命令      | `push` `pull`   |

<rem025/>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  tablesFilter: ["users", "posts", "project1_*"],
});
```

### `verbose`
<rem025/>

在 `drizzle-kit push` 命令执行期间打印所有 SQL 语句。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `false`                    |
| 命令      | `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "sqlite",
  verbose: false,
});
```

### `breakpoints`
<rem025/>

Drizzle Kit 会自动将 `--> statement-breakpoint` 嵌入到生成的 SQL 迁移文件中，
这对于不支持在一个事务中执行多条 DDL 变更语句的数据库（MySQL 和 SQLite）来说是必要的。

`breakpoints` 选项标志让你可以开启和关闭它

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `true`                    |
| 命令      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "sqlite",
  breakpoints: false,
});
```
