# Drizzle Queries + CRUD

<Prerequisites>
  - 如何定义你的 schema - [Schema 基础](/docs/sqlite/sql-schema-declaration)
  - 如何连接数据库 - [连接基础](/docs/sqlite/connect-overview)
</Prerequisites>

Drizzle 为你提供了几种查询数据库的方式，至于在下一个项目中需要哪一种，由你决定。
它可以是类似 SQL 的语法，也可以是关系式语法。让我们来看看：

## 为什么像 SQL？
\
**如果你了解 SQL，你就了解 Drizzle。**

其他 ORM 和数据框架往往会偏离或抽象掉 SQL，从而导致双重学习曲线：你需要同时学习 SQL 和该框架的 API。

Drizzle 则恰恰相反。
我们拥抱 SQL，并让 Drizzle 的核心保持 SQL-like，因此你几乎没有学习成本，并且可以完全发挥 SQL 的能力。

<Section>
```typescript copy
// 访问你的数据
await db
  .select()
	.from(posts)
	.leftJoin(comments, eq(posts.id, comments.post_id))
	.where(eq(posts.id, 10))
```
```sql
SELECT * 
FROM posts
LEFT JOIN comments ON posts.id = comments.post_id
WHERE posts.id = 10
```
</Section>

借助 SQL-like 语法，你可以复现纯 SQL 能做的大部分事情，并且清楚地知道 Drizzle 会做什么、会生成什么查询。你可以执行各种各样的查询，
包括 select、insert、update、delete，以及使用别名、WITH 子句、子查询、预编译语句，
等等。让我们看更多示例

<CodeTabs items={['插入', '更新', '删除']}>
<Section>
```ts
await db.insert(users).values({ email: 'user@gmail.com' })
```
```sql
INSERT INTO users (email) VALUES ('user@gmail.com')
```
</Section>
<Section>
```ts
await db.update(users)
        .set({ email: 'user@gmail.com' })
        .where(eq(users.id, 1))
```
```sql
UPDATE users 
SET email = 'user@gmail.com'
WHERE users.id = 1
```
</Section>
<Section>
```ts
await db.delete(users).where(eq(users.id, 1))
```
```sql
DELETE FROM users WHERE users.id = 1
```
</Section>
</CodeTabs>

## 为什么不使用类 SQL？

我们始终致力于寻求完美平衡的解决方案。虽然 SQL-like 查询覆盖了你 100% 的需求，
但在某些常见场景下，数据可以通过更高效的方式查询。

我们构建了 Queries API，让你能够以最便捷、最高性能的方式从数据库中获取关系型、嵌套的数据，
而无需操心 joins 或数据映射。

**Drizzle 始终只输出一个 SQL 查询**。你可以放心地在 serverless 数据库中使用它，
永远不必担心性能或往返开销！

<Section>
```ts
const result = await db.query.users.findMany({
	with: {
		posts: true
	},
});
```
{/* ```sql
SELECT * FROM users ...
``` */}
</Section>

## 进阶
借助 Drizzle，查询可以按你想要的任何方式进行组合和拆分。你可以独立于主查询组合过滤器，
拆分出子查询或条件语句，等等。
让我们看几个进阶示例：

#### 组合一个 WHERE 语句，然后在查询中使用它
```ts
async function getProductsBy({
  name,
  category,
  maxPrice,
}: {
  name?: string;
  category?: string;
  maxPrice?: number;
}) {
  const filters: SQL[] = [];

  if (name) filters.push(like(products.name, name));
  if (category) filters.push(eq(products.category, category));
  if (maxPrice) filters.push(lte(products.price, maxPrice));

  return db
    .select()
    .from(products)
    .where(and(...filters));
}
```

#### 将子查询拆分到不同变量，然后在主查询中使用它们
```ts
const subquery = db
	.select()
	.from(internalStaff)
	.leftJoin(customUser, eq(internalStaff.userId, customUser.id))
	.as('internal_staff');

const mainQuery = await db
	.select()
	.from(ticket)
	.leftJoin(subquery, eq(subquery.internal_staff.userId, ticket.staffId));
```
