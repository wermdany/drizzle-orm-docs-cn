# Drizzle Seed

`drizzle-seed` 是一个 TypeScript 库，帮助你生成确定性的、同时又足够真实的
假数据来填充数据库。通过利用可设定种子的伪随机数生成器（pRNG），
它确保你生成的数据在不同运行之间保持一致且可复现。
这在测试、开发和调试场景中特别有用。

#### 什么是确定性数据生成？

确定性数据生成意味着相同的输入总是产生相同的输出。
在 `drizzle-seed` 的语境下，当你用相同的种子数字初始化该库时，
它每次都会生成相同序列的假数据。这使数据集可预测且可重复。

#### 伪随机数生成器（pRNG）

伪随机数生成器是一种算法，它产生一个数字序列，
以近似随机数的性质。然而，由于它基于一个称为种子的初始值，
你可以控制它的随机性。通过使用相同的种子，pRNG 将产生
相同的数字序列，使你的数据生成过程可复现。

#### 使用 pRNG 的好处：

- Consistency: 确保你的测试每次都运行在相同的数据上。
- Debugging: 通过提供一致的数据集，更容易复现和修复 bug。
- Collaboration: 团队成员可以共享种子数字，以使用相同的数据集。

使用 drizzle-seed，你同时拥有两者的优势：既能生成真实的假数据，又能在需要时控制其复现。

## 基本用法

在这个示例中，我们将创建 10 个具有随机名字和 id 的 users

```ts {12}
import { sqliteTable, integer, text } from "drizzle-orm/sqlite-core";
import { drizzle } from "drizzle-orm/better-sqlite3";
import { seed } from "drizzle-seed";

const users = sqliteTable("users", {
  id: integer().primaryKey({ autoIncrement: true }),
  name: text().notNull(),
});

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await seed(db, { users });
}

main();
```

## 选项

**`count`**

默认情况下，`seed` 函数会创建 10 个实体。
但如果你的测试需要更多，可以在 seed 选项对象中指定

```ts
await seed(db, schema, { count: 1000 });
```

**`seed`**

如果你需要种子在所有后续运行中生成不同的值集合，可以在
`seed` 选项中定义不同的数字。任何新的数字都会生成一组唯一的值

```ts
await seed(db, schema, { seed: 12345 });
```

## 重置数据库

使用 `drizzle-seed`，你可以轻松重置数据库并用新值填充它，例如在你的测试套件中

```ts
// 指向你想重置的 schema 文件的路径
import * as schema from "./schema.ts";
import { reset } from "drizzle-seed";

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await reset(db, schema);
}

main();
```

## 细化

如果你需要改变 `drizzle-seed` 默认使用的 seed 生成器函数的行为，你可以指定自己的实现，甚至为填充过程使用自己的值列表

`.refine` 是一个回调，它接收 `drizzle-seed` 中所有可用生成器函数的列表。它应当返回一个对象，其键表示你想优化的表，并可按需定义它们的行为。
每张表都可以指定若干属性来简化数据库填充：

<rem025 />

- `columns`: 通过指定所需的生成器函数来优化每一列的默认行为，或者通过指定 `false` 将该列从填充中排除。
- `count`: 指定要插入数据库的行数。默认是 10。如果在 `seed()` 选项中定义了全局 count，这里定义的 count 会针对该特定表覆盖它。
- `with`: 如果你想生成关联实体，定义要为每张父表创建多少个被引用的实体。

<Callout title='info'>
你还可以为想创建的被引用值的数量指定加权随机分布。关于此 API 的详细信息，你可以参考 [Weighted Random docs](#加权随机) 文档章节
</Callout>

**API**
```ts
await seed(db, schema).refine((f) => ({
  users: {
    columns: {},
    count: 10,
    with: {
        posts: 10
    }
  },
}));
```

## 加权随机

在某些情况下，你可能需要在填充阶段向数据库插入多组具有不同优先级的数据集。对于这类情况，drizzle-seed 提供了一个称为 weighted random 的 API

Drizzle Seed 包有几处可以使用加权随机：

- 每张表优化项中的列
- `with` 属性，决定要创建的关联实体数量

我们来看一个同时涉及两者的示例：

```ts filename="schema.ts"
import { sqliteTable, integer, text, text, real } from "drizzle-orm/sqlite-core";

export const orders = sqliteTable(
  "orders",
  {
    id: integer().primaryKey({ autoIncrement: true }),
    name: text().notNull(),
    quantityPerUnit: text().notNull(),
    unitPrice: real().notNull(),
    unitsInStock: integer().notNull(),
    unitsOnOrder: integer().notNull(),
    reorderLevel: integer().notNull(),
    discontinued: integer().notNull(),
  }
);

export const details = sqliteTable(
  "details",
  {
    unitPrice: real().notNull(),
    quantity: integer().notNull(),
    discount: real().notNull(),

    orderId: integer()
      .notNull()
      .references(() => orders.id, { onDelete: "cascade" }),
  }
);
```

**示例 1**：优化 `unitPrice` 的生成逻辑，生成 `5000` 个随机价格，其中 30% 概率为 10-100 之间的价格，70% 概率为 100-300 之间的价格

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/better-sqlite3";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       count: 5000,
       columns: {
           unitPrice: f.weightedRandom(
               [
                   {
                       weight: 0.3,
                       value: funcs.int({ minValue: 10, maxValue: 100 })
                   },
                   {
                       weight: 0.7,
                       value: funcs.number({ minValue: 100, maxValue: 300, precision: 100 })
                   }
               ]
           ),
       }
    }
  }));
}

main();
```

**示例 2**：对于每个 order，以 60% 的概率生成 1 到 3 个 details，以 30% 的概率生成 5 到 7 个 details，以 10% 的概率生成 8 到 10 个 details

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/better-sqlite3";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       with: {
           details:
               [
                   { weight: 0.6, count: [1, 2, 3] },
                   { weight: 0.3, count: [5, 6, 7] },
                   { weight: 0.1, count: [8, 9, 10] },
               ]
       }
    }
  }));
}

main();
```

## 限制

#### `with` 的类型限制

由于 TypeScript 的某些限制以及 Drizzle 当前的 API，无法正确推断表之间的引用，尤其是当表之间存在循环依赖时。

这意味着 `with` 选项会显示 schema 中的所有表，你需要手动选择具有一对多关系的那个表

<Callout title='warning'>
`with` 选项适用于一对多关系。例如，如果你有一个 `user` 和多个 `posts`，你可以使用 users `with` posts，但不能使用 posts `with` users
</Callout>

#### Drizzle 表中第三个参数的类型限制：

目前，我们尚不支持 Drizzle 表中第三个参数的类型。它在运行时可以工作，但在类型层面无法正确运作
