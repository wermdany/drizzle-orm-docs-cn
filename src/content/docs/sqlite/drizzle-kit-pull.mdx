# `drizzle-kit pull`

<Prerequisites>
- Drizzle 和 `drizzle-kit` 入门 - [阅读此处](/docs/sqlite/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/sqlite/sql-schema-declaration) 
- 数据库连接基础 - [阅读此处](/docs/sqlite/connect-overview) 
- Drizzle 迁移基础 - [阅读此处](/docs/sqlite/migrations) 
- Drizzle Kit [概览](/docs/sqlite/kit-overview) 和 [配置文件](/docs/sqlite/drizzle-config-file) 文档
</Prerequisites>

`drizzle-kit pull` 让你直接从现有数据库 schema 中拉取（introspect）并生成 `schema.ts` drizzle schema 文件， 
它旨在覆盖 [数据库优先](/docs/sqlite/migrations) 的 Drizzle 迁移方式。

<Callout collapsed="底层是如何工作的？">
当你运行 Drizzle Kit `pull` 命令时，它会：
1. 从现有数据库中拉取数据库 schema（DDL）
2. 生成 `schema.ts` drizzle schema 文件并保存到 `out` 文件夹

<Section>
```
                                  ┌────────────────────────┐      ┌───────────────────────────────────────┐ 
                                  │                        │ <---  CREATE TABLE `users` (
┌──────────────────────────┐      │                        │        `id` integer primary key autoincrement,
│ ~ drizzle-kit pull       │      │                        │        `name` TEXT,
└─┬────────────────────────┘      │         数据库         │        `email` TEXT UNIQUE
  │                               │                        │       );
  └ 拉取数据库 schema ----------> │                        │
  ┌ 生成 Drizzle           <----- │                        │
  │ schema TypeScript 文件        └────────────────────────┘
  │
  v
```
```typescript
import * as p from "drizzle-orm/sqlite-core";

export const users = p.sqliteTable("users", {
	id: p.integer().primaryKey({ autoIncrement: true }),
	name: p.text(),
	email: p.text().unique(),
});
```
</Section>
</Callout>

如果你需要在 TypeScript 项目之外管理数据库 schema，
或使用由他人管理的数据库，这是一个很好的方式。

<br/>
<hr/>
<br/>

`drizzle-kit pull` 要求你指定 `dialect`，以及
数据库连接 `url` 或 `user:password@host:port/db` 参数，你可以通过
[drizzle.config.ts](/docs/sqlite/drizzle-config-file) 配置文件或 CLI 选项提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  dbCredentials: {
    url: "./sqlite.db",
  },
});
```
```shell
npx drizzle-kit pull
```
</Section>

```shell
npx drizzle-kit pull --dialect=sqlite --url=./sqlite.db
```
</CodeTabs>

### 一个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你存在多个数据库阶段、多个数据库，或同一项目中有不同数据库时，这非常有用：

<Npx>
  drizzle-kit pull --config=drizzle-dev.config.ts
  drizzle-kit pull --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 指定数据库驱动
<Callout type="warning">
**Expo SQLite** 和 **OP SQLite** 是设备端（每用户）数据库，无法从那里 `pull` 数据库 schema。<br/>
对于嵌入式数据库，Drizzle 提供了 **embedded migrations** —— 查看我们的 [get started](/docs/get-started/expo-new) 指南。
</Callout>
Drizzle Kit 不附带预捆绑的数据库驱动， 
它会根据 `dialect: "sqlite"` 从你当前项目中自动选择一个可用的 SQLite 驱动 - [参见讨论](https://github.com/drizzle-team/drizzle-orm/discussions/2203)。

对于 Cloudflare D1 HTTP，请显式指定 `driver: "d1-http"`。

```ts {6}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  driver: "d1-http",
  dbCredentials: {
    accountId: "accountId",
    databaseId: "databaseId",
    token: "token",
  },
});
```

### 初始拉取

你可以使用 `--init` 标志将拉取的 schema 标记为数据库中已应用的迁移， 
这样所有后续迁移都会与初始迁移进行差异比较

```shell
npx drizzle-kit push --init
```

### 包含表
`drizzle-kit pull` 默认会 introspect 所有 SQLite 表。
你可以通过 `tablesFilter` 配置表列表。

|                |                                                                                               |
| :------------- | :-------------------------------------------------------------------------------------------- |
| `tablesFilter` | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认为 `"*"` |
<br/>

让我们配置 drizzle-kit 来 introspect SQLite 数据库中的 **所有表**。

<Section>
```ts filename="drizzle.config.ts" {8}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  dbCredentials: {
     url: "./sqlite.db",
  },
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit pull
```
</Section>

### 配置项扩展列表
我们推荐通过 [drizzle.config.ts](/docs/sqlite/drizzle-config-file) 文件配置 `drizzle-kit`， 
不过如有必要，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中等。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，为 <Dialects/> 之一                                      |
| `driver`            |            | 驱动例外，例如 `d1-http`                                   |
| `out`               |            | 迁移输出文件夹路径，默认为 `./drizzle`                     |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                         |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名称                                                             |
| `config`            |            | 配置文件路径，默认为 `drizzle.config.ts`                          |
| `introspect-casing` |            | 在列、表等中创建 JS 键的策略。`preserve` `camel` |
| `tablesFilter`      |            | 表名过滤器                                                         |

<Npx>
drizzle-kit pull --dialect=sqlite --url=./sqlite.db
drizzle-kit pull --dialect=sqlite --tablesFilter='user*' url=./sqlite.db
</Npx>
