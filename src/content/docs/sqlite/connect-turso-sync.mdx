# Drizzle \<\> Turso Database Sync

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/sqlite/connect-overview)
- Turso Database - [网站](https://docs.turso.tech/introduction)
- Turso Database sync 驱动 - [GitHub](https://github.com/tursodatabase/turso/tree/main/bindings/javascript/sync)
</Prerequisites>

根据 **[官方网站](https://docs.turso.tech/introduction)**，
Turso 是在 AI 时代为你的宏大梦想提供动力的小型数据库。

#### 第 1 步 - 安装包
<Npm>
 drizzle-orm@rc @tursodatabase/sync
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并执行查询
```typescript
import { drizzle } from 'drizzle-orm/tursodatabase-sync';

const db = drizzle({
	connection: {
    	path: 'local.db',                // 用作 sync-engine 创建的本地文件前缀的路径
    	url: 'https://<db>.turso.io',    // 远程数据库的 URL：turso db show <db>
    	authToken: '...',                // 由 Turso Cloud 签发的 auth token：turso db tokens create <db>
    	clientName: 'turso-sync-example' // 任意客户端名称
	}
});

const result = await db.all('select 1');
```

如果你需要提供已有的驱动：

```typescript
import { connect } from '@tursodatabase/sync';
import { drizzle } from 'drizzle-orm/tursodatabase-sync';

const client = await connect({
    path: 'local.db',                // 用作 sync-engine 创建的本地文件前缀的路径
    url: 'https://<db>.turso.io',    // 远程数据库的 URL：turso db show <db>
    authToken: '...',                // 由 Turso Cloud 签发的 auth token：turso db tokens create <db>
    clientName: 'turso-sync-example' // 任意客户端名称
});
const db = drizzle({ client });

const result = await db.all('select 1');
```
