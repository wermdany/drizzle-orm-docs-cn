# Drizzle ORM

Drizzle ORM 是一个带主见的无头 TypeScript ORM。🐲
> Drizzle 是一位好朋友，需要时它就在你身边，你想独处时它也不会打扰你。

它看起来和用起来都很简单，在你的项目进行到第 _1000_ 天时依然表现良好，\
让你按自己的方式做事，并在你需要时随时待命。

**它是唯一同时具备[关系型](/docs/sqlite/rqb)和[类 SQL](/docs/sqlite/select)查询 API 的 ORM**，
在访问关系型数据方面为你提供两全其美的体验。
Drizzle 轻量、高性能、类型安全、不含乳糖、无麸质、清醒、灵活，并且**从设计上就为 serverless 做好准备**。
Drizzle 不只是一个库，它是一种体验。🤩

[![Drizzle bestofjs](@/assets/images/bestofjs.jpg)](https://bestofjs.org/projects/drizzle-orm)

## 无头 ORM？ 
首先，Drizzle 是一个库，也是一组互补的可选工具。

**ORM** 代表 _对象关系映射_，开发者倾向于把类 Django 或类 Spring 的工具称为 ORM。
我们坚信这是一种基于历史命名习惯的误解，我们称它们为**数据框架**。

<Callout type="error" emoji="️💔">
  使用数据框架时，你必须**围绕它们**来构建项目，而不是**用它们**来构建项目。
</Callout>

**Drizzle** 让你按照自己希望的方式来构建项目，不会干扰你的项目或结构。

使用 Drizzle，你可以用 TypeScript 定义和管理数据库 schema，以类 SQL 或关系型的方式访问数据，
并利用可选工具让你的开发体验_一飞冲天_。🤯

## 为什么像 SQL？
**如果你懂 SQL，你就懂 Drizzle。**

其它 ORM 和数据框架往往让你偏离/抽离 SQL，这导致了双重学习曲线：既要了解 SQL，又要了解框架的 API。

Drizzle 恰恰相反。
我们拥抱 SQL，并将 Drizzle 的核心构建为类 SQL，因此你可以拥有零学习曲线或几乎为零的学习曲线，并充分使用 SQL 的全部能力。

我们带来了所有你熟悉的 **[SQL schema](/docs/sqlite/sql-schema-declaration)**、**[查询](/docs/sqlite/select)**、
**[自动迁移](/docs/sqlite/migrations)** 以及 **[还有一件事](/docs/sqlite/rqb)**。✨

<CodeTabs items={["index.ts", "schema.ts", "migration.sql"]}>
```typescript copy
// Access your data
await db
	.select()
	.from(countries)
	.leftJoin(cities, eq(cities.countryId, countries.id))
	.where(eq(countries.id, 10))
```
```typescript copy
// manage your schema
export const countries = sqliteTable('countries', {
  id: integer().primaryKey({ autoIncrement: true }),
  name: text(),
});

export const cities = sqliteTable('cities', {
  id: integer().primaryKey({ autoIncrement: true }),
  name: text(),
  countryId: integer('country_id').references(() => countries.id),
});
```
```sql
-- generate migrations
CREATE TABLE `countries` (
	`id` integer PRIMARY KEY AUTOINCREMENT,
	`name` text
);

CREATE TABLE `cities` (
	`id` integer PRIMARY KEY AUTOINCREMENT,
	`name` text,
	`country_id` integer,
	CONSTRAINT `fk_cities_country_id_countries_id_fk` FOREIGN KEY (`country_id`) REFERENCES `countries`(`id`)
);
```
</CodeTabs>

## 为什么不使用类 SQL？
我们始终在追求一个完美平衡的解决方案，虽然类 SQL 覆盖了 100% 的需求，
但在某些常见场景下，你可以用更好的方式查询数据。

我们为你构建了 **[Queries API](/docs/sqlite/rqb)**，让你能以最便捷、最高性能的方式从数据库中获取关系型嵌套数据，
而不必再考虑 join 和数据映射。

**Drizzle 始终只输出恰好 1 条 SQL 查询。** 你可以放心地在 serverless 数据库中使用它，无需担心性能或往返开销！

```ts
const result = await db.query.users.findMany({
	with: {
		posts: true
	},
});
```

## Serverless？
<Callout type="info" emoji="🥳">
  最好的部分就是没有部分。**Drizzle 恰好有 0 个依赖！**
</Callout>


![Drizzle 轻量且为 Serverless 做好准备](@/assets/images/drizzle31kb.jpg)
  
Drizzle ORM 是方言特定、轻量、高性能，并且**从设计上**为 serverless 做好准备。

我们花了大量时间确保你拥有业界一流的 SQL 方言支持，包括 Postgres、MySQL 等。

Drizzle 通过行业标准的数据库驱动原生运行。我们支持所有主流的 **[PostgreSQL](/docs/get-started-postgresql)**、**[MySQL](/docs/mysql/get-started-mysql)**、**[SQLite](/docs/sqlite/get-started-sqlite)**、**[SingleStore](/docs/singlestore/get-started-singlestore)**、**[MSSQL](/docs/mssql/get-started-mssql)** 或 **[CockroachDB](/docs/cockroach/get-started-cockroach)** 驱动，并且我们正在**[非常快速地](https://twitter.com/DrizzleORM/status/1653082492742647811?s=20)**添加新的驱动。
