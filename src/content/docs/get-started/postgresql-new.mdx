# Drizzle 与 PostgreSQL 入门

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **node-postgres** - 用于查询 PostgreSQL 数据库的包 - [阅读文档](https://node-postgres.com/)
</Prerequisites>

Drizzle 通过 `node-postgres` 和 `postgres.js` 驱动原生支持 PostgreSQL 连接。

在本快速开始示例中我们将使用 `node-postgres`。但如果你想了解连接到 postgresql 的更多方式，请查看
我们的 [PostgreSQL 连接](/docs/get-started-postgresql) 页面
