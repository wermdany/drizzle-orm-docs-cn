#### 步骤 2 - 设置连接变量

在你的项目根目录创建一个 `.env` 文件，并添加你的 Turso 数据库 url 和 auth token：

```plaintext copy
TURSO_DATABASE_URL=
TURSO_AUTH_TOKEN=
```

<Callout type='info' title='重要'>
如果你不知道你的 `TURSO_DATABASE_URL` 和 `TURSO_AUTH_TOKEN` 值，可以参考 LibSQL Driver SDK 教程。
在[此处](https://docs.turso.tech/sdk/ts/quickstart)查看，然后带着生成的所有值返回并将其添加到 `.env` 文件中
</Callout>

#### 步骤 3 - 设置 Drizzle 配置文件

**Drizzle config** - 一个由 [Drizzle Kit](/docs/kit-overview) 使用的配置文件，包含你的数据库连接、迁移文件夹和 schema 文件的全部信息。

在你的项目根目录创建 `drizzle.config.ts` 文件，并添加以下内容：

```typescript copy filename="drizzle.config.ts"
import 'dotenv/config';
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/db/schema.ts',
  dialect: 'turso',
  dbCredentials: {
    url: process.env.TURSO_DATABASE_URL,
    authToken: process.env.TURSO_AUTH_TOKEN,
  },
});
```

#### 步骤 6 - 将 Drizzle ORM 连接到数据库
Drizzle 原生支持所有 @libsql/client 驱动的变体：

<LibsqlTable />
<br/>
<LibsqlTabs />

在 `src` 目录中创建 `index.ts` 文件并初始化连接：

```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/libsql';

// 你可以指定 libsql 连接选项中的任意属性
const db = drizzle({ 
  connection: { 
    url: process.env.TURSO_DATABASE_URL!, 
    authToken: process.env.TURSO_AUTH_TOKEN!
  }
});
```

如果你需要提供已有的驱动：

```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/libsql';
import { createClient } from '@libsql/client';

const client = createClient({ 
  url: process.env.TURSO_DATABASE_URL!, 
  authToken: process.env.TURSO_AUTH_TOKEN!
});

const db = drizzle({ client });
```
