# 在现有项目中使用 Drizzle 和 Bun:SQLite 入门

<Prerequisites>  
  - **dotenv** - 用于管理环境变量的包 - [阅读此处](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读此处](https://tsx.hirok.io/)
  - **bun** - JavaScript 一体化工具包 - [阅读此处](https://bun.sh/)
  - **bun:sqlite** - 高性能 SQLite3 驱动的原生实现 - [阅读此处](https://bun.sh/docs/api/sqlite)
</Prerequisites>

<FileStructure />

#### 第 1 步 - 安装所需的软件包

<Npm>
    drizzle-orm@rc dotenv
    -D drizzle-kit@rc tsx @types/bun
</Npm>

#### 第 2 步 - 设置连接变量

<SetupEnv env_variable='DB_FILE_NAME' />

<Callout type='info' title='重要'>
例如，如果你的项目根目录下有一个 SQLite 数据库文件，你可以使用这个示例：
```plaintext copy
DB_FILE_NAME=mydb.sqlite
```
</Callout>


#### 第 3 步 - 设置 Drizzle 配置文件

<SetupConfig dialect='sqlite' env_variable='DB_FILE_NAME'/>

#### 第 4 步 - 内省你的数据库

<IntrospectSqlite/>

#### 第 5 步 - 将代码转移到实际的 schema 文件

<TransferCode/>

#### 第 6 步 - 将 Drizzle ORM 连接到数据库

<ConnectBun/>

#### 第 7 步 - 查询数据库

<QueryDatabase dialect='bun-sqlite' env_variable='DB_FILE_NAME' />

#### 第 8 步 - 运行 index.ts 文件

要使用 `bun` 运行脚本，请使用以下命令：
```bash copy
bun src/index.ts
```

#### 第 9 步 - 更新你的表 schema（可选）

<UpdateSchema/>

#### 第 9 步 - 将更改应用到数据库（可选）

<ApplyChanges/>

#### 第 10 步 - 使用新字段查询数据库（可选）

<QueryDatabaseUpdated dialect='bun-sqlite' env_variable='DB_FILE_NAME' />
