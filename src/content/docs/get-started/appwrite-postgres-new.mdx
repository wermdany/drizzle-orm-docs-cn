在找 MySQL？请查看我们的 [Appwrite MySQL 指南](/docs/get-started/appwrite-mysql-new)

Appwrite 提供专用的原生 PostgreSQL 数据库，你可以直接通过 TLS 连接。Appwrite 没有专用的驱动，因此本指南使用标准的 `node-postgres` 驱动。

有关创建 Appwrite Postgres 数据库的详细说明，请参阅 [Appwrite PostgreSQL 文档](https://appwrite.io/docs/products/databases/postgresql)。

<FileStructure/>

#### 第 1 步 - 安装 **node-postgres** 包
<InstallPackages lib='pg' devlib=' @types/pg'/>

#### 第 2 步 - 设置连接变量

在你的项目根目录创建一个 `.env` 文件，并添加你的数据库连接变量：

```plaintext copy
DATABASE_URL=postgresql://admin:<password>@db-<hash>.<region>.appwrite.center:5432/<database>?sslmode=require
```

<Callout title='提示'>
你可以在 Appwrite Console 中打开你的数据库并点击 **"Credentials"** 来获取连接字符串。**"Drizzle"**、**"DSN"** 和 **".env"** 标签页包含一个开箱即用的连接字符串，其中已经包含 `sslmode=require`。详细步骤请参阅 [Appwrite PostgreSQL 连接指南](https://appwrite.io/docs/products/databases/postgresql/connections)。
</Callout>
