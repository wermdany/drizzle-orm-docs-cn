# 使用 Drizzle 和 Gel 快速上手

<Prerequisites>
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **gel-js** - 用于查询你的 Gel 数据库的包 - [阅读文档](https://github.com/geldata/gel-js)
</Prerequisites>

Drizzle 通过 `gel` 客户端原生支持连接 Gel。

这是项目的基本文件结构。在 `src` 目录中，我们在 `index.ts` 中定义表。在 `drizzle` 文件夹中有生成的从 Gel 到 Drizzle 的 schema

```plaintext
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 │ └ 📜 index.ts
 ├ 📜 drizzle.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

#### 步骤 1 - 安装并初始化 **Gel** 项目

<Npx>
gel project init
</Npx>

#### 步骤 2 - 定义基本 Gel schema

在 `dbschema/default.esdl` 文件中添加一个基本的 Gel schema

```esdl
module default {
    type user {
        name: str;
        required email: str;
        age: int16;
    }
}
```

#### 步骤 3 - 将 Gel schema 推送到数据库

生成 Gel 迁移文件：
```bash
gel migration create
```

将 Gel 迁移应用到数据库
```bash
gel migration apply
```

<Callout>
现在你应该拥有以下文件结构

```plaintext
📦 <project root>
 ├ 📂 dbschema
 │ ├ 📂 migrations
 │ ├ 📜 default.esdl
 │ └ 📜 scoping.esdl
 ├ 📂 src
 │ └ 📜 index.ts
 ├ 📜 drizzle.config.ts
 ├ 📜 edgedb.toml
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
</Callout>

#### 步骤 4 - 安装所需包
<Npm>
    drizzle-orm@rc gel
    -D drizzle-kit@rc tsx
</Npm>

#### 步骤 5 - 配置 Drizzle 配置文件

**Drizzle config** - 一个由 [Drizzle Kit](/docs/kit-overview) 使用的配置文件，包含你的数据库连接、迁移文件夹和 schema 文件的全部信息。

在你的项目根目录创建 `drizzle.config.ts` 文件，并添加以下内容：

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  dialect: 'gel',
});
```

#### 步骤 6 - 将 Gel 类型拉取到 Drizzle schema

拉取你的数据库 schema：
<Npx>
drizzle-kit pull
</Npx>

以下是生成的 schema.ts 文件示例：

```typescript filename="drizzle/schema.ts"
import { gelTable, uniqueIndex, uuid, smallint, text } from "drizzle-orm/gel-core"
import { sql } from "drizzle-orm"

export const users = gelTable("users", {
	id: uuid().default(sql`uuid_generate_v4()`).primaryKey().notNull(),
	age: smallint(),
	email: text().notNull(),
	name: text(),
}, (table) => [
	uniqueIndex("a8c6061c-f37f-11ef-9249-0d78f6c1807b;schemaconstr").using("btree", table.id.asc().nullsLast().op("uuid_ops")),
]);
```

#### 步骤 7 - 将 Drizzle ORM 连接到数据库

在 `src` 目录中创建 `index.ts` 文件并初始化连接：

```typescript copy filename="src/index.ts"
import { drizzle } from "drizzle-orm/gel";
import { createClient } from "gel";

const gelClient = createClient();
const db = drizzle({ client: gelClient });
```

#### 步骤 8 - 查询数据库

```typescript copy filename="src/index.ts"
import { eq } from "drizzle-orm";
import { drizzle } from "drizzle-orm/gel";
import { createClient } from "gel";
import { users } from "../drizzle/schema";

const gelClient = createClient();
const db = drizzle({ client: gelClient });

async function main() {
  const user: typeof users.$inferInsert = {
    name: "John",
    age: 30,
    email: "john@example.com",
  };

  await db.insert(users).values(user);
  console.log("New user created!");

  const usersResponse = await db.select().from(users);
  console.log("Getting all users from the database: ", usersResponse);
  /*
  const users: {
    id: number;
    name: string;
    age: number;
    email: string;
  }[]
  */

  await db
    .update(users)
    .set({
      age: 31,
    })
    .where(eq(users.email, user.email));
  console.log("User info updated!");

  await db.delete(users).where(eq(users.email, user.email));
  console.log("User deleted!");
}

main();
```
