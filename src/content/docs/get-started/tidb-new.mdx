# Drizzle 与 TiDB 入门

<Prerequisites>  
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **TiDB** - PingCAP 出品的分布式 SQL 数据库 - [阅读文档](https://www.pingcap.com/)

</Prerequisites>

</Callout>
