<Callout title='Appwrite 也提供 PostgreSQL' type='info'>
在找 PostgreSQL？请查看我们的 [Appwrite Postgres 指南](/docs/get-started/appwrite-postgres-new)
</Callout>

Appwrite 提供专用的原生 MySQL 数据库，你可以直接通过 TLS 连接。Appwrite 没有专用的驱动，因此本指南使用标准的 `mysql2` 驱动，通过 `drizzle-orm/mysql2` 包来使用。

有关创建 Appwrite MySQL 数据库的详细说明，请参阅 [Appwrite MySQL 文档](https://appwrite.io/docs/products/databases/mysql)。

<InstallPackages lib='mysql2'/>

#### 第 2 步 - 设置连接变量

在你的项目根目录创建一个 `.env` 文件，并添加你的数据库连接变量：

```plaintext copy
DATABASE_URL=mysql://admin.<hash>:<password>@db-<hash>.<region>.appwrite.center:3306/default?ssl=true
```

<Callout title='提示'>
你可以在 Appwrite Console 中打开你的数据库并点击 **"Credentials"** 来获取连接字符串。用户名是 `admin.<hash>`，其中 hash 与主机名中的 hash 一致，数据库名始终是 `default`。Appwrite 通过该用户名来路由你的连接，因此请始终使用连接字符串中的完整值。详细步骤请参阅 [Appwrite MySQL 连接指南](https://appwrite.io/docs/products/databases/mysql/connections)。
</Callout>
