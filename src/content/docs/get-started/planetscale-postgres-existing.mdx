# 在现有项目中使用 Drizzle 和 PlanetScale Postgres 快速上手

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **PlanetScale Postgres** - PostgreSQL 数据库平台 - [阅读文档](https://planetscale.com/docs/postgres)
  - **node-postgres** - 用于查询 PostgreSQL 数据库的包 - [阅读文档](https://node-postgres.com/)
</Prerequisites>

<Callout title='PlanetScale 也提供 MySQL' type='info'>
正在寻找 MySQL？请查看我们的 [PlanetScale MySQL 指南](/docs/get-started/planetscale-existing)
</Callout>

PlanetScale 同时提供 MySQL（Vitess）和 PostgreSQL 数据库。本指南介绍如何使用标准的 `node-postgres` 驱动连接到 PlanetScale Postgres。

关于创建 PlanetScale Postgres 数据库和获取凭证的详细说明，请参阅 [PlanetScale Postgres 文档](https://planetscale.com/docs/postgres/tutorials/planetscale-postgres-drizzle)。

<FileStructure/>

#### 步骤 1 - 安装 **node-postgres** 包
<InstallPackages lib='pg' devlib=' @types/pg'/>

#### 步骤 2 - 配置连接变量

在你的项目根目录下创建一个 `.env` 文件，并添加你的数据库连接变量：

```plaintext copy
DATABASE_URL=postgresql://{username}:{password}@{host}:{port}/postgres?sslmode=verify-full
```

<Callout title='提示'>
你可以从 PlanetScale 仪表板获取连接凭证：导航到你的数据库，点击 **"Connect"**，然后创建一个 **"Default role"**。详细步骤请参阅 [PlanetScale 连接指南](https://planetscale.com/docs/postgres/tutorials/planetscale-postgres-drizzle#create-credentials-and-connect)。
</Callout>
