# 在现有项目中使用 Drizzle 和 Node:SQLite 快速上手

<Prerequisites>  
  - **node v22.5.0+** - JavaScript 运行时 - [阅读文档](https://nodejs.org/)
  - **node:sqlite** - 高性能 SQLite3 驱动的原生实现 - [阅读文档](https://nodejs.org/api/sqlite.html)
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.is/)
</Prerequisites>

#### 步骤 1 - 安装所需包

<Npm>
    drizzle-orm@rc dotenv
    -D drizzle-kit@rc tsx
</Npm>

#### 步骤 2 - 配置连接变量

<SetupEnv env_variable='DB_FILE_NAME' />

<Callout type='info' title='重要'>
例如，如果你的项目根目录下有一个 SQLite 数据库文件，可以使用这个示例：
```plaintext copy
DB_FILE_NAME=mydb.sqlite
```
</Callout>
