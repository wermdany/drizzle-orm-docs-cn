# Drizzle 和 CockroachDB 入门

<br/>

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **node-postgres** - 用于查询你的 Cockroach 数据库的包 - [阅读文档](https://node-postgres.com/)
</Prerequisites>

Drizzle 通过 `node-postgres` 和 `postgres.js` 驱动原生支持连接 CockroachDB。

在本文的快速开始示例中，我们将使用 `node-postgres`。如果你想了解连接 PostgreSQL 的更多方式，请查看我们的 [CockroachDB 连接](/docs/cockroach/get-started-cockroach) 页面
