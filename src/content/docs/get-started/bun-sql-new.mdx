# Drizzle 和 Bun:SQLite 入门

<Prerequisites>  
  - **bun** - JavaScript 一体化工具包 - [阅读此处](https://bun.sh/)
  - **Bun SQL** - 用于处理 PostgreSQL 数据库的原生绑定 - [阅读此处](https://bun.sh/docs/api/sql)
</Prerequisites>

<Callout type='error'>
在 `1.2.0` 版本中，Bun 在执行并发语句时存在问题，如果你尝试同时运行多个查询，可能会导致错误。
我们创建了一个你可以跟踪的 [github issue](https://github.com/oven-sh/bun/issues/16774)。一旦修复，你在 Bun 的 SQL 侧就不应该再遇到此类错误了
</Callout>
