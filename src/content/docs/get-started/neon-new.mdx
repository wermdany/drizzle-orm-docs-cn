# 使用 Drizzle 和 Neon 快速上手

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **Neon** - 无服务器 Postgres 平台 - [阅读文档](https://neon.tech/docs/introduction)
</Prerequisites>

Drizzle 原生支持使用 `neon-http` 和 `neon-websockets` 驱动连接 Neon。它们底层使用的是 **neon-serverless** 驱动。  
  
使用 `neon-http` 和 `neon-websockets` 驱动，你可以在无服务器环境中通过 HTTP 或 WebSockets 访问 Neon 数据库，而不是 TCP。对于单个非交互式事务，通过 HTTP 查询会更快。  
  
如果你需要会话或交互式事务支持，或者需要一个与 `pg` 驱动完全兼容的即插即用替代方案，你可以使用基于 WebSocket 的 `neon-serverless` 驱动。你也可以使用 [Postgres](/docs/get-started/postgresql-new) 直接连接到 Neon 数据库
