# 使用 Drizzle 和 MSSQL 快速上手

<br/>

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [阅读文档](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [阅读文档](https://tsx.hirok.io/)
  - **node-mssql** - 用于查询 MSSQL 数据库的包 - [阅读文档](https://github.com/tediousjs/node-mssql)
</Prerequisites>

Drizzle 原生支持使用 `node-mssql` 驱动连接 PostgreSQL。

</Npm>
