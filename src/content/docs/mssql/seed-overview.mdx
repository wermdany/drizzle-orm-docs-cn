# Drizzle Seed

`drizzle-seed` 是一个 TypeScript 库，帮助你生成确定性的、却又逼真的
假数据来填充数据库。通过利用可设定种子的伪随机数生成器（pRNG），
它确保你生成的数据在不同运行之间保持一致且可复现。
这对于测试、开发和调试尤其有用。

#### 什么是确定性数据生成？

确定性数据生成意味着相同的输入始终产生相同的输出。
在 `drizzle-seed` 的语境中，当你用相同的种子数字初始化库时，
它每次都会生成相同的假数据序列。这样就能得到可预测、可重复的数据集。

#### 伪随机数生成器（pRNG）

伪随机数生成器是一种算法，它产生的数字序列
近似具有随机数的特性。不过，由于它基于一个称为种子的
初始值，你可以控制其随机性。使用相同的种子，pRNG 会生成
相同的数字序列，从而使你的数据生成过程可复现。

#### 使用 pRNG 的好处：

- 一致性：确保你的测试每次都在相同的数据上运行。
- 调试：通过提供一致的数据集，使复现和修复 bug 更容易。
- 协作：团队成员可以共享种子数字，以便使用相同的数据集。

使用 drizzle-seed，你可以两者兼得：既能生成逼真的假数据，又能控制它在需要时随时复现。

## 基础用法

在这个示例中，我们将创建 10 个具有随机名称和 id 的用户

```ts {12}
import { mssqlTable, int, varchar } from "drizzle-orm/mssql-core";
import { drizzle } from "drizzle-orm/node-mssql";
import { seed } from "drizzle-seed";

const users = mssqlTable("users", {
  id: int().primaryKey().identity(),
  name: varchar({ length: 255 }).notNull(),
});

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await seed(db, { users });
}

main();
```

## 选项

**`count`**

默认情况下，`seed` 函数会创建 10 个实体。
不过，如果你的测试需要更多，可以在 seed 选项对象中指定

```ts
await seed(db, schema, { count: 1000 });
```

**`seed`**

如果你需要一个种子在所有后续运行中生成不同的值集，可以在 `seed` 选项中定义不同的数字。
任何新的数字都会生成唯一的一组值

```ts
await seed(db, schema, { seed: 12345 });
```

## 重置数据库

使用 `drizzle-seed`，你可以轻松重置数据库并用新值填充它，例如在你的测试套件中

```ts
// 你想重置的 schema 文件路径
import * as schema from "./schema.ts";
import { reset } from "drizzle-seed";

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await reset(db, schema);
}

main();
```

## 细化

如果你需要更改 `drizzle-seed` 默认使用的种子生成器函数的行为，可以指定自己的实现，甚至为种子填充过程使用自己的值列表

`.refine` 是一个回调，它接收来自 `drizzle-seed` 的所有可用生成器函数列表。它应返回一个对象，其键代表你想要精细化的表，并按需定义它们的行为。
每个表可以指定若干属性来简化数据库的种子填充：

<rem025 />

- `columns`：通过指定所需的生成器函数来精细化每一列的默认行为，或通过指定 `false` 将该列排除在种子填充之外。
- `count`：指定要插入数据库的行数。默认是 10。如果在 `seed()` 选项中定义了全局 count，这里定义的 count 会针对该特定表覆盖它。
- `with`：如果你想生成关联实体，定义要为每个父表创建多少被引用的实体。

<Callout title='info'>
你还可以为你想要创建的引用值数量指定加权随机分布。关于此 API 的详情，可以参阅 [加权随机文档](#加权随机) 章节
</Callout>

**API**
```ts
await seed(db, schema).refine((f) => ({
  users: {
    columns: {},
    count: 10,
    with: {
        posts: 10
    }
  },
}));
```

## 加权随机

有些情况下，你可能需要使用多个具有不同优先级的数据集，在种子填充阶段插入数据库。对于这类情况，drizzle-seed 提供了一个称为加权随机的 API

Drizzle Seed 包有几个地方可以使用加权随机：

- 每个表精细化配置中的列
- `with` 属性，决定要创建的关联实体数量

让我们看一个同时包含两者的示例：

```ts filename="schema.ts"
import { mssqlTable, int, varchar, numeric } from "drizzle-orm/mssql-core";

export const orders = mssqlTable(
  "orders",
  {
    id: int().primaryKey().identity(),
    name: varchar({ length: 255 }).notNull(),
    quantityPerUnit: varchar().notNull(),
    unitPrice: numeric().notNull(),
    unitsInStock: int().notNull(),
    unitsOnOrder: int().notNull(),
    reorderLevel: int().notNull(),
    discontinued: int().notNull(),
  }
);

export const details = mssqlTable(
  "details",
  {
    unitPrice: numeric().notNull(),
    quantity: int().notNull(),
    discount: numeric().notNull(),

    orderId: int()
      .notNull()
      .references(() => orders.id, { onDelete: "cascade" }),
  }
);
```

**示例 1**：精细化 `unitPrice` 的生成逻辑，生成 `5000` 个随机价格，其中 30% 的概率为 10-100 之间的价格，70% 的概率为 100-300 之间的价格

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/node-mssql";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       count: 5000,
       columns: {
           unitPrice: f.weightedRandom(
               [
                   {
                       weight: 0.3,
                       value: f.int({ minValue: 10, maxValue: 100 })
                   },
                   {
                       weight: 0.7,
                       value: f.number({ minValue: 100, maxValue: 300, precision: 100 })
                   }
               ]
           ),
       }
    }
  }));
}

main();
```

**示例 2**：对于每个订单，以 60% 的概率生成 1 到 3 条 details，以 30% 的概率生成 5 到 7 条，以 10% 的概率生成 8 到 10 条

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/node-mssql";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       with: {
           details:
               [
                   { weight: 0.6, count: [1, 2, 3] },
                   { weight: 0.3, count: [5, 6, 7] },
                   { weight: 0.1, count: [8, 9, 10] },
               ]
       }
    }
  }));
}

main();
```

## 限制

#### `with` 的类型限制

由于 TypeScript 的某些限制以及 Drizzle 中当前的 API，无法正确推断表之间的引用，尤其是当表之间存在循环依赖时。

这意味着 `with` 选项会显示 schema 中的所有表，你需要手动选择具有一对多关系的那张表

<Callout title='warning'>
`with` 选项适用于一对多关系。例如，如果你有一个 `user` 和多个 `posts`，你可以使用 users `with` posts，但不能使用 posts `with` users
</Callout>

#### Drizzle 表中第三个参数的类型限制：

目前，我们还不支持 Drizzle 表第三个参数的类型。虽然它在运行时可以工作，但在类型层面不会正确工作
