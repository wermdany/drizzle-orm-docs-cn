# SQL Insert

<Callout type='info'>
传给 `.values()` 的所有值都会自动参数化。
例如，这个查询：
```ts
await db.insert(users).values({ name: 'Andrew' });
```
会被转换成：
```sql
insert into [users] ([name]) values (@par0); -- params: ['Andrew']
```
</Callout>

<br/>

Drizzle ORM 为你提供了最接近 SQL 的方式，将行插入数据库表中。

使用 Drizzle 插入数据非常直观且贴近 SQL。你自己看看：

<Section>
```typescript copy 
await db.insert(users).values({ name: 'Andrew' });
```

```sql
insert into [users] ([name], [age]) values ('Andrew', default)
```
</Section>

如果你需要为某个特定表获取插入类型，可以使用 `typeof usersTable.$inferInsert` 语法。 
```typescript copy 
type NewUser = typeof users.$inferInsert;

const insertUser = async (user: NewUser) => {
  return db.insert(users).values(user);
}

const newUser: NewUser = { name: "Alef" };
await insertUser(newUser);
```

## 带 Output 的 Insert
MSSQL 支持使用 `OUTPUT` 子句返回插入的行。Drizzle 通过 `.output()` 方法暴露了该能力。

```typescript copy
const result = await db
  .insert(usersTable)
  .output({ id: usersTable.id })
  .values([{ name: 'John' }, { name: 'John1' }]);
//    ^? { id: number }[]
```

你也可以通过不带参数调用 `.output()` 来返回所有插入的列。

```ts
const result = await db.insert(usersTable).output().values({ name: 'John' });
//    ^? typeof usersTable.$inferSelect[]
```

## 插入多行
```typescript copy
await db.insert(users).values([{ name: 'Andrew' }, { name: 'Dan' }]);
```

## Upserts 与冲突
MSSQL 不支持 PostgreSQL 风格的 `ON CONFLICT` 或 MySQL 风格的 `ON DUPLICATE KEY UPDATE` 子句。对于 upsert 工作流，请使用带显式 `select`/`update`/`insert` 逻辑的事务，或使用 `sql` 操作符执行方言特定的 `MERGE` 语句。
