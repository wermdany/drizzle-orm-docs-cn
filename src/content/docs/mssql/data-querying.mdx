# Drizzle 查询 + CRUD

<Prerequisites>
  - 如何定义你的 schema - [Schema 基础](/docs/mssql/sql-schema-declaration)
  - 如何连接到数据库 - [连接基础](/docs/mssql/connect-overview)
</Prerequisites>

Drizzle 提供了几种查询数据库的方式，你可以自行决定在下一个项目中需要哪一种。
它可以是类 SQL 语法，也可以是关系语法。让我们来看看它们：

## 为什么采用类 SQL 风格？

**如果你懂 SQL，你就懂 Drizzle。**

其他 ORM 和数据框架往往会偏离或抽象掉 SQL，导致双重学习曲线：你既要学习 SQL，又要学习框架的 API。

Drizzle 恰恰相反。
我们拥抱 SQL，并将 Drizzle 的核心构建为类 SQL 风格，因此你几乎没有学习曲线，并且能完全使用 SQL 的强大能力。

<Section>
```typescript copy
// 访问你的数据
await db
  .select()
	.from(posts)
	.leftJoin(comments, eq(posts.id, comments.post_id))
	.where(eq(posts.id, 10))
```
```sql
SELECT *
FROM [posts]
LEFT JOIN [comments] ON [posts].[id] = [comments].[post_id]
WHERE [posts].[id] = 10
```
</Section>

使用类 SQL 语法，你可以复现大部分纯 SQL 能做到的事情，并确切知道 Drizzle 会做什么、会生成什么查询。你可以执行各种各样的查询，
包括 select、insert、update、delete，以及使用别名、WITH 子句、子查询、预编译语句等等。让我们看更多示例

<CodeTabs items={['insert', 'update', 'delete']}>
<Section>
```ts
await db.insert(users).values({ email: 'user@gmail.com' })
```
```sql
INSERT INTO [users] ([email]) VALUES ('user@gmail.com')
```
</Section>
<Section>
```ts
await db.update(users)
        .set({ email: 'user@gmail.com' })
        .where(eq(users.id, 1))
```
```sql
UPDATE [users]
SET [email] = 'user@gmail.com'
WHERE [users].[id] = 1
```
</Section>
<Section>
```ts
await db.delete(users).where(eq(users.id, 1))
```
```sql
DELETE FROM [users] WHERE [users].[id] = 1
```
</Section>
</CodeTabs>

## 为什么不采用类 SQL 风格？

我们始终在追求一个完美平衡的解决方案。虽然类 SQL 查询能覆盖你 100% 的需求，
但在某些常见场景下，数据可以更高效地被查询。

我们构建了 Queries API，让你能以最便捷、
最高效的方式从数据库中获取关系型、嵌套的数据，而无需担心连接或数据映射。

**Drizzle 始终只输出一条 SQL 查询**。你可以放心地将其用于无服务器数据库，
永远不必担心性能或往返开销！

<Section>
```ts
const result = await db._query.users.findMany({
	with: {
		posts: true
	},
});
```
{/* ```sql
SELECT * FROM users ...
``` */}
</Section>

## 进阶
使用 Drizzle，查询可以以任何你想要的方式进行组合和拆分。你可以独立于主查询来组合过滤器，
拆分出子查询或条件语句，以及更多。让我们看几个进阶示例：

#### 组合一个 WHERE 语句，然后在查询中使用它
```ts
async function getProductsBy({
  name,
  category,
  maxPrice,
}: {
  name?: string;
  category?: string;
  maxPrice?: number;
}) {
  const filters: SQL[] = [];

  if (name) filters.push(like(products.name, name));
  if (category) filters.push(eq(products.category, category));
  if (maxPrice) filters.push(lte(products.price, maxPrice));

  return db
    .select()
    .from(products)
    .where(and(...filters));
}
```

#### 将子查询拆分到不同的变量中，然后在主查询中使用它们
```ts
const subquery = db
	.select()
	.from(internalStaff)
	.leftJoin(customUser, eq(internalStaff.userId, customUser.id))
	.as('internal_staff');

const mainQuery = await db
	.select()
	.from(ticket)
	.leftJoin(subquery, eq(subquery.internal_staff.userId, ticket.staffId));
```
