# `drizzle-kit pull`

<Prerequisites>
- 快速上手 Drizzle 与 `drizzle-kit` - [阅读此处](/docs/mssql/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/mssql/sql-schema-declaration) 
- 数据库连接基础 - [阅读此处](/docs/mssql/connect-overview) 
- Drizzle 迁移基础 - [阅读此处](/docs/mssql/migrations) 
- Drizzle Kit [概览](/docs/mssql/kit-overview) 与 [配置文件](/docs/mssql/drizzle-config-file) 文档
</Prerequisites>

`drizzle-kit pull` 让你可以按字面意义拉取（内省）你现有的数据库 schema 并生成 `schema.ts` drizzle schema 文件，
它旨在覆盖 Drizzle 迁移的 [database first](/docs/mssql/migrations) 方式。

<Callout collapsed="底层是如何工作的？">
当你运行 Drizzle Kit `pull` 命令时，它会：
1. 从你现有的数据库拉取数据库 schema（DDL）
2. 生成 `schema.ts` drizzle schema 文件并保存到 `out` 文件夹

<Section>
```
                                  ┌────────────────────────┐      ┌───────────────────────────────┐ 
                                  │                        │ <---  CREATE TABLE [users] (
┌──────────────────────────┐      │                        │        [id] int identity primary key,
│ ~ drizzle-kit pull       │      │                        │        [name] varchar(255),
└─┬────────────────────────┘      │        DATABASE        │        [email] varchar(255) unique
  │                               │                        │       );
  └ Pull datatabase schema -----> │                        │
  ┌ Generate Drizzle       <----- │                        │
  │ schema TypeScript file        └────────────────────────┘
  │
  v
```
```typescript
import * as p from "drizzle-orm/mssql-core";

export const users = p.mssqlTable("users", {
	id: p.int().identity({ seed: 1 ,increment: 1 }),
	name: p.varchar({ length: 255 }),
	email: p.varchar({ length: 255 }),
}, (table) => [
	p.primaryKey({ columns: [table.id], name: "PK__users__3213E83F9C94E8E5"}),
	p.unique("UQ__users__AB6E6164167EE806").on(table.email)
]);
```
</Section>
</Callout>

如果你需要在 TypeScript 项目之外管理数据库 schema，或者你使用的数据库由他人管理，
这是一个非常不错的方式。

<br/>

`drizzle-kit pull` 要求你指定 `dialect` 以及
数据库连接 `url` 或 `user:password@host:port/db` 参数，你可以通过
[drizzle.config.ts](/docs/mssql/drizzle-config-file) 配置文件或 CLI 选项提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  dbCredentials: {
    url: "mssql://user:password@host:port/dbname",
  },
});
```
```shell
npx drizzle-kit pull
```
</Section>

```shell
npx drizzle-kit pull --dialect=mssql --url=mssql://user:password@host:port/dbname
```
</CodeTabs>

### 一个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你拥有多个数据库环境或同一项目中有多个数据库或不同数据库时，这非常有用：

<Npx>
  drizzle-kit pull --config=drizzle-dev.config.ts
  drizzle-kit pull --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 初始拉取

你可以使用 `--init` 标志将拉取的 schema 标记为数据库中已应用的迁移，
这样所有后续迁移都会与初始迁移进行差异对比

```shell
npx drizzle-kit pull --init
```

### 包含表和 schema
`drizzle-kit pull` 默认会管理所有 schema 中的所有表。
你可以通过 `tablesFilter` 和 `schemaFilter` 选项配置表和 schema 的列表。

|                     |                                                                                               |
| :------------------ | :-------------------------------------------------------------------------------------------- |
| `tablesFilter`      | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认为 `"*"` |
| `schemaFilter`      | 基于 `glob` 的 schema 名过滤器，例如 `["dbo", "drizzle"]` 或 `"drizzle*"`。默认为 `"*"`                     |
<br/>

让我们配置 drizzle-kit 仅操作 **dbo** schema 中的**所有表**。

<Section>
```ts filename="drizzle.config.ts" {9-10}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mssql://user:password@host:port/dbname",
  },
  schemaFilter: ["dbo"],
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit pull
```
</Section>

### 扩展配置列表
我们建议通过 [drizzle.config.ts](/docs/mssql/drizzle-config-file) 文件配置 `drizzle-kit`，
不过如有必要，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中等。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，可选值为 <Dialects/>                                      |
| `out`               |            | 迁移输出文件夹路径，默认为 `./drizzle`                     |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                         |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名称                                                             |
| `config`            |            | 配置文件路径，默认为 `drizzle.config.ts`                          |
| `introspect-casing` |            | 在列、表等中创建 JS 键的策略。`preserve` `camel` |
| `tablesFilter`      |            | 表名过滤器                                                         |
| `schemaFilter`      |            | schema 名过滤器。默认：`["*"]`                                 |

<Npx>
drizzle-kit pull --dialect=mssql --url=mssql://user:password@host:port/dbname
drizzle-kit pull --dialect=mssql --tablesFilter='user*' url=mssql://user:password@host:port/dbname
</Npx>
