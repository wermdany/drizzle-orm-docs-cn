### int
有符号 4 字节 int     

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	int: int()
});

```

```sql
CREATE TABLE [table] (
	[int] int
);
```
</Section>

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

	int1: int().default(10),
```

```sql
CREATE TABLE [table] (
	[int1] int CONSTRAINT [table_int1_default] DEFAULT ((10))
);
```
</Section>

### bigint
`bigint`

有符号 8 字节 int  

如果你期望的值大于 2^31 但小于 2^53，可以使用 `mode: 'number'`，用 JavaScript 的 number 来处理而不是 bigint。
<Section>
```typescript
import { bigint, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	bigint: bigint({ mode: 'number' })
});

// 将被推断为 `number`
bigint: bigint({ mode: 'number' })

// 将被推断为 `bigint`
bigint: bigint({ mode: 'bigint' })

// 将被推断为 `string`
bigint: bigint({ mode: 'string' })
```

```sql
CREATE TABLE [table] (
	[bigint] bigint
);
```
</Section>

<Section>
```typescript
import { bigint, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	bigint1: bigint({ mode: 'number' }).default(10)
});
```

```sql

	[bigint1] bigint CONSTRAINT [table_bigint1_default] DEFAULT ((10))
);
```

### text
`text`  
可变长度的非 Unicode 数据，使用服务器的代码页，最大字符串长度
为 2^31 - 1（2,147,483,647）

更多信息请参考 MSSQL 官方 **[文档。](https://learn.microsoft.com/en-us/sql/t-sql/data-types/ntext-text-and-image-transact-sql?view=sql-server-ver17#text)**
  
你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。
<Section>
```typescript
import { text, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
  text: text()
});

// 将被推断为 text: "value1" | "value2" | null
text: text({ enum: ["value1", "value2"] })
```

```sql

	[text] text
);
```
</Section>

### varchar
`varchar(n|max)`  
可变大小的字符串数据。使用 n 定义以字节为单位的字符串大小，可以是 1 到 8,000 之间的值

更多信息请参考 MSSQL 官方 **[文档。](https://learn.microsoft.com/en-us/sql/t-sql/data-types/char-and-varchar-transact-sql?view=sql-server-ver17#varchar---n--max--)**

你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。

根据 MSSQL 文档，`length` 参数是可选的。
<Section>
```typescript
import { varchar, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
  varchar1: varchar(),
  varchar2: varchar({ length: 256 }),
  varchar3: varchar({ length: 'max' })
});

// 将被推断为 text: "value1" | "value2" | null
varchar: varchar({ enum: ["value1", "value2"] });
```

```sql
CREATE TABLE [table] (
	[varchar1] varchar,
	[varchar2] varchar(256),
	[varchar3] varchar(max)
);
```
</Section>

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，允许你自定义列的数据类型。

这在处理未知或品牌类型（branded type）时很有用，例如：
```ts
type UserId = number & { __brand: 'user_id' };

export const users = mssqlTable('users', {
  id: int().$type<UserId>().primaryKey(),
});
```

### 默认值
`DEFAULT` 子句为列指定一个默认值，当用户在执行 `INSERT` 时未显式提供值时使用。
如果列定义没有附加显式的 `DEFAULT` 子句，
那么该列的默认值为 `NULL`。

显式的 `DEFAULT` 子句可以指定默认值为 `NULL`

<Section>
```typescript
import { int, mssqlTable, text } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	int: int().default(42),
	text: text().default('text'),
});
```

```sql
CREATE TABLE [table] (
	[int] int CONSTRAINT [table_int_default] DEFAULT ((42)),
	[text] text CONSTRAINT [table_text_default] DEFAULT ('text')
);
```
</Section>

使用 `$default()` 或 `$defaultFn()`（它们只是同一个函数的不同别名）时，
你可以在运行时生成默认值，并在所有 insert 查询中使用这些值。

<Callout type="info" emoji="ℹ️">
	注意：该值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 运行时使用
</Callout>

```ts
import { text, mssqlTable } from "drizzle-orm/mssql-core";
import { createId } from '@paralleldrive/cuid2';

export const table = mssqlTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

使用 `$onUpdate()` 或 `$onUpdateFn()`（它们只是同一个函数的不同别名）时，
你可以在运行时生成默认值，并在所有 update 查询中使用这些值。

为列添加一个动态更新值。该函数会在行被更新时调用，
如果没有提供值，则返回的值将用作列值。
如果没有提供默认值（或 $defaultFn 值），该函数也会在行被插入时调用，
返回的值将用作列值。

<Callout type="info" emoji="ℹ️">
	注意：该值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 运行时使用
</Callout>

```ts
import { int, datetime2, text, mssqlTable } from "drizzle-orm/mssql-core";
import { SQL, sql } from 'drizzle-orm';

export const table = mssqlTable('table', {
	updateCounter: int().default(sql`1`).$onUpdateFn((): SQL => sql`${table.updateCounter} + 1`),
	updatedAt: datetime2({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```


### 非空
`NOT NULL` 约束规定关联的列不能包含 `NULL` 值。

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

	int: int().notNull(),
});
```

```sql
CREATE TABLE [table] (
	[int] int NOT NULL
);
```
</Section>


### 主键
主键约束表示一个列或一组列可以用作表中行的唯一标识符。
这要求这些值既唯一又非空。
<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	id: int().primaryKey(),
});
```

```sql
CREATE TABLE [table] (
	[id] int,
	CONSTRAINT [table_pkey] PRIMARY KEY([id])
);
```
</Section>
