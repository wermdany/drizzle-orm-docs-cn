# `drizzle-kit push`

<Prerequisites>
- 快速上手 Drizzle 与 `drizzle-kit` - [阅读此处](/docs/mssql/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/mssql/sql-schema-declaration) 
- 数据库连接基础 - [阅读此处](/docs/mssql/connect-overview) 
- Drizzle 迁移基础 - [阅读此处](/docs/mssql/migrations) 
- Drizzle Kit [概览](/docs/mssql/kit-overview) 与 [配置文件](/docs/mssql/drizzle-config-file) 文档
</Prerequisites>


`drizzle-kit push` 让你可以按字面意义将你的 schema 及其后续 schema 变更直接推送到
数据库，同时省略 SQL 文件的生成，它旨在覆盖 Drizzle 迁移的 [code first](/docs/mssql/migrations)
方式。

<Callout collapsed="底层是如何工作的？">
当你运行 Drizzle Kit `push` 命令时，它会：
1. 读取你的 Drizzle schema 文件并组合出 schema 的 json 快照
2. 拉取（内省）数据库 schema
3. 根据两者之间的差异生成 SQL 迁移
4. 将 SQL 迁移应用到数据库

<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/mssql-core";

export const users = p.mssqlTable("users", {
  id: p.int().primaryKey().identity(),
  name: p.nvarchar({ length: 255 }),
});
```
```
┌─────────────────────┐                  
│ ~ drizzle-kit push  │                  
└─┬───────────────────┘                  
  │                                           ┌──────────────────────────┐
  └ Pull current datatabase schema ---------> │                          │
                                              │                          │
  ┌ Generate alternations based on diff <---- │         DATABASE         │
  │                                           │                          │
  └ Apply migrations to the database -------> │                          │
                                       │      └──────────────────────────┘
                                       │
  ┌────────────────────────────────────┴─────┐
   CREATE TABLE [users] (
     [id] int IDENTITY(1, 1),
     [name] nvarchar(255),
     CONSTRAINT [users_pkey] PRIMARY KEY([id])
   );
```
</Section>
</Callout>

这是快速原型开发的最佳方式，我们已经看到许多团队
和独立开发者成功地将其作为生产应用程序中的主要迁移流程。
它与蓝绿部署策略、托管数据库部署以及 CI/CD 工作流配合得极其出色。

`drizzle-kit push` 要求你指定 `dialect`、`schema` 文件的路径，以及
数据库连接 `url` 或 `user:password@host:port/db` 参数，你可以通过
[drizzle.config.ts](/docs/mssql/drizzle-config-file) 配置文件或 CLI 选项提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mssql://user:password@host:port/dbname",
  },
});
```
```shell
npx drizzle-kit push
```
</Section>

```shell
npx drizzle-kit push --dialect=mssql --schema=./src/schema.ts --url=mssql://user:password@host:port/dbname
```

</CodeTabs>

### Schema 文件路径

你可以只有一个 `schema.ts` 文件，也可以在项目中散布任意数量的 schema 文件。
Drizzle Kit 要求你通过 `schema` 配置选项以 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的形式指定它们的路径。

### 一个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你拥有多个数据库环境或同一项目中有多个数据库或不同数据库时，这非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.config.ts
  drizzle-kit push --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 包含表和 schema
`drizzle-kit push` 默认会管理所有表和 schema。
你可以通过 `tablesFilter`、`schemaFilter` 选项配置表、schema 的列表。

|                     |                                                                                               |
| :------------------ | :-------------------------------------------------------------------------------------------- |
| `tablesFilter`      | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认为 `"*"` |
| `schemaFilter`      | schema 名过滤器，例如 `["dbo", "drizzle"]`                                             |
<br/>

让我们配置 drizzle-kit 仅操作 **dbo** schema 中的**所有表**。

<Section>
```ts filename="drizzle.config.ts" {9-10}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mssql://user:password@host:port/dbname",
  },
  schemaFilter: ["dbo"],
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit push
```
</Section>

### 扩展配置列表

`drizzle-kit push` 有一系列仅 CLI 可用的选项

<rem025/>

|           |                                                                 |
| :-------- | :---------------------------------------------------------------|
| `verbose` | 在执行前打印所有 SQL 语句                     |
| `explain` | 打印计划中的 SQL 变更，但不应用它们（试运行）  |
| `force`   | 自动接受所有数据丢失语句                            |
<br/>
<Npx>
drizzle-kit push --explain --verbose --force
</Npx>

<br/>
<hr/>
<br/>
我们建议通过 [drizzle.config.ts](/docs/mssql/drizzle-config-file) 文件配置 `drizzle-kit`，
不过如有必要，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中等。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，可选值为 <Dialects/>                                      |
| `schema`            | `required` | typescript schema 文件或包含多个 schema 文件的文件夹的路径 |
| `tablesFilter`      |            | 表名过滤器                                                         |
| `schemaFilter`      |            | schema 名过滤器。默认：`["*"]`                                 |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                         |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名称                                                             |
| `config`            |            | 配置文件路径，默认=`drizzle.config.ts`                             |

<Npx>
drizzle-kit push dialect=mssql schema=src/schema.ts url=mssql://user:password@host:port/dbname
drizzle-kit push dialect=mssql schema=src/schema.ts --tablesFilter='user*' url=mssql://user:password@host:port/dbname
</Npx>
