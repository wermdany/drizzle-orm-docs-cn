# 生成器

<Callout title='warning'>
目前，在支持 `arraySize` 的生成器中同时指定 `arraySize` 和 `isUnique`，会生成唯一值（而非唯一数组），随后这些值会被打包进数组。
</Callout>

## ---

### `default`

<rem025 />
每次调用生成器时生成相同的给定值。

|  | 参数          | 默认值     | 类型
|:-| :--------      | :--------   | :--------
|  |`defaultValue`  |--           |`any`
|  |`arraySize`     |--           |`number`

<rem025 />

```ts 
import { seed } from "drizzle-seed";

await seed(db, schema, { count: 1000 }).refine((funcs) => ({
  posts: {
    columns: {
      content: funcs.default({
        // 你想生成的值
        defaultValue: "post content",

        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```

### `valuesFromArray`

<rem025 />
从给定数组生成值

|  | 参数      | 默认值                     | 类型
|:-| :--------  | :--------                   | :--------
|  |`values`    |--                           |`any[]` \| `{ weight: number; values: any[] }[]`
|  |`isUnique`  |`数据库列唯一性` |`bit`
|  |`arraySize` |--                           |`number`


<rem025 />
```ts 
import { seed } from "drizzle-seed";

await seed(db, schema, { count: 1000 }).refine((funcs) => ({
  posts: {
    columns: {
      title: funcs.valuesFromArray({
        // 你想生成的值数组（可以是带权重的值数组）
        values: ["Title1", "Title2", "Title3", "Title4", "Title5"],

        // 控制生成值是否唯一的属性
        isUnique: true,
        
        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```

### `number`

<rem025 />
在给定范围内生成带小数点的数字

|  | 参数      | 默认值                                                                                               | 类型
|:-| :--------  | :--------                                                                                             | :--------
|  |`isUnique`  |`数据库列唯一性`                                                                           |`bit`
|  |`precision` |`100`                                                                                                  |`number`
|  |`maxValue`  |``` `precision * 1000`，如果 isUnique 为 false``` ``` `precision * count`，如果 isUnique 为 true```  |`number`
|  |`minValue`  |`-maxValue`                                                                                            |`number`
|  |`arraySize` |--                                                                                                     |`number`

<rem025 />
```ts 
import { seed } from "drizzle-seed";

await seed(db, schema, { count: 1000 }).refine((funcs) => ({
  products: {
    columns: {
      unitPrice: funcs.number({
        // 范围下界。
        minValue: 10,

        // 范围上界。
        maxValue: 120,
        
        // 生成数字的精度：
        // precision 等于 10 表示值精确到十分位（1.2、34.6）；
        // precision 等于 100 表示值精确到百分位（1.23、34.67）。
        precision: 100,

        // 控制生成值是否唯一的属性。
        isUnique: false,

        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```

### `date`

<rem025 />
在给定范围内生成日期

|  | 参数      | 默认值                                                                                                   | 类型
|:-| :--------  | :--------------                                                                                           | :--------
|  |`minDate`   |``` `'2024-05-08' - 4 years` - 如果未设置 maxDate``` ``` `maxDate - 8 years`  - 如果已设置 maxDate ```   |`string \| Date`

<Callout type='warning'>
如果只提供了其中一个参数（`minDate` 或 `maxDate`），未指定的参数将通过给已指定参数加上或减去 8 年来计算
</Callout>

```ts 
  users: {
    columns: {
      birthDate: funcs.date({
        // 范围下界。
        minDate: "1990-01-01",

        // 范围上界。
        maxDate: "2010-12-31",

        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```

### `phoneNumber`

<rem025 />
生成唯一电话号码

|  | 参数                    | 默认值                                         | 类型
|:-| :--------                | :--------                                       | :--------
|  |`template`                |--                                               |`string`
|  |`prefixes`                |[用于前缀的数据集](https://github.com/OleksiiKH0240/drizzle-orm/blob/main/drizzle-seed/src/datasets/phonesInfo.ts)   |`string[]`
|  |`generatedDigitsNumbers`  | `7` - `如果已定义 prefixes`                 |`number \| number[]`
|  |`arraySize`               |--                                               |`number`

<rem025 />
```ts 
import { seed } from "drizzle-seed";

// 使用 template 属性生成电话号码
await seed(db, schema, { count: 1000 }).refine((funcs) => ({
  users: {
    columns: {
      phoneNumber: funcs.phoneNumber({ 
        // `template` - 电话号码模板，其中所有 '#' 符号都会被替换为生成的数字。
        template: "+(380) ###-####",

        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```
```ts 
import { seed } from "drizzle-seed";

// 使用 prefixes 和 generatedDigitsNumbers 属性生成电话号码
await seed(db, schema, { count: 1000 }).refine((funcs) => ({
  users: {
    columns: {
      phoneNumber: funcs.phoneNumber({
        // `prefixes` - 你想要的电话号码前缀字符串数组。（与 `template` 属性不兼容）
        prefixes: ["+380 99", "+380 67"],

        // `generatedDigitsNumbers` - 将添加到前缀末尾的数字个数。（与 `template` 属性不兼容）
        generatedDigitsNumbers: 7,

        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```
```ts 
import { seed } from "drizzle-seed";

// 使用 prefixes 和 generatedDigitsNumbers 属性生成电话号码，但为不同前缀指定不同的 generatedDigitsNumbers
await seed(db, schema, { count: 1000 }).refine((funcs) => ({
  users: {
    columns: {
      phoneNumber: funcs.phoneNumber({
        // `prefixes` - 你想要的电话号码前缀字符串数组。（与 `template` 属性不兼容）
        prefixes: ["+380 99", "+380 67", "+1"],

        // `generatedDigitsNumbers` - 将添加到前缀末尾的数字个数。（与 `template` 属性不兼容）
        generatedDigitsNumbers: [7, 7, 10],

        // 每个一维数组中的元素个数。 
        // （如果指定，将生成数组。）
        arraySize: 3
      }),
    },
  },
}));

```

### `geometry`

<rem025 />
根据给定参数生成 geometry 对象。

<Callout title='warnings'>
<Tabs items={['arraySize', 'srid']}>
<Tab>
目前，如果你将 arraySize 设置为大于 1 的值 
或尝试通过 drizzle-orm 向 MSSQL 的 `geometry(point, 0)[]` 列插入多个 `geometry point` 元素， 
就会遇到错误。

该 bug 已在待办列表中。

<Callout title="❌">
```ts {13}
import { seed } from "drizzle-seed";
import { geometry, mssqlTable } from 'drizzle-orm/mssql-core';

const geometryTable = mssqlTable('geometry_table', {
	geometryArray: geometry('geometry_array', { type: 'point', srid: 0 }).array(3),
});

await seed(db, { geometryTable }, { count: 1000 }).refine((funcs) => ({
  geometryTable: {
    columns: {
      geometryArray: funcs.geometry({
        // 目前不支持值大于 1 的 arraySize
        arraySize: 3,
      }),
    },
  },
}));
```
</Callout>

<Callout title='✅'>

```ts {13}
import { seed } from "drizzle-seed";

const geometryTable = mssqlTable('geometry_table', {

await seed(db, { geometryTable }, { count: 1000 }).refine((funcs) => ({
```

```ts

  vectorTable: {
```
