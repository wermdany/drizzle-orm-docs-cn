# Drizzle Kit 配置文件

Drizzle Kit 让你可以在 `TypeScript` 或 `JavaScript` 配置文件中声明配置选项。

<Section>
```plaintext {5}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
<CodeTabs items={["drizzle.config.ts", "drizzle.config.js"]}>
<CodeTab>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
<CodeTab>
```js
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
</CodeTabs>
</Section>

扩展配置文件的示例
```ts collapsable
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "mssql",
  schema: "./src/schema.ts",

  dbCredentials: {
    url: "mssql://user:password@host:3306/dbname",
  },

  schemaFilter: "dbo",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
    schema: "drizzle",
  },

  breakpoints: true,
  verbose: true,
});
```

### 多个配置文件
你可以在项目中拥有多个配置文件，当你有多套数据库阶段、多个数据库，或同一项目中的不同数据库时，这非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 迁移文件夹
`out` 参数让你定义迁移的文件夹，它是可选的，默认为 `drizzle`。
这非常有用，因为你可以在同一项目中为不同的数据库拥有许多独立的 schema，
并为它们设置不同的迁移文件夹。
  
迁移文件夹包含带有 `.sql` 迁移文件的文件夹，供 `drizzle-kit` 使用

<Section>
```plaintext {3}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ ├ 📜 user.ts 
 │ ├ 📜 post.ts 
 │ └ 📜 comment.ts 
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
```ts {6}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema/*",
  out: "./drizzle",
});
```
</Section>

### `dbCredentials`
<rem025/>

数据库连接凭据，形式为 `url` 或
`user:password@host:port/db` 参数。

|               |                      |
| :------------ | :-----------------   |
| 类型          | <Dialects/> |
| 默认值       | --                    |
| 命令      | `push`, `pull`, `migrate`, `studio` |

<rem025/>

<CodeTabs items={["连接字符串", "连接参数"]}>
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "mssql",
  dbCredentials: {
    url: "mssql://user:password@host:3306/db",
  }
});
```
```ts
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  dialect: 'mssql',
  schema: './schema.ts',
  breakpoints: false,
  dbCredentials: {
    database: '',
    password: '',
    port: 3306,
    server: '',
    user: '',
    options: {
      encrypt: true,
      trustServerCertificate: true,
    },
  },
});
```
</CodeTabs>

### `migrations`
<rem025/>

运行 `drizzle-kit migrate` 时 —— drizzle 会在你数据库的 `drizzle` schema 中、
名为 `__drizzle_migrations` 的日志表里记录成功应用的迁移。

`migrations` 配置选项让你可以同时更改迁移日志的 `table` 名称和 `schema`。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `{ table: string, schema: string }` |
| 默认值       | `{ table: "__drizzle_migrations", schema: "drizzle" }`                    |
| 命令      | `migrate`, `push`, `pull` |

<rem025/>

```ts
export default defineConfig({
  dialect: "mssql",
  schema: "./src/schema.ts",
  migrations: {
    table: 'my-migrations-table', // 默认为 `__drizzle_migrations`
    schema: 'my_schema', // 默认为 `drizzle`
  },
});
```

<rem025/>

`casing` 负责代码中列键（column key）的大小写风格

|               |                      |
| :------------ | :-----------------   |
| 类型          | `{ casing: "preserve" \| "camel" }` |
| 默认值       | `{ casing: "camel" }`                    |
| 命令      | `pull`   |

<rem025/>

### `tablesFilter`
<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/mssql/goodies#多项目-schema)。
</Callout>
<rem025/>
`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有表。
你可以通过 `tablesFilters` 和 `schemaFilter` 选项配置表和 schema 的列表。

`tablesFilter` 选项让你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值       | --                    |
| 命令      | `push` `pull`   |

<rem025/>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  tablesFilter: ["users", "posts", "project1_*"],
});
```

### `schemaFilter`


<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/mssql/goodies#多项目-schema)。
</Callout>

`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有 schema。

`schemaFilter` 选项让你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
 的 schema 名称过滤器，例如 `["dbo", "auth"]` 或 `"tenant_*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string[]` |
| 命令      | `push` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "mssql",
  schemaFilter: ["dbo", "schema1", "schema2"],
});
```

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `false`                    |

<rem025/>

```ts
export default defineConfig({
  dialect: "mssql",
  verbose: false,
});
```

### `breakpoints`
<rem025/>

Drizzle Kit 会自动在生成的 SQL 迁移文件中嵌入 `--> statement-breakpoint`，
这对于不支持在一个事务中执行多条 DDL 交替语句的数据库来说是必要的。

`breakpoints` 选项标志让你可以开关它

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值       | `true`                    |
| 命令      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "mssql",
  breakpoints: false,
});
```
