# Drizzle \<\> MySQL

要将 Drizzle 与 MySQL 数据库一起使用，你应该使用 `mysql2` 驱动

根据**[官方网站](https://github.com/sidorares/node-mysql2)**，
`mysql2` 是一个为 Node.js 打造的 MySQL 客户端，专注于性能。  

Drizzle ORM 通过 `drizzle-orm/mysql2` 包原生支持 `mysql2`。

#### 步骤 1 - 安装软件包
<Npm>
 drizzle-orm@rc mysql2
 -D drizzle-kit@rc
</Npm>

#### 步骤 2 - 初始化驱动并执行查询
<CodeTabs items={['mysql2', 'mysql 及配置']}>
```typescript copy
import { drizzle } from "drizzle-orm/mysql2";

const db = drizzle(process.env.DATABASE_URL);

const response = await db.select().from(...)
```
```typescript copy
import { drizzle } from "drizzle-orm/mysql2";

// 你可以指定 mysql2 连接选项中的任意属性
const db = drizzle({ connection:{ uri: process.env.DATABASE_URL }});

const response = await db.select().from(...)
```
</CodeTabs>

如果你需要提供现有的驱动：

<CodeTabs items={['Client 连接', 'Pool 连接']}>
  ```typescript copy
  import { drizzle } from "drizzle-orm/mysql2";
  import mysql from "mysql2/promise";

  const connection = await mysql.createConnection({
    host: "host",
    user: "user",
    database: "database",
    ...
  });

  const db = drizzle({ client: connection });
  ```
  ```typescript copy
  import { drizzle } from "drizzle-orm/mysql2";
  import mysql from "mysql2/promise";

  const poolConnection = mysql.createPool({
    host: "host",
    user: "user",
    database: "database",
    ...
  });

  const db = drizzle({ client: poolConnection });
  ```
</CodeTabs>

<Callout type="warning" emoji="⚙️">
  对于用于 DDL 迁移的内置 `migrate` 函数，我们和驱动都强烈建议你使用单个 `client` 连接。  

  对于查询用途，你可以根据自己的业务需求随意使用 `client` 或 `pool`。
</Callout>
