# `drizzle-kit check`

<Prerequisites>
- Drizzle 和 `drizzle-kit` 入门 - [阅读此处](/docs/mysql/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/mysql/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/mysql/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/mysql/migrations)
- Drizzle Kit [概览](/docs/mysql/kit-overview) 和 [配置文件](/docs/mysql/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读此处](/docs/mysql/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit check` 命令让你检查生成的 SQL 迁移历史是否一致。

当你有多个开发者同时在项目上工作，并在不同分支上修改数据库 schema 时，这非常有用 - 阅读更多关于 [团队迁移](/docs/mysql/kit-migrations-for-teams) 的内容。

<br/>
<hr/>
<br/>

`drizzle-kit check` 命令要求你指定 `dialect` 参数，
你可以通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 配置文件或 CLI 选项提供它

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
});
```
```shell
npx drizzle-kit check
```
</Section>
```shell
npx drizzle-kit check --dialect=mysql
```
</CodeTabs>

### 一个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你存在多个数据库阶段或同一项目中有多个数据库时，这非常有用：
<Npx>
  drizzle-kit check --config=drizzle-dev.config.ts
  drizzle-kit check --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展的配置列表
我们推荐通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 文件配置 `drizzle-kit`，
不过如有必要，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中等。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。可以是 <Dialects/> |
| `out`     |            | 迁移文件夹，默认值=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认值=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit check --dialect=mysql
drizzle-kit check --dialect=mysql --out=./migrations-folder
</Npx>
