# Drizzle \<\> Appwrite MySQL

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/mysql/connect-overview)
- Appwrite 原生 MySQL 数据库 - [网站](https://appwrite.io) & [文档](https://appwrite.io/docs/products/databases/mysql)
- Appwrite MySQL 连接 - [文档](https://appwrite.io/docs/products/databases/mysql/connections)
- Drizzle MySQL 驱动 - [文档](/docs/mysql/get-started-mysql)
</Prerequisites>

Appwrite 提供专用的原生 MySQL 数据库，你可以直接通过 TLS 连接。没有 Appwrite 专属的驱动或抽象层，因此你可以像使用任何 MySQL 服务器一样，通过 `drizzle-orm/mysql2` 包配合 [`mysql2`](https://github.com/sidorares/node-mysql2) 驱动来使用 Drizzle。

要获取连接字符串，请在 Appwrite Console 中打开你的数据库并点击 **Credentials**，或者通过 Appwrite API 使用 `mysql.get()` 获取。用户名是 `admin.<hash>`，其中的 hash 与主机名中的一致，数据库名始终是 `default`。Appwrite 的代理会根据该用户名路由你的连接，因此请始终使用连接字符串中的完整值。

```env
DATABASE_URL="mysql://admin.<hash>:<password>@db-<hash>.<region>.appwrite.center:3306/default?ssl=true"
```

#### 第 1 步 - 安装依赖包
<Npm>
 drizzle-orm@rc mysql2
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并执行查询
<CodeTabs items={['mysql2', 'mysql2 带配置']}>
```typescript copy
import { drizzle } from "drizzle-orm/mysql2";

const db = drizzle(process.env.DATABASE_URL);

const response = await db.select().from(...)
```
```typescript copy
import { drizzle } from "drizzle-orm/mysql2";

// 你可以指定 mysql2 连接选项中的任何属性
const db = drizzle({ connection: { uri: process.env.DATABASE_URL, ssl: { rejectUnauthorized: true } } });

const response = await db.select().from(...)
```
</CodeTabs>

如果你需要提供已有的驱动：

<CodeTabs items={['客户端连接', '连接池连接']}>
```typescript copy
import { drizzle } from "drizzle-orm/mysql2";
import mysql from "mysql2/promise";

const connection = await mysql.createConnection(process.env.DATABASE_URL);

const db = drizzle({ client: connection });
```
```typescript copy
import { drizzle } from "drizzle-orm/mysql2";
import mysql from "mysql2/promise";

const poolConnection = mysql.createPool({
  uri: process.env.DATABASE_URL,
});

const db = drizzle({ client: poolConnection });
```
</CodeTabs>

<Callout type="warning" emoji="⚙️">
Appwrite Cloud 上的连接使用 TLS 加密。如果你的运行时或 `mysql2` 配置没有从连接字符串推断出 TLS，请在连接选项中传入 `ssl: { rejectUnauthorized: true }`。

对于使用 DDL 迁移的内置 `migrate` 函数，我们和驱动都强烈建议你使用单个 `client` 连接。
</Callout>

#### 无服务器环境下的连接池

Appwrite 在相同主机名的 `6033` 端口上运行一个[连接池](https://appwrite.io/docs/products/databases/mysql/connection-pooling)。在无服务器和边缘环境中，请让应用的流量通过连接池路由，以免短生命周期实例耗尽引擎的连接数上限；同时让 Drizzle Kit 继续指向引擎直连端口 `3306`，因为迁移会发出需要会话级连接的 DDL。

```env
# 运行时：连接池，事务模式
DATABASE_URL="mysql://admin.<hash>:<password>@db-<hash>.<region>.appwrite.center:6033/default?ssl=true"

# 迁移与内省：直连引擎
DIRECT_URL="mysql://admin.<hash>:<password>@db-<hash>.<region>.appwrite.center:3306/default?ssl=true"
```

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  dialect: 'mysql',
  schema: './src/schema.ts',
  out: './drizzle',
  dbCredentials: {
    url: process.env.DIRECT_URL!,
  },
});
```

连接池默认使用事务模式，它不会在多个语句之间保持后端连接。Drizzle 常规的查询构建器发送文本查询，可以与事务池化一起工作，但会话级特性（例如显式预处理查询、用户变量和临时表）需要直连端口或会话模式的连接池。
