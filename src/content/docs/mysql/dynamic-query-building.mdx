# 动态查询构建

默认情况下，由于 Drizzle 中所有查询构建器都尽可能遵循 SQL，大多数方法你只能调用一次。
例如，在 `SELECT` 语句中可能只有一个 `WHERE` 子句，所以 `.where()` 只能调用一次：

```ts
const query = db
	.select()
	.from(users)
	.where(eq(users.id, 1))
	.where(eq(users.name, 'John')); // ❌ 类型错误 - where() 只能调用一次
```

在之前的 ORM 版本中，当还没有实现这类限制时，这个例子尤其让许多用户感到困惑，因为他们期望查询构建器把多次 `.where()` 调用「合并」成单个条件。

这种行为对于常规查询构建很有用，也就是当你一次性创建整个查询时。
然而，当你想要动态构建查询时，它就会成为问题，例如你有一个接收查询构建器并对其进行增强的共享函数。
为了解决这个问题，Drizzle 为查询构建器提供了一种特殊的「动态」模式，它取消了方法只能调用一次的限制。
要启用它，你需要在查询构建器上调用 `.$dynamic()`。

让我们通过实现一个简单的 `withPagination` 函数来看看它是如何工作的，该函数会根据提供的页码和可选的分页大小，为查询添加 `LIMIT` 和 `OFFSET` 子句：

```ts
function withPagination<T extends MySqlSelect>(
	qb: T,
	page: number = 1,
	pageSize: number = 10,
) {
  return qb.limit(pageSize).offset((page - 1) * pageSize);
}

const query = db.select().from(users).where(eq(users.id, 1));
withPagination(query, 1); // ❌ 类型错误 - 查询构建器不处于动态模式

const dynamicQuery = query.$dynamic();
withPagination(dynamicQuery, 1); // ✅ 正常
```

注意 `withPagination` 函数是泛型的，这允许你在其中修改查询构建器的结果类型，例如添加一个 join：

```ts
function withFriends<T extends MySqlSelect>(qb: T) {
	return qb.leftJoin(friends, eq(friends.userId, users.id));
}

let query = db.select().from(users).where(eq(users.id, 1)).$dynamic();
query = withFriends(query);
```

这是可行的，因为 `MySqlSelect` 及其他类似类型是专门为在动态查询构建中使用而设计的。它们只能在动态模式下使用。

以下是所有可以用作动态查询构建泛型参数的类型列表：

| 查询  | 类型                                          |
|:-------|:----------------------------------------------|
| Select | `MySqlSelect` / `MySqlSelectQueryBuilder`     |
| Insert | `MySqlInsert`                                 |
| Update | `MySqlUpdate`                                 |
| Delete | `MySqlDelete`                                 |

<Callout type='info'>
	`...QueryBuilder` 类型用于配合[独立的查询构建器
	实例](/docs/mysql/goodies#独立查询构建器)。数据库查询构建器是它们的
	子类，因此你也可以使用它们。

    ```ts
    	import { QueryBuilder } from 'drizzle-orm/mysql-core';

    	function withFriends<T extends MySqlSelectQueryBuilder>(qb: T) {
    		return qb.leftJoin(friends, eq(friends.userId, users.id));
    	}

    	const qb = new QueryBuilder();
    	let query = qb.select().from(users).where(eq(users.id, 1)).$dynamic();
    	query = withFriends(query);
    ```

</Callout>
