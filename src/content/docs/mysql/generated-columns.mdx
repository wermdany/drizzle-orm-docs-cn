# 生成列

1. 虚拟（或非持久化）生成列：这些列在被查询时动态计算。它们不占用数据库的存储空间。

2. 存储（或持久化）生成列：这些列在插入或更新行时计算，其值存储在数据库中。这使它们可以被索引，并能提升查询性能，因为无需为每次查询重新计算这些值。

#### 数据库端
    **类型**: `VIRTUAL`, `STORED`

	未指定类型时，默认使用 `VIRTUAL`

    **工作原理**
    - 在表 schema 中通过表达式定义。
    - 虚拟列在读取操作期间计算。
    - 存储列在写入操作期间计算并存储。

    **能力**
    - 可用于 SELECT、INSERT、UPDATE 和 DELETE 语句。
    - 无论是虚拟列还是存储列，都可以被索引。
    - 可以指定 NOT NULL 及其他约束。
    
    **限制**
    - 不能直接向生成列插入或更新值 

    更多信息，请查看 [MySQL Alter Generated](https://dev.mysql.com/doc/refman/8.4/en/alter-table-generated-columns.html) 文档和 [MySQL create generated](https://dev.mysql.com/doc/refman/8.4/en/create-table-generated-columns.html) 文档

    #### Drizzle 侧
    在 Drizzle 中，你可以在任何列类型上指定 `.generatedAlwaysAs()` 函数，并添加一条受支持的 SQL 查询，
    它会为你生成该列的数据。

    #### 功能 
    该函数可以通过 2 种方式接收生成表达式：

    **`sql`** 标签 - 如果你希望 drizzle 为你转义某些值

    <CodeTab>
    ```ts {2,6}
    export const test_1 = mysqlTable("test_1", {
      generatedName: text("gen_name").generatedAlwaysAs(sql`'hello "world"!'`),
    });
    
    export const test_2 = mysqlTable("test_2", {
      generatedName: text("gen_name").generatedAlwaysAs(sql`'hello "world"!'`, { mode: "stored" }),
    });
    ```
    ```sql {2,6}
    CREATE TABLE `test_1` (
        `gen_name` text GENERATED ALWAYS AS ('hello "world"!') VIRTUAL
    );
    
    CREATE TABLE `test_2` (
        `gen_name` text GENERATED ALWAYS AS ('hello "world"!') STORED
    );
    ```
    </CodeTab>

    **`callback`** - 如果你需要引用表中的列

     <CodeTab>
    ```ts {4,10}
    export const test_1 = mysqlTable("test_1", {
      name: text("first_name"),
      generatedName: text("gen_name")
	     .generatedAlwaysAs((): SQL => sql`concat('hi, ', ${test_1.name}, '!')`),
    });
    
    export const test_2 = mysqlTable("test_2", {
      name: text("first_name"),
      generatedName: text("gen_name")
	     .generatedAlwaysAs((): SQL => sql`concat('hi, ', ${test_2.name}, '!')`, { mode: "stored" }),
    });
    ```
    ```sql {3,8}
    CREATE TABLE `test_1` (
        `first_name` text,
        `gen_name` text GENERATED ALWAYS AS (concat('hi, ', `test_1`.`first_name`, '!')) VIRTUAL
    );
    
    CREATE TABLE `test_2` (
        `first_name` text,
        `gen_name` text GENERATED ALWAYS AS (concat('hi, ', `test_2`.`first_name`, '!')) STORED
    );
    ```
    </CodeTab>

    #### 限制
    Drizzle Kit 对 `push` 命令也会有限制：
    1. 你无法通过 `push` 更改生成约束表达式和类型。Drizzle-kit 会忽略这一变更。要使其生效，你需要 `删除该列`、`push`，然后再 `添加一个带新表达式的列`。这样做是因为数据库侧的映射非常复杂：schema 表达式会在数据库侧被修改，而在 introspection 时我们会得到不同的字符串。我们无法确定是你修改了该表达式，还是它被数据库修改并格式化了。只要这些是生成列，并且 `push` 主要用于在本地数据库上进行原型开发，那么 `删除` 并 `创建` 生成列应该会很快。由于这些列是 `generated` 的，所有数据都会被恢复
    2. `generate` 应该没有限制

	```typescript copy
    export const users = mysqlTable("users", {
        id: int(),
        id2: int(),
        name: text(),
        storedGenerated: text("stored_gen").generatedAlwaysAs(
          (): SQL => sql`concat(${users.name}, ' ', 'hello')`,

        virtualGenerated: text("virtual_gen").generatedAlwaysAs(
          (): SQL => sql`concat(${users.name}, ' ', 'hello')`,
          { mode: "virtual" }
        ),
    });
    ```
    ```sql
    CREATE TABLE `users` (
      `id` int,
      `id2` int,
      `name` text,
      `stored_gen` text GENERATED ALWAYS AS (concat(`users`.`name`, ' ', 'hello')) STORED,
      `virtual_gen` text GENERATED ALWAYS AS (concat(`users`.`name`, ' ', 'hello')) VIRTUAL
    );
    ```
