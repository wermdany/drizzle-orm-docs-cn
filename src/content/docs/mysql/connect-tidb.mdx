# Drizzle \<\> TiDB Serverless

<Prerequisites>
- 使用 Drizzle 连接数据库[基础](/docs/mysql/connect-overview)
- TiDB 数据库 - [网站](https://docs.pingcap.com/)
- TiDB HTTP 驱动 - [网站](https://docs.pingcap.com/developer/serverless-driver)
- Drizzle MySQL 驱动 - [文档](/docs/mysql/get-started-mysql)
</Prerequisites>

根据 **[官方网站](https://www.pingcap.com/tidb-serverless/)** 所述，
TiDB Serverless 是一个全托管、自治的 DBaaS，具备秒级集群开通能力和基于用量的计费方式。

<Callout type="info" emoji="ℹ️">
TiDB Serverless 兼容 MySQL，因此你可以使用 [MySQL 连接指南](/docs/mysql/get-started-mysql) 来连接它。
</Callout>

TiDB Serverless 为边缘环境提供了 [HTTP 驱动](https://docs.pingcap.com/developer/serverless-driver/)。Drizzle ORM 通过 `drizzle-orm/tidb-serverless` 包原生支持它。

#### 步骤 1 - 安装软件包
<Npm>
 drizzle-orm@rc @tidbcloud/serverless
 -D drizzle-kit@rc
</Npm>

#### 步骤 2 - 初始化驱动并执行查询
```typescript copy filename="index.ts"
import { drizzle } from 'drizzle-orm/tidb-serverless';

const db = drizzle({ connection: { url: process.env.TIDB_URL }});

const response = await db.select().from(...)
```

如果你需要提供已有的驱动：
```typescript copy"
import { connect } from '@tidbcloud/serverless';
import { drizzle } from 'drizzle-orm/tidb-serverless';

const client = connect({ url: process.env.TIDB_URL });
const db = drizzle({ client });
```
