## 类型 API
要从表 schema 中获取 `select` 和 `insert` 查询所需的类型，你可以使用我们的类型辅助工具。

```ts
import { int, text, mysqlTable } from 'drizzle-orm/mysql-core';
import { type InferSelectModel, type InferInsertModel } from 'drizzle-orm'

const users = mysqlTable('users', {
  id: int().primaryKey(),
  name: text().notNull(),
});

type SelectUser = typeof users.$inferSelect;
type InsertUser = typeof users.$inferInsert;
// 或
type SelectUser = InferSelectModel<typeof users>;
type InsertUser = InferInsertModel<typeof users>;
```


## 日志记录
要启用默认的查询日志，只需向 `drizzle` 初始化函数传入 `{ logger: true }`：
```typescript copy
import { drizzle } from 'drizzle-orm/mysql2';

const db = drizzle({ logger: true });
```

你可以通过创建一个 `DefaultLogger` 实例并为其提供一个自定义 `writer` 来更改日志的输出去向：
```typescript copy
import { DefaultLogger, type LogWriter } from "drizzle-orm/logger";
import { drizzle } from "drizzle-orm/mysql2";

class MyLogWriter implements LogWriter {
  write(message: string) {
    // 写入文件、stdout 等
  }
}

const logger = new DefaultLogger({ writer: new MyLogWriter() });
const db = drizzle(process.env.DB_URL, { logger });
```

你也可以创建自定义 logger：
```typescript copy
import { type Logger } from 'drizzle-orm/logger';
import { drizzle } from 'drizzle-orm/mysql2';

class MyLogger implements Logger {
  logQuery(query: string, params: unknown[]): void {
    console.log({ query, params });
  }
}

const db = drizzle(process.env.DB_URL, { logger: new MyLogger() });
```


## 多项目 schema
**Table creator** API 让你可以定义自定义的表名。
当你需要将不同项目的 schema 保存在同一个数据库中时，它非常有用。

```ts {3}
import { int, text, mysqlTableCreator } from 'drizzle-orm/mysql-core';

const mysqlTable = mysqlTableCreator((name) => `project1_${name}`);

export const users = mysqlTable('users', {
  id: int().primaryKey(),
  name: text().notNull(),
});
```
```ts {10}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./src/schema/*",
  out: "./drizzle",
  dialect: "mysql", 
  dbCredentials: {
    url: process.env.DATABASE_URL,
  }
  tablesFilter: ["project1_*"],
});
```

你可以应用多个 `or` 过滤器：
```ts
tablesFilter: ["project1_*", "project2_*"]
```


## 打印 SQL 查询
你可以使用 `db` 实例或通过 **[`独立查询构建器`](#独立查询构建器)** 打印 SQL 查询。
```typescript copy
const query = db
  .select({ id: users.id, name: users.name })
  .from(users)
  .groupBy(users.id)
  .toSQL();
// query:
{
  sql: 'select `id`, `name` from `users` group by `users`.`id`',
  params: [],
}
```

## 原始 SQL 查询执行
如果你有一些复杂的查询需要执行，而 `drizzle-orm` 目前还无法处理，
你可以使用 `db.execute` 方法来执行原生 `parametrized` 查询。

```typescript copy
import { ..., type MySqlRawQueryResult } from "drizzle-orm/mysql2";

const userId = 11;
const statement = sql`select * from ${users} where ${users.id} = ${userId}`;

const res: MySqlRawQueryResult = await db.execute(statement);
```


## 独立查询构建器
Drizzle ORM 提供了一个独立的查询构建器，让你无需创建数据库实例
即可构建查询并获取生成的 SQL。
```typescript copy
import { QueryBuilder } from 'drizzle-orm/mysql-core';

const qb = new QueryBuilder();

const query = qb.select().from(users).where(eq(users.name, 'Dan'));
const { sql, params } = query.toSQL();
```

## 获取带类型的列
你可以获取一个带类型的列映射，
当你需要在查询时省略某些列时非常有用。

<CodeTabs items={["index.ts", "schema.ts"]}>
  ```ts
  import { getColumns } from "drizzle-orm";
  import { user } from "./schema";

  const { password, role, ...rest } = getColumns(user);

  await db.select({ ...rest }).from(user);
  ```
  ```ts
  import { int, text, mysqlTable } from "drizzle-orm/mysql-core";

  export const user = mysqlTable("user", {
    id: int().primaryKey().autoincrement(),
    name: text(),
    email: text(),
    password: text(),
    role: text().$type<"admin" | "customer">(),
  });
  ```
</CodeTabs>

## 获取表信息
```ts copy
import { getTableConfig, mysqlTable } from 'drizzle-orm/mysql-core';

export const table = mysqlTable(...);

const {
  columns,
  indexes,
  foreignKeys,
  checks,
  primaryKeys,
  name,
  schema,

```

## 比较对象类型（instanceof 替代方案）

你可以使用 `is()` 函数检查某个对象是否属于特定的 Drizzle 类型。
你可以将其与 Drizzle 中任何可用的类型一起使用。

<Callout type="warning" emoji="⭐️">
  你应该始终使用 `is()` 而不是 `instanceof`
</Callout>

**几个示例**
```ts
import { Column, is } from 'drizzle-orm';

if (is(value, Column)) {
  // value 的类型被收窄为 Column
}
```

### Mock 驱动
这个 API 是未定义的 `drizzle({} as any)` API 的继任者，后者曾被我们在 Drizzle 测试内部使用，很少推荐给外部开发者。

我们决定构建并公开一个正式的 API，现在每个 `drizzle` 驱动都有 `drizzle.mock()`：
```ts
import { drizzle } from "drizzle-orm/mysql2";

const db = drizzle.mock();
```

如有必要，你可以提供 schema 以支持类型
```ts
import { drizzle } from "drizzle-orm/mysql2";
import { relations } from "./relations"

const db = drizzle.mock({ relations  });
```
