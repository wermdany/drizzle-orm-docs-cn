# `drizzle-kit up`

<Prerequisites>
- 快速上手 Drizzle 与 `drizzle-kit` - [阅读这里](/docs/mysql/get-started)
- Drizzle schema 基础 - [阅读这里](/docs/mysql/sql-schema-declaration)
- 数据库连接基础 - [阅读这里](/docs/mysql/connect-overview)
- Drizzle 迁移基础 - [阅读这里](/docs/mysql/migrations)
- Drizzle Kit [概览](/docs/mysql/kit-overview) 与 [配置文件](/docs/mysql/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读这里](/docs/mysql/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit up` 命令让你可以将 drizzle schema 快照升级到更新的版本。
每当我们对 schema 的 json 快照引入破坏性变更并升级内部版本时，都需要用到它。

<br/>
<hr/>
<br/>

`drizzle-kit up` 命令要求你指定 `dialect` 参数，
你可以通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 配置文件或 CLI 选项提供它

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
});
```
```shell
npx drizzle-kit up
```
</Section>
```shell
npx drizzle-kit up --dialect=mysql
```
</CodeTabs>

### 一个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你拥有多个数据库阶段或多个数据库时，它会非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展的配置列表
我们建议通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 文件来配置 `drizzle-kit`，
但如果需要，例如在 CI/CD 流水线中，你也可以通过 CLI 提供所有配置选项。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。可以是 <Dialects/> |
| `out`     |            | 迁移文件夹，默认=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit up --dialect=mysql
drizzle-kit up --dialect=mysql --out=./migrations-folder
</Npx>
