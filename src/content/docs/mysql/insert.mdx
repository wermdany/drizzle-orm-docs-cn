# SQL Insert
Drizzle ORM 为你提供了最贴近 SQL 的方式向数据库表中插入行。

使用 Drizzle 插入数据极其直观且类似 sql。自己看看：

<Section>
```typescript copy 
await db.insert(users).values({ name: 'Andrew' });
```
```sql
insert into `users` (`name`) values ('Andrew');
```
</Section>

如果你需要某张特定表的插入类型，可以使用 `typeof usersTable.$inferInsert` 语法。
```typescript copy 
type NewUser = typeof users.$inferInsert;

const insertUser = async (user: NewUser) => {
  return db.insert(users).values(user);
}

const newUser: NewUser = { name: "Alef" };
await insertUser(newUser);
```

## $returningId
MySQL 本身并不原生支持在 `INSERT` 之后使用 `RETURNING`。对于带 `autoincrement`（或 `serial`）类型的 `primary keys`，只有一种方式可以做到，即访问 `insertId` 和 `affectedRows` 字段。我们为你准备了一种自动的方式，用 Drizzle 处理这类场景，并自动以独立对象的形式接收所有插入的 ID

```ts
import { boolean, int, text, mysqlTable } from 'drizzle-orm/mysql-core';

const usersTable = mysqlTable('users', {
  id: int().autoincrement().primaryKey(),
  name: text().notNull(),
  verified: boolean().notNull().default(false),
});


const result = await db.insert(usersTable).values([{ name: 'John' }, { name: 'John1' }]).$returningId();
//    ^? { id: number }[]
```

同样，使用 Drizzle 时，你可以通过 `$default` 函数指定一个会在运行时生成自定义主键的 `primary key`。我们也会在 `$returningId()` 调用中为你返回这些生成的键

```ts
import { varchar, text, mysqlTable } from 'drizzle-orm/mysql-core';
import { createId } from '@paralleldrive/cuid2';

const usersTableDefFn = mysqlTable('users_default_fn', {
  customId: varchar({ length: 256 }).primaryKey().$defaultFn(createId),
  name: text().notNull(),
});


const result = await db.insert(usersTableDefFn).values([{ name: 'John' }, { name: 'John1' }]).$returningId();
//  ^? { customId: string }[]
```

> 如果没有主键 -> 这类查询的类型将是 `{}[]`

## Upsert 和冲突
Drizzle ORM 提供了简单的接口来处理 upsert 和冲突。

### On duplicate key update
MySQL 支持 [`ON DUPLICATE KEY UPDATE`](https://dev.mysql.com/doc/refman/8.0/en/insert-on-duplicate.html)，而不是 `ON CONFLICT` 子句。MySQL 会根据主键和唯一索引自动确定冲突目标，并且当*任意*唯一索引发生冲突时更新该行。

Drizzle 通过 `onDuplicateKeyUpdate` 方法支持这一点：

```typescript
// 注意，MySQL 会根据主键和唯一索引自动确定目标
await db.insert(users)
  .values({ id: 1, name: 'John' })
  .onDuplicateKeyUpdate({ set: { name: 'John' } });
```

虽然 MySQL 不直接支持在冲突时什么都不做，但你可以通过将任意列的值设为它本身来执行空操作，从而达到相同的效果：

```typescript
import { sql } from 'drizzle-orm';

await db.insert(users)
  .values({ id: 1, name: 'John' })
  .onDuplicateKeyUpdate({ set: { id: sql`id` } });
```

## Insert into ... select

正如 MySQL 文档所提到的：

<Callout>
使用 INSERT ... SELECT，你可以根据 SELECT 语句的结果，快速向表中插入许多行，而该 SELECT 可以从一张或多张表中选择数据
</Callout>

Drizzle 为所有方言支持当前语法，并且它们都共享相同的语法。让我们回顾一些常见场景和 API 用法。
在 insert 语句中使用 select 有几种方式，你可以选择自己喜欢的方式：

- 你可以在 select 函数中传入查询构建器。
- 你可以在回调中使用查询构建器。
- 你可以传入带有任意自定义 select 查询的 SQL 模板标签


<Tabs items={["查询构建器", "回调", "SQL 模板标签"]}>
<Tab>
<Section>
```ts
const insertedEmployees = await db
  .insert(employees)
  .select(
    db.select({ id: users.id, name: users.name }).from(users).where(eq(users.role, 'employee'))
  );
```
```ts
const qb = new QueryBuilder();
await db.insert(employees).select(
    qb.select({ id: users.id, name: users.name }).from(users).where(eq(users.role, 'employee'))
);
```
