# Drizzle Kit 配置文件
<Prerequisites>
- Drizzle 和 `drizzle-kit` 入门 - [阅读此处](/docs/mysql/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/mysql/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/mysql/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/mysql/migrations)
- Drizzle Kit [概览](/docs/mysql/kit-overview) 和 [配置文件](/docs/mysql/drizzle-config-file)
</Prerequisites>

Drizzle Kit 允许你在 `TypeScript` 或 `JavaScript` 配置文件中声明配置选项。

<Section>
```plaintext {5}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
<CodeTabs items={["drizzle.config.ts", "drizzle.config.js"]}>
<CodeTab>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
<CodeTab>
```js
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
</CodeTabs>
</Section>

扩展配置文件的示例
```ts collapsable
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "mysql",
  schema: "./src/schema.ts",

  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },

  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
  },

  breakpoints: true,
  verbose: true,
});

```

### 多个配置文件
你可以在项目中拥有多个配置文件，当你存在多个数据库阶段、多个数据库，或同一项目中有不同数据库时，这非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 迁移文件夹
`out` 参数让你定义迁移的文件夹，它是可选的，默认值为 `drizzle`。  
这非常有用，因为你可以在同一项目中为不同数据库拥有多个独立的 schema，
并为它们设置不同的迁移文件夹。  
  
迁移文件夹包含由 `drizzle-kit` 使用的、存放 `.sql` 迁移文件的文件夹

<Section>
```plaintext {3}
📦 <project root>
 ├ ...
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ ├ 📜 user.ts 
 │ ├ 📜 post.ts 
 │ └ 📜 comment.ts 
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
```ts {6}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema/*",
  out: "./drizzle",
});
```
</Section>

### `dbCredentials`
<rem025/>

数据库连接凭据，形式为 `url`、
`user:password@host:port/db` 参数，或特定驱动（<Drivers/>）的例外连接选项。

|               |                      |
| :------------ | :-----------------   |
| 类型          | <Dialects/> |
| 默认值       | --                    |
| 命令      | `push`, `pull`, `migrate`, `studio` |

<rem025/>

<CodeTabs items={["连接字符串", "连接参数"]}>
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "mysql",
  dbCredentials: {
    url: "mysql://user:password@host:port/db",
  }
});
```
```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: "mysql",
  dbCredentials: {
    host: "host",
    port: 3306,
    user: "user",
    password: "password",
    database: "dbname",
    ssl: "...", // 可以是：string | SslOptions（来自 mysql2）
  }
});
```
</CodeTabs>

### `migrations`
<rem025/>

运行 `drizzle-kit migrate` 时 - drizzle 会将成功应用的迁移记录保存在
你数据库中名为 `__drizzle_migrations` 的日志表中。

`migrations` 配置选项让你同时更改迁移日志的 `table` 名称和 `schema`。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `{ table: string }` |
| 默认值       | `{ table: "__drizzle_migrations" }`                    |
| 命令      | `migrate`, `push`, `pull` |

<rem025/>

```ts
export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  migrations: {
    table: 'my-migrations-table', // 默认为 `__drizzle_migrations`
  },
});
```

| 默认值       | `{ casing: "camel" }`                    |

### `tablesFilter`
<Callout>
如果你想用一个数据库运行多个项目 - 请查看[我们的指南](/docs/mysql/goodies#多项目-schema)。
</Callout>
<rem025/>
`drizzle-kit push` 和 `drizzle-kit pull` 默认会管理所有表。
你可以通过 `tablesFilter` 配置表列表。

`tablesFilter` 选项让你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)
的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`

|               |                      |
| :------------ | :-----------------   |
| 类型          | `string` `string[]` |
| 默认值        | --                    |
| 命令      | `push` `pull`  |

<rem025/>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  tablesFilter: ["users", "posts", "project1_*"],
});
```

### `verbose`
<rem025/>

在执行 `drizzle-kit push` 命令期间打印所有 SQL 语句。

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值        | `false`                    |
| 命令      | `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "mysql",
  verbose: false,
});
```

### `breakpoints`
<rem025/>

Drizzle Kit 会自动将 `--> statement-breakpoint` 嵌入到生成的 SQL 迁移文件中，
这对于不支持在一个事务中执行多条 DDL 变更语句的数据库（MySQL 和 SQLite）是必需的。

`breakpoints` 选项标志让你开启或关闭它

|               |                      |
| :------------ | :-----------------   |
| 类型          | `boolean` |
| 默认值        | `true`                    |
| 命令      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "mysql",
  breakpoints: false,
});
```
