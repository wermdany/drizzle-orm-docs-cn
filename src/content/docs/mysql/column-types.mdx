我们对所有这些类型都有原生支持，但如果这还不够，你也可以随时创建 **[自定义类型](/docs/mysql/custom-types)**。

<Callout title='重要' type='warning'>
本文档这一部分的所有示例都不使用数据库列名别名，列名由 TypeScript 键生成。

如果你愿意，也可以在列名中使用数据库别名，还可以使用 `casing API` 为 Drizzle 定义映射策略。

你可以在 [这里](/docs/mysql/sql-schema-declaration#塑造你的数据-schema) 了解更多。
</Callout>

<Callout title='重要' type='info'>
所有整数类型（`int`、`tinyint`、`smallint`、`mediumint`、`bigint`）默认都是 `signed`（有符号），允许负值和正值。
添加 `{ unsigned: true }` 会将列限制为仅非负值，但会把上限范围翻倍。
</Callout>

### integer

一个 `4` 字节整数，有符号范围为 `-2,147,483,648` 到 `2,147,483,647`，无符号范围为 `0` 到 `4,294,967,295`

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/integer-types.html)**

<Section>
```typescript
import { int, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	int: int(),
	int2: int({ unsigned: true })
});
```

```sql
CREATE TABLE `table` (
	`int` int,
	`int2` int unsigned
);
```
</Section>

### bigint

一个 `8` 字节整数，有符号范围为 `-2^63` 到 `2^63-1`，无符号范围为 `0` 到 `2^64-1`

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/integer-types.html)**

<Section>
```typescript
import { bigint, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	bigint: bigint({ mode: 'number' }),
	bigintUnsigned: bigint({ mode: 'number', unsigned: true })
});

bigint("...", { mode: 'number' | 'bigint' | 'string' });

// 你也可以为 bigint 指定 unsigned 选项
bigint("...", { mode: 'number' | 'bigint' | 'string', unsigned: true });
```

```sql
CREATE TABLE `table` (
	`bigint` bigint,
	`bigintUnsigned` bigint unsigned
);
```
</Section>

我们省略了 `bigint(M)` 中 `M` 的配置，因为它表示数字类型的显示宽度

### binary
`BINARY(M)` 存储一个固定长度的字节串，正好 M 个字节（如果省略，M 默认为 1）。  
插入时，较短的值会用 `0x00` 字节右填充以达到 M 个字节；检索时不会去除填充。
在比较（包括 `ORDER BY` 和 `DISTINCT` 操作）中所有字节都是有效的

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/binary-varbinary.html)**
<Section>
```typescript
import { binary, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	binary: binary(),
	binary2: binary({ length: 10 }),
});
```

```sql
CREATE TABLE `table` (
	`binary` binary,
	`binary2` binary(10)
);
```
</Section>

### varbinary
`VARBINARY(M)` 存储一个变长字节串，最多 M 个字节（M 按需指定）。  
对于 `VARBINARY`，插入时没有填充，检索时也不会去除任何字节。
在比较（包括 `ORDER BY` 和 `DISTINCT` 操作）中所有字节都是有效的

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/binary-varbinary.html)**
<Section>
```typescript
import { varbinary, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	varbinary: varbinary({ length: 2 }),
});
```

```sql
CREATE TABLE `table` (
	`varbinary` varbinary(2)
);
```
</Section>

### blob

`BLOB` 是一个二进制大对象，可以保存可变数量的数据，最大长度为 `65,535` 字节（`64` KB）

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/blob.html)**
<Section>
```typescript
import { blob, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	blob: blob()
});
```

```sql
CREATE TABLE `table` (
	`blob` blob
);
```
</Section>

<Section>
你可以指定 `buffer` 或 `string` 模式：
```typescript
// 将被推断为 `Buffer`
blob: blob({ mode: "buffer" }),

// 将被推断为 `string`
blob: blob({ mode: "string" }),
```
</Section>

> `buffer` 模式是处理 blob 的默认方式。
> Drizzle 会将 blob 值表示为 `Buffer` 实例

> `string` 模式将 blob 值表示为 UTF-8 编码的字符串，
> 在 blob 列中存储文本数据时会很有用

### char

`CHAR(M)` 列的长度固定为你创建表时声明的长度。`M` 可以是 `0` 到 `255` 之间的任意值，默认为 `1`
存储 `CHAR` 值时，它们会用空格右填充到指定长度。检索 `CHAR` 值时，会移除尾随空格，除非启用了 [PAD_CHAR_TO_FULL_LENGTH](https://dev.mysql.com/doc/refman/9.7/en/sql-mode.html#sqlmode_pad_char_to_full_length) SQL 模式。

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/char.html)**

你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断插入和查询类型，它不会检查运行时值。

<Section>
```typescript
import { char, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	char: char(),
});

// 将被推断为 char: "value1" | "value2" | null
char: char({ enum: ["value1", "value2"] })
```

```sql
CREATE TABLE `table` (
	`char` char
);
```
</Section>

### varchar

`VARCHAR` 列中的值是变长字符串。  
`VARCHAR(M)` 最多存储 `M` 个字符，其中 `M` 的范围是 `0` 到 `65,535`
存储 `VARCHAR` 值时不会进行填充。存储和检索值时尾随空格都会被保留，符合标准 SQL

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/char.html)**

你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。
<Section>
```typescript
import { varchar, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
	varchar: varchar({ length: 2 }),
});

// 将被推断为 text: "value1" | "value2" | null
varchar: varchar({ length: 6, enum: ["value1", "value2"] })
```

```sql
CREATE TABLE `table` (
	`varchar` varchar(2)
);
```
</Section>

### timestamp

更多信息请参考 MySQL 官方 **[文档。](https://dev.mysql.com/doc/refman/8.0/en/datetime.html)**

<Section>
```typescript

	timestamp: timestamp(),

```

```sql

	`json` json
);
```
</Section>

你可以指定 `.$type<..>()` 用于 json 对象推断，它**不会**检查运行时值。
它为默认值、插入和查询 schema 提供编译时保护。
```typescript
// 将被推断为 { foo: string }
json: json().$type<{ foo: string }>();

// 将被推断为 string[]
json: json().$type<string[]>();

// 将无法通过编译
json: json().$type<string[]>().default({});
```

### 自定义数据类型

每个列构建器都有一个 `.$type()` 方法，允许你自定义列的数据类型。例如，在不明确或带品牌（branded）的类型上会很有用。

```ts
import { int, json, mysqlTable } from "drizzle-orm/mysql-core";

type UserId = number & { __brand: "user_id" };
type Data = {
  foo: string;
  bar: number;
};

export const users = mysqlTable("users", {
  id: int().$type<UserId>().primaryKey(),
  jsonField: json().$type<Data>(),
});
```

### 默认值

如果在执行 `INSERT` 时用户没有显式提供值，`DEFAULT` 子句指定该列使用的默认值。
如果列定义没有附加显式的 `DEFAULT` 子句，
那么该列的默认值为 `NULL`。

显式的 `DEFAULT` 子句可以指定默认值为 `NULL`、
字符串常量、blob 常量、带符号数字，或任何用括号括起来的常量表达式。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { int, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable("table", {
  int: int().default(3),
  int2: int().default(sql`3`),
});
```

```sql
CREATE TABLE `table` (
	`int` int DEFAULT 3,
	`int2` int DEFAULT (3)
);
```
</Section>

使用 `$default()` 或 `$defaultFn()`（它们只是同一个函数的不同别名）时，
你可以在运行时生成默认值，并在所有插入查询中使用这些值。
这些函数可以帮助你使用 `uuid`、`cuid`、`cuid2` 等各种实现。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它只在 `drizzle-orm` 的运行时中使用
</Callout>

```ts
import { varchar, mysqlTable } from "drizzle-orm/mysql-core";
import { createId } from '@paralleldrive/cuid2';

export const table = mysqlTable('table', {
	id: varchar({ length: 128 }).$defaultFn(() => createId()),
});
```

使用 `$onUpdate()` 或 `$onUpdateFn()`（它们只是同一个函数的不同别名）时，
你可以在运行时生成默认值，并在所有更新查询中使用这些值。

为列添加动态更新值。当行被更新时会调用该函数，
如果没有提供值，则返回的值将用作列值。
如果没有提供默认值（或 $defaultFn）值，那么当行被插入时也会调用该函数，
返回的值将用作列值。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它只在 `drizzle-orm` 的运行时中使用
</Callout>

```ts
import { text, mysqlTable } from "drizzle-orm/mysql-core";

export const table = mysqlTable('table', {
    alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```
