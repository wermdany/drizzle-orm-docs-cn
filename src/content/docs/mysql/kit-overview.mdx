# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 从 Drizzle 和 `drizzle-kit` 开始 - [阅读此处](/docs/mysql/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/mysql/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/mysql/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/mysql/migrations)
</Prerequisites>


**Drizzle Kit** 是一个 CLI 工具，用于配合 Drizzle 管理 SQL 数据库迁移。
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
请确保先阅读 Drizzle 的 [快速开始](/docs/mysql/get-started) 和 [迁移基础](/docs/mysql/migrations)，并选择最适合你业务需求的 SQL 迁移流程。 
</Callout>

基于你的 schema，Drizzle Kit 让你可以生成并运行 SQL 迁移文件，
将 schema 直接推送到数据库、从数据库拉取 schema、启动 drizzle studio，并提供了一些实用命令。
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
drizzle-kit export
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/mysql/drizzle-kit-generate) | 让你根据 Drizzle schema 生成 SQL 迁移文件，可以基于声明时的状态，也可以基于后续的变更，[参见此处](/docs/mysql/drizzle-kit-generate)。       |
| [`drizzle-kit migrate`](/docs/mysql/drizzle-kit-migrate)   | 让你把生成的 SQL 迁移文件应用到数据库，[参见此处](/docs/mysql/drizzle-kit-migrate)。                                                              |
| [`drizzle-kit pull`](/docs/mysql/drizzle-kit-pull)         | 让你拉取（内省）数据库 schema，将其转换为 Drizzle schema 并保存到你的代码库中，[参见此处](/docs/mysql/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/mysql/drizzle-kit-push)         | 让你把 Drizzle schema 推送到数据库，可以基于声明时的状态，也可以基于后续的 schema 变更，[参见此处](/docs/mysql/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/mysql/drizzle-kit-studio)     | 将连接到你的数据库并为 Drizzle Studio 启动代理服务器，你可以用它方便地浏览数据库，[参见此处](/docs/mysql/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/mysql/drizzle-kit-check)       | 将遍历所有生成的迁移，检查生成的迁移是否存在竞态条件（冲突），[参见此处](/docs/mysql/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/mysql/drizzle-kit-up)             | 用于升级之前生成的迁移的快照，[参见此处](/docs/mysql/drizzle-kit-up)                                                                     |
| [`drizzle-kit export`](/docs/mysql/drizzle-kit-export)     | 用于将 TypeScript schema 转换为原始 SQL DDL 并打印输出 [参见此处](/docs/mysql/drizzle-kit-export)                                                                     |
<br/>

Drizzle Kit 通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 配置文件或 CLI 参数进行配置。<br/>
至少需要提供 SQL `dialect` 和 `schema` 路径，Drizzle Kit 才能知道如何生成迁移。
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle 配置文件
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["简单配置", "扩展配置"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "mysql",
  schema: "./src/schema.ts",

  dbCredentials: {
    url: "./database/",
  },

  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
  },

  breakpoints: true,
  verbose: true,
});
```
</CodeTabs>

你可以通过 CLI 参数提供 Drizzle Kit 配置路径，当你有多个数据库阶段、多个数据库，或者同一项目中有不同数据库时，这非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
