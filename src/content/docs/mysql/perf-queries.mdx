# 查询性能
说到 **Drizzle**——我们是 SQL 之上的一层薄薄的 TypeScript，
几乎没有开销；为了让开销真正为 0，你可以利用我们的预编译语句（prepared statements）API。
  
**当你在数据库上运行查询时，会发生以下几件事：**
- 查询构建器的所有配置都被拼接成 SQL 字符串
- 该字符串和参数被发送到数据库驱动
- 驱动将 SQL 查询编译为二进制 SQL 可执行格式并发送到数据库

使用预编译语句时，你在 Drizzle ORM 侧只做一次 SQL 拼接，之后数据库
驱动就可以复用预编译的二进制 SQL，而不必每次都解析查询。
它对大型 SQL 查询有极大的性能优势。  

不同的数据库驱动以不同方式支持预编译语句，有时使用
Drizzle ORM 可以[**比 better-sqlite3 驱动更快。**](https://twitter.com/_alexblokh/status/1593593415907909634)

## 预编译语句

```typescript copy {3}
    const db = drizzle(...);

    const prepared = db.select().from(customers).prepare();
    
    const res1 = await prepared.execute();
    const res2 = await prepared.execute();
    const res3 = await prepared.execute();
    ```

## 占位符
每当你需要嵌入动态的运行时值时，可以使用 `sql.placeholder(...)` API

	```ts copy {6,9-10,15,18}
    import { sql, eq } from "drizzle-orm";

    const p1 = db
      .select()
      .from(customers)
      .where(eq(customers.id, sql.placeholder('id')))
      .prepare()

    await p1.execute({ id: 10 }) // SELECT * FROM customers WHERE id = 10
    await p1.execute({ id: 12 }) // SELECT * FROM customers WHERE id = 12

    const p2 = db
      .select()
      .from(customers)
      .where(sql`${customers.name} like ${sql.placeholder('name')}`)
      .prepare();

    await p2.execute({ name: '%an%' }) // SELECT * FROM customers WHERE name like '%an%'
    ```
