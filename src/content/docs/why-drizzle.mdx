# Drizzle ORM  
> Drizzle 是一个好朋友，在你需要时总会陪在身边，而当你需要一些空间时也不会打扰你。

Drizzle ORM 是一个有主见的无头 TypeScript ORM。🐲

它看起来和用起来都很简单，在你的项目走到第 _1000_ 天时依然表现出色，
让你按自己的方式做事，并在你需要时随时相伴。  

**它是唯一同时提供 [关系式](/docs/rqb) 和 [类 SQL](/docs/select) 查询 API 的 ORM**，
在访问关系型数据时为你带来两全其美的体验。
Drizzle 轻量、高性能、类型安全、不含乳糖、无麸质、清醒、灵活，并且**在设计上就为 serverless 做好准备**。
Drizzle 不只是一个库，它是一种体验。🤩

[![Drizzle bestofjs](@/assets/images/bestofjs.jpg)](https://bestofjs.org/projects/drizzle-orm)

## 无头 ORM？ 
首先也是最重要的，Drizzle 是一个库，以及一组互补的可选工具。

**ORM** 代表 _对象关系映射_，开发者往往把类似 Django 或 Spring 的工具称为 ORM。
我们坚信这是一种基于历史命名的误解，我们将其称为 **数据框架（data frameworks）**。

<Callout type="error" emoji="️💔">
  使用数据框架时，你必须**围绕它们**构建项目，而不是**与它们一起**构建。
</Callout>

**Drizzle** 让你按自己想要的方式构建项目，不会干涉你的项目或结构。

使用 Drizzle，你可以在 TypeScript 中定义和管理数据库 schema，以类 SQL
或关系式的方式访问数据，并利用可选工具
把开发体验推到 _极致_。🤯

## 为什么像 SQL？
**如果你了解 SQL，你就了解 Drizzle。**

其他 ORM 和数据框架往往偏离/抽象掉 SQL，这
导致双重学习曲线：既需要了解 SQL，又需要了解框架的 API。  

Drizzle 正相反。
我们拥抱 SQL，并在核心上把 Drizzle 构建为类 SQL，因此你几乎
无需学习成本，就能用上 SQL 的全部能力。  

我们带来了所有你熟悉的 **[SQL schema](/docs/sql-schema-declaration)**、**[查询](/docs/select)**、
**[自动迁移](/docs/migrations)** 以及 **[还有一件事](/docs/rqb)**。✨

<CodeTabs items={["index.ts", "schema.ts", "migration.sql"]}>
```typescript copy
// 访问你的数据
await db
	.select()
	.from(countries)
	.leftJoin(cities, eq(cities.countryId, countries.id))
	.where(eq(countries.id, 10))
```
```typescript copy
// 管理你的 schema
export const countries = pgTable('countries', {
  id: serial('id').primaryKey(),
  name: varchar('name', { length: 256 }),
});

export const cities = pgTable('cities', {
  id: serial('id').primaryKey(),
  name: varchar('name', { length: 256 }),
  countryId: integer('country_id').references(() => countries.id),
});
```
```sql
-- 生成迁移
CREATE TABLE IF NOT EXISTS "countries" (
	"id" serial PRIMARY KEY NOT NULL,
	"name" varchar(256)
);

CREATE TABLE IF NOT EXISTS "cities" (
	"id" serial PRIMARY KEY NOT NULL,
	"name" varchar(256),
	"country_id" integer
);

ALTER TABLE "cities" ADD CONSTRAINT "cities_country_id_countries_id_fk" FOREIGN KEY ("country_id") REFERENCES "countries"("id") ON DELETE no action ON UPDATE no action;
```
</CodeTabs>

## 为什么不像 SQL？
我们始终在追求完美平衡的方案，尽管类 SQL 能覆盖 100% 的需求，
但在某些常见场景中，你可以用更好的方式查询数据。  

我们为你构建了 **[Queries API](/docs/rqb)**，让你能够
以最便捷、最高效的方式从数据库中获取关系型嵌套数据，并且永远不必考虑 join 和数据映射。  

**Drizzle 始终只输出 1 条 SQL 查询。** 请放心地将其用于 serverless 数据库，永远不必担心性能或往返开销！

```ts
const result = await db.query.users.findMany({
	with: {
		posts: true
	},
});
```

## Serverless？
<Callout type="info" emoji="🥳">
  最好的部件就是没有部件。**Drizzle 拥有恰好 0 个依赖！**
</Callout>


![Drizzle 轻量且为 Serverless 做好准备](@/assets/images/drizzle31kb.jpg)
  
Drizzle ORM 是方言专属的、轻量的、高性能的，并且**在设计上**为 serverless 做好准备。  

我们花了大量时间确保你拥有同类最佳的 SQL 方言支持，包括 Postgres、MySQL 等。

Drizzle 通过业界标准的数据库驱动原生运行。我们支持所有主流的 **[PostgreSQL](/docs/get-started-postgresql)**、**[MySQL](/docs/mysql/get-started-mysql)** 或 **[SQLite](/docs/sqlite/get-started-sqlite)** 驱动，并且正在**[非常快速地](https://twitter.com/DrizzleORM/status/1653082492742647811?s=20)**添加新的驱动。
