# Drizzle \<\> Appwrite Postgres
<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/connect-overview)
- Appwrite 原生 PostgreSQL 数据库 - [网站](https://appwrite.io) 和 [文档](https://appwrite.io/docs/products/databases/postgresql)
- Appwrite PostgreSQL 连接 - [文档](https://appwrite.io/docs/products/databases/postgresql/connections)
- Drizzle PostgreSQL 驱动 - [文档](/docs/get-started-postgresql)
</Prerequisites>

Appwrite 提供专用的原生 PostgreSQL 数据库，你可以通过 TLS 直接连接。没有 Appwrite 专用的驱动或抽象层，因此你可以像使用任何 PostgreSQL 服务器一样，搭配 [`node-postgres`](https://node-postgres.com/) 或 [`postgres.js`](https://github.com/porsager/postgres) 驱动来使用 Drizzle。

要获取连接字符串，请在 Appwrite 控制台中打开你的数据库，然后点击 **Credentials**。**Drizzle** 标签页包含可直接使用的片段，**DSN** 和 **.env** 标签页包含原始连接字符串。你也可以通过 Appwrite API 使用 `postgresql.get()` 获取。连接字符串已包含 `sslmode=require`，因此无需额外的 TLS 配置。

```env
DATABASE_URL="postgresql://admin:<password>@db-<hash>.<region>.appwrite.center:5432/<database>?sslmode=require"
```

如果你需要提供自己已有的驱动：

<CodeTabs items={["node-postgres (pg)", "postgres.js"]}>
```typescript
// 确保安装 'pg' 包
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});
const db = drizzle({ client: pool });

const result = await db.execute('select 1');
```
```typescript
// 确保安装 'postgres' 包
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';

const queryClient = postgres(process.env.DATABASE_URL);
const db = drizzle({ client: queryClient });

const result = await db.execute('select 1');
```

#### 面向 Serverless 的连接池

Appwrite 在同一主机名的 `6432` 端口上运行一个[连接池器](https://appwrite.io/docs/products/databases/postgresql/connection-pooling)。在 serverless 和 edge 环境中，请将应用流量经由连接池器转发，以免短生命周期的实例耗尽引擎的连接上限；同时让 Drizzle Kit 指向引擎的直接端口 `5432`，因为迁移会发出需要会话级连接的 DDL。

```env
# 运行时：经由连接池，事务模式
DATABASE_URL="postgresql://admin:<password>@db-<hash>.<region>.appwrite.center:6432/<database>?sslmode=require"

# 迁移与内省：直接连接引擎
DIRECT_URL="postgresql://admin:<password>@db-<hash>.<region>.appwrite.center:5432/<database>?sslmode=require"
```

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  dialect: 'postgresql',
  schema: './src/schema.ts',
  out: './drizzle',
  dbCredentials: {
    url: process.env.DIRECT_URL!,
  },
});
```

<Callout type="warning" emoji="⚙️">
连接池器默认使用 **transaction mode**，它不会跨语句保持后端连接，因此服务端预处理语句不可用。使用 `postgres.js` 时，通过连接池器连接请自行构建客户端并传入 `prepare: false`：

```typescript
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';

const queryClient = postgres(process.env.DATABASE_URL, { prepare: false });
const db = drizzle({ client: queryClient });
```

如果你依赖预处理语句、advisory locks、`LISTEN`/`NOTIFY`、临时表或 `SET LOCAL`，请将连接池器切换为 session mode，或使用直接端口。
</Callout>
