# `drizzle-kit up`

<Prerequisites>
- Drizzle 与 `drizzle-kit` 入门 - [阅读文档](/docs/get-started)
- Drizzle schema 基础 - [阅读文档](/docs/sql-schema-declaration)
- 数据库连接基础 - [阅读文档](/docs/connect-overview)
- Drizzle 迁移基础 - [阅读文档](/docs/migrations)
- Drizzle Kit [概览](/docs/kit-overview) 与 [配置文件](/docs/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读文档](/docs/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit up` 命令让你可以将 drizzle schema 快照升级到更新的版本。
每当我们对 schema 的 json 快照引入破坏性变更并升级内部版本时，都需要用到它。

<br/>
<hr/>
<br/>

`drizzle-kit up` 命令要求你指定 `dialect` 参数，
你可以通过 [drizzle.config.ts](/docs/drizzle-config-file) 配置文件提供，也可以通过 CLI 选项提供

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
});
```
```shell
npx drizzle-kit up
```
</Section>
```shell
npx drizzle-kit up --dialect=postgresql
```
</CodeTabs>

### 单个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你存在多个数据库环境或同一项目下的多个数据库时，这非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展配置列表
我们推荐通过 [drizzle.config.ts](/docs/drizzle-config-file) 文件来配置 `drizzle-kit`，
但如果需要（例如在 CI/CD 流水线等场景中），你也可以通过 CLI 提供所有配置选项。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。取值为 <Dialects/> 之一                        |
| `out`     |            | 迁移文件夹，默认=`./drizzle`                                            |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                                   |
<br/>
<Npx>
drizzle-kit up --dialect=postgresql
drizzle-kit up --dialect=postgresql --out=./migrations-folder
</Npx>
