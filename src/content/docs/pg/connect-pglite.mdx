# Drizzle \<\> PGlite

<Prerequisites>
- 使用 Drizzle 进行[数据库连接基础](/docs/connect-overview)
- ElectricSQL - [网站](https://electric-sql.com/)
- PgLite 驱动 - [文档](https://pglite.dev/) & [GitHub](https://github.com/electric-sql/pglite)
</Prerequisites>

根据**[官方仓库](https://github.com/electric-sql/pglite)**，PGlite 是一个打包进 TypeScript 客户端库的 WASM Postgres 构建版本，让你可以在浏览器、Node.js 和 Bun 中运行 Postgres，而无需安装任何其它依赖。它压缩后仅有 2.6mb。

它既可以用作临时的内存数据库，也可以将数据持久化到文件系统（Node/Bun）或 indexedDB（浏览器）。

与以往那些“浏览器中的 Postgres”项目不同，PGlite 不使用 Linux 虚拟机——它就是纯粹的 WASM 版 Postgres。

#### 第 1 步 - 安装依赖包

<Npm>
 drizzle-orm@rc @electric-sql/pglite
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并发起查询
<CodeTabs items={["内存模式", "指定目录", "带额外配置项"]}>
```typescript copy"
import { drizzle } from 'drizzle-orm/pglite';

const db = drizzle();

await db.select().from(...);
```
```typescript copy"
import { drizzle } from 'drizzle-orm/pglite';

const db = drizzle('path-to-dir');

await db.select().from(...);
```
```typescript copy"
import { drizzle } from 'drizzle-orm/pglite';

// connection 是原生的 PGLite 配置
const db = drizzle({ connection: { dataDir: 'path-to-dir' }});

await db.select().from(...);
```
</CodeTabs>

如果你需要提供已有的驱动：

```typescript copy"
import { PGlite } from '@electric-sql/pglite';
import { drizzle } from 'drizzle-orm/pglite';

// 内存模式 Postgres
const client = new PGlite();
const db = drizzle({ client });

await db.select().from(users);
```
