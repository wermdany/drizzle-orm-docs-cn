# Drizzle 查询

Drizzle ORM 旨在成为 SQL 之上的一层轻量类型化封装。
我们坚信我们设计出了从 TypeScript 操作 SQL 数据库的最佳方式，并且是时候让它变得更好了。

关系查询旨在为你提供出色的开发者体验，用于从 SQL 数据库查询
嵌套的关系数据，避免多次 join 和复杂的数据映射。

它是对现有 schema 定义和查询构建器的扩展。
你可以根据自己的需求选择是否使用它。
我们确保你既能获得一流的开发者体验，又能获得出色的性能。

<Callout type="info" title='重要'>
在关系查询内部，对表列的引用必须通过回调参数进行，而不是通过导入的表对象。
这适用于每个接受回调的子句——`orderBy`、`where`.`RAW`、`extras` 以及 `extras 中的子查询`。
回调会暴露当前查询作用域的别名表，嵌套查询或自引用查询要生成正确的 SQL 必须这样做。

<Callout type="error" title='❌' collapsed="示例">
```ts
await db.query.posts.findMany({
  orderBy: sql`${posts.id} asc`, // <- ❌ 直接使用表
  with: {
    comments: {
      orderBy: sql`${comments.id} desc`, // <- ❌ 直接使用表
    },
  },
});
```
```ts
await db.query.users.findMany({
  where: {
    RAW: sql`LOWER(${users.name}) LIKE 'john%'`, // <- ❌ 直接使用表
  },
});
```
```ts
await db.query.users.findMany({
  extras: {
    loweredName: sql<string>`lower(${users.name})`, // <- ❌ 直接使用表
    totalPostsCount: db.$count(posts, eq(posts.authorId, users.id)),  // <- ❌ 直接使用表
  },
});
```
</Callout>
<Callout type="default" title='✅' collapsed="示例">
```ts
await db.query.posts.findMany({
  orderBy: (t) => sql`${t.id} asc`, // <- ✅ 使用了回调
  with: {
    comments: {
      orderBy: (t, { desc }) => desc(t.id), // <- ✅ 使用了回调
    },
  },
});
```
```ts
await db.query.users.findMany({
  where: {
    RAW: (t) => sql`LOWER(${t.name}) LIKE 'john%'`, // <- ✅ 使用了回调
  },
});
```
```ts
await db.query.users.findMany({
  extras: {
    loweredName: (t, { sql }) => sql<string>`lower(${t.name})`, // <- ✅ 使用了回调
    totalPostsCount: (t) => db.$count(posts, eq(posts.authorId, t.id)), // <- ✅ 使用了回调
  },
});
```
</Callout>

```typescript copy
import { type AnyPgColumn, integer, pgTable, primaryKey, text, timestamp } from 'drizzle-orm/pg-core';

export const users = pgTable('users', {
	id: integer().primaryKey(),
	name: text().notNull(),
	invitedBy: integer('invited_by').references((): AnyPgColumn => users.id),
});

export const groups = pgTable('groups', {
	id: integer().primaryKey(),
	name: text().notNull(),
	description: text(),
});

export const usersToGroups = pgTable('users_to_groups', {
	id: integer().primaryKey(),
	userId: integer('user_id').notNull().references(() => users.id),
	groupId: integer('group_id').notNull().references(() => groups.id),
}, (t) => [
	primaryKey({ columns: [t.userId, t.groupId] })
]);

export const posts = pgTable('posts', {
	id: integer().primaryKey(),
	content: text().notNull(),
	authorId: integer('author_id').references(() => users.id),
	createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});

export const comments = pgTable('comments', {
	id: integer().primaryKey(),
	content: text().notNull(),
	creator: integer().references(() => users.id),
	postId: integer('post_id').references(() => posts.id),
	createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});

export const commentLikes = pgTable('comment_likes', {
	id: integer().primaryKey(),
	creator: integer().references(() => users.id),
	commentId: integer('comment_id').references(() => comments.id),
	createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});
```
```typescript copy
import { defineRelations } from 'drizzle-orm';
import * as schema from './schema';

export const relations = defineRelations(schema, (r) => ({
    users: {
      invitee: r.one.users({
        from: r.users.invitedBy,
        to: r.users.id,
      }),
      groups: r.many.groups({
        from: r.users.id.through(r.usersToGroups.userId),
        to: r.groups.id.through(r.usersToGroups.groupId),
      }),
      posts: r.many.posts(),
    },
    groups: {
      users: r.many.users(),
    },
    posts: {
      author: r.one.users({
        from: r.posts.authorId,
        to: r.users.id,
      }),
      comments: r.many.comments(),
    },
    comments: {
      post: r.one.posts({
        from: r.comments.postId,
        to: r.posts.id,
      }),
      author: r.one.users({
        from: r.comments.creator,
        to: r.users.id,
      }),
      likes: r.many.commentLikes(),
    },
    commentLikes: {
      comment: r.one.comments({
        from: r.commentLikes.commentId,
        to: r.comments.id,
      }),
      author: r.one.users({
        from: r.commentLikes.creator,
        to: r.users.id,
      }),
    },
  })
);
```

### 包含关系

`With` 操作符让你可以组合来自多个相关表的数据，并正确地聚合结果。

**获取所有带评论的 posts：**
```typescript copy
const posts = await db.query.posts.findMany({
	with: {
		comments: true,
	},
});
```

**获取第一条带评论的 post：**
```typescript copy
const post = await db.query.posts.findFirst({
	with: {
		comments: true,
	},
});
```

你可以按需任意链式嵌套 with 语句。
对于任何嵌套的 `with` 查询，Drizzle 都会使用 [Core Type API](/docs/goodies#类型-api) 来推断类型。

**获取所有带 posts 的 users。每个 post 应包含评论列表：**
```typescript copy
const users = await db.query.users.findMany({
	with: {
		posts: {
			with: {
				comments: true,
			},
		},
	},
});
```

### 部分字段 select
`columns` 参数让你可以包含或省略你想从数据库中获取的列。

<Callout type="info" emoji="ℹ️">
  Drizzle 在查询层面执行部分查询，不会从数据库额外传输数据。

  请记住，**Drizzle 只输出一条 SQL 语句。**
</Callout>

**获取所有只带 `id`、`content` 的 posts，并包含 `comments`：**
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		id: true,
		content: true,
	},
	with: {
		comments: true,
	}
});
```

**获取所有不带 `content` 的 posts：**
```typescript copy
const posts = await db.query.posts.findMany({
	columns: {
		content: false,
	},
});
```

<Callout type="info" emoji="ℹ️">
当同时存在 `true` 和 `false` 查询选项时，所有 `false` 选项都会被忽略。
</Callout>

如果你包含 `name` 字段并排除 `id` 字段，排除 `id` 就是多余的，
因为除 `name` 之外的所有字段无论如何都会被排除。

**在同一次查询中排除和包含字段：**
<Section>
```typescript copy
const users = await db.query.users.findMany({
	columns: {
		name: true,
		id: false //被忽略
	},
});
```
```ts
// 结果类型
const users: {
	name: string;
};
```
</Section>

**只包含嵌套关系的列：**
<Section>
```typescript copy
const res = await db.query.users.findMany({
	columns: {},
	with: {
		posts: true
	}
});
```
```ts
// 结果类型
const res: {
	posts: {
		id: number,
		text: string
	}
}[];
```
</Section>

```typescript copy
const posts = await db.query.posts.findMany({
```

### Select 过滤器
就像我们的类 SQL 查询构建器一样，
关系查询 API 让你可以使用 **[`操作符`](/docs/operators)** 列表来定义过滤器和条件。

你可以从 `drizzle-orm` 导入它们，也可以使用回调语法：
<Section>
```typescript copy
const users = await db.query.users.findMany({
	where: {
		id: 1
	}
});
```
```sql {7}
select
  "d0"."id" as "id",
  "d0"."name" as "name"
from
  "users" as "d0"
where
  "d0"."id" = 1
```
</Section>

查找 `id=1` 的 post，以及在该特定日期之前创建的评论：
```typescript copy
await db.query.posts.findMany({
  where: {
    id: 1,
  },
  with: {
    comments: {
      where: {
        createdAt: { lt: new Date() },
      },
    },
  },
});
```

**所有过滤操作符列表**
```ts
where: {
    OR: [],
    AND: [],
    NOT: {},
    RAW: (table) => sql`${table.id} = 1`,

    // 按关系过滤

	  // 按列过滤
    [column]: {
      OR: [],
      AND: [],
      NOT: {},
      eq: 1,
      ne: 1,
      gt: 1,
      gte: 1,
      lt: 1,
      lte: 1,
      in: [1],
      notIn: [1],
      like: "",
      ilike: "",
      notLike: "",
      notIlike: "",
      isNull: true,
      isNotNull: true,
      arrayOverlaps: [1, 2],
      arrayContained: [1, 2],
      arrayContains: [1, 2]
    },
},
```

### 关系过滤器

借助 Drizzle 关系，你不仅可以按正在查询的表进行过滤，还可以按查询中包含的任何表进行过滤。

**示例：** 获取所有 ID>10 且至少有一条内容以 "M" 开头的 post 的 `users`
```ts
const usersWithPosts = await db.query.usersTable.findMany({
  where: {
    id: {
      gt: 10
    },
    posts: {
      content: {
        like: 'M%'
      }
    }
  },
});
```

**示例：** 获取所有带 posts 的 `users`，仅当用户至少有 1 条 post 时
```ts
const response = await db.query.users.findMany({
  with: {
    posts: true,
  },
  where: {
    posts: true,
  },
});
```

### Limit 与 Offset
Drizzle ORM 为查询以及嵌套实体提供了 `limit` 和 `offset` API。

**查询 5 条 posts：**
```typescript copy
await db.query.posts.findMany({
	limit: 5,
});
```

**查询 posts，并最多获取 3 条评论：**
```typescript copy
await db.query.posts.findMany({
	with: {
		comments: {
			limit: 3,
		},
	},
});
```

<Callout type="warning" emoji="⚠️">
  `offset` 现在也可以在 with 表中使用！
</Callout>
```typescript 
await db.query.posts.findMany({
	limit: 5,
	offset: 2, // 正确 ✅
	with: {
		comments: {
			offset: 3, // 正确 ✅
			limit: 3,
		},
	},
});
```

查询 posts 及其从第 6 条到第 10 条的评论：
```typescript copy
await db.query.posts.findMany({
	with: {
		comments: true,
	},
  limit: 5,
  offset: 5,
});
```

### Order By
Drizzle 为关系查询构建器提供了排序 API。

你可以使用相同的排序 **[核心 API](/docs/select#order-by)**，或
在回调中使用 `order by` 操作符而无需任何导入。

<Callout title='重要'>
当你在同一张表中使用多个 `orderBy` 语句时，它们会按照你添加它们的顺序被包含在查询中
</Callout>

<Section>
```typescript copy
await db.query.posts.findMany({
  orderBy: {
    id: "asc",
  },
});
```
</Section>

**按 `asc` + `desc` 排序：**
```typescript copy
  await db.query.posts.findMany({
    orderBy: { id: "asc" },
    with: {
      comments: {
        orderBy: { id: "desc" },
      },
    },
  });
```

你也可以在 order by 语句中使用自定义 `sql`：

```typescript copy
await db.query.posts.findMany({
  orderBy: (t) => sql`${t.id} asc`,
  with: {
    comments: {
      orderBy: (t, { desc }) => desc(t.id),
    },
  },
});
```

### 包含自定义字段
关系查询 API 让你可以添加自定义的额外字段。
当你需要检索数据并对其应用额外函数时，它会很有用。
<Callout type="warning" emoji="⚠️">
	截至目前，`extras` 中尚不支持聚合，请为此使用 **[`核心查询`](/docs/select)**。
</Callout>

<Section>
```typescript copy {5}
import { sql } from 'drizzle-orm';

await db.query.users.findMany({
  extras: {
    loweredName: (table) => sql`lower(${table.name})`,
  },
});
```
```typescript copy {3}
await db.query.users.findMany({
	extras: {
		loweredName: (users, { sql }) => sql`lower(${users.name})`,
	},
})
```
</Section>

`lowerName` 键会被包含到返回对象的所有字段中。

<Callout type="warning" emoji="⚠️">
  如果你为任何 extras 字段指定了 `.as("<alias>")`，drizzle 将忽略它
</Callout>

要检索所有带 groups 的 users，并包含 fullName 字段（它是 firstName 和 lastName 的拼接），
你可以使用以下带有 Drizzle 关系查询构建器的查询。

<Section>
```typescript copy
const res = await db.query.users.findMany({
	extras: {
		fullName: (users, { sql }) => sql<string>`concat(${users.name}, " ", ${users.name})`,
	},
	with: {
		groups: true,
	},
});
```
```ts
// 结果类型
const res: {
    id: number;
    name: string;
    age: number | null;
    invitedBy: number | null;
```

### 包含子查询

你还可以在关系查询中使用子查询，以利用自定义 SQL 语法的强大能力

**获取带 posts 的 users 以及每个用户的 posts 总数**
```ts
import { posts } from './schema';
import { eq } from 'drizzle-orm';

await db.query.users.findMany({
  with: {
    posts: true
  },
  extras: {
    totalPostsCount: (table) => db.$count(posts, eq(posts.authorId, table.id)),
  }
});
```
```sql
SELECT
  "d0"."id" AS "id",
  "d0"."name" AS "name",
  "d0"."age" AS "age",
  "d0"."invited_by" AS "invitedBy",
  (
    (
      SELECT
        count(*)
      FROM
        "posts"
      WHERE
        "posts"."author_id" = "d0"."id"
    )
  ) AS "totalPostsCount",
  "posts"."r" AS "posts"
FROM
  "users" AS "d0"
  LEFT JOIN LATERAL (
    SELECT
      coalesce(json_agg(row_to_json("t".*)), '[]') AS "r"
    FROM
      (
        SELECT
          "d1"."id" AS "id",
          "d1"."content" AS "content",
          "d1"."author_id" AS "authorId",
          "d1"."created_at"::text AS "createdAt"
        FROM
          "posts" AS "d1"
        WHERE
          "d0"."id" = "d1"."author_id"
      ) AS "t"
  ) AS "posts" ON TRUE
```

### 预处理语句
预编译语句旨在大幅提升查询性能——[详见此处。](/docs/perf-queries)

在本节中，你可以学习如何定义占位符并使用 Drizzle 关系查询构建器
执行预编译语句。

##### **`where` 中的占位符**

<Section>
```ts copy
const prepared = db.query.users.findMany({
    where: { id: { eq: sql.placeholder("id") } },
    with: {
      posts: {
        where: { id: 1 },
      },
    },
}).prepare("query_name");

const usersWithPosts = await prepared.execute({ id: 1 });
```
</Section>
