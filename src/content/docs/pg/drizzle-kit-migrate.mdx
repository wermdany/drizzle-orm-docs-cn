# `drizzle-kit migrate`
<Prerequisites>
- Drizzle 与 `drizzle-kit` 入门 - [阅读文档](/docs/get-started)
- Drizzle schema 基础 - [阅读文档](/docs/sql-schema-declaration)
- 数据库连接基础 - [阅读文档](/docs/connect-overview)
- Drizzle 迁移基础 - [阅读文档](/docs/migrations)
- Drizzle Kit [概览](/docs/kit-overview) 与 [配置文件](/docs/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读文档](/docs/drizzle-kit-generate)
</Prerequisites>
<br/>


`drizzle-kit migrate` 让你可以应用由 [`drizzle-kit generate`](/docs/drizzle-kit-generate) 生成的 SQL 迁移。
它旨在覆盖管理 Drizzle 迁移的 [代码优先（选项 3）](/docs/migrations) 方式。

<Callout collapsed="底层是如何工作的？">
Drizzle Kit 的 `migrate` 命令会触发一系列事件：
1. 读取迁移文件夹，并读取所有 `.sql` 迁移文件
2. 连接数据库并从 drizzle 迁移日志表中获取记录
3. 基于先前已应用的迁移，决定要运行哪些新迁移
4. 运行 SQL 迁移，并将已应用的迁移记录到 drizzle 迁移表中

```plaintext
  │ ├ 📂 20242409125510_premium_mister_fear

```

`drizzle-kit migrate` 命令要求你同时指定 `dialect` 和数据库连接凭据，
你可以通过 [drizzle.config.ts](/docs/drizzle-config-file) 配置文件提供，也可以通过 CLI 选项提供

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname"
  },
});
```
```shell
npx drizzle-kit migrate
```
</Section>
```shell
npx drizzle-kit migrate --dialect=postgresql --url=postgresql://user:password@host:port/dbname
```
</CodeTabs>

### 数据库中的已应用迁移日志
运行迁移后，Drizzle Kit 会将成功应用的迁移记录持久化到你的数据库中。
它会将这些记录存储在 `drizzle` schema 下一个名为 `__drizzle_migrations` 的迁移日志表中。

你可以通过 drizzle 配置文件自定义该表的 **表名** 和 **schema**：
```ts filename="drizzle.config.ts" {8-9}
export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname"
  },
  migrations: {
    table: 'my-migrations-table', // 默认是 `__drizzle_migrations`
    schema: 'public', // 默认是 `drizzle`
  },
});
```

### 单个项目中的多个配置文件
你可以在项目中拥有多个配置文件，当你存在多个数据库环境或同一项目下的多个数据库时，这非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展示例
让我们使用 `drizzle-kit generate` 和 `drizzle-kit migrate` 命令生成 SQL 迁移并将其应用到数据库

```plaintext
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 │ ├ 📜 schema.ts
 │ └ 📜 index.ts
 ├ 📜 drizzle.config.ts
 └ …
```
<CodeTabs items={["drizzle.config.ts", "src/schema.ts"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname"
  },
  migrations: {
    table: 'journal', 
    schema: 'drizzle', 
  },
});
```
```ts 
import * as p from "drizzle-orm/pg-core";

export const users = p.pgTable("users", {
  id: p.serial().primaryKey(),
  name: p.text(),
})
```
</CodeTabs>

现在让我们运行
```shell
npx drizzle-kit generate --name=init
```
它会生成
<Section>
```plaintext {5}
📦 <project root>
 ├ …
 ├ 📂 migrations
 │ ├ 📂 20242409125510_init
 └ …
```
```sql
-- ./drizzle/0000_init.sql

CREATE TABLE "users"(
  "id" serial primary key,
  "name" text
)
```
</Section>

现在让我们运行
```shell
npx drizzle-kit migrate
```

我们的 SQL 迁移现在已成功应用到数据库 ✅
