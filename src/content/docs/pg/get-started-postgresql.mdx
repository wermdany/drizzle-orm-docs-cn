# Drizzle \<\> PostgreSQL
<Prerequisites>
- 使用 Drizzle 的数据库 [连接基础](/docs/connect-overview)
- node-postgres [基础](https://node-postgres.com/)
- postgres.js [基础](https://github.com/porsager/postgres?tab=readme-ov-file#usage)
</Prerequisites>

Drizzle 通过 `node-postgres` 和 `postgres.js` 驱动原生支持 PostgreSQL 连接。

在使用这两个驱动并将它们与 Drizzle ORM 集成时，我们发现了 `node-postgres` 和 `postgres.js` 之间的一些差异。例如：

- 使用 `node-postgres` 时，你可以安装 `pg-native`，将 `node-postgres` 和 Drizzle 的速度提升约 10%。
- `node-postgres` 支持在每次查询的基础上提供类型解析器，而无需全局打补丁。更多细节，请参见 [类型文档](https://node-postgres.com/features/queries#types)。
- `postgres.js` 默认使用预处理语句，你可能需要选择退出该行为。这在 AWS 等环境中可能是一个潜在问题，因此请留意。
- 如果你还有其它想要贡献的内容，我们很乐意在 [这里](https://github.com/drizzle-team/drizzle-orm-docs/pulls) 接收你的 PR

## node-postgres
#### 第 1 步 - 安装依赖包
<Npm>
 drizzle-orm@rc pg
 -D drizzle-kit@rc @types/pg
</Npm>

#### 第 2 步 - 初始化驱动程序并执行查询
<CodeTabs items={["node-postgres", "带配置的 node-postgres"]}>
```typescript copy
// 确保安装了 'pg' 包 
import { drizzle } from 'drizzle-orm/node-postgres';

const db = drizzle(process.env.DATABASE_URL);
 
const result = await db.execute('select 1');
```
```typescript copy
// 确保安装了 'pg' 包 
import { drizzle } from 'drizzle-orm/node-postgres';

// 你可以指定 node-postgres 连接选项中的任意属性
const db = drizzle({ 
  connection: { 
    connectionString: process.env.DATABASE_URL,
    ssl: true
  }
});
 
const result = await db.execute('select 1');
```
</CodeTabs>

如果你需要提供已有的驱动：

```typescript copy
// 确保安装了 'pg' 包 
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});
const db = drizzle({ client: pool });
 
const result = await db.execute('select 1');
```

## postgres.js
#### 第 1 步 - 安装依赖包
<Npm>
 drizzle-orm@rc postgres
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动程序并执行查询
<CodeTabs items={["postgres.js", "带配置的 postgres.js"]}>
```typescript copy
import { drizzle } from 'drizzle-orm/postgres-js';

const db = drizzle(process.env.DATABASE_URL);

const result = await db.execute('select 1');
```
```typescript copy
import { drizzle } from 'drizzle-orm/postgres-js';

// 你可以指定 postgres-js 连接选项中的任意属性
const db = drizzle({ 
  connection: { 
    url: process.env.DATABASE_URL, 
    ssl: true 
  }
});

const result = await db.execute('select 1');
```
</CodeTabs>

如果你需要提供已有的驱动：

```typescript copy
// 确保安装了 'postgres' 包
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';

const queryClient = postgres(process.env.DATABASE_URL);
const db = drizzle({ client: queryClient });

const result = await db.execute('select 1');
```
