# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/migrations)
- Drizzle Kit [概览](/docs/kit-overview) 和 [配置文件](/docs/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读此处](/docs/drizzle-kit-generate)
- `drizzle-kit migrate` 命令 - [阅读此处](/docs/drizzle-kit-migrate)
</Prerequisites>

Drizzle 允许你生成空的迁移文件，以便为目前 Drizzle Kit 尚不支持的 DDL 变更
或数据填充编写你自己的自定义 SQL 迁移，随后你可以使用 [`drizzle-kit migrate`](/docs/drizzle-kit-migrate) 命令运行它们。

```shell
drizzle-kit generate --custom --name=seed-users
```
