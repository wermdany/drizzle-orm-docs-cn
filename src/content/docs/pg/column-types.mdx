### integer
`integer` `int` `int4`  
有符号 4 字节整数     

如果你需要 `integer autoincrement`，请参考 **[serial。](#serial)**

<Section>
```typescript
import { integer, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	int: integer()
});

```

```sql
CREATE TABLE "table" (
	"int" integer
);
```
</Section>

<Section>
```typescript
import { sql } from "drizzle-orm";
import { integer, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	int1: integer().default(10),
	int2: integer().default(sql`10`)
});

```

```sql
CREATE TABLE "table" (
	"int1" integer DEFAULT 10,
	"int2" integer DEFAULT 10
);
```
</Section>

### bigint
`bigint` `int8`  
有符号 8 字节整数  

如果你需要 `bigint autoincrement`，请参考 **[bigserial。](#bigserial)**

如果你期望的值大于 2^31 但小于 2^53，可以使用 `mode: 'number'`，用 JavaScript number 而非 bigint 来处理。
<Section>

```typescript
	bigint: bigint({ mode: 'number' })
});

// 会被推断为 `number`
bigint: bigint({ mode: 'number' })

// 会被推断为 `bigint`
bigint: bigint({ mode: 'bigint' })
```

```sql
CREATE TABLE "table" (
	"bigint" bigint
);
```
</Section>

</Section>

### varchar
`character varying(n)` `varchar(n)`  
变长字符串，最多可存储 **`n`** 个字符（不是字节）。

更多信息请参考 PostgreSQL 官方 **[文档。](https://www.postgresql.org/docs/current/datatype-character.html)**

你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。

根据 PostgreSQL 文档，`length` 参数是可选的。
<Section>

```typescript
// 会被推断为 text："value1" | "value2" | null

```

```sql
CREATE TABLE "table" (
	"varchar1" varchar,
	"varchar2" varchar(256)
);
```
</Section>

### json
`json`  
文本形式的 JSON 数据，如 **[RFC 7159](https://tools.ietf.org/html/rfc7159)** 所规定。

更多信息请参考 PostgreSQL 官方 **[文档。](https://www.postgresql.org/docs/current/datatype-json.html)**
<Section>
```typescript
import { sql } from "drizzle-orm";
import { json, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	json1: json(),
	json2: json().default({ foo: "bar" }),
	json3: json().default(sql`'{"foo": "bar"}'`),
});
```

```sql
CREATE TABLE "table" (
	"json1" json,
	"json2" json DEFAULT '{"foo":"bar"}',
	"json3" json DEFAULT '{"foo": "bar"}'
);
```
</Section>
  
你可以指定 `.$type<..>()` 用于 JSON 对象推断，它**不会**检查运行时值。
它为默认值、insert 和 select schema 提供编译期保护。
```typescript
// 会被推断为 { foo: string }
json: json().$type<{ foo: string }>();

// 会被推断为 string[]
json: json().$type<string[]>();

// 无法通过编译
json: json().$type<string[]>().default({});
```

### timestamp
`timestamp` `timestamptz` `timestamp with time zone` `timestamp without time zone`  
日期和时间，可带或不带时区。

更多信息请参考 PostgreSQL 官方 **[文档。](https://www.postgresql.org/docs/current/datatype-datetime.html)**
<Section>
```typescript
import { sql } from "drizzle-orm";
import { timestamp, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	timestamp1: timestamp(),
	timestamp2: timestamp({ precision: 6, withTimezone: true }),
	timestamp3: timestamp().defaultNow(),
	timestamp4: timestamp().default(sql`now()`),
});
```
```sql
CREATE TABLE "table" (
	"timestamp1" timestamp,
	"timestamp2" timestamp(6) with time zone,
	"timestamp3" timestamp DEFAULT now(),
	"timestamp4" timestamp DEFAULT now()
);
```
</Section>

你可以指定 `date` 或 `string` 推断模式：
```typescript
// 会推断为 date
timestamp: timestamp({ mode: "date" }),

// 会推断为 string
timestamp: timestamp({ mode: "string" }),
```

> `string` 模式不会为你执行任何映射。该模式被加入 Drizzle ORM，是为了让开发者可以
根据自身需求自行处理日期和日期映射。
Drizzle 会以字符串形式在数据库 `to` 和 `from` 之间传递原始日期，因此其行为应尽可能可预测，
并与数据库行为 100% 一致

> `date` 模式是处理日期的常规方式。Drizzle 会负责数据库与 JS Date 对象之间的所有映射

<Callout type='info' emoji='ℹ️'>
 `timestamp` 和 `timestamp with timezone` 的映射如何工作：

 正如 PostgreSQL 文档所述：
 > 对于被确定为 timestamp without time zone 的字面量，PostgreSQL 会静默忽略任何时区指示。
 > 也就是说，结果值由输入值中的日期/时间字段推导而来，不会针对时区进行调整。
 >
 > 对于 timestamp with time zone，内部存储的值始终为 UTC（协调世界时，传统上称为格林尼治标准时间，GMT）。
 指定了显式时区的输入值会使用该时区的相应偏移量转换为 UTC。
 如果输入字符串中未声明时区，则假定为系统 TimeZone 参数所指示的时区，
 并使用该时区的偏移量转换为 UTC。

 因此，对于 `timestamp with timezone`，你会得到转换为 Postgres 实例中所设时区的字符串。
 你可以使用以下 sql 查询查看时区：
 
 ```sql 
 show timezone;
 ```


</Callout>

### point
`point`  
几何点类型

更多信息请参考 PostgreSQL 官方 **[文档。](https://www.postgresql.org/docs/current/datatype-geometric.html#DATATYPE-GEOMETRIC-POINTS)** 

类型 `point` 有 2 种从数据库映射的模式：`tuple` 和 `xy`。

- `tuple`：插入时被接受，select 时映射为元组。因此，数据库中的 Point(1,2) 在 drizzle 中会被类型化为 [1,2]。

- `xy`：插入时被接受，select 时映射为带有 x、y 坐标的对象。因此，数据库中的 Point(1,2) 在 drizzle 中会被类型化为 `{ x: 1, y: 2 }`

<Section>
```typescript
export const items = pgTable('items', {
	point: point(),
	pointObj: point({ mode: 'xy' }),
});
```

```sql
CREATE TABLE "items" (
	"point" point,
	"pointObj" point
);
```
</Section>

### line
`line`  
几何线类型

更多信息请参考 PostgreSQL 官方 **[文档。](https://www.postgresql.org/docs/current/datatype-geometric.html#DATATYPE-LINE)** 

类型 `line` 有 2 种从数据库映射的模式：`tuple` 和 `abc`。

- `tuple`：插入时被接受，select 时映射为元组。因此，数据库中的 Line `{1,2,3}` 在 drizzle 中会被类型化为 `[1,2,3]`。

- `abc`：插入时被接受，select 时映射为带有方程 `Ax + By + C = 0` 中 a、b、c 常量的对象。因此，数据库中的 Line `{1,2,3}` 在 drizzle 中会被类型化为 `{ a: 1, b: 2, c: 3 }`。

<Section>
```typescript
export const items = pgTable('items', {
	line: line(),
	lineObj: line({ mode: 'abc' }),
});
```

```sql
CREATE TABLE "items" (
	"line" line,
	"lineObj" line
);
```
</Section>

### enum 
`enum` `enumerated types`  
枚举（enum）类型是包含一组静态、有序值的数据类型。
它们等价于许多编程语言中支持的 enum 类型。
枚举类型的一个例子可以是一周中的各天，或某个数据的一组状态值。

更多信息请参考 PostgreSQL 官方 **[文档。](https://www.postgresql.org/docs/current/datatype-enum.html)**
<Section>
```typescript
import { pgEnum, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	mood: moodEnum(),
});
```

```sql
CREATE TYPE mood AS ENUM ('sad', 'ok', 'happy');

CREATE TABLE "table" (
	"mood" "mood"
);
```
</Section>

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，允许你自定义该列的数据类型。

例如，这对 unknown 或 branded 类型很有用：
```ts
type UserId = number & { __brand: 'user_id' };
type Data = {
	foo: string;
	bar: number;
};

export const users = pgTable('users', {
	id: serial().$type<UserId>().primaryKey(),
	jsonField: json().$type<Data>(),
});
```

### 标识列

PostgreSQL 支持标识列，作为为列自动生成唯一整数值的一种方式。这些值使用序列生成，可以通过 GENERATED AS IDENTITY 子句定义。

**标识列的类型**
- `GENERATED ALWAYS AS IDENTITY`：数据库始终为该列生成值。除非使用 OVERRIDING SYSTEM VALUE 子句，否则不允许手动插入或更新该列。
- `GENERATED BY DEFAULT AS IDENTITY`：数据库默认生成值，但也可以手动插入或更新值。如果提供了手动值，将使用该值而不是系统生成的值。

**主要特性**
- 自动生成值：利用序列为每一新行生成唯一值。
- 可自定义的序列选项：你可以定义起始值、增量以及其他序列选项。
- 支持多个标识列：PostgreSQL 允许每个表有多个标识列。

**限制**
- 手动插入限制：对于使用 GENERATED ALWAYS AS IDENTITY 定义的列，手动插入或更新需要 OVERRIDING SYSTEM VALUE 子句。
- 序列约束：标识列依赖序列，必须正确管理序列以避免冲突或空缺。

**用法示例**
```ts
import { pgTable, integer, text } from 'drizzle-orm/pg-core' 

export const ingredients = pgTable('ingredients', {
	id: integer().primaryKey().generatedAlwaysAsIdentity({ startWith: 1000 }),
	name: text().notNull(),
	description: text(),
});
```

你可以在 `.generatedAlwaysAsIdentity()` 函数中指定序列可用的所有属性。此外，你还可以为这些序列指定自定义名称

PostgreSQL 文档 [参考](https://www.postgresql.org/docs/current/sql-createtable.html#SQL-CREATETABLE-PARMS-GENERATED-IDENTITY)。

### 默认值
`DEFAULT` 子句指定当用户执行 `INSERT` 时没有显式提供值时该列要使用的默认值。
如果列定义没有附加显式的 `DEFAULT` 子句，
那么该列的默认值为 `NULL`。

显式的 `DEFAULT` 子句可以指定默认值为 `NULL`、
字符串常量、blob 常量、带符号数字，或任何用括号括起来的常量表达式。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { integer, pgTable, uuid } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	integer1: integer().default(42),
	integer2: integer().default(sql`42`),
	uuid1: uuid().defaultRandom(),
	uuid2: uuid().default(sql`gen_random_uuid()`),
});
```

```sql
CREATE TABLE "table" (
	"integer1" integer DEFAULT 42,
	"integer2" integer DEFAULT 42,
	"uuid1" uuid DEFAULT gen_random_uuid(),
	"uuid2" uuid DEFAULT gen_random_uuid()
);
```
</Section>

使用 `$default()` 或 `$defaultFn()` 时（它们只是同一函数的不同别名），
你可以在运行时生成默认值，并在所有 insert 查询中使用这些值。

这些函数可以帮助你利用各种实现，例如 `uuid`、`cuid`、`cuid2` 等。

<Callout type="info" emoji="ℹ️">
	注意：该值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时中使用
</Callout>

```ts
import { text, pgTable } from "drizzle-orm/pg-core";
import { createId } from '@paralleldrive/cuid2';

export const table = pgTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

使用 `$onUpdate()` 或 `$onUpdateFn()` 时（它们只是同一函数的不同别名），
你可以在运行时生成默认值，并在所有 update 查询中使用这些值。

为列添加动态更新值。当行被更新时会调用该函数，
如果未提供值，则返回的值将用作该列的值。
如果未提供默认值（或 $defaultFn）值，则在行被插入时也会调用该函数，
返回的值将用作该列的值。

<Callout type="info" emoji="ℹ️">
	注意：该值不影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时中使用
</Callout>

```ts
import { integer, timestamp, text, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	updateCounter: integer().default(sql`1`).$onUpdateFn((): SQL => sql`${table.update_counter} + 1`),
	updatedAt: timestamp({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```


### 非空
`NOT NULL` 约束规定关联的列不可包含 `NULL` 值。

<Section>
```typescript
import { integer, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	integer: integer().notNull(),
});
```

```sql
CREATE TABLE "table" (
	"integer" integer NOT NULL
);
```
</Section>


### 主键
主键约束表示某一列或一组列可用作表中各行的唯一标识符。
这要求这些值既是唯一的又是非空的。
<Section>
```typescript
import { serial, pgTable } from "drizzle-orm/pg-core";

export const table = pgTable('table', {
	id: serial().primaryKey(),
});
```

```sql
CREATE TABLE "table" (
	"id" serial PRIMARY KEY
);
```
</Section>
