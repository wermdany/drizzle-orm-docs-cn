# Drizzle \<\> Nile

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/connect-overview)
- Nile Database - [网站](https://thenile.dev)
- Drizzle PostgreSQL 驱动 - [文档](/docs/get-started-postgresql)
</Prerequisites>

根据 **[官方网站](https://thenile.dev)**，Nile 是为多租户应用重新设计的 PostgreSQL。

请查看官方 **[Nile + Drizzle 快速开始](https://www.thenile.dev/docs/getting-started/languages/drizzle)** 和 **[迁移](https://www.thenile.dev/docs/getting-started/schema_migrations/drizzle)** 文档。

你可以将 Nile 与 Drizzle 的任意 Postgres 驱动一起使用，下面我们将演示 `node-postgres` 的用法。

#### 第 1 步 - 安装依赖包

<Npm>
 drizzle-orm@rc pg
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并发起查询

```typescript copy filename="index.ts"
// 确保安装 'pg' 包
import { drizzle } from 'drizzle-orm/node-postgres'

const db = drizzle(process.env.NILEDB_URL);

const response = await db.select().from(...);
```

如果你需要提供自己已有的驱动：

```typescript copy filename="index.ts"
// 确保安装 'pg' 包
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});

const db = drizzle({ client: pool });

const response = await db.select().from(...);
```

#### 连接到虚拟租户数据库

Nile 提供虚拟租户数据库。当你设置租户上下文后，Nile 会把你的查询引导到该特定租户的虚拟数据库，所有查询都会作用于该租户（即 `select * from table` 只会返回该租户的记录）。

为了设置租户上下文，我们把每个查询包装在一个事务中，在运行事务前先设置相应的租户上下文。

租户 ID 只需作为参数传入该包装函数即可：

```typescript copy filename="index.ts"
import { drizzle } from 'drizzle-orm/node-postgres';
import { todosTable, tenants } from "./db/schema";
import { sql } from 'drizzle-orm';
import 'dotenv/config';

const db = drizzle(process.env.NILEDB_URL);

function tenantDB<T>(tenantId: string, cb: (tx: any) => T | Promise<T>): Promise<T> {
  return db.transaction(async (tx) => {
    if (tenantId) {
      await tx.execute(sql`set local nile.tenant_id = '${sql.raw(tenantId)}'`);
    }

    return cb(tx);
  }) as Promise<T>;
}

// 在 web 应用中，你可能会从请求的路径参数或请求头中获取它
const tenantId = '01943e56-16df-754f-a7b6-6234c368b400'

const response = await tenantDB(tenantId, async (tx) => {
    // 这里不需要 "where" 子句
    return await tx.select().from(todosTable);
});

console.log(response);
```

如果你使用的 web 框架支持，可以设置 [AsyncLocalStorage](https://nodejs.org/api/async_context.html)，并使用中间件在其中填充租户 ID。这种情况下，你的 Drizzle 客户端设置将是：

```typescript copy filename="db/index.ts
import { drizzle } from 'drizzle-orm/node-postgres';
import dotenv from "dotenv/config";
import { sql } from "drizzle-orm";
import { AsyncLocalStorage } from "async_hooks";

export const db = drizzle(process.env.NILEDB_URL);
export const tenantContext = new AsyncLocalStorage<string | undefined>();

export function tenantDB<T>(cb: (tx: any) => T | Promise<T>): Promise<T> {
  return db.transaction(async (tx) => {
    const tenantId = tenantContext.getStore();
    console.log("executing query with tenant: " + tenantId);
    // 如果有租户 ID，则在事务上下文中设置它
    if (tenantId) {
      await tx.execute(sql`set local nile.tenant_id = '${sql.raw(tenantId)}'`);
    }

    return cb(tx);
  }) as Promise<T>;
}
```

然后，配置一个中间件来填充 AsyncLocalStorage，并在处理请求时使用 `tenantDB` 方法：

```typescript copy filename="app.ts"
// 用于设置租户上下文的中间件
app.use("/api/tenants/:tenantId/*", async (c, next) => {
  const tenantId = c.req.param("tenantId");
  console.log("setting context to tenant: " + tenantId);
  return tenantContext.run(tenantId, () => next());
});

// 路由处理器
app.get("/api/tenants/:tenantId/todos", async (c) => {
    const todos = await tenantDB(c, async (tx) => {
      return await tx
        .select({
          id: todoSchema.id,
          tenant_id: todoSchema.tenantId,
          title: todoSchema.title,
          estimate: todoSchema.estimate,
        })
        .from(todoSchema);
    });
    return c.json(todos);
});
```
