# Drizzle ORM

Drizzle ORM 是一个“有头脑”的无头 TypeScript ORM。🐲
> Drizzle 是一位好朋友，需要时它就在你身边，需要空间时它也不会打扰你。

它看起来和用起来都很简单，在你的项目进行到第 _1000_ 天时依然表现出色，\
让你按自己的方式做事，并在你需要时随时待命。

**它是唯一同时提供[关系式](/docs/rqb)和 [SQL 风格](/docs/select)查询 API 的 ORM**， 
在访问关系型数据时为你提供两全其美的方案。 
Drizzle 轻量、高性能、类型安全、不含乳糖、无麸质、清醒、灵活，并且**在设计上即可用于无服务器环境**。
Drizzle 不只是一个库，它是一种体验。🤩

[![Drizzle bestofjs](@/assets/images/bestofjs.jpg)](https://bestofjs.org/projects/drizzle-orm)

## 无头 ORM？ 
首先，Drizzle 是一个库，以及一组互补的可选工具。 

**ORM** 代表 _object relational mapping_（对象关系映射），开发者倾向于把类似 Django 或 Spring 的工具称为 ORM。 
我们坚信这是基于遗留命名的一种误解，我们称它们为**数据框架**。

<Callout type="error" emoji="️💔">
  使用数据框架时，你必须**围绕它们**来构建项目，而不是**用它们**来构建项目。
</Callout>

**Drizzle** 让你以自己想要的方式构建项目，不会干扰你的项目或结构。 

使用 Drizzle，你可以在 TypeScript 中定义和管理数据库 schema，以 SQL 风格
或关系式的方式访问数据，并利用可选工具
把你的开发体验推*到极致*。🤯 

## 为什么是 SQL-like？
**如果你懂 SQL，你就懂 Drizzle。**

其他 ORM 和数据框架倾向于偏离/抽象掉 SQL，这
会导致双重学习曲线：既需要了解 SQL，又需要了解该框架的 API。  

Drizzle 恰恰相反。 
我们拥抱 SQL，并将 Drizzle 的核心设计为 SQL 风格，因此你几乎没有
学习曲线，并且可以使用 SQL 的全部能力。  

我们带来了所有你熟悉的 **[SQL schema](/docs/sql-schema-declaration)**、**[查询](/docs/select)**、
**[自动迁移](/docs/migrations)** 以及 **[还有一件事](/docs/rqb)**。✨

<CodeTabs items={["index.ts", "schema.ts", "migration.sql"]}>
```typescript copy
// 访问你的数据
await db
	.select()
	.from(countries)
	.leftJoin(cities, eq(cities.countryId, countries.id))
	.where(eq(countries.id, 10))
```
```typescript copy
// 管理你的 schema
export const countries = pgTable('countries', {
  id: serial().primaryKey(),
  name: varchar({ length: 256 }),
});

export const cities = pgTable('cities', {
  id: serial().primaryKey(),
  name: varchar({ length: 256 }),
  countryId: integer('country_id').references(() => countries.id),
});
```
```sql
CREATE TABLE "countries" (
	"id" serial PRIMARY KEY,
	"name" varchar(256)
);

CREATE TABLE "cities" (
	"id" serial PRIMARY KEY,
	"name" varchar(256),
	"country_id" integer
);

ALTER TABLE "cities" ADD CONSTRAINT "cities_country_id_countries_id_fkey" FOREIGN KEY ("country_id") REFERENCES "countries"("id");
```
</CodeTabs>

## 为什么不采用 SQL-like？
我们始终追求完美平衡的解决方案，虽然 SQL 风格已经覆盖了 100% 的需求， 
但在某些常见场景中，你可以用更好的方式查询数据。  

我们为你构建了 **[Queries API](/docs/rqb)**，这样你就可以以最便捷、最高效的方式从数据库中
获取关系型嵌套数据，而不必再考虑 join 和数据映射。  

**Drizzle 始终只输出恰好 1 条 SQL 查询。** 你可以放心地将它与无服务器数据库一起使用，永远不必担心性能或往返成本！

```ts
const result = await db.query.users.findMany({
	with: {
		posts: true
	},
});
```

<Callout type="info" emoji="🥳">

![Drizzle 体积小巧且为无服务器做好准备](@/assets/images/drizzle31kb.jpg)
  
Drizzle ORM 是方言特定的、小巧、高性能，并且**在设计上**即可用于无服务器环境。  

我们花了大量时间确保你拥有同类最佳的 SQL 方言支持，包括 Postgres、MySQL 等。

Drizzle 通过行业标准的数据库驱动原生运行。我们支持所有主流的 **[PostgreSQL](/docs/get-started-postgresql)**、**[MySQL](/docs/mysql/get-started-mysql)**、**[SQLite](/docs/sqlite/get-started-sqlite)**、**[SingleStore](/docs/singlestore/get-started-singlestore)**、**[MSSQL](/docs/mssql/get-started-mssql)** 或 **[CockroachDB](/docs/cockroach/get-started-cockroach)** 驱动，并且我们正在**[非常快速地](https://twitter.com/DrizzleORM/status/1653082492742647811?s=20)**添加新的驱动。
