### `pg_vector`

<Callout>
在 Drizzle schema 中创建扩展没有特定的代码。我们假设如果你使用向量类型、
索引和查询，那么你的 PostgreSQL 数据库已经安装了 pg_vector 扩展。
</Callout>

[`pg_vector`](https://github.com/pgvector/pgvector) 是用于 Postgres 的开源向量相似度搜索

将你的向量和其余数据一起存储。支持：

- 精确和近似最近邻搜索
- 单精度、半精度、二进制和稀疏向量
- L2 距离、内积、余弦距离、L1 距离、汉明距离和杰卡德距离

#### 列类型

**`vector`**

将你的向量和其余数据一起存储

更多信息请参考 pg_vector 官方文档 **[文档。](https://github.com/pgvector/pgvector)**

<Section>
```ts
const table = pgTable('table', {
	embedding: vector({ dimensions: 3 }),
	embedding2: vector({ dimensions: 3 }).default([0, -2, 3])
})
```

```sql
CREATE TABLE "table" (
	"embedding" vector(3),
	"embedding2" vector(3) DEFAULT '[0,-2,3]'
);
```
</Section>

**`halfvec`**

半精度向量类型，存储由半精度浮点值组成的稠密向量

更多信息请参考 pg_vector 官方文档 **[文档。](https://github.com/pgvector/pgvector)**

<Section>
```ts
export const table = pgTable('table', {
	halfvec: halfvec({ dimensions: 3 }),
	halfvec2: halfvec({ dimensions: 3 }).default([0, -2, 3])
})
```

```sql
CREATE TABLE "table" (
	"halfvec" halfvec(3),
	"halfvec2" halfvec(3) DEFAULT '[0,-2,3]'
);
```
</Section>

**`sparsevec`**

稀疏向量类型，高效地存储大部分值为零的向量

更多信息请参考 pg_vector 官方文档 **[文档。](https://github.com/pgvector/pgvector)**

<Section>
```ts
export const table = pgTable('table', {
	sparsevec: sparsevec({ dimensions: 3 }),
	sparsevec2: sparsevec({ dimensions: 5 }).default(`{1:-1,3:2,5:3}/5`)
})
```

```sql
CREATE TABLE "table" (
	"sparsevec" sparsevec(3),
	"sparsevec2" sparsevec(5) DEFAULT '{1:-1,3:2,5:3}/5'
);
```
</Section>

**`bit`**

位字符串类型，用于 pgvector 中的二进制向量

更多信息请参考 pg_vector 官方 **[文档。](https://github.com/pgvector/pgvector)**

<Section>
```ts
export const table = pgTable('table', {
	bit: bit({ dimensions: 5 }),
	bit2: bit({ dimensions: 3 }).default(`101`)
})
```

```sql
CREATE TABLE "table" (
	"bit" bit(5),
	"bit2" bit(3) DEFAULT '101'
);
```
</Section>

#### 索引

你现在可以为 `pg_vector` 指定索引，并利用 `pg_vector` 函数进行查询、排序等操作。

让我们从 `pg_vector` 文档中取一些 `pg_vector` 索引示例，并将它们转换为 Drizzle 写法

#### `vector` 的 L2 距离、内积和余弦距离

```ts
// CREATE INDEX ON items USING hnsw (embedding vector_l2_ops);
// CREATE INDEX ON items USING hnsw (embedding vector_ip_ops);
// CREATE INDEX ON items USING hnsw (embedding vector_cosine_ops);

export const table = pgTable('items', {
    embedding: vector({ dimensions: 3 })
}, (table) => [
  index('l2_index').using('hnsw', table.embedding.op('vector_l2_ops')),
  index('ip_index').using('hnsw', table.embedding.op('vector_ip_ops')),
  index('cosine_index').using('hnsw', table.embedding.op('vector_cosine_ops'))
])
```

#### 辅助函数

对于查询，你可以使用为向量预定义好的函数，也可以使用 SQL 模板操作符创建自定义函数。

你还可以使用以下辅助函数：

```ts
import { l2Distance, l1Distance, innerProduct, 
          cosineDistance, hammingDistance, jaccardDistance } from 'drizzle-orm'

l2Distance(table.column, [3, 1, 2]) // table.column <-> '[3, 1, 2]'
l1Distance(table.column, [3, 1, 2]) // table.column <+> '[3, 1, 2]'

innerProduct(table.column, [3, 1, 2]) // table.column <#> '[3, 1, 2]'
cosineDistance(table.column, [3, 1, 2]) // table.column <=> '[3, 1, 2]'

hammingDistance(table.column, '101') // table.column <~> '101'
jaccardDistance(table.column, '101') // table.column <%> '101'
```

如果 `pg_vector` 还有其它函数要使用，你可以复刻我们现有函数的实现。以下是具体做法

```ts
export function l2Distance(
  column: SQLWrapper | AnyColumn,
  value: number[] | string[] | TypedQueryBuilder<any> | string,
): SQL {
  if (is(value, TypedQueryBuilder<any>) || typeof value === 'string') {
    return sql`${column} <-> ${value}`;
  }
  return sql`${column} <-> ${JSON.stringify(value)}`;
}
```

你可以随意命名并更改操作符。这个示例支持数字数组、字符串数组、字符串，甚至 select 查询。你可以随意创建任何其它类型，甚至贡献代码并提交 PR

#### 示例

让我们从 `pg_vector` 文档中取一些 `pg_vector` 查询示例，并将它们转换为 Drizzle 写法

```ts
import { l2Distance } from 'drizzle-orm';

// SELECT * FROM items ORDER BY embedding <-> '[3,1,2]' LIMIT 5;
db.select().from(items).orderBy(l2Distance(items.embedding, [3,1,2]))

// SELECT embedding <-> '[3,1,2]' AS distance FROM items;
db.select({ distance: l2Distance(items.embedding, [3,1,2]) })

// SELECT * FROM items ORDER BY embedding <-> (SELECT embedding FROM items WHERE id = 1) LIMIT 5;
const subquery = db.select({ embedding: items.embedding }).from(items).where(eq(items.id, 1));
db.select().from(items).orderBy(l2Distance(items.embedding, subquery)).limit(5)

// SELECT (embedding <#> '[3,1,2]') * -1 AS inner_product FROM items;
db.select({ innerProduct: sql`(${innerProduct(items.embedding, [3,1,2])}) * -1` }).from(items)

// 还有更多！
```

### `postgis`

<Callout>
在 Drizzle schema 中创建扩展没有特定的代码。我们假设如果你使用 postgis 类型、索引和查询，那么你的 PostgreSQL 数据库已经安装了 `postgis` 扩展。
</Callout>

正如 [PostGIS](https://postgis.net/) 网站所述：

> PostGIS 通过增加对地理空间数据的存储、索引和查询支持，扩展了 PostgreSQL 关系型数据库的能力。

<Callout type="info">
如果你在使用 PostGIS 扩展的同时使用 `introspect` 或 `push` 命令，并且不希望包含 PostGIS 的表，可以使用 [extensionsFilters](/docs/drizzle-config-file#extensionsfilters) 忽略所有 PostGIS 表
</Callout>

#### 列类型

**`geometry`**

将你的几何数据和其余数据一起存储

更多信息请参考 PostGIS 官方文档 **[文档。](https://postgis.net/workshops/postgis-intro/geometries.html)**

```ts
const items = pgTable('items', {
  geo: geometry('geo', { type: 'point' }),
  geoObj: geometry('geo_obj', { type: 'point', mode: 'xy' }),
  geoSrid: geometry('geo_options', { type: 'point', mode: 'xy', srid: 4000 }),
});
```

**mode**

`geometry` 类型有 2 种从数据库映射的模式：`tuple` 和 `xy`。

- `tuple` 在插入时会被接受，并在 select 时映射为一个元组。因此，使用 drizzle 时数据库几何数据会被类型化为 [1,2]。
- `xy` 在插入时会被接受，并在 select 时映射为一个带有 x、y 坐标的对象。因此，使用 drizzle 时数据库几何数据会被类型化为 `{ x: 1, y: 2 }`

**type**

当前版本有一个预定义类型：`point`，即 PostgreSQL PostGIS 扩展中的 `geometry(Point)` 类型。如果你想使用其它类型，可以在那里指定任意字符串

#### 索引

借助可用的 Drizzle 索引 API，你应该能够为 PostGIS 编写任何索引

**示例**

```ts
// CREATE INDEX custom_idx ON table USING GIST (geom);

const table = pgTable('table', {
  	geo: geometry({ type: 'point' }),
}, (table) => [
  index('custom_idx').using('gist', table.geo)
])
```
