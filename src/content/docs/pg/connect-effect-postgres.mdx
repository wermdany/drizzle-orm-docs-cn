# Drizzle \<\> Effect Postgres

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/connect-overview)
- Effect - [网站](https://effect.website/docs)
- **@effect/sql-pg** - 面向 Effect 的 PostgreSQL 工具包 - [在此阅读](https://effect-ts.github.io/effect/docs/sql-pg)
</Prerequisites>

Drizzle 通过 `@effect/sql-pg` 驱动原生支持 Effect PostgreSQL 连接。

#### 第 1 步 - 安装依赖包
<Npm>
 drizzle-orm@rc effect @effect/sql-pg pg
 -D drizzle-kit@rc @types/pg
</Npm>

#### 第 2 步 - 初始化驱动并发起查询

Drizzle 提供了一个与 Effect 的服务模式集成的 Effect 原生 API。使用 `PgDrizzle.makeWithDefaults()`
可通过合理的默认配置（无日志、无缓存）快速创建 Drizzle 数据库实例。

```typescript copy
import 'dotenv/config';
import * as PgDrizzle from 'drizzle-orm/effect-postgres';
import { PgClient } from '@effect/sql-pg';
import * as Effect from 'effect/Effect';
import * as Redacted from 'effect/Redacted';
import { sql } from 'drizzle-orm';
import { types } from 'pg';

// 使用类型解析器配置 PgClient layer
const PgClientLive = PgClient.layer({
  url: Redacted.make(process.env.DATABASE_URL!),
  types: {
    getTypeParser: (typeId, format) => {
      // 为 date/time 类型返回原始值，交由 Drizzle 处理解析
      if ([1184, 1114, 1082, 1186, 1231, 1115, 1185, 1187, 1182].includes(typeId)) {
        return (val: any) => val;
      }
      return types.getTypeParser(typeId, format);
    },
  },
});

const program = Effect.gen(function*() {
  // 使用默认服务（无日志、无缓存）创建数据库
  const db = yield* PgDrizzle.makeWithDefaults();

  // 执行查询
  const result = yield* db.execute<{ id: number }>(sql`SELECT 1 as id`);
  console.log(result);
});

// 使用 PgClient layer 运行程序
Effect.runPromise(program.pipe(Effect.provide(PgClientLive)));
```

#### 第 3 步 - 为依赖注入创建 DB Layer

对于较大的应用，可创建一个可复用的 DB layer，以便与其他服务组合。这遵循 Effect 推荐的
依赖注入模式：

```typescript copy
import * as PgDrizzle from 'drizzle-orm/effect-postgres';
import { PgClient } from '@effect/sql-pg';
import * as Context from 'effect/Context';
import * as Effect from 'effect/Effect';
import * as Layer from 'effect/Layer';
import * as Redacted from 'effect/Redacted';
import { types } from 'pg';
import * as relations from './schema/relations';

// 配置 PgClient layer
const PgClientLive = PgClient.layer({
  url: Redacted.make(process.env.DATABASE_URL!),
  types: {
    getTypeParser: (typeId, format) => {
      if ([1184, 1114, 1082, 1186, 1231, 1115, 1185, 1187, 1182].includes(typeId)) {
        return (val: any) => val;
      }
      return types.getTypeParser(typeId, format);
    },
  },
});

// 使用默认服务创建 DB effect
const dbEffect = PgDrizzle.make({ relations }).pipe(
  Effect.provide(PgDrizzle.DefaultServices)
);

// 定义用于依赖注入的 DB 服务 tag
class DB extends Context.Tag('DB')<DB, Effect.Effect.Success<typeof dbEffect>>() {}

// 创建提供 DB 服务的 layer
const DBLive = Layer.effect(
  DB,
  Effect.gen(function*() {
    return yield* dbEffect;
  }),
);

// 将所有 layer 组合在一起
const AppLive = Layer.provideMerge(DBLive, PgClientLive);

// 在应用中使用 DB 服务
const program = Effect.gen(function*() {
  const db = yield* DB;
  const users = yield* db.select().from(usersTable);
  return users;
});

// 在提供所有依赖的情况下运行
Effect.runPromise(program.pipe(Effect.provide(AppLive)));
```

#### 进阶：自定义 logger 和 cache 配置

若想更精细地控制日志和缓存，请直接使用 `PgDrizzle.make()` 并提供你自己的服务实现。

##### Logger 配置

默认情况下，`makeWithDefaults()` 使用 no-op logger（不记录日志）。你可以通过提供
不同的 `EffectLogger` 实现来启用日志：

```typescript copy
import * as PgDrizzle from 'drizzle-orm/effect-postgres';
import { EffectLogger } from 'drizzle-orm/effect-postgres';
import * as Effect from 'effect/Effect';

const program = Effect.gen(function*() {
  const db = yield* PgDrizzle.make({ /* schema, relations, casing */ }).pipe(
    // 启用基于 Effect 的日志（使用带注解的 Effect.log）
    Effect.provide(EffectLogger.layer),
    // 提供剩余的默认服务（cache）
    Effect.provide(PgDrizzle.DefaultServices),
  );

  const users = yield* db.select().from(usersTable);
  return users;
});
```

**可用的 logger 选项：**
- `EffectLogger.Default` - no-op logger（不记录任何日志）- 这是默认值
- `EffectLogger.layer` - 使用 Effect 的 `Effect.log()` 记录查询，并带有查询 SQL 和参数的注解。与 Effect 的日志基础设施集成。
- `EffectLogger.fromDrizzle(logger)` - 包装 Drizzle `Logger` 实例以便与 Effect 一起使用
- `EffectLogger.layerFromDrizzle(logger)` - 从 Drizzle logger 创建 Effect Layer

<Callout type='info'>
使用 `EffectLogger.layer` 时，查询会通过 Effect 的日志系统记录。你可以通过提供不同的 Effect logger layer 来配置输出
格式（例如开发环境用 `Logger.pretty`，生产环境用 `Logger.json`）。
</Callout>

**使用 Drizzle logger：**

```typescript copy
import * as PgDrizzle from 'drizzle-orm/effect-postgres';
import { EffectLogger } from 'drizzle-orm/effect-postgres';
import * as Effect from 'effect/Effect';
import { DefaultLogger } from 'drizzle-orm';

const program = Effect.gen(function*() {
  const db = yield* PgDrizzle.make({ /* schema, relations, casing */ }).pipe(
    // 使用为 Effect 包装的 Drizzle logger
    Effect.provide(EffectLogger.layerFromDrizzle(new DefaultLogger())),
    // 提供剩余的默认服务（cache）
    Effect.provide(PgDrizzle.DefaultServices),
  );

  const users = yield* db.select().from(usersTable);
  return users;
});
```

##### Cache 配置

同样地，你也可以提供自定义的缓存实现：

```typescript copy
import * as PgDrizzle from 'drizzle-orm/effect-postgres';
import { EffectLogger } from 'drizzle-orm/effect-postgres';
import { EffectCache } from 'drizzle-orm/cache/core/cache-effect';
import * as Effect from 'effect/Effect';
import { MyCustomCache } from './cache';

const program = Effect.gen(function*() {
  const db = yield* PgDrizzle.make({ /* schema, relations, casing */ }).pipe(
    // 提供为 Effect 包装的自定义 cache
    Effect.provide(EffectCache.layerFromDrizzle(new MyCustomCache())),
    // 提供剩余的默认服务（logger）
    Effect.provide(PgDrizzle.DefaultServices),
  );

  const users = yield* db.select().from(usersTable);
  return users;
});
```

**可用的 cache 选项：**
- `EffectCache.Default` - no-op cache（不进行任何缓存）- 这是默认值
- `EffectCache.fromDrizzle(cache)` - 包装 Drizzle `Cache` 实例以便与 Effect 一起使用
- `EffectCache.layerFromDrizzle(cache)` - 从 Drizzle cache 创建 Effect Layer（便于与其他 layer 组合）
