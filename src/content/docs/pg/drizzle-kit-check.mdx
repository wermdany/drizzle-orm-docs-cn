# `drizzle-kit check`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/migrations)
- Drizzle Kit [概览](/docs/kit-overview)和[配置文件](/docs/drizzle-config-file)
- `drizzle-kit generate` 命令 - [阅读此处](/docs/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit check` 命令让你检查生成的 SQL 迁移历史的一致性。

当你有多位开发者参与同一个项目、并在不同分支上修改数据库 schema 时，这极其有用 - 阅读更多关于[团队迁移](/docs/kit-migrations-for-teams)的内容。

<br/>
<hr/>
<br/>

`drizzle-kit check` 命令要求你指定 `dialect`，
你可以通过 [drizzle.config.ts](/docs/drizzle-config-file) 配置文件或 CLI 选项提供它

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
});
```
```shell
npx drizzle-kit check
```
</Section>
```shell
npx drizzle-kit check --dialect=postgresql
```
</CodeTabs>

### 单个项目中的多个配置文件
项目中可以有多个配置文件，当你拥有多个数据库阶段或同一项目下的多个数据库时，这非常有用：
<Npx>
  drizzle-kit check --config=drizzle-dev.config.ts
  drizzle-kit check --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 忽略冲突

如果你需要 `check` 命令跳过可交换性检查并绕过它，可以使用 `--ignore-conflicts`。如果你确实遇到了需要使用它的情形，那么
很有可能 `drizzle-kit` 没有正确地检查迁移，这是一个 bug。请向我们报告你的情况，以便我们修复它

```shell
drizzle-kit check --ignore-conflicts
```

### 扩展配置列表
我们建议通过 [drizzle.config.ts](/docs/drizzle-config-file) 文件配置 `drizzle-kit`，
但如有必要（例如在 CI/CD 流水线等中），你也可以通过 CLI 提供所有配置选项。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。可以是 <Dialects/> 之一 |
| `out`     |            | 迁移文件夹，默认=`./drizzle`                                         |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit check --dialect=postgresql
drizzle-kit check --dialect=postgresql --out=./migrations-folder
</Npx>
