# Drizzle HTTP 代理

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/connect-overview)
</Prerequisites>

HTTP 代理如何工作以及你可能为什么需要它

当你需要自行实现与数据库的驱动通信时，就会用到 Drizzle Proxy。
它可用于多种情况，例如在现有驱动的查询阶段添加自定义逻辑。
最常见的用法是配合 HTTP 驱动，它把查询发送到带有数据库的你的服务器，在你的数据库上执行查询，
并以原始数据响应，然后 Drizzle ORM 可以将其映射为结果

<Callout collapsed="其底层如何工作？">
```                                  
┌───────────────────────────┐                 ┌─────────────────────────────┐              
│       Drizzle ORM         │                 │  HTTP Server with Database  │             
└─┬─────────────────────────┘                 └─────────────────────────┬───┘             
  │                                                ^                    │
  │-- 1. Build query         2. Send built query --│                    │
  │                                                │                    │
  │              ┌───────────────────────────┐     │                    │
  └─────────────>│                           │─────┘                    │ 
                 │      HTTP Proxy Driver    │                          │
  ┌──────────────│                           │<─────────────┬───────────┘
  │              └───────────────────────────┘              │
  │                                                  3. Execute a query + send raw results back
  │-- 4. Map data and return        
  │                   
  v
```
</Callout>

Drizzle ORM 也支持简单地使用异步回调函数来执行 SQL。

- `sql` 是带有占位符的查询字符串。
- `params` 是参数数组。
- 根据 SQL 语句，会为 `method` 设置以下值之一 - `all`、`execute`。

Drizzle 始终会等待 `{rows: string[][]}` 或 `{rows: string[]}` 作为返回值。

- 当 `method` 为 `execute` 时，你应返回 `{rows: string[]}` 形式的值。
- 否则，你应返回 `{rows: string[][]}`。

<br/>

<Section>
```typescript copy
// 驱动实现示例
import { drizzle } from 'drizzle-orm/pg-proxy';
import axios from "axios";

const db = drizzle(async (sql, params, method) => {
  try {
    const rows = await axios.post('http://localhost:3000/query', { sql, params, method });

    return { rows: rows.data };
  } catch (e: any) {
    console.error('Error from pg proxy server: ', e.response.data)
    return { rows: [] };
  }
});
```
```ts
// 服务端实现示例
import { Client } from 'pg';
import express from 'express';

const app = express();

app.use(express.json());
const port = 3000;

const client = new Client('postgres://postgres:postgres@localhost:5432/postgres');

app.post('/query', async (req, res) => {
  const { sql, params, method } = req.body;

  // 防止多个查询
  const sqlBody = sql.replace(/;/g, '');

  try {
    const result = await client.query({
      text: sqlBody,
      values: params,
      rowMode: method === 'all' ? 'array': undefined,
    });
    res.send(result.rows);
  } catch (e: any) {
    res.status(500).json({ error: e });
  }

  res.status(500).json({ error: 'Unknown method value' });
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```
