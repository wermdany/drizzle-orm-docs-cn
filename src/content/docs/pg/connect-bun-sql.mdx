# Drizzle \<\> Bun SQL

<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/connect-overview)
- Bun - [网站](https://bun.sh/docs)
- Bun SQL - 用于操作 PostgreSQL 数据库的原生绑定 - [在此阅读](https://bun.sh/docs/api/sql)
</Prerequisites>

根据 **[官方网站](https://bun.sh/)**，Bun 是一个快速的、一体化的 JavaScript 运行时。

Drizzle ORM 原生支持 **[`bun sql`](https://bun.sh/docs/api/sql)** 模块，而且快得惊人 🚀  

#### 第 1 步 - 安装依赖包
<Npm>
 drizzle-orm@rc
 -D drizzle-kit@rc
</Npm>

#### 第 2 步 - 初始化驱动并发起查询
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/bun-sql';

const db = drizzle(process.env.DATABASE_URL);

const result = await db.select().from(...);
```

如果你需要提供自己已有的驱动：
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/bun-sql';
import { SQL } from 'bun';

const client = new SQL(process.env.DATABASE_URL!);
const db = drizzle({ client });
```
