# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [阅读此处](/docs/get-started)
- Drizzle schema 基础 - [阅读此处](/docs/sql-schema-declaration)
- 数据库连接基础 - [阅读此处](/docs/connect-overview)
- Drizzle 迁移基础 - [阅读此处](/docs/migrations)
</Prerequisites>


**Drizzle Kit** 是一个用于配合 Drizzle 管理 SQL 数据库迁移的 CLI 工具。
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
请务必先阅读 Drizzle 的[快速开始](/docs/get-started)和[迁移基础](/docs/migrations)，并选择最适合你业务需求的 SQL 迁移流程。 
</Callout>

基于你的 schema，Drizzle Kit 让你能够生成并运行 SQL 迁移文件、
将 schema 直接推送到数据库、从数据库拉取 schema、启动 drizzle studio，并包含几个实用命令。
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
drizzle-kit export
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/drizzle-kit-generate) | 让你基于 Drizzle schema 在声明时或后续变更时生成 SQL 迁移文件，[参见此处](/docs/drizzle-kit-generate)。       |
| [`drizzle-kit migrate`](/docs/drizzle-kit-migrate)   | 让你将生成的 SQL 迁移文件应用到数据库，[参见此处](/docs/drizzle-kit-migrate)。                                                              |
| [`drizzle-kit pull`](/docs/drizzle-kit-pull)         | 让你拉取（introspect）数据库 schema，将其转换为 Drizzle schema 并保存到你的代码库中，[参见此处](/docs/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/drizzle-kit-push)         | 让你在声明时或后续 schema 变更时将 Drizzle schema 推送到数据库，[参见此处](/docs/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/drizzle-kit-studio)     | 会连接到你的数据库并为 Drizzle Studio 启动代理服务器，你可以用它方便地浏览数据库，[参见此处](/docs/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/drizzle-kit-check)       | 会遍历所有已生成的迁移并检查生成迁移之间是否存在任何竞态条件（冲突），[参见此处](/docs/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/drizzle-kit-up)             | 用于升级先前生成的迁移的快照，[参见此处](/docs/drizzle-kit-up)                                                                     |
| [`drizzle-kit export`](/docs/drizzle-kit-export)     | 用于将 TypeScript schema 转换为原生 SQL DDL 并打印出来 [参见此处](/docs/drizzle-kit-export)                                                                     |
<br/>

Drizzle Kit 通过 [drizzle.config.ts](/docs/drizzle-config-file) 配置文件或 CLI 参数进行配置。<br/>
至少需要提供 SQL `dialect` 和 `schema` 路径，Drizzle Kit 才知道如何生成迁移。
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle 配置文件
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["简单配置", "扩展配置"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "postgresql",
  schema: "./schema.ts",

  entities: {
    roles: {
      exclude: ["admin"],
      include: ["user"],
      provider: "supabase",
    },
  },

  driver: "pglite",
  dbCredentials: {
    url: "./database/",
  },

  extensionsFilters: ["postgis"],
  schemaFilter: "public",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
    schema: "public",
  },

  breakpoints: true,
  verbose: true,
});
```
</CodeTabs>

你可以通过 CLI 参数提供 Drizzle Kit 配置路径，当你有多个数据库阶段、多个数据库，或同一项目上有不同数据库时，这非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
