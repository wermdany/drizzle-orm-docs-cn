# Drizzle \<\> Neon Postgres
<Prerequisites>
- 使用 Drizzle 的数据库[连接基础](/docs/connect-overview)
- Neon serverless 数据库 - [网站](https://neon.tech)
- Neon serverless 驱动 - [文档](https://neon.tech/docs/serverless/serverless-driver) 和 [GitHub](https://github.com/neondatabase/serverless)
- Drizzle PostgreSQL 驱动 - [文档](/docs/get-started-postgresql)
</Prerequisites>

Drizzle 通过 `neon-http` 和 `neon-websockets` 驱动原生支持 Neon 连接。它们在底层使用 **neon-serverless** 驱动。  
  
使用 `neon-http` 和 `neon-websockets` 驱动，你可以在 serverless 环境中通过 HTTP 或 WebSockets 而非 TCP 访问 Neon 数据库。  
对于单个、非交互式事务，通过 HTTP 查询更快。  
  
如果你需要会话或交互式事务支持，或需要 `pg` 驱动的完全兼容的即插即用替代品，可以使用基于 WebSocket 的 `neon-serverless` 驱动。  
你可以直接使用 [Postgres](/docs/get-started/postgresql-new) 连接到 Neon 数据库
  
关于在 Cloudflare Worker 中使用 Drizzle ORM 搭配 Neon Serverless 驱动的示例，**[请见此处。](http://driz.link/neon-cf-ex)**  
若要在有服务器的环境中使用 Neon，可以使用 node-postgres 或 Postgres.js 驱动，如 Neon 的 **[官方 Node.js 文档](https://neon.tech/docs/guides/node)** 所述

#### 第 2 步 - 初始化驱动并发起查询
<CodeTabs items={["Neon HTTP", "Neon Websockets", "node-postgres", "postgres.js"]}>
```typescript
// 确保安装 '@neondatabase/serverless' 包 
import { drizzle } from 'drizzle-orm/neon-http';

const db = drizzle(process.env.DATABASE_URL);

const result = await db.execute('select 1');
```
<Section> 
```typescript 
// 确保安装 '@neondatabase/serverless' 包 
import { drizzle } from 'drizzle-orm/neon-serverless';

const db = drizzle(process.env.DATABASE_URL);

const result = await db.execute('select 1');
```
```typescript
// 对于 Node.js - 确保安装 'ws' 和 'bufferutil' 包
import { drizzle } from 'drizzle-orm/neon-serverless';
import ws from 'ws';

const db = drizzle({
  connection: process.env.DATABASE_URL,
  ws: ws,
});

const result = await db.execute('select 1');
```
<Callout type="warning" emoji="⚙️"> 
在未定义 `WebSocket` 全局对象的环境（如 Node.js）中使用 WebSockets 需要额外配置。
将 `ws` 和 `bufferutil` 包添加到项目依赖中，并在 Drizzle config 中设置 `ws`。
</Callout>
</Section>

如果你需要提供自己已有的驱动：

<CodeTabs items={["Neon HTTP", "Neon Websockets", "node-postgres", "postgres.js"]}>
```typescript
// 确保安装 '@neondatabase/serverless' 包 
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';

const sql = neon(process.env.DATABASE_URL!);
const db = drizzle({ client: sql });

const result = await db.execute('select 1');
```
