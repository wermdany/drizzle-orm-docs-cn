# typebox

#### 安装依赖
<Npm>
drizzle-orm@rc typebox
</Npm>

允许你从 Drizzle ORM schema 生成 [typebox](https://sinclairzx81.github.io/typebox/#/) schema

**Features**

- 为表、视图和 enum 创建 select schema。
- 为表创建 insert 和 update schema。
- 支持的方言：CockroachDB、MSSQL、MySQL、PostgreSQL、SingleStore、SQLite。

#### 用法

```ts
import { pgEnum, pgTable, serial, text, timestamp } from 'drizzle-orm/pg-core';
import { createInsertSchema, createSelectSchema, createUpdateSchema } from 'drizzle-orm/typebox';
import { Type } from 'typebox';
import { Value } from 'typebox/value';

const users = pgTable('users', {
	id: serial('id').primaryKey(),
	name: text('name').notNull(),
	email: text('email').notNull(),
	role: text('role', { enum: ['admin', 'user'] }).notNull(),
	createdAt: timestamp('created_at').notNull().defaultNow(),
});

// 用于插入用户的 schema —— 可用于校验 API 请求
const insertUserSchema = createInsertSchema(users);

// 用于更新用户的 schema —— 可用于校验 API 请求
const updateUserSchema = createUpdateSchema(users);

// 用于查询用户的 schema —— 可用于校验 API 响应
const selectUserSchema = createSelectSchema(users);

// 覆盖字段
const insertUserSchema = createInsertSchema(users, {
	role: Type.String(),
});

// 精化字段 —— 如果你想在字段于最终 schema 中变为可空/可选之前修改它们，这很有用
const insertUserSchema = createInsertSchema(users, {
	id: (schema) => Type.Number({ ...schema, minimum: 0 }),
	role: Type.String(),
});

// 用法

const isUserValid: boolean = Value.Check(insertUserSchema, {
	name: 'John Doe',
	email: 'johndoe@test.com',
	role: 'admin',
});
```
