# Drizzle 可持续发展

我们从 2021 年起就在构建 Drizzle，尽管项目经历了几次演进（以及情绪崩溃），
其核心理念与愿景从未改变。

这些年来，我们获得了 100+ 位赞助者，从优秀的个人到支持我们工作的杰出公司

截至 2026 年 3 月，PlanetScale 招募了整个 Drizzle 核心团队，成为我们最大的支持者！

他们招募了整个团队，这样我们就能全职继续投入 Drizzle，持续推动路线图，
交付更多改进，并继续打造我们一直想带给社区的所有雄心勃勃的东西。

在与 PlanetScale 团队和 Sam Lambert 进行了许多很棒的交流后，我们得出了同一个结论：
让 Drizzle 成为地球上最可持续的 ORM 的最佳方式，就是联手。

所以现在，PlanetScale 是我们最大的赞助者，他们招募了我们，而我们得以继续做我们热爱的事：

- 为社区而构建，
- 痴迷于 DX，
- 并让 SQL 和数据库变得非常有趣且易于上手

## 收入流

Drizzle 不只是 `drizzle-orm` 这个仓库，我们还构建并变现了一系列不同的产品

#### Drizzle Studio

Drizzle Studio 是一款基于 Web 的现代数据库浏览器，它有如下几种形态：

1. [用于本地开发的 Drizzle Studio](https://orm.drizzle.team/drizzle-studio/overview)，适用于你的 Drizzle ORM 项目
2. [Drizzle Studio Chrome 扩展](https://driz.link/extension)，让你可以直接在 PlanetScale、Cloudflare D1、Vercel Postgres 和 AWS Data API 的原生控制台中浏览它们
3. [Drizzle Studio Gateway](https://gateway.drizzle.team) 是强化版的 Studio 可部署 Docker 化版本，你可以把它放进自己的基础设施中，并私密地连接到你的数据库
4. `Drizzle Studio embeddable Component` - 是 Drizzle Studio 预打包的、与框架无关的 Web 组件，你可以把它嵌入到你的 UI 中（React/Vue/Svelte/VanillaJS/随便什么）

#### OneDollarStats

和我们发布的所有东西一样，分析工具最初是我们为自己在不同商业项目中使用的产品。
我们找到了一种方法，让它如此实惠，并将其带给社区，这样你就不必在网站分析上花很多钱。

我们目前定价为每月 1 美元、无限制，很快我们将推出基于用量的定价

## Drizzle LLC

Drizzle 是一家总部位于乌克兰的法律实体。
除了 5 位 Drizzle 核心团队成员外，还有 18 位开发者与我们合作，通过外包和咨询参与各种生产级应用。

这实际上在两个重要方面帮助我们构建 Drizzle。

- 首先，它为我们带来了另一个收入来源，这意味着我们可以持续把资金再投入到开源工作中，测试新想法，推动 Drizzle 前进。
- 其次，它给了我们大量真实世界的经验。我们参与各种类型的项目（Web、移动、桌面等），涉及不同语言，尤其侧重 TypeScript。
  这也意味着我们能获得关于大量框架、托管平台以及人们构建和发布产品的不同方式的实战经验。

Drizzle 之所以能有今天的样子，一个重要原因是我们从不把自己局限于只做一件事。我们不断
参与不同类型的项目，这给了我们新想法、更广阔的视角，以及那种帮助我们
以如今这种方式构建 Drizzle 的经验
