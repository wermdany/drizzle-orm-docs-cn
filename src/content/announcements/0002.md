**我们重新设计了 SQL 控制台中的 schema 查看器 ⚙️**
<br/>
<br/>
现在 schema 位于右侧面板，为你提供快速浏览数据库结构所需的一切。
你可以展开特定的表或一次性展开全部表，并隐藏不需要的表。
行数、可空性和默认值会根据你的设置显示。
我们花了相当多时间让它适配不同大小的面板——希望你喜欢！
